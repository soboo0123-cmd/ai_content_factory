# AI 콘텐츠 집필 지침 (v1.0)

## 1. 기본 원칙
- **교과서식 서술:** 개념부터 탄탄하게 설명하며, 독자가 배경지식 없이도 이해할 수 있도록 합니다.
- **자세한 설명:** 요약보다는 원리와 이유를 상세히 풀어서 씁니다.
- **시각화 고려:** 추후 HTML/JS로 시각화할 요소를 미리 마크다운 주석이나 텍스트로 명시합니다 (예: `[시각화: 슬라이더로 변수 값 변경 시각화]`).

## 2. 구성 요소
- **도입:** 주제의 중요성과 학습 목표 제시.
- **본론:** 단계별 개념 설명, 코드 예제, 시각적 비유.
- **요약:** 핵심 포인트 정리.

## 3. 마크다운 규칙
- 제목은 `#` 단계를 적절히 사용.
- 코드는 언어별 코드 블록(```python) 사용.
- 수식은 LaTeX 형식(`$ ... $`) 사용 권장.

## 4. 버전별 집필 전략
- **v1 (초안):** 지침에 따라 충실하게 기본 내용 작성.
- **v2 (재집필):** v1을 보지 않고 목차 제목만 보고 새로운 관점이나 설명 방식으로 작성.
- **v3 (통합):** v1, v2의 장점을 합치고 사용자 피드백을 반영하여 최종본 도출.

## 5. 피드백 반영 및 지침 업데이트
- v3 작성 시 발생한 새로운 규칙이나 팁은 즉시 이 지침 파일의 '업데이트 이력' 섹션에 추가합니다.


## 6. 누적된 집필 노하우 (자동 업데이트)
- [2026-05-23] 단순한 개념 정의보다 '직접 나열했을 때 발견되는 반복되는 묶음(패턴)'을 먼저 보여주면, 추상적인 곱의 법칙과 수식을 독자가 훨씬 직관적으로 받아들일 수 있습니다.
- [2026-05-24] 새롭거나 추상적인 수학적 개념(예: 로그수익률)을 독자에게 설득할 때는 공식의 직접 유도(연속복리 극한)뿐만 아니라, **독자가 이미 잘 알고 있는 기존 개념(예: 일반 주식 수익률)과 등치 관계를 맺어 동치임을 보여주는 두 번째 유도 경로를 제공할 때** 인지적 공백이 가장 부드럽게 메워집니다.
- [2026-05-24] 수학적 정의나 유도 공식을 제시할 때, 그 공식이 지닌 물리적 범위(예: 부등식)와 상호보완적 짝(예: $1-p$)의 성질을 함께 증명해주면, 독자는 수식을 단순 암기 대상이 아닌 완결성 있는 하나의 '확률계(Probability System)'로 입체적으로 이해하게 됩니다.
- [2026-05-24] 독자가 직관적으로 이해하기 어려운 가상의 수학적 도구(위험중립확률)를 설명할 때는, 현실의 주관성(위험 프리미엄)이 어떻게 수학적 장치(복제 포트폴리오의 헷징)를 통해 완벽히 소거되어 '객관적 상수'로 변환되는지의 논리적 필연성을 대조하여 보여줄 때 가장 강력한 설득력을 얻습니다.
- [2026-05-24] 추상적인 수학 함수(예: $\max$ 함수)나 금융 공식을 정의하기 전, 변수에 따른 결과값의 구체적인 수치 패턴을 표나 리스트로 먼저 나열해 주면 독자가 수식의 필요성과 구조를 스스로 유도하듯 직관적으로 납득하게 됩니다.

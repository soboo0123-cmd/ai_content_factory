# AI 콘텐츠 집필 지침 (v1.0)

## 1. 기본 원칙
- **교과서식 서술:** 개념부터 탄탄하게 설명하며, 독자가 배경지식 없이도 이해할 수 있도록 합니다.
- **자세한 설명:** 요약보다는 원리와 이유를 상세히 풀어서 씁니다.
- **시각화 고려:** 추후 HTML/JS로 시각화할 요소를 미리 마크다운 주석이나 텍스트로 명시합니다 (예: `[시각화: 슬라이더로 변수 값 변경 시각화]`).

## 2. 구성 요소
- **도입:** 주제의 중요성과 학습 목표 제시.
- **본론:** 단계별 개념 설명, 코드 예제, 시각적 비유.
- **요약:** 핵심 포인트 정리.

## 3. 마크다운 규칙
- 제목은 `#` 단계를 적절히 사용.
- 코드는 언어별 코드 블록(```python) 사용.
- 수식은 LaTeX 형식(`$ ... $`) 사용 권장.

## 4. 버전별 집필 전략
- **v1 (초안):** 지침에 따라 충실하게 기본 내용 작성.
- **v2 (재집필):** v1을 보지 않고 목차 제목만 보고 새로운 관점이나 설명 방식으로 작성.
- **v3 (통합):** v1, v2의 장점을 합치고 사용자 피드백을 반영하여 최종본 도출.

## 5. 피드백 반영 및 지침 업데이트
- v3 작성 시 발생한 새로운 규칙이나 팁은 즉시 이 지침 파일의 '업데이트 이력' 섹션에 추가합니다.


## 6. 누적된 집필 노하우 (자동 업데이트)
- 수치 패턴 먼저, 공식 나중 : 추상보다 구체가 먼저다
    - 새 공식·함수·연산자를 정의하기 전, 구체적 수치를 표나 리스트로 먼저 나열해 독자가 규칙성을 스스로 체감하게 합니다.
    - 나눗셈·분모 같은 연산자는 단순 계산 편의가 아닌 "무의미한 움직임을 지우는 소거 장치"처럼 물리적 의미로 번역하여 전달합니다.
    - 이산에서 연속으로의 수렴을 설명할 때는 극한 공식을 제시하기 전에 n 단계별 점진적 수치 스케일 표를 먼저 배치합니다.
- 친숙한 개념에서 낯선 개념으로 연결 : 인지적 거부감을 최소화하는 도입 경로
    - 새 개념(로그수익률, $e^{-rt}$ 등)을 소개할 때 독자가 이미 아는 기존 개념(단리·이산복리)의 극한 또는 동치 관계로 유도합니다.
    - 첫 유도에 이어 두 번째 유도 경로(등치 증명)를 추가 제공하면 인지적 공백이 더 부드럽게 메워집니다.
    - 테일러 근사 등 고차 공식은 이전 절의 수치 파라미터를 그대로 재대입해 근사오차가 0에 수렴함을 직접 보여줍니다.
- 실패 사례 → 성공 사례 대조 : 수식의 필연성을 가장 강력하게 전달하는 구조
    - 잘못된 포트폴리오의 손익 불일치 표를 먼저 보여준 뒤, 정밀 복제 포트폴리오의 결과를 대조하여 보여줍니다.
    - 균형 수식($C = \Delta S - B$ 등)은 불균형 상태의 매수/매도 피드백 루프 시나리오를 구체적 숫자로 대조해 '자연법칙'임을 납득시킵니다.
    - 공식의 핵심 전제(독립성 등)를 제거했을 때 값이 폭발하는 반례 표를 제시하면 전제의 필연성이 입체적으로 전달됩니다.
- 동일 수치 시나리오를 일관되게 재소환 : 독자의 인지적 맥락을 붙잡는 장치
    - 이전 절에서 쓴 구체적 수치($n, K, q$ 값 등)를 다음 절 도입부에 그대로 재대입해 새 공식의 타당성을 즉각 교차 검증하게 합니다.
    - 미시적 개별 경로(확률 트리)를 표로 먼저 전개한 뒤, 교환법칙으로 거시적 상태(조합)로 병합하는 과정을 점진적으로 보여줍니다.
    - 추상적 수식(예: 최종 가치 0 수렴)은 초기 마진 취득 $\leftrightarrow$ 만기 방어의 타임라인 대조로 직관적 오해를 즉시 차단합니다.
- 대칭·완결성·범위를 함께 증명 : 공식을 하나의 완결된 시스템으로 이해시키기
    - 공식 제시 후 변수의 물리적 범위($0 \le \Delta \le 1$)와 부호의 경제적 의미($B < 0$ 차입)를 현실 메커니즘과 연계해 증명합니다.
    - 두 확률 공간(실제 측도 vs 위험중립 측도)처럼 추상적 변환은 형식적 동질성과 중심축 평행 이동만 다른 대조표로 대칭 필연성을 보여줍니다.
    - 재귀 관계식은 최종 전개식까지 펼쳐 이항정리 계수와 확률합 = 1의 완결성을 독자가 직접 확인하게 합니다.

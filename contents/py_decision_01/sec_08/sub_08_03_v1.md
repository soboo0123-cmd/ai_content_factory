# 8.3 동시진행의 반복게임 (Simultaneous Repeated Games)

## 도입: 단판 승부와 계속되는 인연의 차이

우리는 앞에서 '죄수의 딜레마'와 같은 **동시진행 게임(Simultaneous Game)**을 살펴보았습니다. 단 한 번의 선택으로 결과가 결정되는 단판 게임에서, 합리적인 행위자들은 서로를 배신하여 최악의 결과를 초래하는 '내쉬 균형'에 도달하곤 합니다.

하지만 현실의 의사결정은 단 한 번으로 끝나지 않는 경우가 훨씬 많습니다. 비즈니스 파트너와의 거래, 친구와의 관계, 국가 간의 외교는 오늘 한 번의 선택으로 끝나는 것이 아니라 내일도, 모레도 계속됩니다. 이렇게 동일한 게임이 여러 번 반복되는 상황을 **반복게임(Repeated Game)**이라고 합니다.

이번 섹션에서는 게임이 반복될 때 사람들의 전략이 어떻게 변하는지, 그리고 왜 반복이 '협력'을 이끌어내는 강력한 도구가 되는지 학습합니다.

---

## 1. 반복게임의 핵심 개념

### 1.1 유한 반복과 무한 반복
반복게임은 게임이 끝나는 시점이 정해져 있느냐에 따라 성격이 완전히 달라집니다.

1.  **유한 반복게임(Finitely Repeated Games):** 게임이 정확히 $N$번 반복된다는 것을 양측이 모두 알고 있는 경우입니다. 이 경우 '역진 귀납법(Backward Induction)'에 의해 마지막 회차부터 분석하게 되는데, 결국 첫 회차부터 배신이 일어날 가능성이 큽니다.
2.  **무한 반복게임(Infinitely Repeated Games):** 게임이 언제 끝날지 모르거나, 다음 라운드가 존재할 확률이 항상 있는 경우입니다. 이때 비로소 상대방의 보복이 무서워 협력을 유지하는 **'미래의 그림자(Shadow of the Future)'** 효과가 나타납니다.

### 1.2 할인 인자 (Discount Factor, $\delta$)
우리는 오늘 당장 얻는 100만 원과 10년 뒤에 얻는 100만 원의 가치를 다르게 평가합니다. 반복게임에서도 미래의 보상(Payoff)은 현재 시점에서 일정한 비율로 할인됩니다.

-   **$\delta$ (델타):** 미래 가치를 현재 가치로 환산하는 비율 ($0 \le \delta \le 1$).
-   $\delta$가 1에 가까울수록 미래를 중요하게 생각하는 것이며, 0에 가까울수록 현재의 이익에만 집착하는 것입니다.

총 보상의 현재 가치($V$)는 다음과 같이 계산됩니다.
$$V = \pi_0 + \delta \pi_1 + \delta^2 \pi_2 + \dots = \sum_{t=0}^{\infty} \delta^t \pi_t$$

## 2. 반복게임에서의 주요 전략

단판 게임에서는 '협력(C)' 또는 '배신(D)'이라는 선택지뿐이었지만, 반복게임에서는 상대의 과거 행동에 대응하는 다양한 **전략(Strategy)**이 등장합니다.

### 2.1 냉혹한 트리거 전략 (Grim Trigger Strategy)
가장 단호한 전략입니다. 
-   처음에는 협력합니다.
-   상대방이 한 번이라도 배신하면, 나는 **영원히** 배신합니다.
-   상대에게 "한 번이라도 실수하면 끝이다"라는 강력한 경고를 주어 협력을 유도합니다.

### 2.2 팃포탯 전략 (Tit-for-Tat, TFT)
눈에는 눈, 이에는 이 전략입니다. 로버트 액셀로드의 토너먼트에서 우승하며 유명해졌습니다.
1.  첫 번째 라운드에서는 협력합니다.
2.  그다음 라운드부터는 **상대방이 직전 라운드에 했던 행동을 그대로 따라 합니다.**
-   상대가 협력하면 나도 협력하고, 상대가 배신하면 나도 응징합니다. 하지만 상대가 다시 협력으로 돌아오면 즉시 용서하고 협력합니다.

`[시각화: 전략별 흐름도 - Grim Trigger는 배신 발생 시 영구적 상태 변화, TFT는 직전 상태를 복사하는 피드백 루프 구조]`

## 3. 파이썬으로 구현하는 반복게임 시뮬레이션

두 플레이어가 20회 동안 '죄수의 딜레마' 게임을 반복할 때, 서로 다른 전략이 맞붙으면 어떤 결과가 나오는지 파이썬으로 확인해 보겠습니다.

```python
import pandas as pd

# 보상 행렬 정의 (협력: C, 배신: D)
# (Player 1 보상, Player 2 보상)
PAYOFF = {
    ('C', 'C'): (3, 3),
    ('C', 'D'): (0, 5),
    ('D', 'C'): (5, 0),
    ('D', 'D'): (1, 1)
}

class Player:
    def __init__(self, strategy_name):
        self.strategy_name = strategy_name
        self.history = []  # 자신의 과거 기록
        self.opponent_history = [] # 상대의 과거 기록

    def make_move(self):
        if self.strategy_name == "Always_C": # 항상 협력
            return 'C'
        
        if self.strategy_name == "Always_D": # 항상 배신
            return 'D'
        
        if self.strategy_name == "Tit_for_Tat": # 팃포탯
            if not self.opponent_history:
                return 'C'
            return self.opponent_history[-1]
        
        if self.strategy_name == "Grim_Trigger": # 냉혹한 트리거
            if 'D' in self.opponent_history:
                return 'D'
            return 'C'
        
        return 'C'

def play_repeated_game(p1_strat, p2_strat, rounds=20):
    p1 = Player(p1_strat)
    p2 = Player(p2_strat)
    results = []

    for r in range(rounds):
        move1 = p1.make_move()
        move2 = p2.make_move()
        
        score1, score2 = PAYOFF[(move1, move2)]
        
        # 기록 업데이트
        p1.history.append(move1)
        p1.opponent_history.append(move2)
        p2.history.append(move2)
        p2.opponent_history.append(move1)
        
        results.append({
            'Round': r + 1,
            'P1_Move': move1,
            'P2_Move': move2,
            'P1_Score': score1,
            'P2_Score': score2
        })
        
    return pd.DataFrame(results)

# 시뮬레이션 실행: 팃포탯 vs 항상 배신
df = play_repeated_game("Tit_for_Tat", "Always_D", rounds=10)
print(df)
```

`[시각화: 라운드별 누적 점수 변화를 보여주는 선 그래프. 팃포탯이 초반엔 밀리지만 상대를 응징하며 피해를 최소화하는 모습 강조]`

## 요약 및 핵심 포인트

1.  **반복의 힘:** 단판 게임에서는 배신이 유리할 수 있지만, 게임이 반복되면 미래의 보상을 지키기 위해 현재의 이익(배신)을 포기하고 **협력**을 선택하는 것이 합리적이 됩니다.
2.  **미래의 가치:** 할인 인자($\delta$)가 충분히 클 때(즉, 미래가 중요할 때) 협력의 균형이 유지될 수 있습니다. 이를 게임이론에서는 **민속 정리(Folk Theorem)**라고 부릅니다.
3.  **성공적인 전략의 조건:** 로버트 액셀로드는 팃포탯의 성공 비결로 **신사적(먼저 배신 안 함), 응징(배신에 대응함), 용서(상대가 돌아오면 즉시 협력), 명료함(상대가 의도를 알기 쉬움)**을 꼽았습니다.

반복되는 의사결정 구조를 이해하면, 왜 우리가 평판을 관리하고 신뢰를 쌓아야 하는지를 수학적/논리적으로 이해할 수 있습니다. 다음 섹션에서는 정보가 불균형한 상황에서의 게임이론에 대해 알아보겠습니다.

# 8.2 동시진행의 1회성 게임 (Simultaneous One-Shot Games)

## 1. 도입: 혼자가 아닌 결정의 시작
우리는 지금까지 의사결정자가 외부 환경의 불확실성(확률)에 대응하여 최선의 선택을 내리는 방법을 배웠습니다. 하지만 현실의 많은 문제는 나 혼자 결정한다고 끝나는 것이 아닙니다. 나의 이득이 상대방의 선택에 의해 결정되고, 상대방의 이득 또한 나의 선택에 좌우되는 상황이 빈번합니다.

이러한 상호 의존적인 상황을 연구하는 학문이 **게임 이론(Game Theory)**입니다. 그중에서도 **'동시진행의 1회성 게임'**은 상대방이 어떤 선택을 할지 모르는 상태에서 단 한 번의 결정을 내려야 하는 가장 기초적이면서도 강력한 분석 틀을 제공합니다.

### 학습 목표
- 동시진행 게임의 정의와 구성 요소를 이해합니다.
- 보상 행렬(Payoff Matrix)을 작성하고 읽는 법을 익힙니다.
- 죄수의 딜레마를 통해 개인의 합리성이 전체의 불합리성을 초래하는 원리를 파악합니다.
- 파이썬을 활용해 게임의 결과를 계산하는 방법을 실습합니다.

---

## 2. 본론: 게임의 규칙과 표현

### 2.1 게임의 3요소
어떤 상황을 '게임'으로 정의하기 위해서는 다음 세 가지 요소가 반드시 필요합니다.

1.  **의사결정자 (Players):** 게임에 참여하여 선택을 내리는 주체입니다. (예: 기업 A, 기업 B)
2.  **전략 (Strategies):** 각 플레이어가 선택할 수 있는 모든 행동의 집합입니다. (예: 가격 인상, 가격 인하)
3.  **보상 (Payoffs):** 각 플레이어의 전략 조합에 따라 얻게 되는 결과물(이익 또는 손실)입니다.

### 2.2 전략형 게임과 보상 행렬
'동시진행'이란 플레이어들이 서로의 선택을 모르는 상태에서 동시에 의사결정을 내리는 것을 의미합니다. 이를 표현하기 가장 좋은 방법이 바로 **보상 행렬(Payoff Matrix)**입니다.

보상 행렬은 행(Row)에는 플레이어 1의 전략을, 열(Column)에는 플레이어 2의 전략을 배치하고, 각 칸에 두 플레이어가 얻게 될 보상을 $(P1의 보상, P2의 보상)$ 형태로 적습니다.

`[시각화: 2x2 보상 행렬 표. 마우스를 올리면 각 숫자가 의미하는 플레이어의 보상을 강조하는 효과]`

---

### 2.3 클래식 모델: 죄수의 딜레마 (Prisoner's Dilemma)
동시진행 게임을 이해하는 데 가장 유명한 사례는 '죄수의 딜레마'입니다.

**상황 설명:**
두 명의 범죄 피의자가 격리된 취조실에서 조사를 받고 있습니다. 검사는 각자에게 다음과 같은 제안을 합니다.
- 둘 다 침묵(협력)하면, 각각 1년형을 삽니다.
- 한 명은 자백(배신)하고 다른 명은 침묵하면, 자백한 사람은 석방되고 침묵한 사람은 10년형을 삽니다.
- 둘 다 자백(배신)하면, 각각 5년형을 삽니다.

이 상황을 보상 행렬(보상은 형량의 음수값으로 표현)로 나타내면 다음과 같습니다.

| 플레이어 1 \ 2 | 침묵 (협력) | 자백 (배신) |
| :--- | :---: | :---: |
| **침묵 (협력)** | (-1, -1) | (-10, 0) |
| **자백 (배신)** | (0, -10) | (-5, -5) |

**분석:**
플레이어 1의 입장에서 생각해 봅시다.
- 상대방이 침묵할 것 같다면? 내가 자백하는 것($0$)이 침묵하는 것($-1$)보다 낫습니다.
- 상대방이 자백할 것 같다면? 내가 자백하는 것($-5$)이 침묵하는 것($-10$)보다 낫습니다.

결국, 상대방이 무엇을 하든 나는 **'자백'**하는 것이 유리합니다. 이를 **우월 전략(Dominant Strategy)**이라고 합니다. 양쪽 모두 우월 전략을 선택한 결과인 $(-5, -5)$는 둘 다 침묵했을 때의 결과인 $(-1, -1)$보다 훨씬 나쁩니다.

---

### 2.4 내슈 균형 (Nash Equilibrium)
존 내슈(John Nash)가 정립한 이 개념은 게임 이론의 핵심입니다. 
> **내슈 균형:** 상대방의 전략이 주어졌을 때, 어느 플레이어도 자신의 전략을 변경함으로써 이득을 얻을 수 없는 상태.

즉, "상대방이 그 선택을 유지하는 한, 나도 지금의 선택을 바꿀 이유가 없다"고 느끼는 안정적인 상태를 말합니다. 죄수의 딜레마에서 (자백, 자백)은 내슈 균형입니다.

---

## 3. 파이썬 실습: 보상 행렬 계산기

파이썬을 사용하여 보상 행렬에서 각 플레이어의 최적 대응(Best Response)을 찾고, 균형점을 도출해 보겠습니다.

```python
import numpy as np

def find_nash_equilibrium(payoff_matrix):
    """
    2x2 게임에서 내슈 균형을 찾는 간단한 함수
    payoff_matrix: (2, 2, 2) 형태의 numpy array
    """
    p1_payoffs = payoff_matrix[:, :, 0]
    p2_payoffs = payoff_matrix[:, :, 1]
    
    # 플레이어 1의 최적 대응 (각 열에서 최대값 찾기)
    p1_best = np.zeros_like(p1_payoffs, dtype=bool)
    for col in range(p1_payoffs.shape[1]):
        max_val = np.max(p1_payoffs[:, col])
        p1_best[p1_payoffs[:, col] == max_val, col] = True
        
    # 플레이어 2의 최적 대응 (각 행에서 최대값 찾기)
    p2_best = np.zeros_like(p2_payoffs, dtype=bool)
    for row in range(p2_payoffs.shape[0]):
        max_val = np.max(p2_payoffs[row, :])
        p2_best[row, p2_payoffs[row, :] == max_val] = True
        
    # 둘 다 최적 대응인 지점이 내슈 균형
    nash_equilibria = np.argwhere(p1_best & p2_best)
    return nash_equilibria

# 죄수의 딜레마 행렬 정의
# (Row, Col, Player) -> [P1_payoff, P2_payoff]
# 0: 침묵, 1: 자백
prisoners_dilemma = np.array([
    [[-1, -1], [-10, 0]], # P1이 침묵할 때
    [[0, -10], [-5, -5]]  # P1이 자백할 때
])

equilibria = find_nash_equilibrium(prisoners_dilemma)

print("찾은 내슈 균형 인덱스:")
for eq in equilibria:
    p1_action = "침묵" if eq[0] == 0 else "자백"
    p2_action = "침묵" if eq[1] == 0 else "자백"
    print(f"({p1_action}, {p2_action})")
```

### 코드 설명
- `numpy`를 활용해 3차원 배열로 보상을 구조화했습니다.
- 플레이어 1은 상대의 선택(열)이 고정되었을 때 자신의 보상(행) 중 큰 것을 고릅니다.
- 플레이어 2는 상대의 선택(행)이 고정되었을 때 자신의 보상(열) 중 큰 것을 고릅니다.
- 두 조건이 모두 만족되는 교차점이 바로 **내슈 균형**입니다.

## 4. 요약 및 핵심 포인트

1.  **동시진행 게임**은 모든 플레이어가 상대의 결정을 모르는 상태에서 한꺼번에 선택을 내리는 상황입니다.
2.  **보상 행렬**을 통해 게임의 복잡한 구조를 한눈에 파악할 수 있습니다.
3.  **우월 전략**은 상대방이 어떤 선택을 하든 나에게 가장 유리한 단 하나의 전략입니다.
4.  **내슈 균형**은 서로가 최선의 선택을 하고 있어 더 이상 전략을 바꿀 유인이 없는 안정적인 상태입니다.
5.  **죄수의 딜레마**는 개인의 합리적 선택이 집단의 최선이 아닐 수 있음을 보여주는 게임 이론의 핵심 사례입니다.

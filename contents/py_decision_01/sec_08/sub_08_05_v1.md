# 8.5 협력게임 (Cooperative Game) - v1 초안

## 1. 도입

지난 섹션들에서 우리는 각 플레이어가 자신의 이익을 극대화하기 위해 독립적으로 행동하는 **비협력 게임(Non-cooperative Game)**에 대해 배웠습니다. 죄수의 딜레마나 내쉬 균형은 상대방의 전략을 고려하되, 결론적으로는 '각자도생'의 결과를 보여주었습니다.

하지만 현실의 의사결정 상황에서는 플레이어들이 서로 힘을 합쳐 더 큰 이익을 창출하고, 그 이익을 어떻게 나눌지 협상하는 경우가 많습니다. 이를 **협력게임(Cooperative Game)** 또는 **석탄기 게임(Coalitional Game)**이라고 합니다.

### 학습 목표
- 협력게임의 정의와 특성함수($v$)의 개념을 이해합니다.
- 전체의 이익을 공정하게 배분하는 **샤플리 가치(Shapley Value)**의 원리와 계산법을 배웁니다.
- 파이썬을 활용해 실제 협력 상황에서의 기여도를 산출해 봅니다.

---

## 2. 본론

### 2.1 협력게임의 기초: 특성함수형 게임

협력게임에서 가장 중요한 것은 "누구와 손을 잡느냐"와 "그 결과로 얼마를 얻느냐"입니다. 이를 수학적으로 표현하기 위해 **특성함수(Characteristic Function)** $v$를 사용합니다.

- **연합(Coalition, $S$):** 플레이어들의 집합 $N$의 부분집합입니다.
- **특성함수 ($v(S)$):** 연합 $S$가 결성되었을 때, 그들이 독자적으로 창출할 수 있는 총 가치(보수)를 의미합니다.

예를 들어, 세 명의 프로그래머 A, B, C가 앱을 개발한다고 가정해 봅시다.
- $v(\{A\}) = 10$, $v(\{B\}) = 10$, $v(\{C\}) = 10$ (혼자 만들면 10의 수익)
- $v(\{A, B\}) = 30$ (둘이 합치면 시너지가 발생해 30의 수익)
- $v(\{A, B, C\}) = 60$ (셋이 모두 합치면 60의 수익)

여기서 핵심 질문은 이것입니다. **"전체 수익 60을 A, B, C에게 어떻게 나누어 주어야 모두가 납득할까?"**

> [시각화: 연합별 가치 다이어그램]
> - 벤 다이어그램 형태로 각 플레이어의 단독 가치와 연합 시 발생하는 추가 가치(시너지)를 시각적으로 표현.

### 2.2 공정한 배분의 기준: 샤플리 가치 (Shapley Value)

노벨 경제학상 수상자 로이드 샤플리(Lloyd Shapley)는 협력게임에서 이익을 배분하는 가장 공정한 방법으로 **샤플리 가치**를 제안했습니다. 이 방법은 각 플레이어의 **'한계 기여도(Marginal Contribution)'**에 주목합니다.

#### 샤플리 가치의 핵심 아이디어
플레이어들이 한 명씩 방에 들어와 연합에 참여한다고 상상해 봅시다. 내가 들어오기 전의 연합 가치와 내가 들어온 후의 연합 가치의 차이가 바로 나의 '기여'입니다. 샤플리 가치는 플레이어들이 참여하는 모든 가능한 순서(순열)를 고려하여, 각 순서에서 발생하는 한계 기여도의 평균을 계산합니다.

#### 수식 이해하기
플레이어 $i$의 샤플리 가치 $\phi_i(v)$는 다음과 같습니다.
$$\phi_i(v) = \sum_{S \subseteq N \setminus \{i\}} \frac{|S|! (n - |S| - 1)!}{n!} [v(S \cup \{i\}) - v(S)]$$

- $n$: 전체 플레이어 수
- $S$: 플레이어 $i$를 제외한 연합
- $v(S \cup \{i\}) - v(S)$: 플레이어 $i$가 참여함으로써 추가된 가치 (한계 기여도)
- $\frac{|S|! (n - |S| - 1)!}{n!}$: 해당 연합이 형성될 확률적 가중치

### 2.3 파이썬으로 구현하는 샤플리 가치

이제 위에서 든 프로그래머 예제를 파이썬 코드로 구현하여 각자의 지분을 계산해 보겠습니다.

```python
import itertools
from math import factorial

def calculate_shapley(players, characteristic_function):
    n = len(players)
    shapley_values = {player: 0 for player in players}
    
    # 모든 가능한 플레이어 순열(Permutations) 생성
    all_permutations = list(itertools.permutations(players))
    num_permutations = len(all_permutations)
    
    for perm in all_permutations:
        current_coalition = set()
        current_value = 0
        
        for player in perm:
            # 플레이어 추가 전 가치
            old_value = current_value
            # 플레이어 추가 후 가치 (새로운 연합 형성)
            current_coalition.add(player)
            # 특성함수에서 현재 연합의 가치 조회 (정렬된 튜플을 키로 사용)
            current_value = characteristic_function[tuple(sorted(current_coalition))]
            
            # 한계 기여도 계산 및 누적
            marginal_contribution = current_value - old_value
            shapley_values[player] += marginal_contribution
            
    # 전체 순열 수로 나누어 평균값 계산
    for player in shapley_values:
        shapley_values[player] /= num_permutations
        
    return shapley_values

# 특성함수 정의 (Key: 연합원 튜플, Value: 가치)
# v(empty) = 0 은 기본값
v = {
    (): 0,
    ('A',): 10,
    ('B',): 10,
    ('C',): 10,
    ('A', 'B'): 30,
    ('A', 'C'): 25,
    ('B', 'C'): 25,
    ('A', 'B', 'C'): 60
}

players = ['A', 'B', 'C']
result = calculate_shapley(players, v)

print("--- 샤플리 가치 계산 결과 ---")
for player, value in result.items():
    print(f"플레이어 {player}: {value:.2f}")
```

#### 코드 설명
1. `itertools.permutations`: 플레이어들이 참여하는 모든 가능한 순서를 만듭니다 (A-B-C, A-C-B, B-A-C 등).
2. `current_value`: 플레이어가 추가될 때마다 해당 시점의 연합 가치를 특성함수에서 가져옵니다.
3. `marginal_contribution`: "내가 들어오기 전"과 "들어온 후"의 차액을 기록합니다.
4. 마지막에 총합을 순열의 개수($n!$)로 나누어 평균 기여도를 구합니다.

> [시각화: 순열별 한계 기여도 테이블]
> - 각 순열(행)에 대해 플레이어(열)가 기여한 금액을 표로 보여주고, 마지막 행에 평균값을 하이라이트.

## 3. 요약

1. **협력게임**은 플레이어들이 연합을 맺고 이익을 공유할 수 있는 상황을 다룹니다.
2. **특성함수 $v(S)$**는 특정 연합이 얻을 수 있는 최대 보상을 정의합니다.
3. **샤플리 가치**는 모든 참여 순서를 고려한 평균 한계 기여도로, 이익 배분의 공정성을 담보하는 핵심 지표입니다.
4. **파이썬**의 `itertools`를 활용하면 복잡한 수식 없이도 모든 경우의 수를 탐색하여 샤플리 가치를 쉽게 계산할 수 있습니다.

협력게임 이론은 기업 간의 이익 배분, 공동 비용 분담, 혹은 머신러닝 모델에서 각 피처(Feature)의 중요도를 산정하는 등 현대 데이터 과학에서도 활발하게 응용되고 있습니다.

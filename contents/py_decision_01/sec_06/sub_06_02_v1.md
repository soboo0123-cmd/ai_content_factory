# 6.2 최적화문제의 방법

## 도입
우리는 앞서 최적화문제가 무엇인지, 그리고 이를 선형계획법(Linear Programming)이라는 틀로 어떻게 정형화하는지 배웠습니다. 이제 수립된 모델을 실제로 어떻게 해결(Solve)할 것인가에 집중해 보겠습니다. 

최적화문제를 해결하는 방법은 크게 직관적인 이해를 돕는 **기하학적 방법**과 대규모 문제를 효율적으로 해결하는 **수리적 알고리즘(심플렉스법)**, 그리고 현대적인 **전산 도구(Python 라이브러리)** 활용으로 나뉩니다. 이 섹션에서는 각 방법의 원리를 단계별로 살펴보고, 왜 우리가 결국 파이썬과 같은 도구를 사용해야 하는지 그 필연성을 학습합니다.

---

## 본론

### 1. 기하학적 방법 (Graphical Method)
기하학적 방법은 의사결정 변수가 2개(예: $x_1, x_2$)일 때 그래프 위에 제약조건과 목적함수를 그려서 최적해를 찾는 방식입니다. 최적화의 기본 원리를 시각적으로 이해하는 데 가장 탁월합니다.

#### (1) 가능해 영역(Feasible Region)의 도출
모든 제약조건을 만족하는 $x_1$과 $x_2$의 영역을 그래프에 표시합니다. 선형계획법에서 제약조건은 직선의 방정식 형태이므로, 이 영역은 항상 직선들로 둘러싸인 **볼록 다각형(Convex Polygon)**의 형태를 띠게 됩니다.

#### (2) 등목적함수선(Isoprofit/Isocost Line)의 이동
목적함수 $z = c_1x_1 + c_2x_2$를 하나의 직선으로 가정합니다. 이 직선을 가능해 영역 안에서 평행 이동시키며 $z$값이 최대(또는 최소)가 되는 지점을 찾습니다.

#### (3) 최적해의 특징: 꼭짓점(Vertex)
선형계획법의 가장 중요한 원리 중 하나는 **'최적해는 반드시 가능해 영역의 꼭짓점(Corner Point) 중 하나에 존재한다'**는 것입니다. 이는 목적함수가 직선이기 때문에 영역의 내부보다는 경계면, 그중에서도 꺾이는 점(꼭짓점)에서 극단적인 값이 나오기 때문입니다.

`[시각화: 2차원 좌표평면에 제약조건 직선 3~4개를 그려 다각형 영역을 색칠하고, 기울기가 고정된 목적함수 직선이 위아래로 움직이며 마지막 꼭짓점을 지나는 애니메이션]`

---

### 2. 심플렉스법 (Simplex Method)
변수가 3개 이상으로 늘어나면 우리는 더 이상 그래프를 그릴 수 없습니다(3차원까지는 시각화가 가능하나 그 이상은 불가능). 이때 사용하는 수리적 알고리즘이 바로 조지 댄지그(George Dantzig)가 고안한 **심플렉스법**입니다.

#### (1) 알고리즘의 원리
심플렉스법은 앞서 언급한 "최적해는 꼭짓점에 있다"는 원리를 이용합니다. 
1. 임의의 한 꼭짓점에서 시작합니다.
2. 인접한 꼭짓점들을 살펴보고, 목적함수 값이 더 좋아지는 방향의 꼭짓점으로 이동합니다.
3. 더 이상 값이 좋아지는 인접 꼭짓점이 없을 때, 그 지점을 최적해로 확정합니다.

#### (2) 대수적 변환 (Standard Form)
심플렉스법을 적용하기 위해서는 부등식 제약조건을 등식으로 바꾸어야 합니다. 이때 **여유 변수(Slack Variable)**라는 개념이 도입됩니다. 
예를 들어, $2x_1 + x_2 \le 10$이라는 제약조건은 $2x_1 + x_2 + s_1 = 10$ ($s_1 \ge 0$)으로 변환됩니다. 여기서 $s_1$은 가용 자원 중 사용되지 않고 남은 양을 의미합니다.

### 3. 파이썬을 이용한 수치적 해결
현대의 복잡한 의사결정 문제는 변수가 수천, 수만 개에 달합니다. 이를 손으로 계산하는 것은 불가능하므로, 우리는 파이썬의 `SciPy` 라이브러리 등을 활용하여 문제를 해결합니다.

#### 파이썬 코드 예제: `scipy.optimize.linprog`

다음과 같은 간단한 최적화 문제를 풀어보겠습니다.
- **목적**: $z = 3x_1 + 2x_2$ 최대화
- **제약**:
    - $2x_1 + x_2 \le 10$
    - $x_1 + 2x_2 \le 8$
    - $x_1, x_2 \ge 0$

```python
from scipy.optimize import linprog

# 목적함수 계수 (linprog는 기본적으로 최소화를 수행하므로 최대화를 위해 마이너스 부호 사용)
c = [-3, -2]

# 제약조건 행렬 A_ub * x <= b_ub
A = [[2, 1], [1, 2]]
b = [10, 8]

# 변수 범위 (0, None)은 0 이상의 실수 의미
x0_bounds = (0, None)
x1_bounds = (0, None)

# 최적화 실행
res = linprog(c, A_ub=A, b_ub=b, bounds=[x0_bounds, x1_bounds], method='highs')

print(f"최적값: {-res.fun}") # 마이너스를 다시 붙여 최대값으로 복원
print(f"최적해: x1 = {res.x[0]}, x2 = {res.x[1]}")
```

#### 코드 설명
- `c`: 목적함수의 계수 벡터입니다. `linprog` 함수는 기본적으로 값을 최소화(Minimize)하도록 설계되어 있으므로, 최대화 문제를 풀 때는 계수에 `-1`을 곱해줍니다.
- `A_ub`, `b_ub`: 'Upper Bound'의 약자로, $\le$ 형태의 제약조건을 행렬과 벡터로 표현한 것입니다.
- `method='highs'`: 최근 가장 성능이 좋은 선형계획법 solver 알고리즘을 사용하도록 지정합니다.

---

## 요약
1. **기하학적 방법**은 변수가 적을 때 사용하며, 최적해가 가능해 영역의 **꼭짓점**에 존재한다는 시각적 통찰을 줍니다.
2. **심플렉스법**은 꼭짓점을 효율적으로 탐색하며 이동하는 대수적 알고리즘으로, 다차원 문제를 해결하는 근간이 됩니다.
3. 실제 문제 해결 시에는 **파이썬의 `linprog`**와 같은 함수를 사용하여 모델의 계수만 입력함으로써 쉽고 빠르게 최적해를 도출할 수 있습니다.

`[시각화: 수식 입력창을 만들고 사용자가 계수를 입력하면 파이썬 코드가 실행되어 그래프와 결과값이 실시간으로 업데이트되는 대시보드 구조]`

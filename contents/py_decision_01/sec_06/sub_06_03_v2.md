## 1. 도입: 왜 파이썬으로 최적화를 공부해야 하는가?

우리는 일상생활에서 매 순간 '최적화(Optimization)'를 실천하고 있습니다. "가장 적은 비용으로 최대의 만족을 얻으려면 어떤 물건을 사야 할까?", "가장 빨리 목적지에 도착하려면 어느 길로 가야 할까?"와 같은 질문들이 모두 최적화의 대상입니다.

수학적으로 **최적화**란 특정 조건(제약 조건) 아래에서 어떤 함수(목적 함수)의 값을 최대화하거나 최소화하는 변수의 값을 찾는 과정을 말합니다. 데이터 과학과 AI 분야에서 최적화는 모델의 오차를 최소화하거나 수익을 극대화하는 핵심 알고리즘으로 사용됩니다.

이 장에서는 파이썬의 대표적인 과학 계산 라이브러리인 **SciPy**를 활용하여, 복잡한 수식을 직접 풀지 않고도 컴퓨터를 이용해 정교하게 최적의 해를 찾는 방법을 학습합니다.

## 2. 본론: 최적화 문제의 구성과 해결 과정

### 2.1 최적화 문제의 3요소

모든 최적화 문제는 다음 세 가지 구성 요소로 정의됩니다.

1.  **목적 함수 (Objective Function):** 우리가 최소화하거나 최대화하려는 대상입니다. 보통 $f(x)$로 표기합니다.
2.  **결정 변수 (Decision Variables):** 결과값을 바꾸기 위해 우리가 조절할 수 있는 값들입니다 ($x_1, x_2, \dots$).
3.  **제약 조건 (Constraints):** 변수가 가질 수 있는 값의 범위나 변수 간의 관계를 규정하는 조건입니다. (예: $x > 0$, $x + y = 10$)

`[시각화: 3D 지형도 위에 공이 굴러 내려가 가장 낮은 골짜기(최솟값)에 멈추는 애니메이션. 제약 조건은 지형 위의 '출입 금지 구역'으로 표시]`

### 2.2 SciPy를 이용한 수치적 최적화

파이썬에서 최적화 문제를 풀 때 가장 널리 쓰이는 도구는 `scipy.optimize` 모듈의 `minimize()` 함수입니다. 이 함수는 우리가 목적 함수와 초기값을 전달하면, 내부적인 알고리즘(예: 경사하강법의 변형들)을 통해 최적의 해를 찾아줍니다.

#### 실전 예제: 울타리 넓이 극대화하기
어떤 농부가 20m의 울타리를 가지고 직사각형 모양의 가축 우리를 만들려고 합니다. 한쪽 면은 이미 벽으로 막혀 있어 울타리를 칠 필요가 없을 때, 가축 우리의 넓이를 최대화하는 가로($x$)와 세로($y$) 길이를 구해봅시다.

**1) 문제 정의**
- **목적:** 넓이 $f(x, y) = x \times y$ 를 최대화 (하지만 `minimize` 함수를 위해 $- (x \times y)$를 최소화하는 문제로 바꿉니다.)
- **제약 조건:** 울타리 길이 $x + 2y = 20$

**2) 파이썬 코드 구현**

```python
import numpy as np
from scipy.optimize import minimize

# 1. 목적 함수 정의 (최대화 문제이므로 마이너스를 붙여 최솟값 문제로 변환)
def objective(params):
    x, y = params
    return - (x * y)

# 2. 제약 조건 정의 (x + 2y = 20  =>  x + 2y - 20 = 0)
def constraint(params):
    x, y = params
    return x + 2*y - 20

# SciPy 형식의 제약 조건 사전(Dictionary)
cons = {'type': 'eq', 'fun': constraint}

# 3. 변수의 범위 (가로, 세로 길이는 0보다 커야 함)
bnds = ((0, None), (0, None))

# 4. 초기값 설정 (추측값)
initial_guess = [5, 5]

# 5. 최적화 실행 (SLSQP 알고리즘 사용)
solution = minimize(objective, initial_guess, method='SLSQP', bounds=bnds, constraints=cons)

x_opt, y_opt = solution.x
print(f"최적의 가로 길이: {x_opt:.2f}m")
print(f"최적의 세로 길이: {y_opt:.2f}m")
print(f"최대 넓이: {-solution.fun:.2f}m^2")
```

### 2.3 제약 조건의 종류: 등식과 부등식

최적화 문제에서 제약 조건은 크게 두 가지로 나뉩니다.

-   **등식 제약 (Equality Constraint):** $h(x) = 0$의 형태. 자원이 정확히 얼마만큼 소모되어야 한다는 조건입니다.
-   **부등식 제약 (Inequality Constraint):** $g(x) \ge 0$의 형태. 자원이 특정 수준 이내여야 하거나(예: 예산 부족), 최소한 얼마 이상이어야 한다는 조건입니다.

`[시각화: 슬라이더를 통해 울타리의 총 길이를 조절하면, 실시간으로 계산된 가로/세로 길이와 넓이 그래프가 업데이트되는 대화형 차트]`

## 3. 요약 및 핵심 포인트

1.  **최적화의 본질:** 제약 조건 안에서 목적 함수의 출력을 최적(최대/최소)으로 만드는 입력값을 찾는 과정입니다.
2.  **파이썬의 도구:** `scipy.optimize.minimize`는 비선형 최적화 문제를 해결하는 강력한 도구입니다.
3.  **문제 변환:** 대부분의 최적화 알고리즘은 최솟값을 찾도록 설계되어 있습니다. 최대화 문제를 풀 때는 목적 함수에 마이너스(`-`)를 곱해 해결합니다.
4.  **과정의 중요성:** 모델링(함수 정의) -> 제약 조건 설정 -> 알고리즘 선택 -> 결과 해석의 흐름을 이해하는 것이 중요합니다.

최적화는 단순히 수학 문제를 푸는 것이 아니라, **한정된 자원으로 최고의 효율을 내는 의사결정의 기술**입니다. 파이썬을 활용하면 수천 개의 변수가 얽힌 복잡한 비즈니스 문제도 단 몇 초 만에 해결할 수 있습니다.

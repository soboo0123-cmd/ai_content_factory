# 6.3 Python을 이용한 최적화문제 (v1 초안)

## 1. 도입: 왜 파이썬으로 최적화문제를 해결하는가?

앞선 절에서 우리는 선형계획법(Linear Programming, LP)의 수학적 원리와 심플렉스법(Simplex Method)의 매커니즘을 학습했습니다. 하지만 변수가 수십 개, 제약 조건이 수백 개에 달하는 실제 비즈니스 현장의 문제를 손으로 직접 계산하는 것은 불가능에 가깝습니다.

파이썬은 이러한 복잡한 최적화 문제를 빠르고 정확하게 해결할 수 있는 강력한 라이브러리들을 제공합니다. 이번 섹션에서는 파이썬의 대표적인 과학 계산 라이브러리인 `SciPy`를 활용하여 실제 최적화 문제를 코드로 구현하고 해를 찾는 과정을 단계별로 학습합니다. 

### 학습 목표
*   선형계획법 문제를 파이썬 코드로 변환하는 과정을 이해합니다.
*   `scipy.optimize.linprog` 함수의 사용법과 주요 파라미터를 익힙니다.
*   최적화 결과값을 해석하고 의사결정에 활용하는 방법을 배웁니다.

## 2. 본론: 파이썬을 이용한 선형계획법 실습

### 2.1 문제 설정: 제품 생산 최적화

먼저, 우리가 해결할 구체적인 시나리오를 설정해 보겠습니다. 한 가구 공장에서 의자($x_1$)와 책상($x_2$)을 생산한다고 가정합시다.

1.  **목적 함수:** 의자 하나당 20만 원, 책상 하나당 30만 원의 이익이 발생합니다. 총 이익($z$)을 최대화해야 합니다.
    *   Maximize $z = 20x_1 + 30x_2$
2.  **제약 조건:**
    *   **노동 시간:** 의자는 2시간, 책상은 1시간의 작업이 필요하며, 하루 총 가용한 노동 시간은 100시간입니다.
        *   $2x_1 + 1x_2 \le 100$
    *   **원재료:** 의자는 1단위, 책상은 2단위의 목재가 필요하며, 하루 총 공급되는 목재는 120단위입니다.
        *   $1x_1 + 2x_2 \le 120$
    *   **비음 조건:** 생산량은 0보다 크거나 같아야 합니다.
        *   $x_1 \ge 0, x_2 \ge 0$

`[시각화: x축은 의자 수, y축은 책상 수로 하는 좌표평면 위에 두 제약 조건이 만드는 다각형(가능해 영역)을 그리고, 이익 선이 이동하며 최적점에 닿는 애니메이션]`

---

### 2.2 SciPy의 `linprog` 함수 이해하기

파이썬의 `scipy.optimize.linprog`는 선형계획법 문제를 푸는 가장 기본적인 도구입니다. 이 함수를 사용할 때 주의할 점은 **기본적으로 '최솟값(Minimization)'을 찾는 방식**이라는 것입니다. 

우리의 목적은 '최대화(Maximization)'이므로, 목적 함수에 마이너스(-) 부호를 붙여 최솟값 문제로 변환하여 입력해야 합니다.

*   $Maximize \ z \equiv Minimize \ (-z)$

`linprog` 함수의 주요 인자는 다음과 같습니다:
*   `c`: 목적 함수의 계수 리스트
*   `A_ub`: 부등식 제약 조건($\le$)의 계수 행렬 (Upper Bound)
*   `b_ub`: 부등식 제약 조건의 우변 상수 리스트
*   `bounds`: 각 변수의 범위 (예: 비음 조건 $(0, None)$)

---

### 2.3 파이썬 코드 구현

이제 앞서 설정한 문제를 파이썬 코드로 작성해 보겠습니다.

```python
import numpy as np
from scipy.optimize import linprog

# 1. 목적 함수 설정 (최대화 문제이므로 계수에 -를 붙임)
# Maximize 20x1 + 30x2  =>  Minimize -20x1 - 30x2
c = [-20, -30]

# 2. 제약 조건 계수 행렬 (A_ub * x <= b_ub)
# 2x1 + 1x2 <= 100
# 1x1 + 2x2 <= 120
A = [[2, 1], 
     [1, 2]]

# 3. 제약 조건 우변 상수
b = [100, 120]

# 4. 각 변수의 범위 (x1 >= 0, x2 >= 0)
x1_bounds = (0, None)
x2_bounds = (0, None)

# 5. 최적화 실행
res = linprog(c, A_ub=A, b_ub=b, bounds=[x1_bounds, x2_bounds], method='highs')

# 6. 결과 출력
print("최적화 상태:", res.message)
print("최적 생산량: 의자 =", round(res.x[0], 2), "개, 책상 =", round(res.x[1], 2), "개")
print("최대 이익:", round(-res.fun, 2), "만 원")
```

---

### 2.4 결과의 해석

코드를 실행하면 다음과 같은 결과를 얻을 수 있습니다.

1.  **최적 해(Optimal Solution):** 의자 약 26.67개, 책상 약 46.67개를 생산할 때 이익이 극대화됩니다. (실제 공정이라면 정수 최적화가 필요하겠지만, 여기서는 선형계획법의 기본 원리에 집중합니다.)
2.  **최적값(Optimal Value):** 이때의 최대 이익은 약 1,933만 원입니다.
3.  **상태(Status):** `Optimization terminated successfully`라는 메시지는 알고리즘이 성공적으로 최적점을 찾았음을 의미합니다.

`[시각화: 코드 실행 결과창을 모사한 텍스트 박스와 각 결과값이 의미하는 바를 화살표로 설명]`

## 3. 요약 및 정리

이번 섹션에서는 파이썬을 사용하여 선형계획법 문제를 해결하는 실전적인 방법을 학습했습니다.

*   **수학적 모델링:** 현실의 문제를 목적 함수와 제약 조건으로 수식화하는 것이 첫 걸음입니다.
*   **표준형 변환:** `linprog` 함수는 최솟값을 기본으로 하므로, 최대화 문제는 목적 함수에 -1을 곱해 변환합니다.
*   **라이브러리 활용:** `scipy.optimize.linprog`를 통해 복잡한 행렬 연산 없이도 효율적으로 최적해를 도출할 수 있습니다.

파이썬을 활용한 최적화는 단순히 답을 구하는 것에 그치지 않고, 제약 조건이 변할 때 최적해가 어떻게 달라지는지 분석하는 '민감도 분석'으로 확장될 수 있습니다. 다음 섹션에서는 더 복잡한 정수 계획법에 대해 알아보겠습니다.

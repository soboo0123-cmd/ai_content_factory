## 7.2 Decision Tree (의사결정나무)

### 1. 도입: 복잡한 문제를 해결하는 가장 직관적인 방법

우리는 일상생활에서 수많은 선택의 기로에 섭니다. "오늘 점심은 무엇을 먹을까?"라는 단순한 질문부터 "이 프로젝트에 투자해야 할까?"라는 복잡한 비즈니스 결정까지, 우리의 뇌는 무의식적으로 일련의 질문을 던지며 답을 찾아갑니다.

**의사결정나무(Decision Tree)**는 이처럼 사람이 논리적으로 판단하는 과정을 나무(Tree) 구조로 도식화한 알고리즘입니다. 데이터로부터 스무고개와 같은 질문들을 학습하여, 최종적인 의사결정이나 예측을 수행합니다. 이번 섹션에서는 의사결정나무의 구조와 작동 원리, 그리고 파이썬을 이용한 구현 방법을 상세히 알아봅니다.

**학습 목표:**

* 불순도(Impurity)와 정보 획득(Information Gain)의 개념을 학습합니다.
* 파이썬 `scikit-learn` 라이브러리를 활용해 의사결정 모델을 구축할 수 있습니다.

### 2. 본론: 의사결정나무의 원리와 구조

#### 2.1 의사결정나무의 구성 요소

의사결정나무는 거꾸로 서 있는 나무와 같은 형태를 가집니다. 위에서 아래로 데이터가 흐르며 조건에 따라 분류됩니다.

1.  **뿌리 노드 (Root Node):** 전체 데이터셋이 시작되는 지점입니다. 가장 처음으로 데이터를 나누는 기준이 되는 질문이 위치합니다.
2.  **중간 노드 (Internal/Decision Node):** 데이터를 분할하는 조건문이 있는 노드입니다. 각 노드에서 질문의 결과(예/아니오)에 따라 가지가 갈라집니다.
3.  **단말 노드 (Leaf Node):** 더 이상 분할되지 않는 최종 노드입니다. 여기에 최종적인 결정값(클래스 또는 수치)이 담깁니다.
4.  **가지 (Branch):** 노드와 노드를 연결하는 선으로, 질문의 선택지를 의미합니다.

`[시각화: 간단한 '외출 여부' 결정 트리 예시 (비가 오는가? -> 우산이 있는가? -> 외출/대기)를 다이어그램으로 제시]`

#### 2.2 최적의 질문을 찾는 법: 불순도와 엔트로피

의사결정나무의 핵심은 **"어떤 질문을 먼저 던지는 것이 가장 효율적인가?"**입니다. 이를 위해 머신러닝에서는 '불순도(Impurity)'라는 개념을 사용합니다.

*   **불순도(Impurity):** 해당 집단에 서로 다른 종류의 데이터가 얼마나 섞여 있는지를 나타내는 척도입니다.
*   **엔트로피(Entropy):** 무질서도를 측정하는 지표입니다. 모든 데이터가 하나의 클래스에 속하면 엔트로피는 0이며, 반반씩 섞여 있으면 최대값인 1이 됩니다.
    *   수식: $H(S) = -\sum_{i=1}^{c} p_i \log_2 p_i$ (여기서 $p_i$는 해당 클래스의 비율)

의사결정나무는 데이터를 나누었을 때 **엔트로피가 가장 많이 감소하는(Information Gain이 큰)** 변수를 선택하여 질문으로 만듭니다.

`[시각화: 두 개의 주머니에 공이 섞여 있는 모습과, 색깔별로 완벽히 분리된 모습의 엔트로피 수치 비교]`

#### 2.3 파이썬 실습: Scikit-learn을 이용한 모델 구축

파이썬의 대표적인 머신러닝 라이브러리인 `scikit-learn`을 사용하면 복잡한 수학적 계산 없이도 의사결정나무를 만들 수 있습니다.

```python
import pandas as pd
from sklearn.tree import DecisionTreeClassifier
from sklearn import tree
import matplotlib.pyplot as plt

# 1. 간단한 데이터 생성 (날씨와 습도에 따른 테니스 경기 여부)
# 습도(Humidity): 0(낮음), 1(높음) / 바람(Wind): 0(약함), 1(강함)
data = {
    'Humidity': [1, 1, 1, 0, 0, 0, 1, 0],
    'Wind': [0, 1, 0, 0, 1, 0, 1, 1],
    'Play': [0, 0, 1, 1, 1, 1, 0, 1]  # 1: 경기 진행, 0: 취소
}
df = pd.DataFrame(data)

# 2. 특성(X)과 타겟(y) 분리
X = df[['Humidity', 'Wind']]
y = df['Play']

# 3. 모델 생성 및 학습 (엔트로피 기준 사용)
clf = DecisionTreeClassifier(criterion='entropy', max_depth=3)
clf.fit(X, y)

# 4. 결과 시각화
plt.figure(figsize=(10, 6))
tree.plot_tree(clf, feature_names=['Humidity', 'Wind'], 
               class_names=['Cancel', 'Play'], filled=True)
plt.show()

# 5. 새로운 데이터에 대한 예측
# 습도가 높고(1), 바람이 강한(1) 날씨라면?
prediction = clf.predict([[1, 1]])
print(f"예측 결과: {'경기 진행' if prediction[0] == 1 else '경기 취소'}")
```

#### 2.4 기대치(Expected Value)와의 연결

의사결정나무의 각 단말 노드는 특정 조건에 도달할 **확률**을 내포하고 있습니다. 이전 섹션에서 배운 '기대치' 개념을 적용하면, 단순히 분류를 넘어서 비즈니스 가치를 계산할 수 있습니다.

예를 들어, "Play" 노드에 도달할 확률이 80%이고 경기 시 수익이 100만 원, 취소 시 손실이 20만 원이라면, 해당 경로의 기대치는 다음과 같습니다.
$E = (0.8 \times 100) + (0.2 \times -20) = 76\text{만 원}$

이처럼 의사결정나무는 복잡한 확률적 상황을 구조화하여 최적의 기대치를 갖는 경로를 선택하도록 돕습니다.

# 7.3.1 Decision Tree의 한계 예 (v1 초안)

## 1. 도입: 완벽한 모델은 없다
의사결정나무(Decision Tree)는 데이터의 흐름을 직관적으로 보여주고, 마치 사람이 판단을 내리는 것과 같은 논리 구조를 가지고 있어 매우 강력한 도구입니다. 하지만 우리가 앞서 배운 기대치 기반의 의사결정이 모든 상황에서 최선의 답을 보장하지 않듯, 의사결정나무 역시 몇 가지 태생적인 한계를 지니고 있습니다.

이번 섹션에서는 의사결정나무가 실무에서 직면하는 주요 한계점들을 구체적인 사례와 파이썬 코드를 통해 살펴보겠습니다. 모델의 한계를 이해하는 것은 더 나은 모델(예: 랜덤 포레스트, 부스팅)로 나아가기 위한 필수적인 과정입니다.

---

## 2. 본론: 의사결정나무의 주요 한계

### 2.1 축에 수직인 분할의 한계 (Orthogonal Decision Boundaries)
의사결정나무는 한 번에 하나의 변수만을 선택하여 특정 임계값($\text{threshold}$)을 기준으로 데이터를 나눕니다. 수학적으로 표현하면 $X_i \le \text{value}$ 형태의 조건만을 사용합니다. 이로 인해 결정 경계(Decision Boundary)는 항상 특징 축에 수직(Orthogonal)인 격자 형태를 띠게 됩니다.

**[비유: 케이크 자르기]**
대각선으로 예쁘게 잘린 케이크 조각을 상상해 보세요. 의사결정나무는 이 대각선을 한 번에 자르지 못합니다. 대신 아주 작은 수직과 수평의 칼질을 수없이 반복하여 대각선과 '유사한' 계단 모양을 만들어냅니다.

**[시각화: 대각선 데이터 분포와 의사결정나무의 계단형 경계 비교 그래프]**

### 2.2 데이터의 작은 변화에 대한 민감성 (High Variance)
의사결정나무는 매우 '예민한' 모델입니다. 훈련 데이터셋에 아주 작은 변화가 생기거나 노이즈가 섞여 들어오면, 나무의 뿌리(Root)부터 완전히 다른 구조로 성장할 수 있습니다. 이는 의사결정나무가 **탐욕적 알고리즘(Greedy Algorithm)**을 사용하기 때문입니다. 매 순간 최적의 분할을 찾으려다 보니, 초기 단계의 작은 변화가 하위 노드로 내려갈수록 증폭되어 전체 결과가 뒤바뀌는 것입니다.

### 2.3 과적합(Overfitting)의 위험
나무가 깊어질수록 모델은 훈련 데이터를 완벽하게 분류하려고 시도합니다. 이 과정에서 데이터의 본질적인 패턴이 아니라, 우연히 발생한 통계적 잡음(Noise)까지 학습하게 됩니다. 이는 실제 상황(테스트 데이터)에서 예측력이 급격히 떨어지는 원인이 됩니다.

## 3. 파이썬 실습: 대각선 데이터 경계 문제

의사결정나무가 대각선 형태의 경계를 가진 데이터를 얼마나 비효율적으로 처리하는지 파이썬 코드로 확인해 보겠습니다.

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.tree import DecisionTreeClassifier
from sklearn.datasets import make_moons

# 1. 대각선 방향으로 구분되는 가상의 데이터 생성
np.random.seed(42)
X = np.random.rand(200, 2)
# y는 x1 + x2 > 1 인지 아닌지로 결정 (대각선 경계)
y = (X[:, 0] + X[:, 1] > 1).astype(int)

# 2. 의사결정나무 모델 학습
tree_clf = DecisionTreeClassifier(max_depth=5)
tree_clf.fit(X, y)

# 3. 결정 경계 시각화 함수
def plot_decision_boundary(clf, X, y):
    x1_range = np.linspace(0, 1, 100)
    x2_range = np.linspace(0, 1, 100)
    xx1, xx2 = np.meshgrid(x1_range, x2_range)
    X_new = np.c_[xx1.ravel(), xx2.ravel()]
    y_pred = clf.predict(X_new).reshape(xx1.shape)
    
    plt.contourf(xx1, xx2, y_pred, alpha=0.3, cmap='Wistia')
    plt.scatter(X[:, 0], X[:, 1], c=y, s=30, edgecolor='k', cmap='Wistia')
    plt.xlabel("$x_1$")
    plt.ylabel("$x_2$")
    plt.title("Decision Tree's Diagonal Boundary (Staircase Effect)")

plt.figure(figsize=(8, 6))
plot_decision_boundary(tree_clf, X, y)
plt.show()

# [시각화: 슬라이더로 max_depth를 조절하며 '계단 현상'이 심화되는 과정을 관찰하는 인터랙티브 그래프]
```

### 코드 설명
- 위 코드에서 실제 정답 경계는 $x_2 = -x_1 + 1$이라는 단순한 대각선 직선입니다.
- 하지만 의사결정나무는 이 직선을 표현하기 위해 수많은 수평/수직 분할을 시도하며 '계단 모양'의 경계를 만듭니다.
- 결과적으로 모델은 불필요하게 복잡해지고, 데이터가 조금만 바뀌어도 계단의 위치가 크게 요동치게 됩니다.

## 4. 요약
의사결정나무는 직관적이지만 다음과 같은 태생적 한계를 가집니다.

1.  **계단식 결정 경계:** 축에 평행한 분할 방식 때문에 대각선 형태의 상관관계를 표현하는 데 서투릅니다.
2.  **불안정성:** 데이터의 작은 변화에도 나무 구조가 크게 바뀔 수 있어 일반화 성능이 낮아질 우려가 있습니다.
3.  **복잡도 제어의 필요성:** 과적합을 막기 위해 나무의 깊이를 제한하거나 가지치기(Pruning)를 하는 등의 추가적인 전략이 필수적입니다.

이러한 한계를 극복하기 위해 현대 데이터 과학에서는 하나의 나무가 아닌 여러 개의 나무를 사용하는 **앙상블(Ensemble)** 기법을 주로 사용합니다. 다음 장에서는 이러한 한계를 극복하는 고도화된 기법들을 다루겠습니다.

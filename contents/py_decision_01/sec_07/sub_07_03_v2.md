# 7.3 Decision Tree의 한계 (v2)

의사결정나무(Decision Tree)는 그 직관적인 구조와 해석의 용이성 덕분에 머신러닝 입문자부터 전문가까지 널리 사랑받는 알고리즘입니다. 하지만 강력한 도구임에도 불구하고, 데이터의 특성에 따라 치명적인 약점을 드러내기도 합니다. 이번 섹션에서는 의사결정나무가 가진 본질적인 한계점들을 기하학적, 구조적 관점에서 깊이 있게 살펴보겠습니다.

---

## 1. 축에 수직인 분할의 한계 (Axis-Aligned Split)

의사결정나무의 가장 큰 특징 중 하나는 한 번에 하나의 변수(Feature)만을 기준으로 데이터를 분할한다는 점입니다. 이는 시각적으로 볼 때 결정 경계(Decision Boundary)가 항상 좌표축에 수직인 형태를 띠게 만듭니다.

### 기하학적 제약
만약 데이터의 진정한 경계가 대각선 방향(두 변수의 상관관계가 강한 경우)이라면, 의사결정나무는 이를 표현하기 위해 계단 모양의 복잡한 경계를 만들어야 합니다.

- **문제점:** 대각선 형태의 분포를 가진 데이터에 대해서는 매우 많은 분할이 필요하며, 이는 모델의 복잡도를 불필요하게 높이고 예측의 정확도를 떨어뜨립니다.
- **예시:** $x_1 > x_2$와 같은 단순한 선형 관계를 학습하기 위해 의사결정나무는 수많은 수직/수평선을 그어야 합니다.

> **[시각화: 대각선 분포 데이터에 대한 결정 경계 비교]**
> - 왼쪽: 선형 모델이 단 하나의 직선으로 데이터를 완벽히 분리하는 모습.
> - 오른쪽: 의사결정나무가 대각선 경계를 따라 미세한 계단 모양(Staircase effect)으로 분할하는 모습.

---

## 2. 높은 분산과 구조적 불안정성 (High Variance & Instability)

의사결정나무는 데이터의 작은 변화에 매우 민감하게 반응합니다. 이를 통계학적으로 **'분산(Variance)이 높다'**고 표현합니다.

### 나비 효과 (The Butterfly Effect)
의사결정나무의 학습은 최상단 노드(Root Node)부터 순차적으로 이루어집니다. 만약 훈련 데이터에 아주 약간의 노이즈가 추가되어 최상단 노드의 분할 기준이 바뀌게 된다면, 그 아래의 모든 하위 노드 구조가 완전히 뒤바뀌게 됩니다.

- **원인:** 계층적 구조(Hierarchical Structure) 특성상 상위 노드의 결정이 하위 모든 결정에 영향을 미치기 때문입니다.
- **결과:** 동일한 데이터셋에서 샘플링을 조금만 다르게 해도 전혀 다른 모양의 나무가 생성될 수 있으며, 이는 모델의 신뢰성을 떨어뜨리는 요인이 됩니다.

---

## 3. 탐욕적 알고리즘의 덫 (Greedy Approach)

의사결정나무는 분할 시점에 가장 최적인 기준을 선택하는 **탐욕적(Greedy) 알고리즘**을 사용합니다.

### 지역 최적화 vs 전역 최적화
학습 과정에서 나무는 "지금 당장 불순도를 가장 많이 낮출 수 있는 분할은 무엇인가?"만을 고민합니다.

- **한계:** 지금 당장은 최선이 아닌 분할이더라도, 몇 단계 뒤에 훨씬 더 좋은 분할을 가능하게 하는 시나리오를 의사결정나무는 고려하지 못합니다.
- **수식적 이해:** 특정 시점의 최적 분할 $s^*$는 다음과 같이 정의됩니다.
  $$s^* = \arg\max_{s \in S} \Delta I(s, D)$$
  여기서 $\Delta I$는 불순도의 감소량입니다. 이는 미래의 이득을 고려하지 않은 현재 상태에서의 최대화입니다.

---

## 4. 과적합(Overfitting)의 위험성

의사결정나무는 제약 조건을 걸지 않으면 모든 리프 노드(Leaf Node)의 불순도가 0이 될 때까지 무한히 성장하는 경향이 있습니다.

- **현상:** 훈련 데이터의 아주 미세한 이상치(Outlier)나 노이즈까지 학습하여, 실제 데이터의 본질적인 패턴이 아닌 '데이터 그 자체'를 외워버리는 현상이 발생합니다.
- **결과:** 훈련 데이터에 대해서는 100%의 정확도를 보일 수 있지만, 새로운 데이터(Test Data)에 대해서는 성능이 급격히 저하됩니다.

> **[시각화: 나무의 깊이(Depth)에 따른 과적합 시뮬레이션]**
> - 슬라이더로 나무의 최대 깊이를 조절.
> - 깊이가 깊어질수록 결정 경계가 개별 데이터 포인트 하나하나를 감싸는 복잡한 형태로 변하는 과정을 시각화.

---

## 5. 외삽(Extrapolation)의 불가능

의사결정나무는 회귀 문제에서 학습 데이터의 범위를 벗어나는 데이터에 대해 예측 능력이 없습니다.

- **원인:** 의사결정나무의 예측값은 해당 데이터가 속한 리프 노드의 평균값(회귀)이나 최빈값(분류)으로 결정됩니다. 따라서 훈련 데이터의 타겟 값이 $[10, 100]$ 사이였다면, 입력값이 아무리 크더라도 예측값은 결코 $100$을 넘을 수 없습니다.
- **비교:** 선형 회귀 모델이 추세를 따라 값을 확장(Extrapolation)하는 것과 대조적입니다.

```python
# 외삽 한계 예시 코드
import numpy as np
from sklearn.tree import DecisionTreeRegressor

# X: 1부터 10까지, y: 1부터 10까지 (y = x)
X = np.arange(1, 11).reshape(-1, 1)
y = np.arange(1, 11)

model = DecisionTreeRegressor()
model.fit(X, y)

# 학습 데이터 범위를 벗어나는 20을 예측 시도
prediction = model.predict([[20]])
print(f"Input 20 -> Prediction: {prediction[0]}") 
# 결과는 학습 데이터의 최댓값인 10에 머물게 됨
```

## 요약

의사결정나무는 강력하고 직관적이지만, 다음과 같은 태생적 한계를 가집니다:

1.  **기하학적 제약:** 축에 수직으로만 분할하여 대각선 패턴 학습에 취약함.
2.  **높은 분산:** 데이터의 작은 변화에도 나무 구조가 통째로 바뀔 수 있음.
3.  **탐욕적 선택:** 미래를 내다보지 않는 현재 시점의 최적 분할만 수행함.
4.  **과적합:** 제약이 없으면 데이터를 암기하려 함.
5.  **외삽 불가:** 학습 데이터 범위 밖의 수치를 예측하지 못함.

이러한 한계들을 극복하기 위해 이후에 등장하는 **랜덤 포레스트(Random Forest)**나 **그래디언트 부스팅(Gradient Boosting)** 같은 앙상블 기법들이 의사결정나무를 기본 단위로 사용하게 됩니다.

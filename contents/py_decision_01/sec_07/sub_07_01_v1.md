# 07 기대치와 Decision Tree

## 7.1 기대치란

### 도입: 불확실성 속에서 최선의 선택을 하는 기준
우리는 일상 속에서 매 순간 선택의 기로에 놓입니다. "오늘 우산을 챙길까?", "이 주식에 투자할까?", "A 프로젝트와 B 프로젝트 중 무엇을 먼저 시작할까?" 이러한 질문들의 공통점은 결과가 **확실하지 않다**는 점입니다. 우산을 챙겼는데 비가 오지 않을 수도 있고, 투자를 했는데 손실을 볼 수도 있습니다.

이처럼 결과가 확률적으로 결정되는 상황에서, 우리는 어떤 기준을 가지고 의사결정을 내려야 할까요? 이때 가장 강력한 길잡이가 되는 개념이 바로 **기대치(Expected Value)**입니다. 이번 섹션에서는 기대치의 수학적 정의와 그 속에 담긴 의미, 그리고 파이썬을 활용해 이를 계산하는 방법을 알아보겠습니다.

---

### 1. 기대치의 정의: 확률적 평균
기대치란 **'어떤 사건이 반복적으로 일어났을 때 얻을 수 있는 결과값들의 평균'**을 의미합니다. 단순히 산술 평균(모든 값을 더해 개수로 나누는 것)과는 차이가 있습니다. 각 결과가 발생할 **확률**이 다르기 때문에, 각 결과값에 그 확률을 곱하여 가중치를 둔 '가중 평균'의 성격을 띱니다.

#### 수학적 공식
확률 변수 $X$가 가질 수 있는 값들을 $x_1, x_2, \dots, x_n$이라 하고, 각각의 값이 나타날 확률을 $P(x_1), P(x_2), \dots, P(x_n)$이라고 할 때, 기대치 $E[X]$는 다음과 같이 정의됩니다.

$$E[X] = \sum_{i=1}^{n} x_i P(x_i) = x_1P(x_1) + x_2P(x_2) + \dots + x_nP(x_n)$$

- $x_i$: 발생 가능한 $i$번째 결과값 (이익, 손실, 점수 등)
- $P(x_i)$: $x_i$가 발생할 확률 (모든 확률의 합은 반드시 1이어야 함)

`[시각화: 주머니 속에서 서로 다른 점수가 적힌 공을 뽑는 인터랙티브 요소. 사용자가 공의 개수(확률)를 조절하면 실시간으로 기대치 막대그래프가 변하는 모습]`

---

### 2. 비유로 이해하기: 가중치가 있는 시소
기대치는 **무게 중심**과 같습니다. 시소의 양 끝에 서로 다른 무게의 추(결과값 $x$)가 놓여 있다고 가정해 봅시다. 이때 각 추가 놓인 위치의 중요도(확률 $P$)가 다르다면, 시소가 수평을 이루는 지점이 바로 기대치입니다.

예를 들어, 동전 던지기 게임을 한다고 가정해 봅시다.
- 앞면이 나오면 1,000원을 얻습니다. (확률 50%)
- 뒷면이 나오면 500원을 잃습니다. (-500원, 확률 50%)

이 게임의 기대치는 얼마일까요?
$$E[X] = (1,000 \times 0.5) + (-500 \times 0.5) = 500 - 250 = 250\text{원}$$

즉, 이 게임을 수만 번 반복한다면 한 판당 평균적으로 250원의 이득을 보게 된다는 뜻입니다. 만약 참가비가 300원이라면 이 게임은 참여할수록 손해이며, 참가비가 200원이라면 참여하는 것이 이득이라는 합리적 판단을 내릴 수 있습니다.

---

### 3. 파이썬으로 구현하는 기대치 계산
파이썬의 리스트와 반복문을 사용하여 간단한 기대치 계산기를 만들어 보겠습니다.

```python
def calculate_expected_value(outcomes, probabilities):
    """
    결과값 리스트와 확률 리스트를 받아 기대치를 계산합니다.
    """
    if len(outcomes) != len(probabilities):
        raise ValueError("결과값과 확률의 개수가 일치해야 합니다.")
    
    if abs(sum(probabilities) - 1.0) > 1e-9:
        raise ValueError("확률의 총합은 1이어야 합니다.")

    expected_value = 0
    for i in range(len(outcomes)):
        expected_value += outcomes[i] * probabilities[i]
    
    return expected_value

# 예시: 신제품 출시 프로젝트의 예상 수익
# 대박(1억 원), 평타(2천만 원), 쪽박(-5천만 원)
outcomes = [10000, 2000, -5000] # 단위: 만원
probabilities = [0.2, 0.5, 0.3]  # 각각의 확률

ev = calculate_expected_value(outcomes, probabilities)
print(f"프로젝트의 기대 수익: {ev}만 원")
```

이 코드는 복잡한 비즈니스 모델에서도 각 시나리오별 확률만 추정할 수 있다면, 해당 사업의 가치를 수치화하는 데 즉시 활용될 수 있습니다.

### 4. 기대치의 한계와 의사결정
기대치는 매우 유용한 도구이지만, 만능은 아닙니다. 
1. **분산(Variance)의 무시:** 두 선택지의 기대치가 같더라도, 하나는 변동성이 매우 크고 하나는 안정적일 수 있습니다. (예: 100% 확률로 1억 원 vs 10% 확률로 10억 원)
2. **심리적 가치:** 사람마다 위험을 감수하려는 정도(위험 회피 성향)가 다르기 때문에 기대치만으로 모든 행동을 설명할 수는 없습니다.

그럼에도 불구하고 기대치는 데이터에 기반하여 **'가장 확률적으로 유리한 방향'**을 제시하는 의사결정의 가장 기초적인 초석이 됩니다.

---

### 요약
- **기대치**는 발생 가능한 모든 결과값에 각각의 확률을 곱해 더한 값으로, '확률적 평균'을 의미한다.
- **수식:** $E[X] = \sum x_i P(x_i)$
- **의사결정의 기준:** 기대치가 양수이거나 비용 대비 높을 때, 우리는 그 선택이 '합리적'이라고 판단한다.
- **파이썬 활용:** 가중 평균의 원리를 코드로 구현하여 복잡한 시나리오의 가치를 산출할 수 있다.

`[시각화: 사용자가 직접 시나리오(결과와 확률)를 입력하면 기대치를 계산해 주고, 이를 다른 시나리오와 비교해 주는 계산기 위젯]`

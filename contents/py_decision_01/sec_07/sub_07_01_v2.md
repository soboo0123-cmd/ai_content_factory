# 7.1 기대치(Expectation)란: 미래의 평균을 설계하는 도구

## 1. 도입: 통계학이 미래를 보는 방법

우리는 일상에서 '평균(Average)'이라는 단어를 자주 사용합니다. 하지만 통계학에서 다루는 **기대치(Expectation, 혹은 기댓값)**는 단순히 과거 데이터의 평균을 내는 것 이상의 의미를 갖습니다.

우리가 주사위를 던지기 전, 혹은 새로운 비즈니스 모델에 투자하기 전, "과연 결과적으로 어느 정도의 이득(혹은 손실)을 보게 될까?"를 수치화한 것이 바로 기대치입니다. 즉, 기대치는 **불확실한 미래 상황에서 우리가 기대할 수 있는 '무게 중심'**과 같습니다. 이번 장에서는 확률과 결과값이 결합하여 어떻게 하나의 대표적인 수치를 만들어내는지 그 원리를 깊이 있게 탐구합니다.

---

## 2. 본론: 기대치의 원리와 구조

### (1) 단순 평균과 기대치의 결정적 차이
초등학교 시절 배운 평균은 모든 데이터의 중요도가 동일하다고 가정합니다. 예를 들어, 시험 점수가 80점과 100점이라면 평균은 $(80+100)/2 = 90$점입니다.

하지만 현실 세계에서는 각 사건이 발생할 **확률(Probability)**이 서로 다릅니다. 
- 복권에 당첨될 확률은 매우 낮고, 낙첨될 확률은 매우 높습니다.
- 이때 단순히 '당첨금'과 '0원'을 더해 2로 나누는 것은 아무런 의미가 없습니다.

이처럼 각 결과값에 그것이 일어날 확률을 곱해 가중치를 두는 방식을 **가중 평균(Weighted Average)**이라 하며, 확률 분포에서의 가중 평균이 바로 **기대치**입니다.

### (2) 수학적 정의
확률 변수 $X$가 가질 수 있는 값들을 $x_1, x_2, \dots, x_n$이라 하고, 각 값이 나타날 확률을 $P(x_1), P(x_2), \dots, P(x_n)$이라고 할 때, 기대치 $E[X]$는 다음과 같이 정의됩니다.

$$E[X] = \sum_{i=1}^{n} x_i P(x_i)$$

- $x_i$: 발생 가능한 결과값 (예: 주사위 눈)
- $P(x_i)$: 해당 결과가 발생할 확률
- $\sum$: 모든 가능한 경우를 전부 합산함

### (3) 시각적 비유: 시소 위의 무게 중심
기대치를 이해하는 가장 좋은 방법은 **'물리학의 무게 중심'**으로 생각하는 것입니다.

수직선 위에 각 결과값($x_i$)이 위치해 있고, 그 지점 위에 확률($P(x_i)$)만큼의 무게를 가진 상자가 놓여 있다고 가정해 봅시다. 이때 시소가 어느 한쪽으로 기울어지지 않고 완벽하게 평형을 이루는 지점이 바로 **기대치**입니다.

`[시각화: 가로축 눈금 위에 서로 다른 높이(확률)의 막대 그래프가 있고, 그 그래프 아래에서 삼각형 받침대(기대치 지점)가 좌우로 움직이며 수평을 맞추는 인터랙티브 애니메이션]`

### (4) 파이썬 코드로 확인하는 기대치
주사위 던지기를 예로 들어 보겠습니다. 주사위의 각 눈($1, 2, 3, 4, 5, 6$)이 나올 확률은 모두 $1/6$입니다. 이론적 기대치는 다음과 같습니다.

$$E[X] = (1 \times \frac{1}{6}) + (2 \times \frac{1}{6}) + \dots + (6 \times \frac{1}{6}) = 3.5$$

실제로 무수히 많이 던졌을 때 평균이 3.5로 수렴하는지 파이썬으로 시뮬레이션해 볼 수 있습니다.

```python
import random

def simulate_dice_expectation(trials):
    total_sum = 0
    results = []
    
    for i in range(1, trials + 1):
        roll = random.randint(1, 6)
        total_sum += roll
        current_avg = total_sum / i
        
        if i % (trials // 10) == 0 or i < 10:
            print(f"{i:6d}회 시행 후 평균: {current_avg:.4f}")
    
    return current_avg

# 100,000번의 주사위 던지기 시뮬레이션
print("시뮬레이션 시작...")
final_avg = simulate_dice_expectation(100000)
print(f"\n최종 수렴값: {final_avg}")
```

이 시뮬레이션 결과는 시행 횟수가 늘어날수록 이론적 기대치인 **3.5**에 가까워집니다. 이를 통계학에서는 **대수의 법칙(Law of Large Numbers)**이라고 부릅니다.

## 3. 요약: 이것만은 꼭!

1.  **미래의 요약본:** 기대치는 어떤 불확실한 사건을 무한히 반복했을 때 얻게 될 결과의 평균적인 값입니다.
2.  **확률적 가중치:** 단순 평균과 달리, 각 결과값에 '발생 가능성(확률)'이라는 무게를 곱하여 계산합니다.
3.  **균형점:** 확률 분포라는 지형에서 전체 무게가 평형을 이루는 '무게 중심' 역할을 합니다.
4.  **의사결정의 기준:** 기대치가 (+)라면 장기적으로 이득을 보는 선택이며, (-)라면 손실을 보는 선택임을 의미합니다.

`[시각화: 슬라이더를 조절하여 특정 사건의 확률을 높이거나 낮추었을 때, 기대치(평균점)가 실시간으로 이동하는 그래프]`

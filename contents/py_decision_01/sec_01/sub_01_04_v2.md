# 1.4 모델링(Decision Modeling): 현실을 수학의 언어로 번역하기

## 도입
우리는 일상 속에서 수많은 결정을 내립니다. "내일 비가 올까?", "이 중고차의 가격은 적당한가?", "어떤 경로가 가장 빠를까?"와 같은 질문에 답하기 위해 우리 뇌는 경험을 바탕으로 추론합니다. 인공지능에서의 **모델링(Modeling)**은 바로 이 인간의 추론 과정을 수학적이고 논리적인 체계로 옮겨놓는 과정입니다.

이번 섹션에서는 모델링이 단순한 '코드 작성'이 아니라, 복잡한 현실 세계를 추상화하여 컴퓨터가 이해할 수 있는 '수학적 함수'로 변환하는 본질적인 원리에 대해 학습합니다.

---

## 1. 모델링의 본질: 추상화(Abstraction)
모델(Model)의 사전적 의미는 '실물의 복제품' 또는 '모범'입니다. 데이터 과학에서의 모델은 **현실의 복잡한 현상을 단순화하여 핵심적인 관계만을 추출해낸 수학적 구조**를 의미합니다.

### 1.1 지도와 모델의 비유
지도는 현실 세계의 모든 나무, 돌멩이, 사람을 표시하지 않습니다. 길을 찾기 위해 필요한 도로, 건물, 지형만을 선택적으로 표현합니다. 모델링도 이와 같습니다.
- **현실:** 수만 개의 변수가 얽혀 있는 복잡한 문제
- **추상화:** 의사결정에 불필요한 노이즈(Noise)를 제거하고 유의미한 패턴(Pattern)을 식별
- **모델:** 데이터 사이의 관계를 설명하는 수학적 공식

`[시각화: 현실의 복잡한 3D 도시 풍경이 점차 단순화되어 선과 면으로 구성된 2D 지도로 변하는 애니메이션]`

---

## 2. 의사결정 모델의 수학적 구조
모든 머신러닝 모델은 근본적으로 입력을 출력으로 변환하는 **함수($f$)**를 찾는 과정입니다.

$$y = f(x; \theta)$$

- $x$: 입력 데이터 (특징량, Features)
- $y$: 모델의 예측값 (Target / Prediction)
- $f$: 모델의 구조 (가설, Hypothesis)
- $\theta$: 모델이 학습해야 할 파라미터 (매개변수, Weights)

### 2.1 가설 설정 (Hypothesis Space)
모델링의 첫 번째 단계는 어떤 형태의 함수를 사용할지 정하는 것입니다. "데이터가 직선의 관계를 가질 것이다"라고 가정하면 선형 모델이 되고, "복잡한 곡선 형태일 것이다"라고 가정하면 딥러닝 모델이 됩니다.

### 2.2 목적 함수 (Objective Function)
모델이 얼마나 잘 예측하고 있는지를 측정하는 기준이 필요합니다. 이를 **손실 함수(Loss Function)**라고도 부릅니다. 모델링의 목표는 이 손실 함수의 값을 최소화하는 $\theta$를 찾아내는 것입니다.

$$Loss = \sum (y_{actual} - y_{predicted})^2$$

`[시각화: 3차원 곡면 그래프(Loss Surface) 위에서 공이 가장 낮은 골짜기를 찾아 굴러 내려가는 모습]`

---

## 3. 모델링 프로세스: 단계별 접근

### 1단계: 문제의 정의 (Problem Definition)
단순히 "예측하고 싶다"가 아니라, 무엇을(What) 기준으로 어떻게(How) 결정할지 정해야 합니다.
- **분류(Classification):** "이 이메일은 스팸인가, 아닌가?" (이진 결정)
- **회귀(Regression):** "내일 삼성전자의 주가는 얼마인가?" (연속적인 값 결정)

### 2단계: 데이터의 수치화 (Vectorization)
컴퓨터는 텍스트나 이미지를 그대로 이해할 수 없습니다. 모든 정보를 숫자 리스트(벡터)로 변환해야 합니다.

### 3단계: 알고리즘 선택 및 학습 (Training)
데이터의 특성에 맞는 모델 구조를 선택하고, 데이터를 반복적으로 주입하여 최적의 파라미터 $\theta$를 찾아냅니다.

---

## 4. 코드 예제: 아주 간단한 선형 결정 모델
가장 기초적인 모델링인 '선형 회귀(Linear Regression)'를 통해 모델이 어떻게 데이터를 학습하는지 살펴보겠습니다.

```python
import numpy as np
from sklearn.linear_model import LinearRegression
import matplotlib.pyplot as plt

# 1. 데이터 준비 (공부 시간 대비 시험 성적)
# x: 공부 시간, y: 시험 성적
X = np.array([[1], [2], [3], [4], [5]])
y = np.array([15, 28, 42, 59, 72])

# 2. 모델 선택 (선형 가설 설정: y = ax + b)
model = LinearRegression()

# 3. 모델 학습 (데이터로부터 최적의 a와 b를 찾음)
model.fit(X, y)

# 4. 의사결정 및 예측 (6시간 공부했을 때의 성적은?)
hours_to_study = [[6]]
predicted_score = model.predict(hours_to_study)

print(f"예측 결과: 6시간 공부 시 예상 성적은 {predicted_score[0]:.2f}점입니다.")
print(f"모델의 가중치(Slope): {model.coef_[0]:.2f}")
```

이 짧은 코드에서 모델은 데이터($X, y$) 사이의 관계를 $y \approx 14.3x + 1.1$이라는 수학적 모델로 변환해낸 것입니다.

---

## 5. 모델링 시 주의사항: 일반화(Generalization)
좋은 모델링이란 단순히 가진 데이터에만 정답을 잘 맞추는 것이 아닙니다. **한 번도 보지 못한 데이터(Unseen Data)**에 대해서도 정확한 결정을 내릴 수 있어야 합니다.

1.  **과적합(Overfitting):** 훈련 데이터에 너무 과하게 최적화되어 실제 현상의 본질을 놓치고 노이즈까지 학습한 상태. (암기 위주의 공부)
2.  **과소적합(Underfitting):** 모델이 너무 단순하여 데이터의 기본적인 패턴조차 파악하지 못한 상태.

`[시각화: 데이터 포인트들을 지날 때, 적절한 직선(Good), 너무 구불구불한 선(Overfitting), 아무 상관 없는 직선(Underfitting)의 비교]`

---

## 요약
- **모델링**은 복잡한 현실 데이터를 수학적인 함수 관계($y = f(x)$)로 정의하는 과정입니다.
- 핵심은 불필요한 정보를 걷어내는 **추상화**와 최적의 답을 찾아가는 **최적화**에 있습니다.
- 모델은 고정된 정답이 아니라, 데이터를 통해 계속해서 업데이트되는 **의사결정의 틀**입니다.
- 좋은 모델링의 척도는 새로운 데이터에 대해서도 올바른 예측을 수행하는 **일반화 성능**에 달려 있습니다.

# 1.3 리스크와 데이터 분석

의사결정의 과정은 단순히 최선의 선택을 내리는 것을 넘어, 그 선택이 가져올 결과의 **불확실성(Uncertainty)**을 관리하는 과정이기도 합니다. 본 절에서는 의사결정론에서 말하는 '리스크'의 개념을 정의하고, 데이터 분석이 어떻게 리스크를 관리 가능한 수치로 변환하는지 학습합니다.

## 1. 리스크와 불확실성의 구분

의사결정론의 선구자인 프랭크 나이트(Frank Knight)는 '불확실성'과 '리스크'를 엄격히 구분했습니다. 이 구분을 이해하는 것이 데이터 분석의 목적을 파악하는 첫걸음입니다.

- **불확실성(Uncertainty):** 발생 가능한 결과의 확률 분포를 전혀 알 수 없는 상태입니다. "내일 외계인이 지구를 방문할 확률"처럼 과거의 데이터가 없어 예측이 불가능한 영역입니다.
- **리스크(Risk):** 발생 가능한 결과와 그 결과가 나타날 확률을 알고 있거나, 데이터를 통해 추정할 수 있는 상태입니다. 동전 던지기나 과거 판매 데이터를 바탕으로 한 다음 달 매출 예측 등이 이에 해당합니다.

**데이터 분석의 궁극적인 목표는 모호한 '불확실성'의 영역을 측정 가능한 '리스크'의 영역으로 끌어오는 것입니다.**

[시각화: '불확실성'이라는 안개 속에 가려진 길이 데이터 분석(손전등)을 통해 확률적 경로(리스크)로 드러나는 인포그래픽]

---

## 2. 데이터 분석을 통한 리스크의 정량화

데이터 분석은 과거의 경험과 수치를 바탕으로 미래의 발생 가능성을 **확률(Probability)**로 변환합니다. 리스크를 정량화할 때 주로 사용하는 두 가지 핵심 지표는 **기댓값(Expected Value)**과 **표준편차(Standard Deviation)**입니다.

### 2.1 기댓값 (Expected Value)
기댓값은 어떤 선택을 했을 때 평균적으로 기대할 수 있는 결과값입니다.

$$E[X] = \sum_{i=1}^{n} x_i p_i$$

여기서 $x_i$는 발생 가능한 결과값이고, $p_i$는 그 결과가 발생할 확률입니다. 하지만 기댓값만으로는 리스크를 온전히 설명할 수 없습니다.

### 2.2 표준편차와 분산 (Variance)
리스크의 핵심은 '변동성'입니다. 기댓값이 같더라도 결과가 얼마나 퍼져 있느냐에 따라 리스크는 달라집니다. 데이터 분석에서는 이를 분산($\sigma^2$) 또는 표준편차($\sigma$)로 측정합니다. 표준편차가 클수록 결과의 불확실성이 크며, 이는 곧 리스크가 높음을 의미합니다.

[시각화: 평균은 같지만 표준편차가 다른 두 개의 정규분포 곡선 비교. 슬라이더로 표준편차를 조절하며 그래프의 너비가 변하는 모습 제시]

## 3. 파이썬 실습: 투자 안안의 리스크 비교

두 가지 투자 안(A, B)이 있다고 가정해 봅시다. 두 안의 평균 수익은 같지만, 데이터 분석을 통해 리스크를 계산해 보면 전혀 다른 결과가 나옵니다.

```python
import numpy as np

# 투자 안 A: 안정적인 수익 (변동성 작음)
# 투자 안 B: 하이리스크 하이리턴 (변동성 큼)
investment_a = [100, 105, 95, 102, 98]
investment_b = [150, 50, 200, -50, 150]

def analyze_risk(data, name):
    mean = np.mean(data)
    std_dev = np.std(data)
    print(f"[{name} 분석 결과]")
    print(f"평균 수익(기댓값): {mean}")
    print(f"표준편차(리스크): {std_dev:.2f}")
    print("-" * 20)

analyze_risk(investment_a, "투자 안 A")
analyze_risk(investment_b, "투자 안 B")
```

### 코드 설명
- `np.mean()`: 데이터의 산술 평균을 계산하여 기댓값을 구합니다.
- `np.std()`: 데이터의 표준편차를 계산합니다. 이 값이 클수록 의사결정자는 더 큰 리스크를 감수해야 함을 직관적으로 알 수 있습니다.

## 4. 리스크 기반 의사결정의 프로세스

데이터 분석을 활용한 의사결정은 다음과 같은 단계를 거칩니다.

1.  **데이터 수집:** 과거의 유사 사례나 실험 데이터를 확보합니다.
2.  **확률 모델링:** 수집된 데이터를 바탕으로 결과의 확률 분포를 추정합니다.
3.  **리스크 지표 계산:** 기댓값, 표준편차, 최악의 경우(VaR: Value at Risk) 등을 산출합니다.
4.  **의사결정 기준 적용:** 의사결정자의 리스크 성향(위험 회피형, 위험 추구형 등)에 따라 최적의 안을 선택합니다.

**핵심 원리:** 데이터가 많아질수록(표본 크기가 커질수록) 우리는 미래 리스크를 더 정확하게 예측할 수 있으며, 이는 의사결정의 성공 확률을 높이는 강력한 무기가 됩니다.

---

## 요약
- **리스크**는 확률을 통해 관리할 수 있는 불확실성입니다.
- **데이터 분석**은 불확실성을 리스크로 변환하여 '계산 가능한 상태'로 만듭니다.
- **기댓값**은 평균적인 성과를, **표준편차**는 의사결정이 내포한 리스크의 크기를 나타냅니다.
- 파이썬의 통계 라이브러리를 활용하면 복잡한 데이터 속에서도 직관적인 리스크 지표를 추출할 수 있습니다.

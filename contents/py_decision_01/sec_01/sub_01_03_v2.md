# 1.3 리스크와 데이터 분석 (v2)

## 1. 도입
우리가 살아가는 세상은 불확실성으로 가득 차 있습니다. 내일의 주가, 다음 달의 제품 수요, 혹은 특정 기계의 고장 시점 등 우리가 알고 싶어 하는 중요한 사건들은 대부분 확정되어 있지 않습니다. 이러한 불확실성 속에서 발생하는 잠재적 손실이나 변동성을 우리는 **리스크(Risk)**라고 부릅니다.

데이터 분석의 궁극적인 목적 중 하나는 과거의 데이터를 통해 미래의 리스크를 식별하고, 이를 수치화하여 통제 가능한 영역으로 가져오는 것입니다. 본 섹션에서는 리스크의 정의를 데이터 과학적 관점에서 재해석하고, 이를 분석하기 위한 통계적 도구들을 살펴보겠습니다.

**학습 목표:**
- 불확실성과 리스크의 차이를 이해합니다.
- 데이터 분석을 통해 리스크를 정량화하는 핵심 지표(기댓값, 분산 등)를 학습합니다.
- 리스크 관리에서 데이터 분석이 담당하는 역할을 파악합니다.

## 2. 본론

### 2.1 불확실성을 리스크로 바꾸는 과정
경제학자 프랭크 나이트(Frank Knight)는 '측정할 수 없는 불확실성'과 '측정 가능한 리스크'를 구분했습니다. 데이터 분석이 없다면 우리는 막연한 불안감(불확실성) 속에 머물게 되지만, 데이터를 통해 확률 분포를 파악하면 이를 계산 가능한 **리스크**의 영역으로 전환할 수 있습니다.

- **불확실성(Uncertainty):** 발생 가능한 결과나 그 확률을 전혀 알 수 없는 상태.
- **리스크(Risk):** 결과의 분포와 각 결과가 발생할 확률을 데이터로 추정할 수 있는 상태.

> **[시각화: 불확실성 vs 리스크]**
> - 왼쪽: 안개가 자욱한 도로 (불확실성 - 앞이 보이지 않음)
> - 오른쪽: 내비게이션에 사고 확률과 우회로가 표시된 도로 (리스크 - 확률적 예측 가능)

### 2.2 리스크의 척도: 평균과 분산
데이터 분석에서 리스크를 측정할 때 가장 기본적으로 사용하는 도구는 통계량입니다. 우리는 수집된 데이터를 통해 미래 사건의 '중심'과 '퍼짐 정도'를 계산합니다.

#### (1) 기댓값 (Expected Value)
기댓값은 어떤 사건이 반복되었을 때 기대할 수 있는 평균적인 결과값입니다. 리스크 분석에서는 이를 '기준점'으로 삼습니다.

$$E[X] = \sum_{i=1}^{n} x_i P(x_i)$$

- $x_i$: 발생 가능한 결과값
- $P(x_i)$: 해당 결과가 발생할 확률

#### (2) 분산(Variance)과 표준편차(Standard Deviation)
데이터 분석에서 **리스크의 직접적인 지표**는 바로 분산입니다. 평균(기댓값)에서 데이터가 얼마나 멀리 떨어져 있는가를 나타내며, 이 값이 클수록 미래의 불확실성(리스크)이 크다는 것을 의미합니다.

$$Var(X) = E[(X - \mu)^2]$$
$$\sigma = \sqrt{Var(X)}$$

- 분산이 크다: 결과의 변동성이 크다 → 리스크가 높다.
- 분산이 작다: 결과가 예측 범위 내에 존재한다 → 리스크가 낮다.

> **[시각화: 확률 밀도 함수 그래프]**
> - 두 개의 종 모양 곡선(정규분포)을 제시. 
> - 폭이 좁은 곡선(저리스크)과 폭이 넓은 곡선(고리스크)을 비교하며 분산의 의미 설명. 
> - [슬라이더: 사용자가 분산 값을 조절하면 그래프의 폭이 변하며 '예측 범위'가 넓어지는 효과 시각화]

### 2.3 데이터 분석을 활용한 리스크 관리 사례

#### ① 금융권의 신용 평가 (Credit Scoring)
은행은 대출 신청자의 과거 금융 거래 데이터, 소득, 직업 등을 분석하여 '부도 리스크'를 계산합니다. 이는 과거 데이터를 학습한 머신러닝 모델을 통해 특정 고객이 대출금을 갚지 못할 확률($P(Default)$)을 수치화하는 작업입니다.

#### ② 제조 현장의 이상 탐지 (Anomaly Detection)
공장의 센서 데이터(진동, 온도, 압력 등)를 실시간으로 분석하면 기계가 고장 날 리스크를 사전에 파악할 수 있습니다. 정상 범위를 벗어나는 데이터의 '변동성'을 감지하여 막대한 수리 비용과 가동 중단 리스크를 방지합니다.

```python
import numpy as np
import matplotlib.pyplot as plt

# 리스크 분석 예시: 두 투자 상품의 수익률 변동성 비교
np.random.seed(42)

# 상품 A: 평균 수익률 5%, 표준편차 2% (저리스크)
asset_a = np.random.normal(0.05, 0.02, 1000)

# 상품 B: 평균 수익률 7%, 표준편차 10% (고리스크)
asset_b = np.random.normal(0.07, 0.10, 1000)

print(f"상품 A의 평균 수익률: {np.mean(asset_a):.2%}, 표준편차: {np.std(asset_a):.2%}")
print(f"상품 B의 평균 수익률: {np.mean(asset_b):.2%}, 표준편차: {np.std(asset_b):.2%}")

# 데이터 분석 결과: 상품 B는 평균 수익률이 높지만, 표준편차가 커서 원금 손실 리스크가 훨씬 높음.
```

## 3. 요약

리스크와 데이터 분석은 뗄 수 없는 관계에 있습니다. 데이터 분석은 보이지 않는 위험을 숫자로 바꾸어 우리 눈앞에 보여주는 렌즈와 같습니다.

1.  **데이터의 역할:** 막연한 '불확실성'을 계산 가능한 '리스크'로 전환합니다.
2.  **핵심 지표:** **기댓값**으로 미래의 평균적 성과를 예측하고, **분산/표준편차**를 통해 그 예측이 빗나갈 위험(리스크)의 크기를 측정합니다.
3.  **의사결정:** 데이터 분석을 통해 도출된 리스크 지표는 단순히 위험을 피하는 것이 아니라, 위험 대비 수익이 적절한지를 판단하는 근거가 됩니다.

결국 데이터 분석을 잘한다는 것은, 미래의 위험을 완벽히 제거하는 것이 아니라 **내가 감당해야 할 위험이 얼마인지 정확히 알고 대응하는 것**을 의미합니다.

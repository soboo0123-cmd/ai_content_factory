# 1.4 모델링 (Decision Modeling)

우리는 살면서 수많은 선택의 기로에 섭니다. 점심 메뉴를 고르는 가벼운 결정부터, 기업의 투자 방향을 정하는 중대한 결정까지 그 범위는 매우 넓습니다. 하지만 현실 세계는 너무나 복잡하고 변수가 많아서, 단순히 감에 의존해서는 최선의 결과를 얻기 어렵습니다. 이때 필요한 것이 바로 **'모델링(Modeling)'**입니다.

이 섹션에서는 복잡한 현실 문제를 논리적이고 수학적인 구조로 변환하는 '의사결정 모델링'의 개념과 구성 요소, 그리고 그 과정을 자세히 살펴보겠습니다.

---

## 1. 모델링이란 무엇인가?

모델링은 **복잡한 현실 세계를 단순화하여 특정 목적에 맞게 추상화하는 과정**을 의미합니다. 

지도(Map)를 예로 들어봅시다. 지도는 실제 지형의 모든 풀숲과 돌멩이를 표시하지 않습니다. 대신 길 찾기라는 목적을 위해 도로, 건물, 주요 지형지물만을 선과 면으로 단순화하여 보여줍니다. 의사결정 모델 역시 마찬가지입니다. 문제의 본질을 파악하기 위해 불필요한 정보는 쳐내고, 결과에 결정적인 영향을 미치는 핵심 요소들만 추출하여 논리적인 관계로 연결한 것이 바로 '모델'입니다.

### 의사결정 모델링의 목적
1.  **현상의 이해:** 복잡하게 얽힌 변수들 사이의 관계를 명확히 파악합니다.
2.  **결과 예측:** 특정 선택을 했을 때 어떤 결과가 나타날지 미리 시뮬레이션합니다.
3.  **최적화:** 제한된 자원 안에서 목표를 가장 잘 달성할 수 있는 대안을 찾습니다.

---

## 2. 의사결정 모델의 구성 요소

하나의 완결된 의사결정 모델을 만들기 위해서는 다음과 같은 네 가지 핵심 요소가 정의되어야 합니다.

### (1) 의사결정 변수 (Decision Variables)
의사결정자가 직접 제어할 수 있는 값입니다. "무엇을 얼마나 할 것인가?"에 해당합니다.
- *예: 제품 생산량, 광고 집행 예산, 포트폴리오 내 주식 비중*
- 수학적 기호로는 주로 $x_1, x_2, \dots, x_n$으로 표기합니다.

### (2) 외생 변수 및 파라미터 (Parameters / Exogenous Variables)
의사결정자가 통제할 수 없지만 결과에 영향을 주는 외부 요인입니다.
- *예: 원자재 가격, 시장 수요, 법정 이자율*
- 모델 내에서는 상수로 취급되거나 확률 분포를 가진 값으로 정의됩니다.

### (3) 목적 함수 (Objective Function)
우리가 달성하고자 하는 목표를 수학적으로 표현한 식입니다. 보통 특정 값을 최대화(Maximize)하거나 최소화(Minimize)하는 것을 목표로 합니다.
- *예: 이윤 극대화, 비용 최소화, 고객 만족도 점수 최대화*
- 주로 $f(x)$ 또는 $Z$로 표현하며, $Z = 3x_1 + 5x_2$와 같은 형태를 가집니다.

### (4) 제약 조건 (Constraints)
의사결정 시 반드시 지켜야 하는 한계나 규칙입니다. 현실의 물리적, 경제적 한계를 반영합니다.
- *예: 예산 한도, 원자재 재고량, 일일 작업 시간*
- $2x_1 + x_2 \le 100$과 같이 부등식이나 등식의 형태로 표현됩니다.

`[시각화: 슬라이더를 통해 의사결정 변수(x)를 조절하면 제약 조건 범위 내에서 목적 함수(결과값)가 어떻게 변하는지 보여주는 인터랙티브 그래프]`

---

## 3. 모델링의 단계별 과정

모델링은 단순히 수식을 쓰는 것이 아니라, 문제를 정의하고 검증하는 일련의 흐름을 가집니다.

1.  **문제 정의:** 해결해야 할 의사결정 문제가 무엇인지 명확히 합니다.
2.  **변수 식별:** 결정해야 할 것(변수)과 주어진 것(파라미터)을 구분합니다.
3.  **관계 설정:** 변수들이 서로 어떻게 영향을 주는지 논리적/수학적 관계식을 만듭니다.
4.  **모델 구현:** 파이썬과 같은 도구를 사용하여 모델을 코드로 변환합니다.
5.  **검증 및 민감도 분석:** 모델이 현실을 잘 반영하는지 확인하고, 외부 변수가 변할 때 결과가 어떻게 바뀌는지 분석합니다.

## 4. 파이썬을 활용한 기초 모델링 예시

간단한 예시를 통해 모델링을 코드로 구현해 보겠습니다.
**문제:** 한 회사가 A 제품을 만듭니다. 제품 하나당 이익은 5만 원입니다. 단, 하루에 사용할 수 있는 최대 노동 시간은 8시간이며, 제품 하나를 만드는 데 2시간이 걸립니다. 이익을 최대화하려면 몇 개를 만들어야 할까요?

### [모델 설계]
- **변수 ($x$):** 제품 생산량
- **목적 함수:** $Maximize \ Z = 5x$ (이익)
- **제약 조건:** $2x \le 8$ (시간 제한), $x \ge 0$ (생산량은 음수일 수 없음)

```python
# 파이썬으로 표현한 간단한 의사결정 로직

def decision_model(production_quantity):
    """
    제품 생산량에 따른 이익과 제약 조건 위반 여부를 계산하는 모델
    """
    unit_profit = 5  # 단위당 이익 (만원)
    max_hours = 8    # 최대 가용 시간
    hours_per_unit = 2 # 단위당 소요 시간
    
    # 제약 조건 체크
    required_hours = production_quantity * hours_per_unit
    
    if required_hours > max_hours:
        return None, "제약 조건 위반: 노동 시간이 부족합니다."
    
    # 목적 함수 계산
    total_profit = production_quantity * unit_profit
    return total_profit, "정상"

# 다양한 대안 시뮬레이션
for x in range(6):
    profit, status = decision_model(x)
    print(f"생산량: {x}개 | 이익: {profit if profit is not None else 0}만원 | 상태: {status}")
```

이 코드는 매우 단순하지만, **'대안 탐색(Range) -> 제약 조건 확인(If) -> 성과 측정(Function)'**이라는 모델링의 핵심 구조를 모두 담고 있습니다.

## 5. 요약

1.  **모델링**은 복잡한 현실을 목적에 맞게 단순화하고 추상화하는 과정입니다.
2.  의사결정 모델은 **의사결정 변수, 파라미터, 목적 함수, 제약 조건**의 4가지 요소로 구성됩니다.
3.  좋은 모델은 현실의 모든 것을 담는 것이 아니라, **의사결정에 필요한 핵심 논리**를 명확하게 담고 있어야 합니다.
4.  파이썬을 활용하면 이러한 논리 구조를 코드로 구현하여 다양한 시나리오를 빠르게 테스트할 수 있습니다.

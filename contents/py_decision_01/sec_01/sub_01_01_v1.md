# 1.1 인간의 주권과 이론

## 1. 도입
우리의 삶은 매 순간 선택의 연속입니다. 아침에 일어나 어떤 옷을 입을지 같은 사소한 결정부터, 기업의 운명을 결정짓는 대규모 투자나 국가의 정책 결정에 이르기까지 '의사결정'은 인류 문명을 지탱하는 핵심적인 활동입니다. 

본 섹션에서는 의사결정론의 출발점인 **'인간의 주권'**에 대해 살펴봅니다. 왜 우리가 복잡한 수학적 모델과 파이썬 코드를 배우기에 앞서, 결정을 내리는 주체인 '인간'과 그를 둘러싼 '이론'의 관계를 이해해야 하는지 학습하는 것이 이번 장의 목표입니다.

## 2. 본론

### 2.1 의사결정이란 무엇인가?
의사결정(Decision Making)이란 **'여러 대안 중에서 특정 목적을 달성하기 위해 가장 적합한 하나를 선택하는 과정'**을 의미합니다. 단순히 무언가를 고르는 행위를 넘어, 목표를 설정하고 정보를 수집하며 각 대안의 결과를 예측하는 논리적 과정을 포함합니다.

의사결정론은 이러한 과정을 체계화하여 연구하는 학문입니다. 우리가 파이썬이라는 도구를 사용하는 이유는 인간의 직관이 가진 한계를 보완하고, 데이터에 기반한 객관적인 판단을 내리기 위함입니다.

### 2.2 인간의 주권: 최종 결정권자는 누구인가?
현대 사회에서 AI와 알고리즘이 비약적으로 발전함에 따라 "기계가 인간을 대신해 결정을 내리는가?"라는 질문이 자주 던져집니다. 하지만 의사결정론의 대원칙은 **'인간의 주권(Human Sovereignty)'**에 있습니다.

1.  **가치 판단의 주체:** 알고리즘은 효율성을 계산할 수 있지만, 무엇이 '가치 있는가'를 정의하는 것은 인간입니다. 예를 들어, 수익률 10%와 환경 보호 중 무엇을 우선시할지는 인간의 가치관에 달려 있습니다.
2.  **책임의 소재:** 의사결정의 결과로 발생하는 책임은 오직 주권을 가진 인간만이 질 수 있습니다.
3.  **도구로서의 이론:** 수학적 모델과 파이썬 코드는 인간의 판단을 돕는 '비서'일 뿐, 주권을 가진 '주인'이 아닙니다.

> **[시각화: 의사결정 프로세스 다이어그램]**
> - 입력값(데이터, 가치관) -> 분석 도구(파이썬 모델) -> 권고안 생성 -> **인간의 최종 판단(주권)** -> 결과 산출 및 책임
> - 이 과정에서 '인간의 최종 판단' 단계가 가장 핵심임을 강조하는 애니메이션 효과.

### 2.3 의사결정 이론의 두 축: 규범적 이론과 기술적 이론
인간이 어떻게 결정을 내리는지 이해하기 위해 학자들은 이론을 두 가지 방향으로 발전시켰습니다.

#### (1) 규범적 의사결정론 (Normative Decision Theory)
"인간은 어떻게 결정해야 하는가?"에 집중합니다. 완벽한 합리성을 가진 인간(Homo Economicus)을 가정하며, 기대 가치를 극대화하는 수학적 최적해를 찾는 것이 목표입니다. 파이썬의 `scipy.optimize`와 같은 라이브러리를 활용해 최적값을 찾는 과정이 주로 여기에 해당합니다.

#### (2) 기술적 의사결정론 (Descriptive Decision Theory)
"인간은 실제로 어떻게 결정하는가?"에 집중합니다. 인간은 감정, 편향, 시간적 제약 때문에 항상 합리적인 선택을 하지는 못합니다. 이를 '제한된 합리성(Bounded Rationality)'이라고 합니다.

```python
# [코드 예제] 합리적 선택 vs 실제 선택의 단순 모델링

def rational_choice(options):
    # 각 옵션의 (기대 수익, 위험도)
    # 규범적 이론: 수익이 가장 높은 것을 무조건 선택
    return max(options, key=lambda x: x['profit'])

def human_choice(options, risk_aversion=True):
    # 기술적 이론: 인간은 수익이 조금 낮더라도 위험이 적은 것을 선호할 수 있음(편향 반영)
    if risk_aversion:
        # 위험도가 0.5 미만인 것 중 수익이 높은 것 선택
        safe_options = [o for o in options if o['risk'] < 0.5]
        return max(safe_options, key=lambda x: x['profit']) if safe_options else None
    return rational_choice(options)

options = [
    {'name': '대안 A', 'profit': 100, 'risk': 0.8},
    {'name': '대안 B', 'profit': 70, 'risk': 0.2}
]

print(f"규범적(합리적) 선택: {rational_choice(options)['name']}")
print(f"실제 인간의 선택(위험 회피형): {human_choice(options)['name']}")
```

### 2.4 이론이 필요한 이유: 주관의 객관화
인간에게 주권이 있음에도 불구하고 '이론'이 필요한 이유는 **주관적인 판단을 객관적인 언어로 번역**하기 위해서입니다. $V = \sum p_i v_i$와 같은 수식은 나의 막연한 선호도를 타인에게 논리적으로 설명하고 설득할 수 있는 도구가 됩니다. 

파이썬은 이러한 이론적 수식을 코드로 구현하여, 대규모 데이터를 바탕으로 우리의 주권 행사가 올바른 방향으로 나아가고 있는지 검증하는 강력한 수단이 됩니다.

## 3. 요약
1.  **의사결정**은 목표 달성을 위해 대안을 선택하는 논리적 과정입니다.
2.  **인간의 주권**이란 가치 판단과 책임의 주체가 인간임을 의미하며, 기술은 이를 보조하는 역할을 합니다.
3.  **규범적 이론**은 '최적의 방법'을, **기술적 이론**은 '현실적인 행태'를 다룹니다.
4.  우리는 파이썬을 통해 **주관적인 판단을 객관화**하고 보다 정교한 의사결정을 내릴 수 있습니다.

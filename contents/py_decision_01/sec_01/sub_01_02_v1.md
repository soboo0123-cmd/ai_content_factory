# 01 의사결정론에 대하여

## 1.2 평균치의 공과

### 도입
우리가 어떤 결정을 내릴 때 가장 먼저 확인하는 데이터는 무엇일까요? 아마도 십중팔구 **'평균(Mean)'**일 것입니다. "이 제품의 평균 수명은 얼마인가?", "이 주식의 평균 수익률은?", "우리 부서의 평균 성과는?" 등 평균은 복잡한 데이터를 단 하나의 숫자로 요약해 주는 강력한 도구입니다.

하지만 의사결정론의 관점에서 평균은 '가장 유용한 정보'인 동시에 '가장 위험한 함정'이 되기도 합니다. 이번 섹션에서는 평균이 가진 강력한 요약 능력(공, 功)과 그 이면에 숨겨진 치명적인 왜곡(과, 過)에 대해 심도 있게 살펴보겠습니다.

---

### 1. 평균의 공(功): 복잡성의 단순화

데이터 분석의 첫 번째 단계는 '데이터의 중심이 어디인가'를 파악하는 것입니다. 수천, 수만 개의 데이터를 일일이 확인하며 의사결정을 내리는 것은 불가능에 가깝습니다. 이때 평균은 다음과 같은 역할을 수행합니다.

1.  **대표성:** 집단 전체를 대표하는 단 하나의 수치를 제공하여 직관적인 이해를 돕습니다.
2.  **비교 가능성:** 서로 다른 두 집단의 규모가 다르더라도 평균을 통해 성과나 특성을 비교할 수 있게 합니다.
3.  **통계적 기초:** 대부분의 통계 모델과 의사결정 이론(예: 기대가치 이론)은 평균값을 기초로 설계됩니다.

`[시각화: 서로 다른 두 집단의 데이터 분포가 산만하게 퍼져 있다가, 각각의 평균선으로 수렴하며 비교되는 애니메이션]`

---

### 2. 평균의 과(過): 정보의 손실과 왜곡

평균의 가장 큰 문제는 **'데이터의 분포(Distribution)'**를 완전히 무시한다는 점입니다. "평균 수심 1m인 강을 건너다 1m 80cm인 사람이 빠져 죽는다"는 유명한 격언은 평균의 함정을 가장 잘 설명합니다.

#### (1) 아웃라이어(Outlier)의 영향
산술 평균은 극단적으로 크거나 작은 값에 매우 민감합니다. 예를 들어, 연봉이 3천만 원인 사원 9명이 있는 방에 연봉 100억 원인 회장님이 들어오는 순간, 그 방의 평균 연봉은 약 10억 원으로 치솟습니다. 이 10억 원이라는 숫자는 그 방에 있는 누구의 삶도 대변하지 못합니다.

#### (2) 비대칭 분포와 '평균의 실종'
데이터가 종 모양(정규분포)을 이루지 않고 한쪽으로 쏠려 있거나(Skewed), 양쪽 끝으로 갈라져 있다면(Bimodal) 평균은 아무런 의미를 갖지 못합니다. 

`[시각화: 슬라이더를 조절하여 아웃라이어 값을 높일 때, 평균(Mean) 선이 실제 데이터 밀집 지역에서 얼마나 멀어지는지 실시간 시각화]`

---

### 3. 파이썬으로 확인하는 평균의 함정

실제 데이터를 통해 평균이 어떻게 우리를 속일 수 있는지 파이썬 코드로 확인해 보겠습니다.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# 1. 데이터 생성
# 대부분의 사람들이 200~300 사이의 수치를 가지지만, 한 명의 극단적인 부자(10,000)가 있는 경우
data = [210, 225, 230, 240, 250, 260, 270, 280, 290, 10000]

# 2. 기초 통계량 계산
mean_val = np.mean(data)
median_val = np.median(data)

print(f"데이터의 평균: {mean_val}")
print(f"데이터의 중앙값: {median_val}")

# 3. 시각화
plt.figure(figsize=(10, 6))
plt.hist(data, bins=50, color='skyblue', edgecolor='black', alpha=0.7)
plt.axvline(mean_val, color='red', linestyle='dashed', linewidth=2, label=f'Mean: {mean_val}')
plt.axvline(median_val, color='green', linestyle='dashed', linewidth=2, label=f'Median: {median_val}')
plt.title("The Flaw of Averages")
plt.xlabel("Value")
plt.ylabel("Frequency")
plt.legend()
plt.show()
```

위 코드에서 평균은 약 1,024에 달하지만, 데이터의 90%는 300 미만에 몰려 있습니다. 의사결정자가 "우리 고객의 평균 구매액이 1,000이 넘으니 고가 전략을 쓰자"라고 결정한다면, 90%의 고객을 놓치는 우를 범하게 됩니다.

---

### 4. 올바른 의사결정을 위한 제언

평균의 함정에 빠지지 않기 위해 의사결정자는 다음 세 가지를 반드시 기억해야 합니다.

1.  **중앙값(Median)과 최빈값(Mode)을 함께 보라:** 데이터에 아웃라이어가 있다면 중앙값이 훨씬 더 '보통의 상태'를 잘 나타냅니다.
2.  **분산(Variance)과 표준편차(Standard Deviation)를 확인하라:** 평균에서 데이터가 얼마나 떨어져 있는지(위험도)를 파악해야 합니다.
3.  **데이터의 모양(Distribution)을 직접 그려보라:** 숫자로 된 요약표만 보지 말고 히스토그램이나 박스플롯을 통해 데이터의 생김새를 눈으로 확인해야 합니다.

---

### 요약
- **평균**은 복잡한 데이터를 한눈에 파악하게 해주는 훌륭한 요약 도구입니다.
- 하지만 **아웃라이어**가 존재하거나 **비대칭 분포**일 경우, 평균은 실제 현실을 심각하게 왜곡합니다.
- 현명한 의사결정자는 평균이라는 단일 수치에 의존하지 않고, **중앙값, 분산, 그리고 데이터의 분포**를 종합적으로 고려합니다.

`[시각화: 요약 섹션에서 '평균', '중앙값', '분산'의 관계를 인포그래픽 형태로 정리]`

# 3.3 상관계수의 산출 (v2)

## 1. 도입: 데이터 간의 '닮음'을 수치화하기
우리는 앞서 두 변수가 함께 변하는 경향성인 '공분산'에 대해 배웠습니다. 하지만 공분산만으로는 한계가 있습니다. 예를 들어, '키와 몸무게'의 관계를 센티미터($cm$)로 계산할 때와 미터($m$)로 계산할 때 공분산 값은 크게 달라집니다. 측정 단위에 상관없이 두 변수의 관계가 얼마나 밀접한지 객관적으로 비교하기 위해 도입된 것이 바로 **상관계수(Correlation Coefficient)**입니다.

본 장에서는 공분산의 한계를 극복하고, 두 변수의 선형적 관계를 $-1$에서 $1$ 사이의 값으로 표준화하여 산출하는 원리와 그 과정을 상세히 살펴봅니다.

**학습 목표:**
- 공분산에서 상관계수로 넘어가는 수학적 필연성을 이해합니다.
- 피어슨 상관계수의 산출 공식을 단계별로 분해하여 해석합니다.
- 실제 데이터를 바탕으로 상관계수를 직접 계산하는 능력을 배양합니다.

---

## 2. 본론: 상관계수 산출의 원리와 과정

### 2.1 공분산의 '단위 문제' 해결하기
상관계수를 구하는 핵심 아이디어는 **'표준화(Standardization)'**에 있습니다. 공분산은 두 변수의 편차를 곱하기 때문에, 각 변수의 흩어진 정도(표준편차)가 클수록 값도 무한정 커질 수 있습니다.

이를 해결하기 위해 공분산을 각 변수의 표준편차로 나누어 줍니다. 이렇게 하면 각 변수의 단위(unit)가 상쇄되어, 순수하게 '방향성과 강도'만을 나타내는 지표가 남게 됩니다.

`[시각화: 두 개의 산점도 비교. 왼쪽은 원본 데이터, 오른쪽은 표준화된(Z-score) 데이터를 배치하여 분포의 모양은 같으나 축의 단위가 변하는 모습을 애니메이션으로 구현]`

---

### 2.2 피어슨 상관계수(Pearson r)의 공식 분해
가장 널리 쓰이는 피어슨 상관계수($r$)의 공식은 다음과 같습니다.

$$r_{xy} = \frac{\sum_{i=1}^{n} (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{n} (x_i - \bar{x})^2} \sqrt{\sum_{i=1}^{n} (y_i - \bar{y})^2}}$$

이 공식은 세 가지 구성 요소의 결합으로 볼 수 있습니다.

1.  **분자: 공분산의 분자 ($\sum(x_i - \bar{x})(y_i - \bar{y})$)**
    - 두 변수가 같은 방향으로 움직이는지(양수), 반대 방향으로 움직이는지(음수)를 결정합니다.
2.  **분모 왼쪽: $x$의 변동성 ($\sqrt{\sum(x_i - \bar{x})^2}$)**
    - $x$ 데이터가 평균으로부터 얼마나 떨어져 있는지(편차 제곱의 합)를 나타냅니다.
3.  **분모 오른쪽: $y$의 변동성 ($\sqrt{\sum(y_i - \bar{y})^2}$)**
    - $y$ 데이터가 평균으로부터 얼마나 떨어져 있는지를 나타냅니다.

결국 상관계수는 **"두 변수가 함께 변하는 정도를 각 변수가 따로 변하는 정도의 최대치로 나눈 것"**이라고 정의할 수 있습니다.

---

### 2.3 단계별 산출 절차
상관계수를 직접 계산할 때는 다음의 4단계를 거칩니다.

**단계 1: 평균 구하기**
- 두 변수 $X$와 $Y$의 산술 평균($\bar{x}, \bar{y}$)을 구합니다.

**단계 2: 편차와 편차의 곱 계산**
- 각 데이터 포인트에 대해 $(x_i - \bar{x})$와 $(y_i - \bar{y})$를 구하고, 이 둘을 곱한 값들의 합을 구합니다. (분자 결정)

**단계 3: 각 변수의 편차 제곱합 계산**
- $(x_i - \bar{x})^2$의 합과 $(y_i - \bar{y})^2$의 합을 각각 구합니다. (분모 결정)

**단계 4: 공식에 대입**
- 위에서 구한 값들을 공식에 넣어 $-1$과 $1$ 사이의 최종 결과값을 도출합니다.

---

### 2.4 파이썬을 활용한 산출 예제
이론적인 계산 과정을 코드로 구현하면 그 원리가 더 명확해집니다.

```python
import numpy as np

# 데이터 생성
x = np.array([10, 20, 30, 40, 50])
y = np.array([12, 24, 28, 45, 55])

# 1. 평균 계산
mean_x, mean_y = np.mean(x), np.mean(y)

# 2. 분자: 편차 곱의 합 (Covariance Numerator)
covariance_num = np.sum((x - mean_x) * (y - mean_y))

# 3. 분모: 각 변수의 편차 제곱합의 제곱근 (Standard Deviation terms)
std_x_num = np.sqrt(np.sum((x - mean_x)**2))
std_y_num = np.sqrt(np.sum((y - mean_y)**2))

# 4. 상관계수 산출
r = covariance_num / (std_x_num * std_y_num)

print(f"산출된 상관계수 r: {r:.4f}")
# 결과: 0.9901 (매우 강한 양의 상관관계)
```

`[시각화: 사용자가 데이터를 직접 입력하거나 점을 드래그하여 배치하면, 실시간으로 위 코드가 실행되어 r값이 계산되는 인터랙티브 대시보드]`

## 3. 요약: 상관계수 산출의 핵심 포인트

1.  **표준화의 산물:** 상관계수는 단위가 서로 다른 두 변수를 동일한 잣대로 비교하기 위해 공분산을 표준편차로 나눈 '표준화된 공분산'입니다.
2.  **무차원 수(Dimensionless):** 계산 과정에서 단위가 서로 상쇄되므로, 결과값은 단위가 없는 순수한 수치입니다. 이 덕분에 전 세계 어디서든 동일한 기준으로 관계의 강도를 비교할 수 있습니다.
3.  **값의 범위:** 코시-슈바르츠 부등식의 원리에 의해 항상 $-1 \le r \le 1$의 범위를 가집니다.
    - $r = 1$: 완벽한 직선 관계 (양)
    - $r = -1$: 완벽한 직선 관계 (음)
    - $r = 0$: 선형적인 관계가 전혀 없음

상관계수의 산출법을 이해하는 것은 데이터 과학에서 두 변수 간의 연결 고리를 찾는 가장 기초적이면서도 강력한 도구를 얻는 것과 같습니다.

# 3.3 상관계수의 산출

## 도입
우리는 앞선 절에서 두 변수가 서로 어떻게 움직이는지, 즉 '상관성'의 개념에 대해 배웠습니다. 하지만 단순히 "두 변수가 양의 관계에 있다" 혹은 "음의 관계에 있다"라고 말하는 것만으로는 충분하지 않습니다. 데이터 분석과 의사결정의 과정에서는 **"얼마나 강하게"** 관계를 맺고 있는지를 수치로 표현하는 것이 매우 중요합니다.

이번 섹션에서는 두 연속형 변수 간의 선형적 관계 강도를 나타내는 대표적인 척도인 **피어슨 상관계수(Pearson Correlation Coefficient)**의 수학적 원리를 이해하고, 파이썬을 이용해 이를 직접 산출하는 방법을 학습합니다.

---

## 본론

### 1. 공분산(Covariance)에서 상관계수까지
상관계수를 이해하기 위한 출발점은 **공분산**입니다. 공분산은 두 변수의 편차를 곱한 값들의 평균으로, 두 변수가 함께 변하는 경향성을 나타냅니다.

$$ \text{Cov}(X, Y) = \frac{\sum_{i=1}^{n} (X_i - \bar{X})(Y_i - \bar{Y})}{n-1} $$

하지만 공분산에는 치명적인 약점이 있습니다. 바로 **'단위(Unit)'에 민감하다**는 점입니다. 예를 들어, 키(cm)와 몸무게(kg)의 관계를 구할 때와 키(m)와 몸무게(g)의 관계를 구할 때 공분산의 값은 완전히 달라집니다. 관계의 본질은 같은데 숫자의 크기만 바뀌는 것이죠.

이 문제를 해결하기 위해 공분산을 각 변수의 표준편차로 나누어 **'표준화'**한 것이 바로 상관계수($r$)입니다.

`[시각화: 공분산의 값이 단위 변경에 따라 커지는 모습과, 표준화 이후 -1~1 사이로 고정되는 과정을 애니메이션으로 표현]`

### 2. 피어슨 상관계수의 수식 이해
피어슨 상관계수의 공식은 다음과 같습니다.

$$ r_{XY} = \frac{\sum (X_i - \bar{X})(Y_i - \bar{Y})}{\sqrt{\sum (X_i - \bar{X})^2 \sum (Y_i - \bar{Y})^2}} $$

이 식을 풀어서 해석하면 다음과 같은 의미를 갖습니다.
1. **분자 (공분산의 핵심):** 두 변수가 같은 방향으로 움직이면 양수, 반대 방향이면 음수가 됩니다.
2. **분모 (표준편차의 곱):** 결과값을 $-1$에서 $1$ 사이의 범위로 가둡니다(Scaling).

결과값 $r$은 다음과 같은 특성을 가집니다.
- **$r = 1$:** 완벽한 양의 선형 관계
- **$r = -1$:** 완벽한 음의 선형 관계
- **$r = 0$:** 선형 상관관계 없음

### 3. 파이썬을 활용한 상관계수 산출
이제 파이썬의 `NumPy`와 `Pandas` 라이브러리를 사용하여 실제로 상관계수를 계산해 보겠습니다.

#### 1) NumPy를 이용한 계산
`numpy`는 `corrcoef` 함수를 통해 상관계수 행렬을 제공합니다.

```python
import numpy as np

# 데이터 생성: 공부 시간과 시험 점수
study_hours = [2, 4, 6, 8, 10]
test_scores = [40, 55, 65, 85, 95]

# 상관계수 계산
correlation_matrix = np.corrcoef(study_hours, test_scores)
r = correlation_matrix[0, 1]

print(f"공부 시간과 시험 점수의 상관계수: {r:.4f}")
```

#### 2) Pandas를 이용한 계산
실제 데이터 분석 환경에서는 `DataFrame` 객체의 `corr()` 메서드를 가장 많이 사용합니다.

```python
import pandas as pd

# 데이터프레임 생성
data = {
    '공부시간': [2, 4, 6, 8, 10],
    '시험점수': [40, 55, 65, 85, 95],
    '게임시간': [5, 4, 3, 1, 0]
}
df = pd.DataFrame(data)

# 전체 변수 간의 상관계수 행렬 산출
corr_matrix = df.corr()

print("상관계수 행렬:")
print(corr_matrix)
```

`[시각화: Pandas의 corr() 결과인 Heatmap 시각화. 상관계수가 높을수록 진한 색으로 표시]`

### 4. 산출 시 주의사항: 이상치(Outlier)의 영향
상관계수는 평균과 표준편차를 기반으로 계산되기 때문에, 극단적인 값(이상치) 하나에 의해 값이 크게 왜곡될 수 있습니다. 

- 데이터가 적을 때 하나의 특이값이 상관계수를 0.9에서 0.1로 떨어뜨릴 수도 있습니다.
- 따라서 상관계수 수치만 보고 판단하기보다는, 반드시 **산점도(Scatter Plot)**를 그려 데이터의 분포를 육안으로 확인해야 합니다.

`[시각화: 인터렉티브 산점도. 사용자가 점 하나를 마우스로 드래그하여 옮길 때마다 실시간으로 계산되는 r의 값 변화를 보여줌]`

---

## 요약
1. **상관계수의 정의:** 공분산을 각 변수의 표준편차로 나눈 값으로, $-1$부터 $1$ 사이의 값을 가집니다.
2. **수학적 원리:** 두 변수의 변화 방향성을 표준화하여 단위의 영향을 제거한 것입니다.
3. **파이썬 구현:** `np.corrcoef()` 또는 `df.corr()`를 사용하여 손쉽게 구할 수 있습니다.
4. **해석의 주의점:** 상관계수는 선형적인 관계만을 측정하며, 이상치에 민감하므로 시각화와 병행해야 합니다.

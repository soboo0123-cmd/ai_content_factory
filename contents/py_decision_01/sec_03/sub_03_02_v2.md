# 3.2 상관계수 (Correlation Coefficient)

## 도입: 두 변수의 ‘운명적 동행’을 숫자로 측정하기
우리는 일상 속에서 두 사건이 서로 밀접하게 연결되어 있다는 느낌을 자주 받습니다. "공부 시간이 늘어날수록 성적이 오른다", "기온이 높아질수록 아이스크림 판매량이 증가한다"와 같은 문장들은 두 변수 사이의 관계를 설명합니다. 

데이터 분석에서 이러한 '관계의 깊이'를 단순히 느낌이 아닌, 객관적인 수치로 나타낸 것이 바로 **상관계수(Correlation Coefficient)**입니다. 상관계수를 이해하면 데이터 속에 숨겨진 흐름을 파악하고, 한 변수의 변화를 통해 다른 변수의 변화를 예측하는 기초를 다질 수 있습니다.

---

## 1. 상관계수의 출발점: 공분산(Covariance)의 한계
상관계수를 이해하기 위해서는 먼저 **공분산**이라는 개념을 알아야 합니다. 공분산은 두 변수가 '함께(Co-) 변하는(Variance)' 정도를 나타냅니다.

### 공분산의 원리
데이터 $X$와 $Y$가 있을 때, 각 데이터 포인트가 각자의 평균에서 얼마나 떨어져 있는지를 곱하여 합산한 뒤 데이터 개수로 나눕니다.
$$ \text{cov}(X, Y) = \frac{\sum_{i=1}^{n} (X_i - \bar{X})(Y_i - \bar{Y})}{n-1} $$

- 두 변수가 같은 방향으로 움직이면(둘 다 평균보다 크거나, 둘 다 평균보다 작으면) 결과는 **양수(+)**가 됩니다.
- 두 변수가 반대 방향으로 움직이면 결과는 **음수(-)**가 됩니다.

### 공분산의 치명적인 약점
공분산은 값의 크기가 '단위'에 의존한다는 큰 단점이 있습니다. 예를 들어, 키를 'm'로 계산할 때와 'cm'로 계산할 때 공분산 값은 100배 차이가 납니다. 값이 1,000이라고 해서 두 변수가 매우 밀접하다고 단정할 수 없는 이유입니다.

`[시각화: 단위 변경에 따라 공분산 수치만 크게 변하는 인터랙티브 차트]`

---

## 2. 피어슨 상관계수: 표준화된 관계의 척도
이러한 공분산의 단점을 극복하기 위해 등장한 것이 **피어슨 상관계수(Pearson Correlation Coefficient, $r$)**입니다. 공분산을 각 변수의 표준편차의 곱으로 나누어, 값의 범위를 항상 **-1에서 1 사이**로 고정한 것입니다.

### 수식 이해하기
$$ r = \frac{\text{cov}(X, Y)}{\sigma_X \sigma_Y} $$
(여기서 $\sigma_X, \sigma_Y$는 각 변수의 표준편차입니다.)

이 수식은 공분산에서 '단위'의 영향력을 제거하고 '순수한 관계의 강도'만을 남기는 과정(표준화)이라고 볼 수 있습니다.

---

## 3. 상관계수 값의 해석
상관계수 $r$은 두 가지 정보를 동시에 전달합니다.

### 1) 부호 (+ / -): 방향성
- **$r > 0$ (양의 상관관계):** $X$가 증가할 때 $Y$도 증가합니다. (예: 키와 몸무게)
- **$r < 0$ (음의 상관관계):** $X$가 증가할 때 $Y$는 감소합니다. (예: 자동차의 연비와 중량)
- **$r = 0$ (무상관):** 두 변수 사이에 선형적인 관계가 없습니다.

### 2) 절댓값 (0 ~ 1): 강도
- **0.0 ~ 0.2:** 관계가 거의 없음
- **0.3 ~ 0.6:** 뚜렷한 상관관계가 있음
- **0.7 ~ 1.0:** 매우 강한 상관관계가 있음

`[시각화: r 값이 1.0, 0.5, 0, -0.5, -1.0일 때의 산점도 분포 변화 슬라이더]`

---

## 4. 파이썬 실습: 상관계수 계산하기
데이터 분석 라이브러리인 `pandas`와 `numpy`를 사용하면 간단하게 상관계수를 구할 수 있습니다.

```python
import pandas as pd
import numpy as np

# 가상의 데이터 생성 (공부 시간과 시험 점수)
data = {
    'Study_Hours': [2, 3, 5, 7, 9],
    'Test_Score': [50, 60, 75, 85, 95]
}
df = pd.DataFrame(data)

# 상관계수 행렬 계산
correlation_matrix = df.corr()

print("상관계수 행렬:")
print(correlation_matrix)

# 특정 두 변수 간의 상관계수 출력
r = df['Study_Hours'].corr(df['Test_Score'])
print(f"\n공부 시간과 시험 점수 사이의 상관계수: {r:.2f}")
```

## 5. 주의할 점: 상관관계는 인과관계가 아니다
상관계수를 다룰 때 가장 주의해야 할 함정이 있습니다. **"상관관계가 있다고 해서 반드시 인과관계(원인과 결과)가 있는 것은 아니다"**라는 점입니다.

- **예시:** 여름철 아이스크림 판매량과 익사 사고 횟수는 높은 양의 상관관계를 보입니다. 하지만 아이스크림이 익사 사고를 일으키는 것은 아닙니다. '기온 상승'이라는 제3의 변수가 두 현상에 영향을 준 것뿐입니다.

또한, 상관계수는 **선형적(직선) 관계**만을 측정합니다. 데이터가 원형이나 V자 형태로 뚜렷한 관계를 맺고 있어도, 선형적이지 않다면 상관계수는 0에 가깝게 나타날 수 있습니다.

## 요약 및 핵심 포인트
1. **상관계수**는 두 변수가 함께 변하는 정도를 -1에서 1 사이의 숫자로 나타낸 것입니다.
2. **공분산**의 단위 문제를 해결하기 위해 표준편차로 나누어 정규화한 값입니다.
3. **+1**에 가까울수록 강한 양의 관계, **-1**에 가까울수록 강한 음의 관계를 의미합니다.
4. 상관계수는 **선형성**만을 측정하며, **인과관계**를 직접적으로 설명하지는 않습니다.

# 3.1 상관계수 (Correlation Coefficient)

## 1. 도입: 데이터 사이의 '연결고리'를 찾아서
우리가 마주하는 수많은 데이터는 홀로 존재하지 않습니다. 키가 크면 몸무게가 많이 나가는 경향이 있고, 기온이 올라가면 아이스크림 판매량이 늘어나는 식입니다. 이처럼 한 변수가 변할 때 다른 변수가 어떻게 함께 변하는지를 파악하는 것은 데이터 과학의 첫걸음입니다.

**상관계수(Correlation Coefficient)**는 두 변수 사이의 선형적 관계가 얼마나 강한지, 그리고 어느 방향으로 움직이는지를 하나의 숫자로 요약해 주는 강력한 지표입니다. 이번 절에서는 상관계수가 왜 필요한지, 어떤 원리로 계산되는지, 그리고 해석 시 주의할 점은 무엇인지 깊이 있게 살펴보겠습니다.

---

## 2. 본론: 관계의 크기를 측정하는 원리

### (1) 공분산(Covariance): 함께 움직이는 정도
상관계수를 이해하기 위한 출발점은 **공분산**입니다. 두 변수 $X$와 $Y$가 있을 때, $X$가 커질 때 $Y$도 커지면 공분산은 양(+)의 값을, 반대로 $Y$가 작아지면 음(-)의 값을 가집니다.

$$Cov(X, Y) = \frac{\sum_{i=1}^{n} (X_i - \bar{X})(Y_i - \bar{Y})}{n-1}$$

하지만 공분산에는 치명적인 약점이 있습니다. 바로 **'단위(Unit)'에 의존한다**는 점입니다. 예를 들어, 키를 cm로 측정할 때와 m로 측정할 때 공분산의 값은 완전히 달라집니다. 관계의 강도는 그대로인데 숫자의 크기만 변하는 것이죠.

### (2) 표준화(Standardization): 단위의 벽을 허물다
공분산의 문제를 해결하기 위해 도입된 것이 바로 **피어슨 상관계수(Pearson Correlation Coefficient)**입니다. 공분산을 각 변수의 표준편차($\sigma$)로 나누어, 값의 범위를 $-1$에서 $1$ 사이로 고정(정규화)시킨 것입니다.

$$\rho_{X,Y} = \frac{Cov(X, Y)}{\sigma_X \sigma_Y}$$

이렇게 계산된 상관계수 $r$ (혹은 $\rho$)은 다음과 같은 특징을 가집니다.
- **$r = 1$:** 완벽한 양의 선형 관계 (한쪽이 늘면 다른 쪽도 일정하게 늘어남)
- **$r = -1$:** 완벽한 음의 선형 관계 (한쪽이 늘면 다른 쪽은 일정하게 줄어듦)
- **$r = 0$:** 선형적인 상관관계가 없음

`[시각화: 상관계수 값(-1.0, -0.5, 0, 0.5, 1.0)에 따른 산점도(Scatter Plot) 변화 애니메이션]`

### (3) 시각적 비유: 두 무용수의 호흡
상관계수를 **'두 무용수의 커플 댄스'**에 비유해 봅시다.
- **강한 양의 상관계수:** 두 무용수가 손을 맞잡고 거울을 보듯 똑같은 방향으로 완벽하게 일치하여 움직이는 상태입니다.
- **강한 음의 상관계수:** 한 무용수가 전진할 때 다른 무용수가 똑같은 거리만큼 후진하며, 대칭적인 움직임을 유지하는 상태입니다.
- **상관계수 0:** 두 무용수가 서로의 움직임을 전혀 고려하지 않고 각자 무대를 돌아다니는 상태입니다. 한 명이 움직여도 다른 명의 위치를 전혀 예측할 수 없습니다.

### (4) 파이썬 코드 예제
실제 데이터를 통해 상관계수를 구하는 방법은 매우 간단합니다. Pandas 라이브러리의 `.corr()` 함수를 주로 사용합니다.

```python
import pandas as pd
import numpy as np

# 가상의 데이터 생성
data = {
    '공부시간': [2, 4, 6, 8, 10],
    '시험점수': [50, 65, 70, 85, 95],
    '수면시간': [8, 7, 6, 5, 4]
}
df = pd.DataFrame(data)

# 상관계수 행렬 계산
correlation_matrix = df.corr()

print("상관계수 행렬:")
print(correlation_matrix)

# 결과 해석:
# 공부시간과 시험점수는 1에 가까운 양의 상관관계를 보일 것입니다.
# 공부시간과 수면시간은 -1에 가까운 음의 상관관계를 보일 것입니다.
```

## 3. 주의사항: 상관계수의 함정

상관계수를 해석할 때는 반드시 다음의 두 가지를 명심해야 합니다.

1.  **선형성(Linearity)의 한계:** 피어슨 상관계수는 오직 **직선 형태의 관계**만 측정합니다. 만약 데이터가 $Y = X^2$과 같은 곡선 형태(이차함수)로 완벽하게 얽혀 있더라도, 상관계수는 0에 가깝게 나올 수 있습니다.
2.  **상관관계는 인과관계가 아니다:** "아이스크림 판매량과 익사 사고 발생률은 양의 상관관계가 있다"는 통계가 있습니다. 하지만 아이스크림이 익사 사고를 유발하는 것은 아닙니다. '여름철 기온 상승'이라는 **제3의 변수(잠재 변수)**가 두 현상에 영향을 준 것이기 때문입니다.

`[시각화: 비선형 관계(예: 원형, U자형 데이터 분포)에서도 상관계수가 0으로 나타나는 사례 제시]`

## 4. 요약 및 핵심 포인트

-   **개념:** 두 변수가 함께 변하는 경향성을 -1에서 1 사이의 숫자로 나타낸 것.
-   **방향:** 양수(+)는 같은 방향, 음수(-)는 반대 방향으로 움직임을 의미함.
-   **강도:** 절댓값이 1에 가까울수록 데이터가 직선에 가깝게 모여 있음을 의미함.
-   **주의:** 상관계수는 '직선 관계'만을 측정하며, 결과가 곧 '원인과 결과'를 의미하지는 않음.

상관계수는 데이터의 전반적인 분위기를 파악하는 훌륭한 나침반입니다. 하지만 숫자에만 매몰되지 말고, 반드시 산점도를 그려 데이터의 실제 모양을 눈으로 확인하는 습관이 중요합니다.

# 3.4 상관계수를 이용한 응용 예

앞서 우리는 상관계수의 개념과 계산 방법, 그리고 그 의미를 해석하는 방법을 배웠습니다. 하지만 "상관계수가 0.8이다"라는 수치를 아는 것만으로는 부족합니다. 실제 의사결정 과정에서 이 수치를 어떻게 활용하여 가치를 창출할 수 있는지가 중요합니다. 

이 섹션에서는 데이터 과학, 금융, 그리고 마케팅 분야에서 상관계수가 구체적으로 어떻게 응용되는지 살펴보겠습니다.

---

## 1. 데이터 전처리: 특성 선택 (Feature Selection)

머신러닝 모델을 구축할 때, 우리는 수많은 변수(특성)를 마주하게 됩니다. 모든 데이터를 모델에 넣는 것이 항상 좋은 결과를 보장하지는 않습니다. 이때 상관계수는 중요한 가이드 역할을 합니다.

### (1) 타겟 변수와의 관계 파악
우리가 예측하고자 하는 '정답(타겟 변수)'과 높은 상관관계를 가진 변수를 우선적으로 선택해야 합니다. 예를 들어, 집값을 예측할 때 '방의 개수'와 '집값'의 상관계수가 높다면, '방의 개수'는 예측에 매우 중요한 변수가 됩니다.

### (2) 다중공선성(Multicollinearity) 방지
독립 변수들끼리 너무 강한 상관관계(보통 0.9 이상)를 가지는 경우를 '다중공선성'이라고 합니다. 이는 모델의 해석력을 떨어뜨리고 성능을 불안정하게 만듭니다. 상관계수 행렬을 통해 서로 비슷하게 움직이는 변수 중 하나를 제거하거나 결합함으로써 모델을 더 가볍고 강력하게 만들 수 있습니다.

`[시각화: 상관계수 히트맵(Heatmap)을 통해 변수 간의 관계를 색상으로 표현하고, 특정 임계값 이상의 변수를 하이라이트하는 기능]`

---

## 2. 금융 및 투자: 포트폴리오 분산 투자

금융 분야에서 상관계수는 '위험 관리'의 핵심 도구입니다. 현대 포트폴리오 이론의 핵심은 "계란을 한 바구니에 담지 마라"는 것입니다.

### 상관계수를 이용한 리스크 헤징(Hedging)
투자자는 서로 **음의 상관관계**를 갖거나 **상관계수가 낮은** 자산들을 섞어서 포트폴리오를 구성합니다.
- **예시:** 주식과 채권은 일반적으로 낮은 상관관계를 보입니다. 주식 시장이 폭락할 때 채권 가격이 오르거나 유지된다면, 전체 자산의 손실을 방어할 수 있습니다.
- 만약 모든 자산의 상관계수가 1에 가깝다면, 시장 위기 시 모든 자산이 동시에 하락하여 분산 투자의 효과가 사라지게 됩니다.

---

## 3. 추천 시스템: 협업 필터링 (Collaborative Filtering)

넷플릭스나 유튜브에서 "당신이 좋아할 만한 콘텐츠"를 추천할 때도 상관계수가 사용됩니다.

### 사용자 간 유사도 측정
나와 취향이 비슷한 사람을 찾기 위해 **피어슨 상관계수(Pearson Correlation Coefficient)**를 사용합니다. 
- 사용자 A와 사용자 B가 매긴 여러 영화의 평점들을 비교하여 상관계수를 구합니다. 
- 상관계수가 1에 가깝다면 두 사람의 취향은 매우 유사한 것입니다. 
- 시스템은 사용자 B가 높게 평가했지만 사용자 A는 아직 보지 않은 영화를 A에게 추천합니다.

## 4. 파이썬 실습: 상관계수 응용 (히트맵 분석)

실제 데이터를 활용하여 변수 간의 관계를 한눈에 파악하는 코드를 작성해 보겠습니다.

```python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt
import numpy as np

# 1. 예시 데이터 생성 (주택 가격 관련 가상 데이터)
data = {
    'Price': [50, 60, 80, 45, 90, 100],        # 집값
    'Rooms': [2, 3, 4, 2, 4, 5],               # 방 개수
    'Distance': [10, 5, 2, 12, 1, 0.5],        # 도심과의 거리
    'Year': [2010, 2015, 2020, 2008, 2022, 2023], # 건축연도
    'Income': [500, 600, 800, 440, 910, 1050]  # 주변 가구 소득
}
df = pd.DataFrame(data)

# 2. 상관계수 행렬 계산
corr_matrix = df.corr()

# 3. 히트맵 시각화
plt.figure(figsize=(8, 6))
sns.heatmap(corr_matrix, annot=True, cmap='RdBu', fmt=".2f")
plt.title("Variable Correlation Matrix")
plt.show()

# 4. 특정 조건(예: 상관계수 0.8 이상) 변수 추출
high_corr = corr_matrix[corr_matrix > 0.8]
print("High Correlation Pairs:\n", high_corr)
```

### 코드 설명
- `df.corr()`: 데이터프레임 내의 모든 숫자형 변수 간의 피어슨 상관계수를 계산합니다.
- `sns.heatmap()`: 계산된 상관계수를 시각화합니다. `RdBu` 컬러맵은 양의 상관관계는 파란색, 음의 상관관계는 빨간색으로 표시하여 직관적인 이해를 돕습니다.
- **분석 결과 예시:** 만약 `Price`와 `Income`의 상관계수가 0.99로 나타난다면, 주변 소득 수준이 집값 결정의 결정적 요인임을 알 수 있습니다.

## 요약

1.  **특성 선택:** 상관계수를 통해 예측 모델에 중요한 변수를 선별하고, 중복된 정보를 가진 변수를 제거하여 모델의 효율성을 높입니다.
2.  **리스크 관리:** 금융에서 서로 상관관계가 낮은 자산을 조합함으로써 투자 위험을 분산시킵니다.
3.  **유사도 측정:** 추천 시스템에서 사용자 간 혹은 아이템 간의 취향 유사성을 계산하는 척도로 활용됩니다.
4.  **시각화 활용:** 상관계수 행렬과 히트맵을 사용하면 복잡한 데이터 속에서도 핵심적인 관계를 빠르게 파악할 수 있습니다.

상관계수는 단순한 통계 수치를 넘어, 복잡한 현실 세계의 데이터를 단순화하고 올바른 의사결정을 내리게 돕는 강력한 도구입니다.

# 03 상관계수

## 3.1 상관계수의 이해

### 1. 도입
우리는 일상 속에서 "두 대상이 서로 밀접하게 관련되어 있다"는 표현을 자주 사용합니다. 예를 들어, '공부 시간이 길어질수록 성적이 오른다'거나 '기온이 올라갈수록 아이스크림 판매량이 늘어난다'는 식의 관계입니다. 

데이터 과학과 의사결정 모델링에서 가장 먼저 해야 할 일 중 하나는 바로 이러한 **변수 간의 관계**를 수치적으로 파악하는 것입니다. 단순히 "관계가 있다"라고 말하는 것을 넘어, **"얼마나 강하게, 어떤 방향으로 관계가 있는가?"**를 정밀하게 측정하는 도구가 바로 **상관계수(Correlation Coefficient)**입니다.

이 섹션에서는 상관계수의 개념과 수학적 원리, 그리고 파이썬을 이용한 계산 방법을 학습합니다.

---

### 2. 상관관계란 무엇인가?
상관관계(Correlation)는 한 변수가 변할 때 다른 변수가 어떻게 변하는지를 나타내는 통계적 척도입니다. 이는 크게 두 가지 요소로 결정됩니다.

1.  **방향(Direction):** 
    *   **양(+)의 상관관계:** 한 변수가 증가할 때 다른 변수도 함께 증가하는 경우.
    *   **음(-)의 상관관계:** 한 변수가 증가할 때 다른 변수는 감소하는 경우.
2.  **강도(Strength):** 데이터들이 얼마나 직선에 가깝게 모여 있는지를 나타냅니다.

`[시각화: 산점도(Scatter Plot)를 통해 양의 상관관계, 음의 상관관계, 관계없음(무상관)의 형태를 보여주는 인터랙티브 그래프]`

### 3. 피어슨 상관계수의 원리
가장 널리 쓰이는 방식은 **피어슨 상관계수(Pearson Correlation Coefficient)**입니다. 기호로는 보통 $r$ 또는 $\rho$(로)라고 표기합니다.

#### 3.1 수학적 정의
두 변수 $X$와 $Y$에 대하여, 상관계수 $r$은 다음과 같이 정의됩니다.

$$r = \frac{\sum_{i=1}^{n} (X_i - \bar{X})(Y_i - \bar{Y})}{\sqrt{\sum_{i=1}^{n} (X_i - \bar{X})^2 \cdot \sum_{i=1}^{n} (Y_i - \bar{Y})^2}}$$

이 식의 의미를 풀어서 설명하면 다음과 같습니다.
*   **분자(공분산):** $X$와 $Y$가 각자의 평균에서 얼마나 같은 방향으로 움직이는지를 나타냅니다. 만약 $X$가 커질 때 $Y$도 커지면 분자는 큰 양수가 됩니다.
*   **분모(표준편차의 곱):** 결과값을 $-1$에서 $1$ 사이로 정규화(Normalization)하는 역할을 합니다. 이를 통해 데이터의 단위(예: cm, kg, 원)에 상관없이 관계의 강도만을 비교할 수 있게 됩니다.

#### 3.2 상관계수 값의 해석
상관계수 $r$은 항상 $-1$과 $1$ 사이의 값을 가집니다.
*   **$r = 1$:** 완벽한 양의 선형 관계 (모든 점이 직선 위에 있음)
*   **$0.7 \leq r < 1$:** 강한 양의 상관관계
*   **$0.3 \leq r < 0.7$:** 뚜렷한 양의 상관관계
*   **$-0.3 < r < 0.3$:** 상관관계가 거의 없음
*   **$r = -1$:** 완벽한 음의 선형 관계

### 4. 파이썬 실습: 상관계수 계산하기
파이썬의 `pandas`와 `numpy` 라이브러리를 사용하면 복잡한 수식을 직접 계산하지 않고도 간편하게 상관계수를 구할 수 있습니다.

```python
import pandas as pd
import numpy as np

# 1. 예시 데이터 생성 (공부 시간과 시험 점수)
data = {
    '공부시간': [2, 4, 6, 8, 10],
    '시험점수': [40, 55, 65, 80, 95],
    '수면시간': [8, 7, 6, 5, 4]
}

df = pd.DataFrame(data)

# 2. 피어슨 상관계수 계산
correlation_matrix = df.corr()

print("--- 상관계수 행렬 ---")
print(correlation_matrix)

# 3. 특정 변수 간의 상관계수 출력
r_value = df['공부시간'].corr(df['시험점수'])
print(f"\n공부시간과 시험점수의 상관계수: {r_value:.2f}")
```

**코드 설명:**
- `df.corr()` 메소드는 데이터프레임 내의 모든 숫자형 열 사이의 상관계수를 행렬 형태로 반환합니다.
- 결과값을 보면 '공부시간'과 '시험점수'는 1에 가까운 높은 양의 상관관계를, '공부시간'과 '수면시간'은 -1에 가까운 음의 상관관계를 보일 것입니다.

---

### 5. 주의사항: "상관관계는 인과관계가 아니다"
데이터 분석에서 가장 주의해야 할 격언입니다. 두 변수의 상관계수가 높다고 해서 반드시 **"A가 B의 원인이다"**라고 단정 지을 수 없습니다.

*   **예시:** 아이스크림 판매량과 익사 사고 횟수는 높은 양의 상관관계를 보입니다. 하지만 아이스크림이 익사 사고를 일으키는 것은 아닙니다. '여름철 기온 상승'이라는 제3의 변수가 두 현상에 모두 영향을 준 것이기 때문입니다.

이를 **허위 상관(Spurious Correlation)**이라고 하며, 의사결정 시에는 도메인 지식을 바탕으로 인과관계를 신중히 검토해야 합니다.

---

### 요약 및 핵심 포인트
1.  **상관계수**는 두 변수 사이의 선형적 관계의 방향과 강도를 수치화한 것이다.
2.  **값의 범위**는 $-1$부터 $1$까지이며, $0$에 가까울수록 관계가 약하다.
3.  **피어슨 상관계수**는 데이터의 단위를 제거하고 관계만을 보기 위해 공분산을 표준편차로 나눈 값이다.
4.  **상관관계와 인과관계**를 혼동해서는 안 되며, 결과 해석 시 배경 상황을 고려해야 한다.

### 의사결정의 중요성

### 학습 목표

- **휴리스틱(Heuristics)**의 정의와 장단점을 알고, 인공지능 알고리즘에서의 활용 사례를 확인합니다.

## 2. 본론: 합리성의 이상과 현실의 제약

### 2.1 완벽한 합리성 (Perfect Rationality)

전통적인 경제학이나 초기 인공지능 이론에서는 의사결정자를 '완벽하게 합리적인 존재'로 가정합니다. 이를 **기대 효용 극대화 원칙**이라고 합니다.

#### 기대 효용(Expected Utility) 공식
어떤 선택지 $A$의 가치는 발생 가능한 모든 결과($x_i$)와 그 확률($P(x_i)$), 그리고 그 결과가 주는 유용성($U(x_i)$)의 곱의 합으로 표현됩니다.

$$E[U(A)] = \sum_{i=1}^{n} P(x_i) U(x_i)$$

[시각화: 슬라이더를 조절하여 확률($P$)과 효용($U$)이 변할 때, 여러 선택지의 기대 효용 그래프가 실시간으로 변동하며 최적의 선택지(Max)를 강조하는 대화형 차트]

**완벽한 합리성을 위한 전제 조건:**
1. **모든 정보의 공개:** 발생할 수 있는 모든 선택지와 결과를 알고 있어야 함.
2. **무한한 계산 능력:** 복잡한 확률 계산을 즉각적으로 수행할 수 있어야 함.
3. **일관된 선호도:** 가치 판단 기준이 변하지 않아야 함.

### 2.2 제한된 합리성 (Bounded Rationality)

1950년대 허버트 사이먼(Herbert Simon)은 인간과 컴퓨터가 현실적으로 완벽한 합리성을 달성할 수 없음을 지적하며 **'제한된 합리성'** 개념을 제시했습니다.

*   **시간의 제약:** 의사결정에는 마감 기한이 존재합니다.
*   **정보의 불완전성:** 모든 데이터를 수집하는 것은 비용이 너무 많이 들거나 불가능합니다.
*   **인지적/계산적 한계:** 인간의 뇌나 컴퓨터의 CPU/메모리 자원은 한정되어 있습니다.

이 관점에서 의사결정자는 **최적화(Optimization)** 대신 **만족화(Satisficing)** 전략을 취합니다. 즉, '최고의 선택'이 아니라 '충분히 좋은(Good enough) 선택'을 찾는 것입니다.

### 2.3 휴리스틱(Heuristics): 생각의 지름길

휴리스틱이란 복잡한 문제를 빠르고 효율적으로 해결하기 위해 사용하는 **경험적인 규칙(Rule of Thumb)**입니다. 논리적으로 완벽한 정답을 보장하지는 않지만, 현실적인 시간 내에 합리적인 수준의 해답을 제공합니다.

#### 대표적인 휴리스틱 사례
1.  **가용성 휴리스틱(Availability Heuristic):** 최근에 본 정보나 기억에 잘 남는 정보를 바탕으로 확률을 판단하는 경향.
2.  **대표성 휴리스틱(Representativeness Heuristic):** 특정 대상이 속한 집단의 전형적인 특징을 보고 판단하는 지름길.
3.  **고정 및 조정(Anchoring and Adjustment):** 처음에 주어진 숫자나 기준점에 얽매여 판단하는 현상.

[시각화: 복잡한 미로(Search Space)에서 모든 길을 탐색하는 '완전 탐색'과 특정 규칙(벽 따라가기 등)을 사용하여 빠르게 탈출하는 '휴리스틱 탐색'의 속도 비교 애니메이션]

---

## 3. 알고리즘 예제: 완전 탐색 vs 휴리스틱 탐색

컴퓨터 공학에서 합리적 결정과 휴리스틱의 차이를 가장 잘 보여주는 예는 **'배낭 문제(Knapsack Problem)'**입니다. 제한된 무게 내에서 가치의 합이 최대가 되도록 물건을 담는 문제입니다.

```python
# 1. 탐욕적 알고리즘 (Greedy Heuristic) - '무게 대비 가치가 높은 순'으로 담기
def heuristic_knapsack(items, capacity):
    # 단가(가치/무게) 기준으로 정렬하는 휴리스틱 사용
    items.sort(key=lambda x: x['value']/x['weight'], reverse=True)
    
    total_value = 0
    used_capacity = 0
    selected_items = []

    for item in items:
        if used_capacity + item['weight'] <= capacity:
            used_capacity += item['weight']
            total_value += item['value']
            selected_items.append(item['name'])
            
    return total_value, selected_items

# 데이터 예시
items = [
    {'name': '금괴', 'value': 100, 'weight': 10},
    {'name': '보석', 'value': 60, 'weight': 20},
    {'name': '은괴', 'value': 120, 'weight': 30}
]
capacity = 50

value, picked = heuristic_knapsack(items, capacity)
print(f"휴리스틱 결과: 총 가치 {value}, 선택된 품목 {picked}")
```

**설명:** 위 코드의 탐욕적(Greedy) 방식은 '단가가 높은 것을 먼저 담는다'는 휴리스틱을 사용합니다. 모든 조합을 계산(완전 합리성)하지 않아도 매우 빠르게 꽤 좋은 해답을 찾아냅니다.

## 4. 요약 및 시사점

### 핵심 요약
1.  **합리적 의사결정**은 모든 확률과 유용성을 고려하여 기대 효용을 극대화하는 과정입니다.
2.  **제한된 합리성**은 현실적인 자원(시간, 정보, 계산력)의 한계를 인정하는 개념입니다.
3.  **휴리스틱**은 완벽한 정답 대신 '빠르고 쓸만한 해답'을 얻기 위한 전략적 지름길입니다.

### 시사점
인공지능 설계 시, 우리는 언제나 **정확도(Accuracy)**와 **효율성(Efficiency)** 사이의 트레이드오프(Trade-off)를 고민해야 합니다. 체스 AI가 모든 경우의 수를 계산할 수 없기에 특정 수의 유리함을 평가하는 '휴리스틱 함수'를 사용하는 것처럼, 현대의 AI는 휴리스틱을 통해 제한된 자원 속에서 지능적인 판단을 내리고 있습니다.

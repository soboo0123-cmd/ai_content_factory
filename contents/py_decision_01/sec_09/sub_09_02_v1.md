## 도입
우리는 흔히 인간이 합리적인 사고를 통해 최선의 선택을 내린다고 가정합니다. 이를 경제학에서는 '호모 에코노미쿠스(Homo Economicus)'라고 부릅니다. 하지만 실제 인간의 의사결정 과정은 논리적인 계산보다는 심리적 기제와 편향(Bias)에 의해 좌우되는 경우가 많습니다. 

이 섹션에서는 의사결정 이론에서 가장 중요하게 다뤄지는 심리적 요소들을 파이썬 코드로 시뮬레이션하며 이해해 봅니다. 구체적으로 **프레이밍 효과(Framing Effect)**, **손실 회피(Loss Aversion)**, 그리고 **기준점 편향(Anchoring Effect)**이 우리의 판단을 어떻게 바꾸는지 실습을 통해 학습하는 것이 목표입니다.

## 1. 프레이밍 효과 (Framing Effect)

### 1.1 개념 설명
프레이밍 효과란 동일한 정보라도 어떤 '틀(Frame)'에 담아 제시하느냐에 따라 사람의 선택이 달라지는 현상을 말합니다. 예를 들어, 수술의 성공률이 "90%이다"라고 말할 때와 사망률이 "10%이다"라고 말할 때 사람들은 전자를 더 긍정적으로 받아들이고 선택할 확률이 높습니다.

### 1.2 파이썬 시뮬레이션
동일한 기댓값을 가진 두 가지 옵션을 '이득'의 관점과 '손실'의 관점에서 제시했을 때, 사용자들의 선택 분포가 어떻게 달라지는지 시뮬레이션해 보겠습니다.

```python
import random

def decision_simulation(frame_type, trials=1000):
    """
    frame_type: 'positive' (이득 강조) 또는 'negative' (손실 강조)
    """
    selections = {"certainty": 0, "gamble": 0}
    
    for _ in range(trials):
        if frame_type == 'positive':
            # 옵션 A: 200명을 확실히 살린다.
            # 옵션 B: 1/3 확률로 600명을 살리고, 2/3 확률로 아무도 못 살린다.
            # 사람들은 보통 '확실한 이득'을 선호함.
            prob_certainty = 0.72  # 심리학 실험 기반 추정치
        else:
            # 옵션 A: 400명이 확실히 죽는다.
            # 옵션 B: 1/3 확률로 아무도 안 죽고, 2/3 확률로 600명이 죽는다.
            # 사람들은 보통 '확실한 손실'을 피하기 위해 도박을 선택함.
            prob_certainty = 0.28
            
        if random.random() < prob_certainty:
            selections["certainty"] += 1
        else:
            selections["gamble"] += 1
            
    return selections

# 결과 출력
pos_res = decision_simulation('positive')
neg_res = decision_simulation('negative')

print(f"[긍정 프레임] 확실한 선택: {pos_res['certainty']}, 도박 선택: {pos_res['gamble']}")
print(f"[부정 프레임] 확실한 선택: {neg_res['certainty']}, 도박 선택: {neg_res['gamble']}")
```

`[시각화: 긍정 프레임과 부정 프레임 시나리오에서 '확실한 선택' vs '도박'의 비율을 나타내는 막대그래프]`

### 1.3 원리 분석
코드에서 `prob_certainty` 값은 실제 행동경제학 실험 결과를 참고하여 설정되었습니다. 논리적으로는 두 프레임의 결과가 동일하지만, 인간은 **이득 프레임에서는 위험을 회피**하고, **손실 프레임에서는 위험을 추구**하는 경향을 보입니다. 이를 알고리즘에 반영할 때는 데이터의 '제시 방식'이 사용자 이탈률이나 전환율에 큰 영향을 미칠 수 있음을 인지해야 합니다.

## 2. 손실 회피와 전망 이론 (Prospect Theory)

### 2.1 개념 설명
대니얼 카너먼(Daniel Kahneman)이 제시한 **전망 이론**의 핵심은 "사람은 얻은 기쁨보다 잃은 슬픔을 더 크게 느낀다"는 것입니다. 일반적으로 손실의 고통은 이득의 즐거움보다 약 2~2.5배 정도 더 강력하다고 알려져 있습니다.

수식으로 표현하면, 가치 함수 $V(x)$는 다음과 같은 특징을 가집니다.
- $x > 0$ (이득) 일 때: $V(x) = x^\alpha$ (오목한 모양, 한계 효용 체감)
- $x < 0$ (손실) 일 때: $V(x) = -\lambda(-x)^\beta$ (볼록한 모양, $\lambda > 1$로 인해 가파름)

### 2.2 파이썬 예제: 가치 함수 구현
손실 회피 계수 $\lambda$를 적용하여 인간이 느끼는 주관적 가치를 계산해 보겠습니다.

```python
import numpy as np
import matplotlib.pyplot as plt

def prospect_value(x, alpha=0.88, beta=0.88, lambd=2.25):
    """
    x: 실제 이득이나 손실 금액
    lambd: 손실 회피 계수 (기본값 2.25)
    """
    if x >= 0:
        return x**alpha
    else:
        return -lambd * ((-x)**beta)

# 가치 변화 시뮬레이션
money_range = np.linspace(-100, 100, 500)
perceived_values = [prospect_value(m) for m in money_range]

# 시각화 코드
plt.figure(figsize=(10, 6))
plt.plot(money_range, perceived_values, label='Prospect Value Function')
plt.axhline(0, color='black', linewidth=0.5)
plt.axvline(0, color='black', linewidth=0.5)
plt.title("Prospect Theory: Value Function")
plt.xlabel("Actual Gain/Loss ($)")
plt.ylabel("Perceived Value (Utility)")
plt.grid(True)
plt.show()
```

`[시각화: 원점을 지나는 S자형 곡선. 손실 영역(3사분면)의 기울기가 이득 영역(1사분면)보다 훨씬 가파른 것을 슬라이더로 lambda 값을 조절하며 관찰]`

### 2.3 원리 분석
위 그래프에서 볼 수 있듯이, 똑같이 100달러를 움직여도 마이너스 영역에서의 기울기가 훨씬 가파릅니다. 이는 의사결정 모델을 설계할 때 **손실에 대한 페널티를 이득에 대한 보상보다 크게 설정**해야 실제 인간의 행동 패턴과 유사한 예측을 할 수 있음을 시사합니다.

## 3. 기준점 편향 (Anchoring Effect)

### 3.1 개념 설명
기준점 편향은 처음에 제시된 숫자(기준점)가 이후의 판단에 왜곡된 영향을 미치는 현상입니다. 중고차 가격 협상을 할 때 판매자가 처음에 높은 가격을 부르면, 구매자는 그 가격을 기준으로 협상을 시작하게 되어 결국 더 높은 가격에 합의하게 되는 것이 대표적인 예입니다.

### 3.2 파이썬 예제: 협상 시뮬레이션
기준점이 주어졌을 때와 주어지지 않았을 때, 최종 합의 가격이 어떻게 형성되는지 확률 모델로 구현해 봅니다.

```python
def negotiation_simulation(anchor_price=None, real_value=5000):
    """
    anchor_price: 처음 제시된 가격 (없으면 무작위)
    real_value: 실제 적정 가치
    """
    if anchor_price is None:
        # 기준점이 없을 때는 적정 가치 근처에서 시작
        start_point = real_value + random.uniform(-500, 500)
    else:
        # 기준점이 있을 때는 기준점의 영향을 강하게 받음 (가중치 0.6)
        start_point = (anchor_price * 0.6) + (real_value * 0.4)
    
    # 협상 과정에서의 노이즈 발생
    final_price = start_point + random.normalvariate(0, 200)
    return final_price

# 1. 기준점이 낮게 설정된 경우 (3000)
low_anchor = [negotiation_simulation(3000) for _ in range(100)]
# 2. 기준점이 높게 설정된 경우 (7000)
high_anchor = [negotiation_simulation(7000) for _ in range(100)]

print(f"낮은 기준점 평균 합의가: {np.mean(low_anchor):.2f}")
print(f"높은 기준점 평균 합의가: {np.mean(high_anchor):.2f}")
```

### 3.3 원리 분석
기준점 편향은 시스템의 '디폴트 값(Default Value)' 설정과도 밀접한 관련이 있습니다. 사용자에게 기부 금액을 제안할 때 `[1만원, 5만원, 10만원]`을 보여주는 것과 `[5만원, 10만원, 20만원]`을 보여주는 것은 최종 기부 액수에 큰 차이를 만듭니다. 파이썬 모델링 시 이러한 '초기 입력값'이 결과에 미치는 민감도를 분석하는 것이 중요합니다.

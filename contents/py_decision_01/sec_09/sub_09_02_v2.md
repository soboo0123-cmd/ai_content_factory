# 9.2 심리적 요소에 얽힌 예제 (v2)

인간과 동물의 학습 과정은 단순히 수치를 최적화하는 과정이 아닙니다. 행동의 이면에는 '보상에 대한 기대', '새로운 것에 대한 호기심', 그리고 '미래를 위해 현재의 유혹을 참는 인내심'과 같은 복잡한 심리적 역학이 작용합니다. 강화학습(Reinforcement Learning)은 이러한 생물학적 학습 원리를 수학적으로 모델링한 분야입니다.

이번 절에서는 강화학습의 주요 개념들이 심리학적 요소와 어떻게 맞닿아 있는지 구체적인 예제를 통해 살펴보겠습니다.

## 1. 지연된 보상과 인내심: 마시멜로 테스트 예제

심리학에서 가장 유명한 실험 중 하나인 '마시멜로 테스트'는 아이의 자제력이 미래의 성공에 어떤 영향을 미치는지 보여줍니다. 이를 강화학습의 관점에서 보면 **할인율(Discount Factor, $\gamma$)**의 개념으로 설명할 수 있습니다.

### 심리학적 배경
아이는 눈앞의 마시멜로 1개를 즉시 먹을 수도 있고, 선생님이 돌아올 때까지 기다려 2개를 받을 수도 있습니다. 이때 '현재의 확실한 보상'과 '미래의 더 큰 보상' 사이의 갈등이 발생합니다.

### 강화학습 모델링
강화학습 에이전트가 미래의 보상을 현재 가치로 환산할 때 사용하는 수식은 다음과 같습니다.
$$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \dots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}$$
여기서 $\gamma$ (gamma)는 0과 1 사이의 값입니다.

- **$\gamma$가 낮을 때 (충동적 에이전트):** 미래의 보상을 거의 가치 없게 여깁니다. 마시멜로를 즉시 먹는 선택을 합니다.
- **$\gamma$가 높을 때 (인내심 있는 에이전트):** 미래의 보상을 현재와 비슷하게 가치 있게 여깁니다. 더 큰 보상을 위해 기다림을 선택합니다.

`[시각화: 슬라이더를 이용해 γ 값을 조절하면, 시간에 따른 보상의 현재 가치 그래프가 어떻게 감쇠하는지 보여주는 인터랙티브 차트]`

## 2. 내적 동기와 호기심: 미지의 방 탐험 예제

전형적인 강화학습은 외부에서 주어지는 보상(Extrinsic Reward)에 의존합니다. 하지만 인간은 외부 보상이 없어도 '궁금해서' 행동합니다. 이를 **내적 동기(Intrinsic Motivation)**라고 합니다.

### 심리학적 배경
아무런 보상이 없는 빈 방에 아이를 두어도, 아이는 방 안의 물건을 만져보고 열어보며 탐색합니다. 이러한 호기심은 생명체가 환경에 대한 정보를 수집하여 생존 확률을 높이려는 본능적인 기제입니다.

### 강화학습 모델링: 호기심 기반 학습 (Curiosity-driven Learning)
에이전트에게 외부 보상 $R_e$ 외에, 스스로 생성한 내적 보상 $R_i$를 추가로 부여합니다.
$$R_{total} = R_e + R_i$$

여기서 $R_i$는 보통 **'예측 오차(Prediction Error)'**로 정의됩니다. 에이전트가 자신의 행동 결과를 예측하기 어려운(생소한) 상황일수록 높은 내적 보상을 주어, 그 환경을 더 탐험하게 만드는 원리입니다.

```python
# 호기심 보상을 계산하는 개념 코드
import numpy as np

def calculate_intrinsic_reward(current_state, action, next_state, forward_model):
    # forward_model은 현재 상태와 행동을 보고 다음 상태를 예측하는 신경망
    predicted_next_state = forward_model.predict(current_state, action)
    
    # 예측값과 실제 결과의 차이(오차)를 계산
    prediction_error = np.mean(np.square(next_state - predicted_next_state))
    
    # 오차가 클수록(처음 겪는 일일수록) 호기심 보상이 커짐
    intrinsic_reward = prediction_error 
    return intrinsic_reward
```

`[시각화: 미로에서 에이전트가 지나간 경로의 '친숙도'를 색상으로 표시. 에이전트가 색이 옅은(덜 방문한) 곳으로 이끌리는 모습 시각화]`

## 3. 후회와 기회비용: 다중 슬롯머신(Multi-Armed Bandit) 예제

우리는 매일 "먹던 메뉴를 먹을까(활용), 새로운 맛집에 도전해볼까(탐색)?"라는 고민에 빠집니다. 이는 심리학의 **선택 편향**과 **후회 최소화** 전략과 연결됩니다.

### 심리학적 배경
사람은 이전에 만족스러웠던 경험에 안주하려는 경향이 있지만, 동시에 더 나은 선택지가 있을지 모른다는 불안감(기회비용에 대한 인지)도 가집니다.

### 강화학습 모델링: $\epsilon$-greedy 전략
에이전트는 대부분의 시간($1-\epsilon$)에는 지금까지 가장 보상이 좋았던 행동을 선택하지만, 아주 적은 확률($\epsilon$)로 무작위 행동을 합니다.

- **활용(Exploitation):** 알고 있는 최선의 선택을 함 (심리적 안정).
- **탐색(Exploration):** 새로운 시도를 함 (심리적 모험).

이 과정에서 에이전트는 '내가 만약 다른 선택을 했다면 얻었을 보상'과 '현재 보상'의 차이인 **후회(Regret)**를 최소화하는 방향으로 학습해 나갑니다.

## 요약

강화학습의 알고리즘들은 인간의 심리적 의사결정 과정을 수학적 언어로 번역한 것과 같습니다.

1.  **할인율($\gamma$):** 당장의 유혹과 미래의 가치 사이의 저울질(인내심).
2.  **내적 보상($R_i$):** 새로운 정보에 대한 갈망(호기심).
3.  **탐색과 활용:** 안정적인 선택과 불확실한 도전 사이의 균형(기회비용).

이러한 심리학적 요소의 결합은 AI가 단순히 계산기처럼 동작하는 것을 넘어, 보다 생명체에 가까운 유연하고 지능적인 행동을 가능하게 합니다.

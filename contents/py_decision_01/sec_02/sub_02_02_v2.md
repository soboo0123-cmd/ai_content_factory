# 2.2 의사결정에 필요한 통계방법 (v2)

## 1. 도입: 데이터는 어떻게 확신으로 변하는가?

우리는 매일 수많은 선택의 기로에 놓입니다. "이 마케팅 캠페인이 효과가 있었나?", "새로운 알고리즘이 기존보다 더 정확한가?"와 같은 질문에 답해야 합니다. 하지만 단순히 데이터의 평균값이 올랐다고 해서 "성공"이라고 단정 지을 수 있을까요? 그것이 단순한 **'우연'**일 가능성은 없을까요?

통계학은 불확실성이라는 안개 속에서 **'의사결정의 근거'**를 마련해 주는 도구입니다. 이번 절에서는 단순한 데이터 요약을 넘어, 데이터를 기반으로 객관적인 결론을 도출하는 '추론 통계'의 핵심 원리와 방법론을 학습합니다. 우리의 목표는 '감'이 아닌 '수치적 확신'을 가지고 의사결정을 내리는 법을 익히는 것입니다.

## 2. 본론: 의사결정의 과학적 프레임워크

### 2.1 가설 검정: 법정에서의 증명 과정과 같다

통계적 의사결정의 핵심은 **가설 검정(Hypothesis Testing)**입니다. 이는 새로운 주장이 맞는지 확인하기 위해 기존의 믿음을 뒤집을만한 충분한 증거가 있는지 검토하는 과정입니다. 이를 이해하기 위해 법정의 비유를 들어보겠습니다.

1.  **귀무가설 ($H_0$, Null Hypothesis):** "피고인은 무죄이다." 즉, 아무런 변화나 차이가 없다는 기본 상태입니다. (예: 신약은 효과가 없다.)
2.  **대립가설 ($H_1$, Alternative Hypothesis):** "피고인은 유죄이다." 우리가 새롭게 증명하고 싶은 주장입니다. (예: 신약은 효과가 있다.)
3.  **검정통계량:** 판사가 판결을 내리기 위해 검토하는 '증거물'입니다.
4.  **유의수준 ($\alpha$):** 유죄 판결을 내리기 위해 필요한 '확신의 정도'입니다. 보통 5%($0.05$)를 사용하는데, 이는 "무죄인 사람을 유죄라고 잘못 판단할 위험을 5% 이내로 관리하겠다"는 뜻입니다.

> **[시각화: 가설 검정의 구조]**
> - 왼쪽: 귀무가설의 분포 (정규분포 곡선).
> - 오른쪽: 임계값(Critical Value)을 기준으로 '채택역'과 '기각역'을 색상으로 구분.
> - 슬라이더: 유의수준($\alpha$)을 조절함에 따라 기각역의 넓이가 변하는 모습 시각화.

---

### 2.2 P-value: 우연이 만들어낸 장난일 확률

의사결정에서 가장 자주 등장하는 용어가 바로 **P-value(유의확률)**입니다. P-value는 "만약 귀무가설이 참이라면(효과가 없다면), 현재 우리가 관찰한 데이터와 같은 결과가 나올 확률이 얼마인가?"를 의미합니다.

-   **P-value가 낮다 (보통 < 0.05):** "우연히 이런 결과가 나올 확률이 극히 희박하네? 이건 우연이 아니라 진짜 효과가 있는 거구나!" $\rightarrow$ **귀무가설 기각, 대립가설 채택.**
-   **P-value가 높다:** "우연히도 충분히 일어날 수 있는 일이네." $\rightarrow$ **귀무가설 채택.**

---

### 2.3 실전 도구: 두 집단의 차이를 비교하는 T-검정 (T-test)

가장 대표적인 의사결정 상황은 "A안과 B안 중 무엇이 더 나은가?"를 판단하는 것입니다. 이때 사용하는 것이 **T-검정**입니다. 

T-검정은 두 집단의 '평균' 차이를 계산하되, 데이터가 얼마나 흩어져 있는지(분산)와 샘플의 개수를 함께 고려합니다. T-값의 공식은 개념적으로 다음과 같습니다.

$$ t = \frac{\text{두 집단의 평균 차이}}{\text{표준 오차(불확실성)}} $$

**[코드 예제: 파이썬을 이용한 A/B 테스트 검정]**

웹사이트의 버튼 색상을 빨간색에서 파란색으로 바꿨을 때, 클릭률(CTR)에 유의미한 차이가 있는지 검정해 보겠습니다.

```python
import numpy as np
from scipy import stats

# 데이터 준비 (A: 기존 빨간색 버튼, B: 새로운 파란색 버튼)
# 각 값은 사용자별 페이지 체류 시간이라고 가정
group_a = [20, 22, 19, 24, 25, 21, 18, 23, 19, 20]
group_b = [26, 28, 23, 27, 25, 29, 24, 26, 22, 27]

# 독립표본 T-검정 수행
t_stat, p_val = stats.ttest_ind(group_a, group_b)

print(f"T-통계량: {t_stat:.4f}")
print(f"P-value: {p_val:.4f}")

if p_val < 0.05:
    print("결론: 두 그룹 간에 유의미한 차이가 있습니다. 파란색 버튼이 효과적입니다.")
else:
    print("결론: 두 그룹 간에 유의미한 차이가 없습니다. 우연일 가능성이 높습니다.")
```

### 2.4 신뢰구간 (Confidence Interval): 점이 아닌 범위로 보기

평균값 하나만 보고 결정하는 것은 위험합니다. "이 상품의 만족도는 80점입니다"라고 말하는 것보다, "우리는 95%의 확신으로 만족도가 78점에서 82점 사이에 있다고 말할 수 있습니다"라고 하는 것이 훨씬 정보량이 많고 안전한 의사결정입니다.

이 범위를 **신뢰구간**이라고 합니다. 신뢰구간이 좁을수록 데이터의 정밀도가 높다는 것을 의미하며, 의사결정자는 최악의 상황(하한선)과 최선의 상황(상한선)을 모두 고려할 수 있게 됩니다.

> **[시각화: 신뢰구간 비교 그래프]**
> - 두 개의 막대그래프 위에 오차 막대(Error Bar)를 표시.
> - 샘플 사이즈가 커질수록 오차 막대가 좁아지는 인터랙티브 요소 포함.

## 3. 요약: 데이터 기반 의사결정의 3단계

1.  **질문을 가설로 변환하라:** "차이가 없다($H_0$)"와 "차이가 있다($H_1$)"를 명확히 정의합니다.
2.  **증거의 무게를 측정하라:** T-검정 등의 방법을 통해 P-value를 계산하고, 이것이 사전에 정한 기준(0.05 등)보다 작은지 확인합니다.
3.  **범위로 판단하라:** 단일 수치에 매몰되지 말고 신뢰구간을 통해 결과의 정밀도와 비즈니스적 임팩트의 크기를 가늠합니다.

통계는 정답을 알려주는 마법 구슬이 아닙니다. 하지만 우리가 내린 결정이 틀릴 확률을 수치화함으로써, **'관리 가능한 위험'** 안에서 최선의 선택을 하도록 돕는 가장 강력한 나침반입니다.

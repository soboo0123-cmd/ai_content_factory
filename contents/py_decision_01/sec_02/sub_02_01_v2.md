# 2.1 통계와 관련된 Excel 함수 (v2)

## 도입: 데이터의 '인상'을 숫자로 요약하기

우리는 매일 엄청난 양의 데이터 속에서 살아갑니다. 하지만 수만 줄의 엑셀 행을 단순히 쳐다보는 것만으로는 데이터가 가진 진짜 의미를 파악하기 어렵습니다. 통계란 결국 **"복잡한 데이터를 요약하여 유의미한 정보를 추출하는 기술"**입니다. 

Excel은 복잡한 통계 수식을 직접 계산하지 않아도, 함수 몇 가지만으로 데이터의 중심이 어디인지, 데이터가 얼마나 퍼져 있는지, 혹은 어떤 분포를 따르는지를 즉시 계산해 줍니다. 이번 장에서는 데이터를 탐색하고 분석하는 과정에 따라 필수적인 통계 함수들의 원리와 사용법을 깊이 있게 살펴보겠습니다.

---

## 본론

### 1. 데이터의 규모 파악: 기초 개수 세기 (Counting)
본격적인 분석에 앞서, 우리가 가진 데이터가 총 몇 개인지, 누락된 값은 없는지 파악하는 것이 첫걸음입니다.

*   **COUNT vs COUNTA:** 
    - `COUNT(범위)`: 오직 **숫자**가 포함된 셀의 개수만 셉니다.
    - `COUNTA(범위)`: 숫자, 텍스트, 오류값 등 **비어 있지 않은 모든 셀**의 개수를 셉니다. (Count All)
*   **COUNTBLANK:** 범위 내에서 데이터가 입력되지 않은 빈 셀의 개수를 찾아내어 데이터의 결측치(Missing Value) 상태를 확인하는 데 사용됩니다.

`[시각화: 데이터 시트에서 숫자 셀과 텍스트 셀이 섞여 있을 때, COUNT와 COUNTA의 결과값이 어떻게 달라지는지 강조하는 하이라이트 애니메이션]`

---

### 2. 중심 경향성: 데이터의 대표값 찾기 (Central Tendency)
데이터 집단을 하나의 숫자로 대표한다면 어떤 값을 선택해야 할까요? 이를 '중심 경향성'이라고 합니다.

#### 1) 산술 평균 (Mean)
가장 보편적인 방법으로, 모든 값의 합을 개수로 나눈 값입니다.
- **Excel 함수:** `AVERAGE(범위)`
- **수식:** $\bar{x} = \frac{\sum_{i=1}^{n} x_i}{n}$
- **주의점:** 평균은 '이상치(Outlier)'에 매우 민감합니다. 예를 들어, 전 직원의 연봉을 계산할 때 억대 연봉자가 한 명 포함되면 평균이 급격히 올라가 전체를 대변하기 어려워질 수 있습니다.

#### 2) 중앙값 (Median)
데이터를 크기순으로 나열했을 때 정중앙에 위치하는 값입니다.
- **Excel 함수:** `MEDIAN(범위)`
- **특징:** 극단적인 값이 존재할 때 평균보다 훨씬 더 안정적인 대표값 역할을 합니다.

#### 3) 최빈값 (Mode)
가장 자주 나타나는 값입니다.
- **Excel 함수:** `MODE.SNGL(범위)` (단일 최빈값), `MODE.MULT(범위)` (여러 최빈값)
- **특징:** 범주형 데이터(예: 가장 많이 팔린 상품 사이즈)를 분석할 때 유용합니다.

`[시각화: 슬라이더를 이용해 데이터에 큰 수(이상치)를 추가했을 때, 평균(Mean) 막대는 크게 움직이지만 중앙값(Median) 막대는 안정적으로 유지되는 비교 그래프]`

---

### 3. 산포도: 데이터의 흩어짐 측정하기 (Dispersion)
두 집단의 평균이 같더라도, 데이터가 몰려 있는지 널리 퍼져 있는지에 따라 그 성격은 완전히 다릅니다.

#### 1) 분산(Variance)과 표준편차(Standard Deviation)
데이터가 평균으로부터 얼마나 떨어져 있는지를 수치화한 것입니다.
- **분산 수식:** $s^2 = \frac{\sum (x_i - \bar{x})^2}{n-1}$
- **표준편차 수식:** $s = \sqrt{s^2}$

Excel에서는 분석 대상이 '모집단 전체'인지 '표본'인지에 따라 함수를 구분합니다.
- **표본(Sample):** `VAR.S`, `STDEV.S` (일반적으로 우리가 다루는 부분 집단)
- **모집단(Population):** `VAR.P`, `STDEV.P` (전수 조사 시 사용)

> **왜 n이 아니라 n-1로 나누나요?**
> 표본을 통해 모집단을 추정할 때는 오차가 발생할 수밖에 없습니다. `n-1`로 나누는 것(베셀의 보정)은 표본 분산이 모집단 분산보다 작게 계산되는 편향을 줄이기 위한 통계적 장치입니다.

---

### 4. 상관관계: 변수 간의 관계 파악하기
두 변수(예: 광고비와 매출액)가 서로 어떤 관련이 있는지 알고 싶을 때 상관계수를 사용합니다.

- **Excel 함수:** `CORREL(범위1, 범위2)`
- **해석:** 
    - **+1에 가까울수록:** 강한 양의 상관관계 (같이 증가)
    - **-1에 가까울수록:** 강한 음의 상관관계 (한쪽이 늘면 한쪽은 감소)
    - **0에 가까울수록:** 아무런 관계가 없음.

`[시각화: 산점도(Scatter Plot) 상에서 점들의 분포가 선형에 가까워질수록 CORREL 함수 결과값이 실시간으로 -1에서 1 사이로 변하는 시뮬레이션]`

## 요약: 데이터 분석의 단계별 함수 지도

| 분석 단계 | 분석 목적 | 주요 엑셀 함수 |
| :--- | :--- | :--- |
| **기초 탐색** | 데이터의 양과 누락 확인 | `COUNT`, `COUNTA`, `COUNTBLANK` |
| **중심 찾기** | 집단의 대표 성질 파악 | `AVERAGE`, `MEDIAN`, `MODE.SNGL` |
| **퍼짐 확인** | 데이터의 안정성/변동성 측정 | `STDEV.S`, `VAR.S` |
| **관계 분석** | 두 변수 간의 연관성 확인 | `CORREL` |

Excel 통계 함수는 단순한 계산 도구가 아니라, 방대한 데이터 속에서 **"중심은 어디인가?"**, **"얼마나 퍼져 있는가?"**, **"다른 데이터와 무슨 관계인가?"**라는 질문에 답을 주는 강력한 렌즈입니다. 이 함수들을 조합하는 것만으로도 데이터의 기초적인 형태를 완벽하게 파악할 수 있습니다.

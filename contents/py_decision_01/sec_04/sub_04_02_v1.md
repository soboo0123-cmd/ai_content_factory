# 4.2 검정이란 (v1 초안)

## 1. 도입: 데이터의 차이는 '우연'일까 '필연'일까?

우리가 데이터를 분석하는 궁극적인 이유는 무엇일까요? 대부분은 **"차이를 확인하고 결정을 내리기 위해서"**입니다. 예를 들어, 새로운 광고 시안 A와 기존 시안 B를 비교했을 때 A의 클릭률이 더 높다면, 우리는 "A가 더 효과적이다"라고 결론짓고 싶어 합니다.

하지만 여기서 중요한 질문이 생깁니다. **"그 차이가 정말 광고의 효과 때문인가, 아니면 단순히 운이 좋아서(우연히) 발생한 것인가?"**

통계적 **검정(Hypothesis Testing)**은 바로 이 질문에 답하는 과정입니다. 검정은 수집된 데이터가 단순히 우연에 의한 결과인지, 아니면 통계적으로 의미 있는(Significant) 결과인지를 엄밀하게 따져보는 의사결정의 도구입니다. 이 섹션에서는 검정의 기본 원리와 절차를 교과서적인 관점에서 차근차근 살펴보겠습니다.

---

## 2. 본론: 검정의 핵심 원리와 절차

### 2.1 가설 세우기: 귀무가설과 대립가설
검정은 두 가지 상반된 가설을 세우는 것에서 시작합니다. 법정에서의 '무죄 추정의 원칙'을 떠올리면 이해하기 쉽습니다.

1.  **귀무가설(Null Hypothesis, $H_0$):** "차이가 없다", "효과가 없다"라고 가정하는 기본 가설입니다. 피고인이 무죄라고 가정하는 것과 같습니다. 우리가 깨고 싶어 하는 가설이기도 합니다.
2.  **대립가설(Alternative Hypothesis, $H_1$):** "차이가 있다", "효과가 있다"라고 주장하는 가설입니다. 우리가 데이터를 통해 증명하고 싶어 하는 새로운 주장입니다.

`[시각화: 법정의 판사와 검사 비유 일러스트 - 검사는 대립가설을 주장하고, 판사는 증거가 불충분하면 귀무가설을 유지함]`

### 2.2 p-value: 우연히 발생할 확률
가설을 세웠다면, 이제 데이터를 통해 **p-value(유의확률)**를 계산합니다. p-value는 "귀무가설이 참이라는 가정하에, 현재와 같은 결과(혹은 그보다 더 극단적인 결과)가 나타날 확률"을 의미합니다.

-   **p-value가 매우 낮다면:** "귀무가설이 참인데 이런 결과가 나올 확률이 이렇게 낮다고? 그럼 귀무가설이 틀렸을 가능성이 높겠네!"라고 판단합니다.
-   **p-value가 높다면:** "이 정도 결과는 우연히 발생할 수도 있겠네. 귀무가설을 부정할 증거가 부족해."라고 판단합니다.

### 2.3 유의수준($\alpha$): 판단의 기준선
그렇다면 p-value가 얼마나 낮아야 "의미가 있다"고 할까요? 그 기준점이 바로 **유의수준($\alpha$)**입니다. 사회과학이나 일반적인 데이터 분석에서는 보통 **0.05(5%)**를 기준으로 삼습니다.

-   **$p < 0.05$:** 통계적으로 유의미함 (귀무가설 기각, 대립가설 채택)
-   **$p \ge 0.05$:** 통계적으로 유의미하지 않음 (귀무가설 채택)

`[시각화: 정규분포 곡선에서 양 끝의 5% 영역(기각역)과 중앙 영역(채택역)을 구분하는 인터랙티브 차트]`

### 2.4 파이썬 예제: 두 집단의 평균 차이 검정
실제로 파이썬을 이용해 두 집단의 평균 차이가 통계적으로 유의미한지 검정(t-test)해보겠습니다.

```python
import numpy as np
from scipy import stats

# 데이터 생성: A 그룹(기존), B 그룹(신규)
# B 그룹의 평균이 약간 더 높게 설정함
group_a = [20, 22, 19, 21, 23, 18, 20, 21, 19, 22]
group_b = [25, 27, 24, 26, 28, 23, 25, 26, 24, 27]

# 1. 귀무가설(H0): 두 그룹의 평균 차이는 없다.
# 2. 대립가설(H1): 두 그룹의 평균 차이는 있다.

# 독립표본 t-검정 수행
t_statistic, p_value = stats.ttest_ind(group_a, group_b)

print(f"t-통계량: {t_statistic:.4f}")
print(f"p-value: {p_value:.4f}")

# 결과 해석
alpha = 0.05
if p_value < alpha:
    print("결과: p-value가 유의수준보다 작으므로 귀무가설을 기각합니다.")
    print("즉, 두 그룹 간에는 통계적으로 유의미한 차이가 있습니다.")
else:
    print("결과: p-value가 유의수준보다 크므로 귀무가설을 기각할 수 없습니다.")
    print("즉, 발생한 차이는 우연일 가능성이 높습니다.")
```

## 3. 요약: 이것만은 꼭 기억하세요

1.  **검정은 증명하는 과정이다:** 단순히 숫자가 크고 작음을 보는 것이 아니라, 그 차이가 통계적으로 견고한지 확인하는 과정입니다.
2.  **귀무가설($H_0$)은 보수적이다:** "차이가 없다"는 기본 상태에서 시작하며, 이를 뒤집으려면 확실한 증거(데이터)가 필요합니다.
3.  **p-value는 '우연의 확률'이다:** p-value가 0.05보다 작다는 것은, 이 결과가 우연히 일어났을 확률이 5% 미만이라는 뜻이며, 이는 곧 "우연이 아니라고 봐도 좋다"는 근거가 됩니다.
4.  **결정의 책임:** 유의수준($\alpha$)을 얼마로 잡느냐에 따라 의사결정의 엄격함이 달라집니다. 분석가는 도메인의 특성에 맞게 이 기준을 이해하고 설정해야 합니다.

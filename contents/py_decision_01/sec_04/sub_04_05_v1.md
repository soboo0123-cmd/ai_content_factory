# 4.5 분산 분석 (ANOVA): 세 집단 이상의 평균 차이 검정하기 (v1 초안)

## 1. 도입: 왜 '분산'으로 '평균'을 비교할까?

우리는 앞서 두 집단의 평균을 비교하기 위해 **t-검정(t-test)**을 배웠습니다. 예를 들어 'A안과 B안 중 어떤 광고의 클릭률이 더 높은가?'라는 질문에는 t-검정이 훌륭한 답을 줍니다. 

하지만 비즈니스 현장이나 연구 환경에서는 비교 대상이 셋 이상인 경우가 많습니다. 
- "서울, 부산, 대구 지점의 월 평균 매출에 차이가 있는가?"
- "A, B, C 세 가지 비료 중 어떤 비료가 작물 성장에 가장 효과적인가?"

이때 t-검정을 여러 번 반복하면 안 될까요? (A-B, B-C, A-C 비교) 안타깝게도 t-검정을 반복할수록 '1종 오류(실제로 차이가 없는데 차이가 있다고 결론 내릴 확률)'가 누적되어 전체적인 신뢰도가 급격히 떨어집니다.

이 문제를 해결하기 위해 등장한 것이 바로 **분산 분석(ANOVA, Analysis of Variance)**입니다. 이번 섹션에서는 여러 집단의 평균을 한 번에 비교하는 분산 분석의 원리와 파이썬 실습 방법을 학습합니다.

---

## 2. 본론

### 2.1 분산 분석의 핵심 원리: '신호'와 '소음'

분산 분석의 이름이 '평균 분석'이 아니라 '분산 분석'인 이유는 **데이터의 변동성(분산)을 나누어 분석함으로써 평균의 차이를 입증**하기 때문입니다.

전체 데이터의 변동은 크게 두 가지로 나뉩니다.

1.  **집단 간 분산 (Between-group Variance):** 서로 다른 집단(그룹)의 평균들이 얼마나 떨어져 있는가? (우리가 찾고자 하는 **'신호'**)
2.  **집단 내 분산 (Within-group Variance):** 같은 집단 안에서 개별 데이터들이 얼마나 흩어져 있는가? (개별 오차인 **'소음'**)

분산 분석에서 사용하는 **F-통계량(F-value)**은 이 두 값의 비율로 정의됩니다.

$$ F = \frac{\text{집단 간 분산 (신호)}}{\text{집단 내 분산 (소음)}} $$

- **F값이 크다면:** 집단 내에서 발생하는 우연한 변동(소음)보다 집단 간의 차이(신호)가 훨씬 크다는 뜻입니다. 즉, "평균이 서로 다르다"고 판단할 근거가 됩니다.
- **F값이 작다면 (1에 가깝다면):** 집단 간의 차이가 개별 데이터의 우연한 변동 수준에 불과하다는 뜻입니다. 즉, "평균의 차이가 없다"고 판단합니다.

`[시각화: 세 개의 정규분포 곡선이 서로 멀리 떨어져 있는 경우(높은 F값)와 겹쳐 있는 경우(낮은 F값)를 슬라이더로 조절하며 F-통계량 변화 관찰]`

---

### 2.2 분산 분석의 전제 조건

분산 분석을 정확하게 수행하기 위해서는 데이터가 다음 세 가지 조건을 만족해야 합니다.

1.  **독립성:** 각 집단의 관측치는 서로 독립적이어야 합니다.
2.  **정규성:** 각 집단의 데이터는 정규분포를 따라야 합니다.
3.  **등분산성:** 모든 집단의 분산(흩어진 정도)은 대략적으로 같아야 합니다.

---

### 2.3 파이썬 실습: 세 가지 교육 방식의 효과 비교

어느 기업에서 세 가지 서로 다른 교육 방식(A, B, C)이 직원들의 성과 점수에 미치는 영향을 확인하고자 합니다.

```python
import pandas as pd
import scipy.stats as stats
import matplotlib.pyplot as plt
import seaborn as sns

# 1. 데이터 생성
data = {
    'method': ['A']*30 + ['B']*30 + ['C']*30,
    'score': [
        *stats.norm.rvs(loc=70, scale=10, size=30), # 방법 A: 평균 70
        *stats.norm.rvs(loc=75, scale=10, size=30), # 방법 B: 평균 75
        *stats.norm.rvs(loc=82, scale=10, size=30)  # 방법 C: 평균 82
    ]
}
df = pd.DataFrame(data)

# 2. 시각화: 박스 플롯으로 분포 확인
plt.figure(figsize=(8, 5))
sns.boxplot(x='method', y='score', data=df)
plt.title('Performance Score by Education Method')
plt.show()

# [시각화: 박스 플롯을 통해 각 그룹의 중앙값과 사분위 범위 시각적으로 비교]

# 3. 일원 분산 분석(One-way ANOVA) 수행
group_A = df[df['method'] == 'A']['score']
group_B = df[df['method'] == 'B']['score']
group_C = df[df['method'] == 'C']['score']

f_stat, p_val = stats.f_oneway(group_A, group_B, group_C)

print(f"F-통계량: {f_stat:.4f}")
print(f"p-value: {p_val:.4f}")

# 4. 결과 해석
alpha = 0.05
if p_val < alpha:
    print("결론: p-value가 유의수준보다 작으므로, 교육 방식에 따른 성과 차이가 통계적으로 유의합니다.")
else:
    print("결론: p-value가 유의수준보다 크므로, 교육 방식에 따른 성과 차이가 있다고 볼 수 없습니다.")
```

---

### 2.4 사후 검정 (Post-hoc Analysis)

분산 분석의 결과가 유의미하다는 것은 "적어도 어느 한 집단은 다른 집단과 평균이 다르다"는 뜻일 뿐, 구체적으로 **어떤 집단끼리 차이가 나는지는 알려주지 않습니다.**

이를 확인하기 위해 수행하는 것이 **사후 검정**입니다. 대표적으로 **Tukey의 HSD(Honestly Significant Difference)** 검법이 사용됩니다.

```python
from statsmodels.stats.multicomp import pairwise_tukeyhsd

# 사후 검정 수행
posthoc = pairwise_tukeyhsd(df['score'], df['method'], alpha=0.05)
print(posthoc)

# [시각화: 사후 검정 결과표를 기반으로 집단 간 신뢰구간이 0을 포함하는지 보여주는 그래프]
```

## 3. 요약

1.  **분산 분석(ANOVA)**은 세 집단 이상의 평균을 비교할 때 사용합니다.
2.  **원리:** 전체 변동을 '집단 간의 차이(신호)'와 '집단 내의 차이(소음)'로 나누어 비율(F-통계량)을 계산합니다.
3.  **p-value가 0.05보다 작으면:** 적어도 한 집단 이상의 평균이 통계적으로 유의미하게 다르다고 판단합니다.
4.  **사후 검정:** ANOVA 결과가 유의미할 때, 구체적으로 어떤 집단들 사이에 차이가 있는지 확인하기 위해 수행합니다.

분산 분석은 단순한 평균 비교를 넘어, 실험 계획이나 마케팅 전략의 효과성을 다각도로 검증하는 강력한 도구입니다. 이제 여러분은 여러 대안 중 최선의 의사결정을 내릴 수 있는 통계적 기초를 마련했습니다.

# 4.3 독립성의 검정 (Independence Test)

## 1. 도입: "두 사건은 서로 관련이 있을까?"

우리는 일상에서 "A와 B는 아무 상관이 없어"라거나 "A를 보니 B가 결정되는구나"라는 판단을 자주 내립니다. 예를 들어, **'성별에 따라 선호하는 스마트폰 브랜드가 다를까?'** 혹은 **'특정 약물 복용 여부가 완치율과 관계가 있을까?'** 같은 질문들입니다.

데이터 분석과 의사결정 과정에서 두 범주형 변수(Categorical Variables) 사이의 관계를 파악하는 것은 매우 중요합니다. 만약 두 변수가 서로 영향을 주지 않는다면 우리는 이를 **'독립(Independent)'**이라고 부르며, 서로 관련이 있다면 **'종속(Dependent)'** 또는 **'연관성이 있다'**고 말합니다.

이번 섹션에서는 통계적 도구인 **카이제곱 독립성 검정(Chi-square Test of Independence)**을 통해, 관측된 데이터가 우연인지 아니면 실제로 두 변수 사이에 유의미한 관계가 있는지를 증명하는 방법을 배웁니다.

### 학습 목표
1. 독립성의 개념과 분할표(Contingency Table)의 구조를 이해합니다.
2. 기대 빈도(Expected Frequency)의 원리를 파악합니다.
3. 파이썬을 활용해 카이제곱 검정을 수행하고 결과를 해석하는 능력을 갖춥니다.

---

## 2. 본론: 독립성 검정의 원리와 실습

### 4.3.1 분할표(Contingency Table) 이해하기
독립성 검정을 수행하기 위한 첫 번째 단계는 데이터를 빈도수 형태로 정리하는 것입니다. 이를 **분할표** 또는 **교차표**라고 합니다.

예를 들어, 200명의 소비자를 대상으로 '성별'과 '선호 제품(A, B)'을 조사했다고 가정해 봅시다.

| 성별 \ 제품 | 제품 A | 제품 B | 합계 |
| :--- | :---: | :---: | :---: |
| **남성** | 60 | 40 | 100 |
| **여성** | 30 | 70 | 100 |
| **합계** | 90 | 110 | 200 |

이 표가 우리가 실제로 조사해서 얻은 **관측 빈도(Observed Frequency)**입니다.

`[시각화: 사용자가 분할표의 숫자를 수정하면 실시간으로 막대그래프로 변하는 인터랙티브 차트]`

---

### 4.3.2 독립일 때의 모습: 기대 빈도(Expected Frequency)
만약 성별과 제품 선호도가 **완전히 독립적**이라면, 남성과 여성이 제품 A를 선택할 비율은 전체 비율(90/200 = 45%)과 같아야 합니다.

이처럼 "두 변수가 독립이다"라는 가설(귀무가설) 하에 계산된 이론적인 빈도를 **기대 빈도**라고 합니다. 계산식은 다음과 같습니다.

$$E_{i,j} = \frac{(\text{i행의 합계}) \times (\text{j열의 합계})}{\text{전체 합계}}$$

위 예시에서 '남성이면서 제품 A를 선택할 기대 빈도'는 다음과 같습니다.
$$E_{남성, A} = \frac{100 \times 90}{200} = 45$$

실제 관측값은 60이었는데, 기대값은 45입니다. 이 차이가 클수록 두 변수는 독립이 아닐 가능성이 높아집니다.

---

### 4.3.3 카이제곱($\chi^2$) 통계량
관측 빈도($O$)와 기대 빈도($E$)의 차이를 수치화한 것이 카이제곱 통계량입니다.

$$\chi^2 = \sum \frac{(O - E)^2}{E}$$

- 차이가 작으면 $\chi^2$ 값은 작아지고, 귀무가설(독립이다)을 채택합니다.
- 차이가 크면 $\chi^2$ 값은 커지고, 귀무가설을 기각(독립이 아니다 = 관련이 있다)합니다.

`[시각화: 카이제곱 분포 그래프에서 유의수준(p-value)에 따른 기각역 표시 슬라이더]`

---

### 4.3.4 파이썬 실습: 독립성 검정 수행하기
파이썬의 `scipy.stats` 라이브러리는 독립성 검정을 위한 `chi2_contingency` 함수를 제공합니다.

```python
import numpy as np
from scipy.stats import chi2_contingency

# 1. 분할표 데이터 생성 (관측 빈도)
# 행: 남성, 여성 / 열: 제품 A, 제품 B
observed = np.array([[60, 40], [30, 70]])

# 2. 카이제곱 검정 수행
chi2, p_value, dof, expected = chi2_contingency(observed)

print(f"카이제곱 통계량: {chi2:.4f}")
print(f"p-value: {p_value:.4f}")
print(f"자유도: {dof}")
print("기대 빈도 표:")
print(expected)

# 3. 결과 해석
alpha = 0.05
if p_value < alpha:
    print("\n결론: p-value가 유의수준보다 작으므로 귀무가설을 기각합니다.")
    print("즉, 성별과 제품 선호도 사이에는 유의미한 관계가 있습니다.")
else:
    print("\n결론: p-value가 유의수준보다 크므로 귀무가설을 채택합니다.")
    print("즉, 성별과 제품 선호도는 서로 독립적이라고 볼 수 있습니다.")
```

#### 코드 설명
- `chi2_contingency()`: 관측 빈도 배열을 입력하면 카이제곱 통계량, p-value, 자유도, 기대 빈도를 한 번에 계산해 줍니다.
- `dof` (자유도): $(행의 수 - 1) \times (열의 수 - 1)$로 계산됩니다. 여기서는 $(2-1) \times (2-1) = 1$입니다.
- `p_value`: 이 값이 0.05(보통의 유의수준)보다 작으면 "이 차이는 우연히 발생했다고 보기 어렵다"고 판단합니다.

---

## 3. 요약

1. **독립성 검정**은 두 범주형 변수 간의 연관성을 확인하기 위해 사용합니다.
2. **귀무가설($H_0$)**은 "두 변수는 독립이다(관련이 없다)"이며, **대립가설($H_1$)**은 "두 변수는 독립이 아니다(관련이 있다)"입니다.
3. **기대 빈도**와 **관측 빈도**의 차이가 클수록 카이제곱 통계량이 커지며, p-value는 작아집니다.
4. 파이썬의 `scipy.stats.chi2_contingency`를 사용하면 복잡한 수식 계산 없이 데이터로부터 즉시 의사결정을 내릴 수 있습니다.

데이터 분석가로서 여러분은 단순히 "A와 B가 달라 보인다"는 직관에 의존하는 대신, 독립성 검정을 통해 **95% 이상의 확신을 가지고 "이 둘은 연관되어 있다"라고 당당하게 주장**할 수 있게 되었습니다.

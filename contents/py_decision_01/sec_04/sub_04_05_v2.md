# 4.5 분산 분석 (ANOVA: Analysis of Variance)

## 1. 도입: 왜 평균의 차이를 '분산'으로 분석할까?

우리는 앞서 두 집단의 평균을 비교할 때 **T-검정(T-test)**을 사용했습니다. 하지만 비교해야 할 집단이 3개, 4개로 늘어난다면 어떻게 될까요? 예를 들어, A, B, C 세 가지 교육 방법의 효과를 비교하고 싶을 때 T-검정을 사용하려면 (A-B), (B-C), (A-C) 이렇게 세 번의 검정을 거쳐야 합니다.

문제는 검정 횟수가 늘어날수록 **제1종 오류(실제로 차이가 없는데 차이가 있다고 결론 내릴 위험)**가 눈덩이처럼 불어난다는 점입니다. 이를 '다중 비교의 문제'라고 합니다.

**분산 분석(ANOVA)**은 이러한 문제를 해결하기 위해 탄생했습니다. 이름은 '분산' 분석이지만, 궁극적인 목적은 **"여러 집단의 평균들이 서로 유의미하게 다른가?"**를 한 번에 판정하는 것입니다. 이번 장에서는 전체 변동성을 '신호'와 '소음'으로 나누어 분석하는 ANOVA의 원리를 깊이 있게 살펴보겠습니다.

---

## 2. 본론: ANOVA의 핵심 원리

### 2.1 신호(Signal)와 소음(Noise)의 비유
ANOVA를 이해하는 가장 쉬운 방법은 데이터를 **'신호'**와 **'소음'**의 결합으로 보는 것입니다.

- **신호 (집단 간 분산, Between-group Variance):** 우리가 알고 싶은 효과입니다. 교육 방법의 차이 때문에 발생하는 데이터의 움직임입니다.
- **소음 (집단 내 분산, Within-group Variance):** 개별적인 차이입니다. 같은 교육을 받아도 사람마다 점수가 다른, 즉 통제할 수 없는 우연한 변동입니다.

**[시각화: 세 개의 정규분포 그래프. 각 분포의 중심(평균) 거리가 멀어지는 애니메이션과 각 분포의 폭(표준편차)이 넓어지는 애니메이션을 비교하여 '구분 가능성'을 시각화]**

ANOVA는 **"우리가 관찰한 집단 간의 차이(신호)가 개별 데이터의 무작위한 변동(소음)보다 충분히 큰가?"**를 질문합니다.

### 2.2 변동의 분할 (Sum of Squares)
ANOVA는 전체 데이터가 가진 총 변동성($SS_{Total}$)을 두 가지 성분으로 쪼갭니다.

1.  **집단 간 제곱합 ($SS_{Between}$):** 각 집단의 평균이 전체 평균으로부터 얼마나 떨어져 있는지를 계산합니다. (신호의 크기)
2.  **집단 내 제곱합 ($SS_{Within}$):** 각 집단 내부의 개별 데이터들이 자기 집단의 평균으로부터 얼마나 떨어져 있는지를 계산합니다. (소음의 크기)

$$SS_{Total} = SS_{Between} + SS_{Within}$$

이것을 각자의 **자유도(degree of freedom)**로 나누어주면 '평균적인 변동성'인 **분산(Mean Square)**이 됩니다.

- $MS_{Between} = \frac{SS_{Between}}{k-1}$ (단, $k$는 집단의 수)
- $MS_{Within} = \frac{SS_{Within}}{n-k}$ (단, $n$은 전체 데이터 수)

### 2.3 F-통계량: 결정적인 비(Ratio)
이제 ANOVA의 주인공인 **F-통계량**이 등장합니다. F-통계량은 소음 대비 신호의 비율입니다.

$$F = \frac{MS_{Between} (신호)}{MS_{Within} (소음)}$$

- **F값이 1에 가깝다면:** 신호가 소음과 비슷한 수준입니다. 즉, 집단 간 차이가 우연일 가능성이 높습니다.
- **F값이 1보다 충분히 크다면:** 소음에 비해 신호가 압도적으로 큽니다. 즉, "적어도 한 집단은 다른 집단과 평균이 다르다"라고 결론 내릴 수 있습니다.

**[시각화: F-분포 그래프에서 임계값(Critical Value) 오른쪽의 '기각역'을 색칠하고, 계산된 F값이 그 영역에 들어가는지 보여주는 인터랙티브 차트]**

## 3. ANOVA 수행 단계 및 코드 예제

### 3.1 ANOVA의 가정
분산 분석을 수행하기 전에는 반드시 세 가지 전제 조건을 확인해야 합니다.
1.  **독립성:** 각 집단의 관측치는 서로 독립적이어야 합니다.
2.  **정규성:** 각 집단의 데이터는 정규분포를 따라야 합니다.
3.  **등분산성:** 모든 집단의 분산은 서로 비슷해야 합니다. (소음의 크기가 집단마다 일정해야 공정한 비교가 가능하기 때문입니다.)

### 3.2 Python 코드 실습
세 가지 사료(A, B, C)에 따른 가축의 무게 변화를 비교하는 상황을 가정해 보겠습니다.

```python
import scipy.stats as stats
import pandas as pd

# 데이터 준비
group_A = [28, 30, 32, 29, 31]
group_B = [35, 38, 36, 37, 39]
group_C = [25, 24, 26, 27, 23]

# 1. 일원 분산 분석(One-way ANOVA) 수행
f_statistic, p_value = stats.f_oneway(group_A, group_B, group_C)

print(f"F-통계량: {f_statistic:.4f}")
print(f"p-value: {p_value:.4e}")

# 결과 해석
if p_value < 0.05:
    print("결론: 집단 간 평균 차이가 유의미합니다. (귀무가설 기각)")
else:
    print("결론: 집단 간 평균 차이가 유의미하지 않습니다. (귀무가설 채택)")
```

### 3.3 사후 분석 (Post-hoc Analysis)
ANOVA에서 p-value가 0.05보다 작게 나와 귀무가설을 기각하더라도, 정확히 **"어느 집단과 어느 집단이 다른지"**는 알 수 없습니다. 이때 수행하는 것이 **사후 분석**입니다. 대표적으로 **Tukey's HSD** 방식이 있으며, 이는 다중 비교 시 발생하는 오류를 보정하면서 집단 간 차이를 일대일로 비교합니다.

## 4. 요약 및 핵심 포인트

- **ANOVA의 목적:** 3개 이상 집단의 평균 차이를 '동시에' 검정하여 제1종 오류를 방지합니다.
- **핵심 메커니즘:** 전체 데이터의 변동을 **'집단 간 변동(신호)'**과 **'집단 내 변동(소음)'**으로 나눕니다.
- **F-통계량:** 소음(MSW)에 비해 신호(MSB)가 얼마나 큰지를 나타내는 수치입니다.
- **한계점:** ANOVA는 "차이가 있다/없다"만 알려줄 뿐, 정확히 어떤 집단 간에 차이가 있는지는 **사후 분석**을 통해 추가로 확인해야 합니다.

**[시각화: ANOVA 분석 전체 흐름도 - 데이터 입력 -> 가정 검정 -> F-통계량 계산 -> p-value 판단 -> (유의할 경우) 사후 분석 진행]**

# 4.3 독립성의 검정 (v2)

## 1. 도입
데이터 분석의 핵심은 '관계'를 찾아내는 것입니다. "성별에 따라 선호하는 스마트폰 브랜드가 다를까?", "거주 지역에 따라 정당 지지율에 차이가 있을까?"와 같은 질문들은 모두 두 변수 사이의 **연관성**을 묻고 있습니다. 

**독립성의 검정(Test of Independence)**은 두 개의 범주형 변수(Categorical Variables)가 서로 아무런 관련 없이 독립적인지, 아니면 통계적으로 유의미한 관계가 있는지를 파악하는 강력한 도구입니다. 이번 절에서는 교차표를 통해 데이터를 구조화하고, 기대 빈도라는 개념을 통해 두 변수의 연결 고리를 추적하는 방법을 학습합니다.

---

## 2. 본론

### 2.1 범주형 데이터의 요약: 교차표 (Contingency Table)
독립성 검정을 수행하기 위한 첫 단계는 데이터를 **교차표(이원 분할표)** 형태로 정리하는 것입니다. 교차표는 두 변수의 범주를 행과 열로 배치하고, 각 조합에 해당하는 빈도(Frequency)를 기록한 표입니다.

- **관측 빈도($O_{ij}$):** 실제로 수집된 데이터에서 각 셀에 해당하는 빈도수입니다.

`[시각화: 사용자가 행과 열의 이름을 입력하면 빈 칸의 교차표가 생성되고, 숫자를 입력할 수 있는 대화형 그리드]`

### 2.2 독립성의 의미와 기대 빈도 (Expected Frequency)
통계학에서 두 변수가 **독립**이라는 것은, 한 변수의 상태가 다른 변수의 확률 분포에 아무런 영향을 주지 않는다는 것을 의미합니다.

만약 두 변수가 독립이라면, 특정 셀 $(i, j)$에 데이터가 속할 확률은 각 변수의 주변 확률(Marginal Probability)의 곱과 같아야 합니다. 이를 바탕으로 계산한 '이론적인 빈도'가 바로 **기대 빈도($E_{ij}$)**입니다.

$$ E_{ij} = \frac{(\text{i번째 행의 합계}) \times (\text{j번째 열의 합계})}{\text{전체 합계(N)}} $$

**왜 이런 식이 나올까요?**
전체 $N$명 중 $i$행에 속할 확률은 $R_i/N$이고, $j$열에 속할 확률은 $C_j/N$입니다. 두 사건이 독립이라면 동시에 일어날 확률은 $(R_i/N) \times (C_j/N)$이 됩니다. 여기에 전체 개수 $N$을 곱하면 기대 빈도가 유도됩니다.

### 2.3 카이제곱($\chi^2$) 통계량: 차이의 수치화
이제 우리가 실제로 관측한 값($O$)과, 독립이라고 가정했을 때 나와야 할 값($E$) 사이의 거리를 측정해야 합니다. 이 거리가 멀면 멀수록 "두 변수는 독립이다"라는 가설은 설득력을 잃게 됩니다.

$$ \chi^2 = \sum \frac{(O_{ij} - E_{ij})^2}{E_{ij}} $$

- **분자의 제곱:** 관측값과 기대값의 차이가 음수가 되는 것을 방지하고, 차이가 클수록 가중치를 줍니다.
- **분모의 기대 빈도:** 빈도가 큰 셀에서의 차이와 작은 셀에서의 차이를 상대적으로 비교(표준화)하기 위함입니다.

`[시각화: 관측 빈도 슬라이더를 조절함에 따라 카이제곱 통계량 값이 실시간으로 계산되어 그래프 상의 점으로 표시되는 시뮬레이션]`

### 2.4 자유도와 기각역
카이제곱 통계량은 변수의 범주 개수에 따라 분포의 모양이 달라집니다. 이때 결정적인 역할을 하는 것이 **자유도(Degrees of Freedom, $df$)**입니다.

- **자유도 계산:** $df = (r - 1) \times (c - 1)$
  - $r$: 행의 개수, $c$: 열의 개수
- **의미:** 행의 합계와 열의 합계가 정해져 있을 때, 표 안에서 자유롭게 채울 수 있는 칸의 개수를 의미합니다.

### 2.5 가설 검정 절차
1.  **가설 설정**
    - 귀무가설($H_0$): 두 변수는 서로 독립이다. (연관성이 없다.)
    - 대립가설($H_1$): 두 변수는 서로 독립이 아니다. (연관성이 있다.)
2.  **유의수준($\alpha$) 결정:** 통상적으로 0.05 또는 0.01을 사용합니다.
3.  **검정 통계량 계산:** 위의 $\chi^2$ 공식을 사용합니다.
4.  **p-value 확인 및 결론:** 계산된 통계량이 임계값보다 크거나 p-value가 $\alpha$보다 작으면 귀무가설을 기각합니다.

## 3. 코드 예제: Python을 활용한 독립성 검정

`scipy.stats` 라이브러리의 `chi2_contingency` 함수를 사용하면 교차표 입력만으로 모든 값을 한 번에 계산할 수 있습니다.

```python
import numpy as np
from scipy.stats import chi2_contingency

# 예시 데이터: 흡연 여부와 폐질환 발생 여부 교차표
# 행: 흡연자, 비흡연자 / 열: 질환 있음, 질환 없음
observed = np.array([[30, 10],   # 흡연자 그룹
                     [20, 40]])  # 비흡연자 그룹

# 독립성 검정 수행
chi2, p, dof, expected = chi2_contingency(observed)

print(f"카이제곱 통계량: {chi2:.4f}")
print(f"p-value: {p:.4f}")
print(f"자유도: {dof}")
print("기대 빈도 표:")
print(expected)

# 결론 도출
alpha = 0.05
if p < alpha:
    print("결론: 귀무가설을 기각합니다. 두 변수 사이에는 유의미한 연관성이 있습니다.")
else:
    print("결론: 귀무가설을 채택합니다. 두 변수는 독립적이라고 볼 수 있습니다.")
```

## 4. 요약
1.  **목적:** 두 범주형 변수가 서로 독립인지, 아니면 관계가 있는지를 검정합니다.
2.  **기대 빈도:** 두 변수가 독립이라는 가정하에 계산된 이론적 빈도입니다.
3.  **카이제곱 통계량:** 관측 빈도와 기대 빈도의 차이가 클수록 통계량이 커지며, 이는 두 변수 간의 강한 연관성을 시사합니다.
4.  **주의사항:** 각 셀의 기대 빈도가 5 미만인 경우가 많으면 검정의 신뢰도가 떨어지므로, '피셔의 정확 검정(Fisher's Exact Test)' 등을 고려해야 합니다.

`[시각화: 카이제곱 분포 곡선에서 유의수준 5%에 해당하는 임계 영역(Critical Region)을 색칠하여 보여주고, 계산된 p-value의 위치를 화살표로 표시]`

# 4.4 t-검정 (t-test)

## 1. 도입: 데이터 사이의 '진짜' 차이를 찾아서
우리가 의사결정을 내릴 때 가장 자주 마주하는 질문 중 하나는 **"두 집단의 평균이 정말로 다른가?"**입니다. 예를 들어, "신메뉴를 출시한 매장의 매출이 기존 매장보다 높은가?", "A 광고안이 B 광고안보다 클릭률이 높은가?"와 같은 질문들입니다.

단순히 두 집단의 평균값을 계산해서 비교하면 되지 않을까요? 하지만 여기에는 **'우연'**이라는 함정이 숨어 있습니다. 우리가 수집한 데이터는 전체(모집단) 중 일부(표본)일 뿐이며, 우연히 특정 시점에만 평균이 높게 나타났을 가능성이 있기 때문입니다. 

**t-검정(t-test)**은 바로 이러한 '우연의 일치'를 배제하고, 관측된 차이가 통계적으로 **의미 있는(Significant) 차이**인지를 판정하는 도구입니다. 이 장에서는 t-검정의 원리부터 파이썬을 활용한 실습까지 차근차근 알아보겠습니다.

---

## 2. 본론

### 2.1 t-검정의 핵심 원리: '차이'와 '불확실성'의 비율
t-검정의 핵심 결과물은 **t-값(t-statistic)**이라는 수치입니다. 이 수치는 다음과 같은 개념적인 구조를 가집니다.

$$t = \frac{\text{두 집단 사이의 평균 차이 (Signal)}}{\text{집단 내부의 변동성 (Noise)}}$$

*   **분자(차이):** 두 그룹의 평균이 멀리 떨어져 있을수록 t-값은 커집니다.
*   **분모(불확실성):** 각 그룹 내에서 데이터들이 흩어져 있는 정도(표준오차)를 의미합니다. 데이터가 여기저기 흩어져 있다면(노이즈가 크다면), 평균 차이가 조금 나더라도 그것이 진짜 차이인지 확신하기 어렵습니다.

결국 t-검정은 **"노이즈에 비해 시그널이 충분히 큰가?"**를 묻는 과정입니다.

[시각화: 두 개의 정규분포 그래프. (1) 평균은 다르지만 표준편차가 커서 많이 겹치는 경우와 (2) 평균 차이는 같지만 표준편차가 작아 확연히 구분되는 경우를 비교하여 t-값의 의미를 시각화]

### 2.2 t-분포와 자유도
t-검정은 왜 'z-검정(정규분포)'이 아닌 't-검정'이라고 부를까요? 현실적으로 우리는 모집단의 정확한 분산을 알 수 없습니다. 표본의 크기가 작을 때(보통 30명 미만), 정규분포보다 양 끝단(Tail)이 더 두터운 **t-분포**를 사용하면 훨씬 안전한 결론을 내릴 수 있습니다.

여기서 중요한 개념이 **자유도(Degrees of Freedom)**입니다. 간단히 말해 표본의 개수($n$)에서 1을 뺀 값($n-1$)으로 이해할 수 있습니다. 표본이 많아질수록(자유도가 높아질수록) t-분포는 정규분포와 거의 흡사해집니다.

### 2.3 t-검정의 세 가지 유형
의사결정 상황에 따라 사용하는 t-검정의 종류가 달라집니다.

1.  **단일표본 t-검정 (One-sample t-test):** 한 집단의 평균이 특정 기준값(예: 우리 과자 한 봉지의 무게는 정말 100g인가?)과 같은지 확인합니다.
2.  **독립표본 t-검정 (Independent two-sample t-test):** 서로 다른 두 집단(예: 남성과 여성, A팀과 B팀)의 평균을 비교합니다.
3.  **대응표본 t-검정 (Paired-sample t-test):** 동일한 대상의 전/후(예: 다이어트 약 복용 전후의 몸무게)를 비교합니다.

---

### 2.4 파이썬 실습: 독립표본 t-검정
가장 많이 쓰이는 '독립표본 t-검정'을 파이썬으로 구현해 보겠습니다. `scipy.stats` 라이브러리를 사용하면 간단히 계산할 수 있습니다.

**시나리오:** A 쇼핑몰 사이트의 레이아웃을 변경(A안 vs B안)했을 때, 고객들의 평균 체류 시간에 차이가 있는지 검정합니다.

```python
import numpy as np
from scipy import stats

# 1. 데이터 생성 (가상의 체류 시간 데이터)
# A안: 평균 120초, 표준편차 15초 / B안: 평균 130초, 표준편차 15초
np.random.seed(42)
group_a = np.random.normal(120, 15, 30)
group_b = np.random.normal(130, 15, 30)

# 2. 독립표본 t-검정 수행 (Independent t-test)
t_stat, p_value = stats.ttest_ind(group_a, group_b)

print(f"t-통계량: {t_stat:.4f}")
print(f"p-value: {p_value:.4f}")

# 3. 결과 해석
alpha = 0.05 # 유의수준 5%
if p_value < alpha:
    print("결과: 두 집단 간의 평균 차이는 통계적으로 유의합니다. (귀무가설 기각)")
else:
    print("결과: 두 집단 간의 평균 차이는 통계적으로 유의하지 않습니다. (귀무가설 채택)")
```

### 2.5 결과의 핵심: p-value 읽는 법
코드 결과에서 가장 중요한 것은 **p-value**입니다.
*   **p-value < 0.05:** "두 집단이 사실 같은데, 우연히 이런 차이가 나타날 확률이 5%도 안 된다"는 뜻입니다. 즉, **"이 차이는 진짜다"**라고 결론 내립니다.
*   **p-value >= 0.05:** "이 정도 차이는 우연히 발생할 수 있는 수준이다"라고 판단하며, 차이가 없다고 결론 내립니다.

[시각화: t-분포 그래프에서 임계값(Critical Value)과 p-value 영역을 색칠하여 표시. 사용자가 유의수준(alpha)을 조절하면 기각역이 변하는 모습 시각화]

---

## 3. 요약
1.  **t-검정**은 두 집단의 평균 차이가 우연인지, 아니면 통계적으로 유의미한 실제 차이인지를 판별하는 기법입니다.
2.  **t-값**은 평균의 차이를 데이터의 변동성(노이즈)으로 나눈 값으로, 이 값이 클수록 실제 차이일 가능성이 높습니다.
3.  **p-value**가 0.05(유의수준)보다 작을 때, 우리는 "통계적으로 유의미한 차이가 있다"고 말하며 의사결정의 근거로 삼습니다.
4.  파이썬의 `scipy.stats.ttest_ind` 등을 활용하면 복잡한 수식 없이도 실무 데이터에 즉시 적용이 가능합니다.

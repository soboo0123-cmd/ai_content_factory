회귀분석(Regression Analysis)은 이처럼 변수들 사이의 관계를 통계적으로 모델링하여, 특정 변수의 값을 바탕으로 다른 변수의 값을 예측하는 가장 대표적인 기법입니다. 이번 섹션에서는 회귀분석의 어원과 정의, 그리고 의사결정 과정에서 회귀분석이 왜 중요한지 기초부터 탄탄히 학습해 보겠습니다.

## 2. 본론

### 2.1 회귀(Regression)의 기원: 평균으로의 회귀
'회귀'라는 용어는 영국의 유전학자 프랜시스 골턴(Francis Galton)의 연구에서 시작되었습니다. 골턴은 부모의 키와 자녀의 키 사이의 관계를 조사하던 중 흥미로운 사실을 발견했습니다. 아주 키가 큰 부모의 자녀는 부모보다 조금 작고, 아주 키가 작은 부모의 자녀는 부모보다 조금 큰 경향이 있었습니다. 즉, 자녀의 키가 세대를 거듭할수록 인류의 **평균 키로 돌아가려는(Regress)** 성질이 있다는 것입니다.

현대 통계학에서 회귀분석은 이 '평균으로 돌아가는 현상' 자체보다는, **변수들 간의 함수적인 관계를 찾아내어 미래의 값을 예측하는 것**에 더 큰 초점을 맞춥니다.

### 2.2 독립변수와 종속변수
회귀분석을 이해하기 위해서는 먼저 두 가지 종류의 변수를 명확히 정의해야 합니다.

1.  **독립변수 (Independent Variable, $X$):** 원인이 되는 변수입니다. '설명변수'라고도 부르며, 우리가 조절하거나 관찰할 수 있는 값입니다.
2.  **종속변수 (Dependent Variable, $Y$):** 결과가 되는 변수입니다. '반응변수'라고도 부르며, 독립변수의 변화에 따라 값이 결정되는 우리가 예측하고자 하는 대상입니다.

> **예시:** "배달 소요 시간($Y$)은 배달 거리($X$)에 따라 달라진다."
> 여기서 거리는 우리가 통제할 수 없거나 관찰하는 대상이므로 **독립변수**, 그에 따라 결정되는 시간은 **종속변수**가 됩니다.

[시각화: 산점도(Scatter Plot) 위에 마우스를 올리면 각 점의 (X, Y) 좌표가 표시되고, 독립변수와 종속변수의 명칭을 강조하는 툴팁 표시]

### 2.3 선형 회귀의 수학적 모델
가장 단순한 형태인 **단순 선형 회귀(Simple Linear Regression)**는 독립변수 $X$와 종속변수 $Y$의 관계를 다음과 같은 직선의 방정식으로 표현합니다.

$$Y = \beta_0 + \beta_1X + \epsilon$$

*   $\beta_0$: **절편(Intercept)**. $X$가 0일 때의 $Y$ 값입니다.
*   $\beta_1$: **기울기(Slope)**. $X$가 1단위 증가할 때 $Y$가 변화하는 양입니다. 이것이 곧 두 변수의 '관계의 세기'를 나타냅니다.
*   $\epsilon$: **오차항(Error term)**. 모델이 설명하지 못하는 실제 값과 예측값의 차이를 의미합니다.

회귀분석의 목적은 수집된 데이터를 가장 잘 설명하는 최적의 $\beta_0$와 $\beta_1$을 찾아내는 것입니다.

[시각화: 슬라이더를 이용해 $\beta_0$와 $\beta_1$ 값을 조절하면 그래프상의 직선이 실시간으로 움직이며 데이터 포인트들과의 거리가 변하는 모습 시각화]

### 2.4 파이썬으로 구현하는 기초 회귀 모델
파이썬의 `scikit-learn` 라이브러리를 사용하면 복잡한 수학적 계산 없이도 간단히 회귀분석을 수행할 수 있습니다. 공부 시간과 시험 점수 데이터를 바탕으로 간단한 모델을 만들어 보겠습니다.

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression

# 1. 데이터 준비 (공부 시간 대비 시험 점수)
# 독립변수 X는 2차원 배열 형태여야 합니다.
X = np.array([[1], [2], [3], [4], [5], [6], [7], [8]]) 
Y = np.array([15, 25, 35, 50, 60, 75, 80, 95])

# 2. 모델 생성 및 학습
model = LinearRegression()
model.fit(X, Y)

# 3. 기울기(Slope)와 절편(Intercept) 출력
print(f"기울기(beta_1): {model.coef_[0]:.2f}")
print(f"절편(beta_0): {model.intercept_:.2f}")

# 4. 새로운 데이터로 예측 (10시간 공부했을 때)
hours_new = np.array([[10]])
score_pred = model.predict(hours_new)
print(f"10시간 공부 시 예상 점수: {score_pred[0]:.2f}점")

# 5. 시각화
plt.scatter(X, Y, color='blue', label='Actual Data') # 실제 데이터
plt.plot(X, model.predict(X), color='red', label='Regression Line') # 회귀 직선
plt.xlabel('Study Hours')
plt.ylabel('Score')
plt.legend()
plt.show()
```

## 3. 요약
1.  **회귀분석의 정의:** 변수들 사이의 관계를 파악하여 독립변수($X$)로 종속변수($Y$)를 예측하는 통계 기법입니다.
2.  **역사적 배경:** 골턴의 '평균으로의 회귀'에서 유래하였으나, 현재는 예측 모델링의 핵심으로 사용됩니다.
3.  **핵심 요소:**
    *   **독립변수:** 원인, 입력값 ($X$)
    *   **종속변수:** 결과, 예측값 ($Y$)
    *   **회귀 계수:** 직선의 기울기와 절편을 의미하며, 데이터 사이의 관계를 규정합니다.
4.  **의사결정의 가치:** 과거 데이터를 통해 검증된 수치적 근거를 바탕으로 미래의 결과를 예측함으로써 객관적인 의사결정을 가능하게 합니다.

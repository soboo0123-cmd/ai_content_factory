# 5.4 다중회귀분석 (Multiple Linear Regression) - v2

## 1. 도입: 단순한 세상에서 복잡한 현실로
우리는 앞서 하나의 독립변수($X$)가 하나의 종속변수($Y$)에 미치는 영향을 파악하는 '단순회귀분석'을 배웠습니다. 예를 들어 "공부 시간이 성적에 미치는 영향"을 분석했죠. 하지만 현실은 그렇게 단순하지 않습니다. 성적에 영향을 주는 요인은 공부 시간뿐만 아니라, 집중력, 수면 시간, 이전 학습 수준 등 매우 다양합니다.

**다중회귀분석(Multiple Linear Regression)**은 이처럼 여러 개의 독립변수가 동시에 하나의 종속변수에 미치는 영향을 분석하는 기법입니다. 이를 통해 우리는 현실 세계의 복잡한 인과관계를 보다 정확하게 모델링하고 예측할 수 있게 됩니다.

### 학습 목표
- 다중회귀분석의 개념과 수식 구조를 이해합니다.
- '평면'과 '초평면'의 개념을 통해 고차원 회귀 모델을 시각화합니다.
- 다중회귀분석에서 각 변수가 갖는 의미(편회귀계수)를 파악합니다.

---

## 2. 본론: 다차원의 세계를 선형으로 잇다

### 2.1 다중회귀식의 구조
단순회귀분석이 2차원 평면 위의 '선'을 찾는 과정이었다면, 다중회귀분석은 3차원 이상의 공간에서 '면' 또는 '체'를 찾는 과정입니다. $n$개의 독립변수가 있을 때의 수식은 다음과 같습니다.

$$Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \beta_3 X_3 + \dots + \beta_n X_n + \epsilon$$

- $Y$: 종속변수 (결과)
- $X_1, X_2, \dots, X_n$: 독립변수 (원인들)
- $\beta_0$: 절편 (모든 $X$가 0일 때의 $Y$값)
- $\beta_1, \beta_2, \dots, \beta_n$: **편회귀계수 (Partial Regression Coefficients)**
- $\epsilon$: 오차항 (모델이 설명하지 못하는 변동분)

`[시각화: 3차원 좌표계(X1, X2, Y축)에 산점도가 뿌려져 있고, 그 데이터들 사이를 가로지르는 반투명한 '회귀 평면'이 생성되는 인터랙티브 그래프]`

### 2.2 편회귀계수의 의미: "다른 조건이 일정할 때"
다중회귀분석에서 가장 중요한 개념은 $\beta_i$의 해석입니다. 이를 **편회귀계수**라고 부르는 이유는 **"다른 모든 독립변수의 값이 고정되어 있을 때"** 해당 변수($X_i$)가 한 단위 변화함에 따라 $Y$가 변화하는 양을 나타내기 때문입니다.

예를 들어, 아파트 가격($Y$)을 예측할 때 '면적($X_1$)'과 '준공 연도($X_2$)'를 변수로 쓴다면:
- $\beta_1$: 준공 연도가 같을 때, 면적이 1평 넓어짐에 따라 변화하는 가격.
- $\beta_2$: 면적이 같을 때, 준공 연도가 1년 최신일수록 변화하는 가격.

이것은 변수 간의 영향력을 분리해서 볼 수 있게 해준다는 점에서 매우 강력한 도구가 됩니다.

### 2.3 최적의 평면 찾기: 최소제곱법(LSE)의 확장
단순회귀와 마찬가지로 다중회귀에서도 실제 값과 모델의 예측값 차이의 제곱합($RSS$)을 최소화하는 계수들을 찾습니다.

$$RSS = \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$

변수가 많아지면 이를 손으로 계산하기는 매우 어렵기 때문에, 행렬 연산(Matrix Algebra)을 통해 한 번에 계산합니다. 컴퓨터는 수만 개의 변수가 있어도 선형대수학의 원리를 이용해 순식간에 최적의 $\beta$ 값들을 찾아냅니다.

### 2.4 파이썬 코드 예제
실제 데이터를 사용하여 다중회귀 모델을 구현해 보겠습니다.

```python
import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression

# 1. 가상의 데이터 생성 (공부시간, 수면시간 -> 시험점수)
data = {
    'Study_Hours': [2, 4, 6, 8, 10],
    'Sleep_Hours': [7, 8, 5, 6, 7],
    'Test_Score': [65, 75, 82, 90, 95]
}
df = pd.DataFrame(data)

# 2. 독립변수(X)와 종속변수(y) 분리
X = df[['Study_Hours', 'Sleep_Hours']]
y = df['Test_Score']

# 3. 모델 학습
model = LinearRegression()
model.fit(X, y)

# 4. 결과 출력
print(f"절편(Intercept): {model.intercept_:.2f}")
print(f"계수(Coefficients):")
for col, coef in zip(X.columns, model.coef_):
    print(f" - {col}: {coef:.2f}")

# 5. 새로운 데이터 예측 (12시간 공부하고 6시간 잤을 때)
new_data = np.array([[12, 6]])
prediction = model.predict(new_data)
print(f"\n예측 점수: {prediction[0]:.2f}")
```

`[시각화: 슬라이더를 조절하여 공부 시간과 수면 시간을 바꾸면, 실시간으로 예측 점수가 계산되어 게이지 바(Gauge Bar) 형태로 나타나는 위젯]`

## 3. 요약 및 핵심 포인트

1.  **다중회귀분석**은 두 개 이상의 독립변수가 종속변수에 미치는 영향을 동시에 분석하는 기법입니다.
2.  **기하학적 의미**: 변수가 2개면 3차원 공간상의 '평면'으로, 3개 이상이면 '초평면(Hyperplane)'으로 표현됩니다.
3.  **편회귀계수($\beta$)**: 다른 변수의 영향을 통제한 상태에서 특정 변수만이 갖는 순수한 영향력을 의미합니다.
4.  **모델의 확장성**: 현실의 복잡한 인과관계를 반영할 수 있지만, 변수가 너무 많아지면 모델이 복잡해지는 '과적합'이나 변수 간 상관관계가 높은 '다중공선성' 문제를 주의해야 합니다.

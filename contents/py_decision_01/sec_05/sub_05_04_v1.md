# 05 회귀분석
## 5.4 다중회귀분석(Multiple Linear Regression)

### 1. 도입: 현실은 복합적인 원인으로 구성된다
우리는 앞서 하나의 독립변수($X$)가 종속변수($Y$)에 미치는 영향을 파악하는 '단순회귀분석'을 학습했습니다. 예를 들어 "기온이 올라가면 아이스크림 판매량이 늘어난다"는 가설을 검증했죠. 

하지만 현실 세계의 의사결정 문제는 훨씬 더 복잡합니다. 아이스크림 판매량에 영향을 주는 것이 오직 '기온'뿐일까요? 습도, 요일(주말 여부), 근처 학교의 방학 여부 등 수많은 요인이 동시에 작용할 것입니다. **다중회귀분석(Multiple Linear Regression)**은 이처럼 여러 개의 독립변수를 동시에 고려하여 종속변수를 예측하고 분석하는 기법입니다. 

본 섹션에서는 다중회귀분석의 원리를 이해하고, 파이썬을 통해 복잡한 인과관계를 모델링하는 방법을 배웁니다.

---

### 2. 다중회귀분석의 수학적 모델
다중회귀분석은 단순회귀분석의 식을 확장한 형태입니다. 독립변수가 $k$개인 경우, 모델은 다음과 같은 선형 방정식으로 표현됩니다.

$$Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \dots + \beta_k X_k + \epsilon$$

- $Y$: 종속변수 (결과)
- $X_1, X_2, \dots, X_k$: 독립변수 (원인들)
- $\beta_0$: 절편 (모든 독립변수가 0일 때의 $Y$ 값)
- $\beta_1, \beta_2, \dots, \beta_k$: 회귀계수 (각 독립변수의 영향력)
- $\epsilon$: 오차항 (모델이 설명하지 못하는 잔차)

**[시각화: 단순회귀의 '선(Line)'이 다중회귀(변수 2개 기준)에서 '평면(Plane)'으로 확장되는 3D 그래프]**

#### 회귀계수의 의미: "다른 조건이 동일할 때"
다중회귀분석에서 가장 중요한 개념 중 하나는 **'통제(Control)'**입니다. $\beta_1$은 다른 모든 변수($X_2, \dots, X_k$)의 값이 고정되어 있을 때, $X_1$이 1단위 증가함에 따라 $Y$가 얼마나 변화하는지를 나타냅니다. 이를 통해 우리는 특정 요인의 순수한 영향력을 파악할 수 있습니다.

---

### 3. 다중회귀분석의 주요 가정
다중회귀분석이 신뢰성을 얻으려면 몇 가지 전제 조건이 충족되어야 합니다.

1.  **선형성:** 독립변수와 종속변수 간의 관계가 직선 형태여야 합니다.
2.  **독립성:** 오차항 간에 상관관계가 없어야 합니다.
3.  **등분산성:** 오차의 분산이 모든 독립변수 값에 대해 일정해야 합니다.
4.  **정규성:** 오차항이 정규분포를 따라야 합니다.
5.  **다중공선성(Multicollinearity) 부재:** 독립변수들끼리 서로 강한 상관관계를 가지면 안 됩니다. (예: '섭씨 온도'와 '화씨 온도'를 동시에 변수로 넣는 경우)

---

### 4. 파이썬 실습: 주택 가격 예측하기
주택 가격($Y$)에 영향을 미치는 요소인 면적($X_1$), 방의 개수($X_2$), 건축 연도($X_3$)를 활용하여 다중회귀분석을 수행해 보겠습니다.

#### 4.1 데이터 준비
```python
import pandas as pd
import statsmodels.api as sm

# 가상의 데이터 생성
data = {
    'Price': [245, 312, 279, 308, 199, 219, 405, 324, 319, 255],
    'Size': [1400, 1600, 1700, 1875, 1100, 1550, 2350, 2450, 1425, 1700],
    'Bedrooms': [3, 3, 2, 4, 2, 3, 4, 4, 3, 3],
    'Age': [15, 10, 20, 5, 30, 18, 2, 8, 12, 25]
}

df = pd.DataFrame(data)

# 독립변수(X)와 종속변수(Y) 분리
X = df[['Size', 'Bedrooms', 'Age']]
y = df['Price']

# statsmodels에서는 절편을 위해 상수항을 명시적으로 추가해야 함
X = sm.add_constant(X)
```

#### 4.2 모델 학습 및 결과 출력
```python
# 다중회귀모델 생성 및 적합
model = sm.OLS(y, X).fit()

# 결과 리포트 출력
print(model.summary())
```

---

### 5. 결과의 해석
`model.summary()`를 실행하면 방대한 표가 출력됩니다. 우리는 다음 항목에 주목해야 합니다.

1.  **R-squared (결정계수):** 모델이 전체 데이터의 변동성을 얼마나 설명하는지 나타냅니다(0~1 사이). 1에 가까울수록 설명력이 높습니다.
2.  **Adj. R-squared (수정된 결정계수):** 독립변수의 개수가 늘어나면 R-squared는 무조건 커지는 경향이 있습니다. 이를 보정한 값이 수정된 결정계수이며, 다중회귀에서는 이 값을 더 신뢰합니다.
3.  **P-value ($P>|t|$):** 해당 독립변수가 종속변수에 유의미한 영향을 미치는지 판단합니다. 보통 0.05보다 작으면 "통계적으로 유의하다"고 봅니다.
4.  **Coefficients (Coef):** 회귀계수입니다. 이 수치가 해당 변수의 영향력 크기와 방향을 결정합니다.

**[시각화: 결과 표에서 R-squared, P-value, Coef 항목에 하이라이트를 주고 풍선 도움말로 설명을 띄움]**

---

### 6. 요약
- 다중회귀분석은 **두 개 이상의 독립변수**를 사용하여 종속변수를 예측하는 기법입니다.
- 각 회귀계수는 **다른 변수를 통제한 상태**에서의 독립적인 영향력을 의미합니다.
- 모델의 성능은 **수정된 결정계수(Adj. R-squared)**로 판단하며, 각 변수의 유의성은 **P-value**로 확인합니다.
- 변수 간의 강한 상관관계(다중공선성)가 있는지 주의 깊게 살펴야 모델의 왜곡을 막을 수 있습니다.

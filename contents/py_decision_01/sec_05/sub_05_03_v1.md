# 5.3 회귀분석의 메커니즘

## 1. 도입: 기계는 어떻게 '최선의 선'을 찾아내는가?

앞선 섹션에서 우리는 회귀분석이 변수 사이의 관계를 파악하여 미래의 값을 예측하는 도구임을 배웠습니다. 그렇다면 컴퓨터는 수많은 데이터 사이를 가로지르는 수만 가지의 직선 중, 어떤 기준으로 '가장 적절한 직선'을 선택하는 것일까요?

회귀분석의 메커니즘을 이해하는 것은 단순히 공식을 외우는 것이 아니라, 데이터 속에 숨겨진 규칙성을 찾아내는 **최적화(Optimization)** 과정을 이해하는 것입니다. 이번 섹션에서는 회귀분석이 정답을 찾아가는 내부 원리인 '최소자승법(Ordinary Least Squares)'과 '비용 함수'의 개념을 단계별로 살펴보겠습니다.

---

## 2. 본론: 회귀분석의 단계별 원리

### 2.1 가설 세우기: 직선의 방정식
회귀분석은 독립변수 $x$와 종속변수 $y$의 관계를 다음과 같은 직선의 방정식으로 가정하는 것에서 시작합니다.

$$y = wx + b$$

- **$w$ (Weight, 가중치):** 직선의 기울기입니다. $x$가 1단위 변할 때 $y$가 얼마나 변하는지를 나타내며, 영향력을 의미합니다.
- **$b$ (Bias, 편향):** $y$절편입니다. $x$가 0일 때의 기본 $y$값을 의미합니다.

우리의 목표는 실제 데이터들을 가장 잘 대변하는 최적의 $w$와 $b$를 찾는 것입니다.

---

### 2.2 오차(Error)와 잔차(Residual)
데이터는 완벽한 직선 위에 있지 않습니다. 실제 값($y$)과 모델이 예측한 값($\hat{y}$) 사이에는 항상 차이가 발생합니다. 이 차이를 **잔차(Residual)**라고 부릅니다.

$$Residual = y_{actual} - \hat{y}_{predicted}$$

`[시각화: 산점도(Scatter Plot) 위에 회귀선이 있고, 각 데이터 포인트에서 회귀선까지 수직으로 연결된 선분(잔차)을 표시하는 그래프]`

---

### 2.3 비용 함수(Cost Function): 최소자승법
가장 좋은 회귀선은 모든 데이터 포인트와의 잔차 합이 최소가 되는 선입니다. 그런데 단순히 잔차를 더하면 양수(+) 오차와 음수(-) 오차가 서로 상쇄되어 전체 오차가 0이 되는 오류가 발생할 수 있습니다. 

이를 해결하기 위해 잔차를 **제곱**하여 합산하는 방식을 사용하는데, 이를 **RSS(Residual Sum of Squares)** 혹은 **SSE(Sum of Squared Errors)**라고 합니다.

$$RSS = \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 = \sum_{i=1}^{n} (y_i - (wx_i + b))^2$$

이 값을 최소화하는 $w$와 $b$를 구하는 방법을 **최소자승법(Ordinary Least Squares, OLS)**이라고 부릅니다. 

**왜 제곱을 하나요?**
1. **부호 제거:** 모든 오차를 양수로 만들어 합산 가능하게 합니다.
2. **패널티 부여:** 오차가 클수록 제곱 값은 기하급수적으로 커지므로, 큰 오차를 가진 모델에 더 큰 불이익을 주어 정교한 예측을 유도합니다.

`[시각화: 기울기 w를 변화시킴에 따라 RSS(비용 함수) 값이 2차 함수 곡선(U자 형태)을 그리며 변하는 모습]`

---

### 2.4 파이썬으로 확인하는 메커니즘
실제로 파이썬의 `Scikit-learn` 라이브러리를 사용하여 내부적으로 어떻게 계수가 계산되는지 확인해 보겠습니다.

```python
import numpy as np
from sklearn.linear_model import LinearRegression
import matplotlib.pyplot as plt

# 1. 샘플 데이터 생성 (공부 시간 대비 성적)
X = np.array([1, 2, 3, 4, 5]).reshape(-1, 1) # 독립변수 (공부 시간)
y = np.array([15, 28, 42, 58, 72])           # 종속변수 (시험 점수)

# 2. 회귀 모델 객체 생성 및 학습
model = LinearRegression()
model.fit(X, y)

# 3. 학습된 메커니즘 결과 확인 (기울기와 절편)
w = model.coef_[0]      # 가중치 (기울기)
b = model.intercept_   # 편향 (절편)

print(f"회귀 방정식: y = {w:.2f}x + {b:.2f}")

# 4. 예측값 계산
y_pred = model.predict(X)

# 시각화
plt.scatter(X, y, color='blue', label='Actual Data')
plt.plot(X, y_pred, color='red', label='Regression Line')
plt.xlabel('Study Hours')
plt.ylabel('Score')
plt.legend()
plt.show()
```

위 코드에서 `model.fit(X, y)`를 실행하는 순간, 컴퓨터는 앞서 설명한 **RSS를 최소화하는 $w$와 $b$**를 수학적 최적화 기법을 통해 순식간에 계산해냅니다.

---

## 3. 요약: 핵심 포인트

회귀분석의 메커니즘은 결국 **'최선의 타협점'**을 찾는 과정입니다.

1.  **모델링:** 데이터를 설명할 수 있는 직선의 방정식($y = wx + b$)을 설정합니다.
2.  **오차 측정:** 실제 값과 예측 값의 차이인 '잔차'를 계산합니다.
3.  **목표 설정:** 잔차의 제곱합(RSS)을 최소화하는 것을 목표로 합니다.
4.  **최적화:** 수학적 연산을 통해 RSS를 최소로 만드는 최적의 가중치 $w$와 편향 $b$를 결정합니다.

이 메커니즘을 이해하면, 단순히 예측 결과를 수용하는 것을 넘어 모델이 왜 특정 방향으로 기울어졌는지, 그리고 데이터의 노이즈가 모델에 어떤 영향을 주는지 비판적으로 사고할 수 있게 됩니다.

# 5.5 회귀분석의 응용

## 도입
지금까지 우리는 회귀분석의 수학적 원리와 선형 회귀 모델을 구축하는 기본적인 방법을 학습했습니다. 하지만 모델을 만드는 법을 아는 것과, 이를 실제 의사결정 문제에 어떻게 적용할지 아는 것은 별개의 문제입니다.

회귀분석은 단순히 미래의 수치를 예측하는 도구를 넘어, 변수 간의 인과관계를 파악하고 비즈니스 전략을 수립하는 데 강력한 근거를 제공합니다. 이번 섹션에서는 회귀분석이 실무에서 어떻게 응용되는지, 특히 **범주형 데이터의 처리**와 **비선형 관계의 모델링**을 중심으로 구체적인 사례와 파이썬 코드를 통해 알아보겠습니다.

---

## 1. 예측(Prediction)과 설명(Inference)
회귀분석의 응용 목적은 크게 두 가지 방향으로 나뉩니다.

### 1.1 수치 예측 (Prediction)
새로운 데이터($X$)가 주어졌을 때, 결과값($Y$)이 무엇이 될지 맞추는 것이 목적입니다.
*   **예시:** 내일의 주가 예측, 다음 달 예상 매출액 계산.
*   **초점:** 모델의 예측 오차(RMSE, MAE 등)를 최소화하는 데 집중합니다.

### 1.2 인과관계 설명 (Inference)
어떤 요인이 결과에 얼마나 영향을 미치는지 분석하는 것이 목적입니다.
*   **예시:** 광고비 지출이 매출에 유의미한 영향을 주는가? 교육 수준이 연봉 상승에 얼마나 기여하는가?
*   **초점:** 회귀 계수($\beta$)의 크기와 통계적 유의성(p-value)을 해석하는 데 집중합니다.

---

## 2. 범주형 변수의 활용 (가변수, Dummy Variables)
실제 의사결정 상황에서는 '온도'나 '가격'처럼 연속적인 숫자 외에도 '성별', '지역', '이벤트 여부'와 같은 범주형(Categorical) 데이터가 중요하게 작용합니다. 회귀 모델은 수치만을 입력으로 받기 때문에, 이러한 범주형 데이터를 **가변수(Dummy Variable)**로 변환하여 활용합니다.

### 원리: 0과 1의 세계
예를 들어 '주말 여부'라는 변수가 있다면, 주말이면 `1`, 평일이면 `0`으로 코딩합니다.
$$ Y = \beta_0 + \beta_1 X_{price} + \beta_2 D_{weekend} + \epsilon $$
여기서 $\beta_2$는 '다른 조건이 동일할 때, 평일 대비 주말에 매출이 얼마나 증가(또는 감소)하는가'를 나타내는 지표가 됩니다.

`[시각화: 가변수에 따른 회귀선 평행 이동 - 평일 회귀선과 주말 회귀선이 Y축 절편만 다르게 그려지는 모습]`

---

## 3. 비선형 관계의 모델링 (로그 변환)
세상의 모든 관계가 직선(Linear)은 아닙니다. 어떤 변수는 값이 커질수록 영향력이 줄어들거나(한계 효용 체감), 반대로 기하급수적으로 늘어나기도 합니다. 이때 **로그(Log) 변환**을 응용하면 곡선 관계를 선형 회귀로 풀 수 있습니다.

*   **로그-레벨 모델 ($log(Y) = \beta_0 + \beta_1 X$):** $X$가 1단위 증가할 때 $Y$가 약 $\beta_1 \times 100\%$ 변화한다고 해석합니다. (성장률 분석에 유용)
*   **로그-로그 모델 ($log(Y) = \beta_0 + \beta_1 log(X)$):** $X$가 1% 변화할 때 $Y$가 $\beta_1 \%$ 변화한다고 해석합니다. 이를 경제학에서는 **탄력성(Elasticity)**이라고 부릅니다.

## 4. 파이썬 실전 응용 예제
마케팅 데이터셋을 가정하여 광고 매체별 효율성과 '주말 이벤트'의 효과를 분석해 보겠습니다.

```python
import pandas as pd
import numpy as np
import statsmodels.api as sm

# 1. 가상의 마케팅 데이터 생성
data = {
    'sales': [100, 120, 110, 150, 170, 210, 200, 250],
    'ad_spend': [50, 60, 55, 80, 85, 100, 95, 120],
    'is_weekend': [0, 0, 0, 1, 1, 0, 0, 1]  # 1: 주말/이벤트, 0: 평일
}
df = pd.DataFrame(data)

# 2. 독립변수(X)와 종속변수(Y) 설정
# statsmodels에서는 절편(intercept)을 위해 constant를 추가해야 합니다.
X = df[['ad_spend', 'is_weekend']]
X = sm.add_constant(X)
y = df['sales']

# 3. OLS(최소자승법) 모델 적합
model = sm.OLS(y, X).fit()

# 4. 결과 출력
print(model.summary())
```

### 코드 결과 해석 가이드
*   `ad_spend`의 계수($\beta_1$): 광고비를 1단위 더 쓸 때 증가하는 매출의 양.
*   `is_weekend`의 계수($\beta_2$): 광고비가 같더라도 주말일 때 추가로 발생하는 매출. 만약 이 값의 p-value가 0.05보다 작다면 "주말 효과는 통계적으로 유의미하다"고 결론 내릴 수 있습니다.

2.  **범주형 변수:** '예/아니오'와 같은 데이터는 0과 1의 가변수로 만들어 모델에 포함시킵니다.
3.  **로그 변환:** 데이터가 곡선 형태를 띠거나 퍼센트(%) 단위의 해석이 필요할 때 활용합니다.
4.  **의사결정 활용:** 회귀 계수의 유의성을 검토함으로써 어떤 마케팅 채널에 예산을 집중할지, 특정 이벤트가 효과적이었는지 데이터에 기반해 판단할 수 있습니다.

# 5.2 회귀분석의 방법

회귀분석은 단순히 데이터 사이를 지나는 선을 긋는 작업이 아닙니다. 이는 데이터 속에 숨겨진 **변수 간의 상관관계**를 수학적 모델로 정의하고, 그 모델이 실제 현상을 얼마나 잘 설명하는지 정량화하는 과정입니다. 본 절에서는 회귀분석이 데이터를 해석하는 근본적인 원리와, 최적의 해를 찾아가는 수학적 방법론에 대해 깊이 있게 학습합니다.

---

## 1. 회귀분석의 출발점: 선형 모델의 정의

회귀분석의 가장 기본은 독립변수($X$)와 종속변수($Y$)의 관계를 직선의 방정식 형태로 가정하는 것입니다. 이를 **단순 선형 회귀(Simple Linear Regression)** 모델이라고 하며, 다음과 같은 수식으로 표현합니다.

$$y = \beta_0 + \beta_1x + \epsilon$$

- **$y$ (종속변수):** 우리가 예측하고자 하는 결과값입니다.
- **$x$ (독립변수):** 결과값에 영향을 주는 원인 변수입니다.
- **$\beta_0$ (절편, Intercept):** 독립변수가 0일 때의 기본값입니다.
- **$\beta_1$ (기울기, Slope):** $x$가 1단위 변화할 때 $y$가 변화하는 정도를 나타내며, 변수 간의 영향력을 의미합니다.
- **$\epsilon$ (오차항, Error Term):** 모델이 설명하지 못하는 무작위 변동성을 의미합니다.

학습의 목표는 수집된 데이터를 바탕으로 실제값과 예측값의 차이를 최소화하는 최적의 **$\beta_0$와 $\beta_1$**을 찾아내는 것입니다.

`[시각화: 산점도 위에 직선이 그려져 있고, 특정 x값에서 직선 위의 점(예측값)과 실제 데이터 점(실제값) 사이의 수직 거리를 표시하는 애니메이션]`

---

## 2. '좋은 모델'의 기준: 잔차와 손실 함수

어떤 직선이 데이터를 가장 잘 설명하는지 판단하기 위해서는 '틀린 정도'를 측정할 기준이 필요합니다. 이를 위해 **잔차(Residual)**라는 개념을 사용합니다.

### 2.1 잔차 (Residual)
잔차는 실제 데이터의 값($y_i$)과 모델이 예측한 값($\hat{y}_i$)의 차이를 의미합니다.
$$e_i = y_i - \hat{y}_i$$

### 2.2 평균제곱오차 (MSE, Mean Squared Error)
모든 데이터 포인트에 대한 잔차를 단순히 합산하면 양수와 음수가 서로 상쇄되어 정확한 오차를 측정할 수 없습니다. 따라서 잔차를 제곱하여 모두 더한 뒤 평균을 내는 방식을 주로 사용합니다. 이를 **손실 함수(Loss Function)** 또는 **비용 함수(Cost Function)**라고 부릅니다.

$$MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 = \frac{1}{n} \sum_{i=1}^{n} (y_i - (\beta_0 + \beta_1x_i))^2$$

- **제곱을 하는 이유:** 
  1. 음수 오차를 양수로 만들어 오차의 크기를 합산하기 위함입니다.
  2. 오차가 큰 데이터 포인트에 더 큰 패널티를 부여하여, 모델이 극단적인 오차를 줄이도록 유도합니다.

`[시각화: 슬라이더를 조절하여 직선의 기울기를 바꿀 때마다 실시간으로 계산되는 MSE 값이 그래프로 변하는 인터렉티브 차트]`

---

## 3. 최적의 파라미터를 찾는 방법

회귀계수($\beta_0, \beta_1$)를 결정하는 방법은 크게 두 가지 관점으로 나뉩니다.

### 3.1 최소제곱법 (OLS: Ordinary Least Squares)
최소제곱법은 미분을 활용하여 손실 함수($MSE$)가 최소가 되는 지점을 수학적으로 한 번에 찾아내는 방식입니다. $MSE$ 식을 각 파라미터($\beta_0, \beta_1$)로 편미분하여 그 값이 0이 되는 지점을 구하면 다음과 같은 정규 방정식(Normal Equation) 유도가 가능합니다.

- 통계학에서 전통적으로 사용하는 방식입니다.
- 데이터의 크기가 아주 크지 않을 때 매우 빠르고 정확한 해를 제공합니다.

### 3.2 경사하강법 (Gradient Descent)
데이터의 양이 너무 많아 한 번에 연산하기 어렵거나, 딥러닝과 같은 복잡한 모델에서는 경사하강법을 사용합니다. 이는 임의의 지점에서 시작하여 손실 함수의 기울기를 따라 조금씩 하강하며 최솟값을 찾아가는 반복적(Iterative) 최적화 알고리즘입니다.

```python
# 경사하강법의 개념적 구현 (Python 예시)
learning_rate = 0.01
w = 0.0  # 기울기 초기값
b = 0.0  # 절편 초기값

for i in range(1000):
    # 예측값 계산
    y_pred = w * x_data + b
    
    # 오차에 따른 기울기(Gradient) 계산
    dw = (2/n) * sum((y_pred - y_actual) * x_data)
    db = (2/n) * sum(y_pred - y_actual)
    
    # 파라미터 업데이트
    w = w - learning_rate * dw
    b = b - learning_rate * db
```

`[시각화: 이차함수 모양의 손실 함수 그래프 위에서 공이 골짜기(최솟값)를 향해 굴러 내려가는 경사하강법 시뮬레이션]`

## 4. 회귀 모델의 평가: $R^2$ (결정계수)

모델을 만들었다면 이 모델이 얼마나 쓸모 있는지 평가해야 합니다. 이때 가장 많이 사용되는 지표가 **결정계수($R^2$)**입니다.

$$R^2 = 1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2} = 1 - \frac{SSE}{SST}$$

- **SST (Total Sum of Squares):** 데이터 전체의 분산(평균으로부터의 거나).
- **SSE (Sum of Squared Errors):** 모델이 설명하지 못한 오차.
- **해석:** $R^2$가 1에 가까울수록 모델이 데이터를 완벽하게 설명한다는 뜻이고, 0에 가까울수록 단순히 평균값으로 예측하는 것보다 나을 게 없다는 뜻입니다.

## 요약

1. **회귀분석**은 독립변수와 종속변수 간의 관계를 선형 방정식으로 모델링하는 과정입니다.
2. **잔차의 제곱합(MSE)**을 최소화하는 것이 분석의 핵심 목표입니다.
3. 최적의 해를 찾기 위해 수학적 공식인 **최소제곱법**이나 반복적 최적화 방식인 **경사하강법**을 사용합니다.
4. 완성된 모델의 성능은 **결정계수($R^2$)**를 통해 데이터의 변동성을 얼마나 잘 설명하는지 판단합니다.

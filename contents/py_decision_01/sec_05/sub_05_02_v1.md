# 5.2 회귀분석의 방법

## 도입
우리는 앞서 회귀분석이 변수 간의 관계를 파악하고 미래의 값을 예측하는 강력한 도구임을 배웠습니다. 그렇다면 실제로 회귀분석은 어떤 원리로 작동할까요? 단순히 점들 사이에 선을 긋는 것 이상의 수학적, 통계적 원리가 숨어 있습니다.

이 섹션에서는 회귀분석의 가장 기초가 되는 **단순 선형 회귀**부터 여러 변수를 동시에 고려하는 **다중 선형 회귀**, 그리고 컴퓨터가 '최적의 선'을 찾아내는 핵심 원리인 **최소제곱법(Ordinary Least Squares, OLS)**에 대해 자세히 살펴보겠습니다. 이 과정을 통해 우리는 데이터 속에 숨겨진 규칙을 수식으로 도출하는 방법을 습득하게 될 것입니다.

---

## 1. 단순 선형 회귀 (Simple Linear Regression)
단순 선형 회귀는 하나의 **독립 변수($X$)**와 하나의 **종속 변수($Y$)** 사이의 관계를 선형(직선)으로 모델링하는 방법입니다.

### 1.1 기본 가정과 수식
우리는 $X$가 변화함에 따라 $Y$가 어떻게 변하는지를 다음과 같은 직선의 방정식으로 표현합니다.

$$y = \beta_0 + \beta_1x + \epsilon$$

- $y$: 종속 변수 (예측하고자 하는 값, 예: 시험 점수)
- $x$: 독립 변수 (원인이 되는 값, 예: 공부 시간)
- $\beta_0$: **절편(Intercept)**. $x$가 0일 때의 $y$ 값입니다.
- $\beta_1$: **기울기(Coefficient)**. $x$가 1단위 증가할 때 $y$가 변화하는 양을 나타냅니다.
- $\epsilon$: **오차항(Error term)**. 모델이 설명하지 못하는 무작위 변동성을 의미합니다.

### 1.2 시각적 비유: 데이터의 흐름을 가로지르는 길
좌표평면에 흩뿌려진 데이터 점들을 생각해보세요. 단순 선형 회귀는 이 점들의 한가운데를 가로지르는 '가장 대표적인 직선'을 찾는 과정입니다. 이 직선은 데이터의 전체적인 경향성을 나타내며, 새로운 $x$ 값이 들어왔을 때 $y$가 어디쯤 위치할지 알려주는 이정표 역할을 합니다.

`[시각화: 슬라이더를 조절하여 기울기(beta1)와 절편(beta0)을 변경함에 따라 직선이 움직이고, 각 점과의 거리(잔차)가 실시간으로 변화하는 산점도 그래프]`

---

## 2. 다중 선형 회귀 (Multiple Linear Regression)
현실 세계의 문제는 대개 하나의 원인으로만 결정되지 않습니다. 아파트 가격($Y$)을 예측할 때 면적($X_1$)뿐만 아니라 방의 개수($X_2$), 지하철역과의 거리($X_3$) 등 여러 요인을 고려해야 하는 것과 같습니다.

### 2.1 수식의 확장
다중 선형 회귀는 여러 개의 독립 변수를 사용하여 모델을 구성합니다.

$$y = \beta_0 + \beta_1x_1 + \beta_2x_2 + \dots + \beta_nx_n + \epsilon$$

이 모델에서는 각 독립 변수($x_n$)마다 고유한 기울기($\beta_n$)를 가집니다. 이는 다른 변수들이 고정되어 있을 때, 해당 변수가 결과값에 미치는 개별적인 영향력을 의미합니다.

---

## 3. 최적의 선을 찾는 원리: 최소제곱법 (OLS)
모델을 만든다는 것은 결국 가장 적절한 $\beta_0$와 $\beta_1$ 값을 찾아내는 과정입니다. 그렇다면 '가장 적절하다'는 것은 무엇을 의미할까요? 통계학에서는 실제 데이터 값과 모델이 예측한 값 사이의 차이, 즉 **잔차(Residual)**를 최소화하는 것을 목표로 합니다.

### 3.1 잔차 (Residual)
실제 관측값을 $y_i$, 모델에 의해 계산된 예측값을 $\hat{y}_i$라고 할 때, 잔차 $e_i$는 다음과 같습니다.

$$e_i = y_i - \hat{y}_i$$

### 3.2 최소제곱법의 개념
단순히 잔차를 모두 더하면 양수와 음수가 서로 상쇄되어 오차의 크기를 정확히 측정할 수 없습니다. 따라서 잔차를 **제곱**하여 모두 더한 값을 최소화하는 방법을 사용하는데, 이를 **최소제곱법(Ordinary Least Squares)**이라고 부릅니다.

$$RSS(Residual \ Sum \ of \ Squares) = \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$

RSS가 작을수록 모델은 실제 데이터를 잘 반영하고 있다고 볼 수 있습니다. 미분을 통해 RSS를 최소로 만드는 $\beta$ 값을 찾아내는 것이 회귀분석 알고리즘의 핵심입니다.

## 4. 파이썬 실습: 회귀 모델 구현하기
파이썬의 `scikit-learn` 라이브러리를 사용하면 복잡한 수학적 계산 없이도 간단하게 회귀 분석을 수행할 수 있습니다.

```python
import numpy as np
from sklearn.linear_model import LinearRegression
import matplotlib.pyplot as plt

# 1. 가상의 데이터 생성 (공부 시간 vs 시험 점수)
# X: 공부 시간 (독립 변수), y: 시험 점수 (종속 변수)
X = np.array([1, 2, 3, 4, 5]).reshape(-1, 1)
y = np.array([15, 25, 35, 55, 65])

# 2. 선형 회귀 모델 객체 생성
model = LinearRegression()

# 3. 모델 학습 (최소제곱법을 통해 최적의 beta를 찾음)
model.fit(X, y)

# 4. 결과 확인
beta_0 = model.intercept_ # 절편
beta_1 = model.coef_[0]    # 기울기

print(f"회귀 방정식: y = {beta_1:.2f}x + {beta_0:.2f}")

# 5. 새로운 데이터로 예측 (6시간 공부했을 때)
new_hour = [[6]]
predicted_score = model.predict(new_hour)
print(f"6시간 공부 시 예상 점수: {predicted_score[0]:.2f}")
```

### 코드 설명
- `reshape(-1, 1)`: 사이킷런 모델은 독립 변수 $X$를 2차원 배열 형태로 입력받아야 하므로 형태를 변환해줍니다.
- `fit()`: 이 함수를 호출하는 순간, 내부적으로 최소제곱법 계산이 이루어져 최적의 기울기와 절편이 결정됩니다.
- `predict()`: 학습된 모델에 새로운 값을 넣어 결과를 도출합니다.

## 요약
1. **단순 선형 회귀**는 하나의 원인 변수로 결과를 예측하며, 직관적인 관계 파악에 용이합니다.
2. **다중 선형 회귀**는 여러 변수를 복합적으로 고려하여 현실적인 예측력을 높입니다.
3. **최소제곱법(OLS)**은 실제값과 예측값의 차이(잔차)의 제곱합을 최소화하여 최적의 모델을 찾는 수학적 방법입니다.
4. 파이썬의 `LinearRegression` 라이브러리를 활용하면 이러한 복잡한 과정을 자동화하여 실무에 바로 적용할 수 있습니다.

우리가 살아가는 세상은 수많은 변수로 가득 차 있습니다. 기온이 오르면 아이스크림 판매량이 늘어나고, 공부 시간이 길어지면 시험 성적이 오르는 경향이 있죠. 이처럼 **하나의 변수가 변함에 따라 다른 변수가 어떻게 변하는지 그 규칙성을 수학적으로 모델링하는 기법**을 **회귀분석(Regression Analysis)**이라고 합니다.

이번 절에서는 회귀분석이 왜 '회귀(돌아오는)'라는 이름을 갖게 되었는지, 그리고 데이터 속에서 어떻게 최적의 선을 찾아내는지 그 원리를 자세히 살펴보겠습니다.

## 2. 본론

### 2.1 '회귀'의 유래: 평균으로의 회귀
회귀라는 단어는 영국의 유전학자 프랜시스 골턴(Francis Galton)의 연구에서 시작되었습니다. 그는 부모의 키와 자녀의 키 사이의 관계를 조사하던 중 흥미로운 사실을 발견했습니다.

부모의 키가 아주 크더라도 자녀의 키는 부모보다 조금 작아져 전체 평균에 가까워지려는 경향이 있었고, 반대로 부모가 아주 작더라도 자녀는 부모보다 조금 더 커져 평균에 가까워졌습니다. 골턴은 이를 **'평균으로의 회귀(Regression toward the mean)'**라고 불렀습니다. 

오늘날 통계학에서의 회귀분석은 이 유래를 넘어, **변수들 사이의 관계를 가장 잘 설명하는 함수(회귀선)를 찾는 모든 과정**을 의미합니다.

### 2.2 독립변수와 종속변수
회귀분석을 이해하기 위해서는 두 가지 핵심 역할을 구분해야 합니다.

1.  **독립변수 (Independent Variable, $x$):** 원인이 되는 변수입니다. 설명변수라고도 하며, 우리가 통제하거나 관찰하는 값입니다.
2.  **종속변수 (Dependent Variable, $y$):** 결과가 되는 변수입니다. 독립변수의 변화에 따라 값이 결정되는 우리가 예측하고자 하는 대상입니다.

> **예시:** '공부 시간($x$)'에 따른 '시험 점수($y$)' 예측
> - 여기서 공부 시간은 우리가 조절할 수 있는 원인이고, 시험 점수는 그에 따라 달라지는 결과입니다.

### 2.3 단순 선형 회귀의 수학적 모델
가장 기본적인 회귀 모델은 직선의 형태를 띱니다. 이를 **단순 선형 회귀(Simple Linear Regression)**라고 합니다.

$$y = wx + b$$

- $y$: 예측값 (종속변수)
- $x$: 입력값 (독립변수)
- $w$ (Weight): **가중치** 또는 기울기. $x$가 $y$에 주는 영향력을 의미합니다.
- $b$ (Bias): **편향** 또는 절편. $x$가 0일 때의 기본값을 의미합니다.

[시각화: 산점도(Scatter Plot) 위에 마우스를 올리면 기울기($w$)와 절편($b$) 슬라이더가 나타나고, 슬라이더를 조절함에 따라 직선이 데이터 사이를 통과하며 움직이는 인터랙티브 차트]

### 2.4 최적의 선을 찾는 원리: 오차의 최소화
데이터가 평면 위에 흩어져 있을 때, 수많은 직선 중 어떤 것이 '최적의 선'일까요? 정답은 **"실제 데이터와 직선 사이의 거리가 가장 가까운 선"**입니다.

이 거리를 **오차(Error)** 또는 **잔차(Residual)**라고 합니다. 회귀분석의 핵심 목표는 이 오차들을 제곱하여 합한 값(SSE, Sum of Squared Errors)을 최소로 만드는 $w$와 $b$를 찾아내는 것입니다.

1.  **예측값 계산:** 현재의 $w, b$로 $y$값을 예측합니다.
2.  **오차 계산:** 실제 값과 예측 값의 차이를 구합니다.
3.  **평가:** 오차가 크다면 $w, b$를 수정합니다. (이 과정에서 경사하강법 같은 최적화 알고리즘이 사용됩니다.)

### 2.5 파이썬 예제 코드 (Scikit-learn 활용)
간단한 데이터를 생성하고 선형 회귀 모델을 학습시키는 과정을 살펴보겠습니다.

```python
import numpy as np
from sklearn.linear_model import LinearRegression
import matplotlib.pyplot as plt

# 1. 데이터 생성 (공부 시간 대비 점수)
X = np.array([[1], [2], [3], [4], [5]]) # 독립변수 (2차원 배열 형태 필요)
y = np.array([15, 28, 42, 58, 72])      # 종속변수

# 2. 모델 생성 및 학습
model = LinearRegression()
model.fit(X, y)

# 3. 예측 및 파라미터 확인
predicted_score = model.predict([[6]])
print(f"6시간 공부했을 때 예상 점수: {predicted_score[0]:.2f}")
print(f"가중치(w): {model.coef_[0]:.2f}, 편향(b): {model.intercept_:.2f}")

# 4. 시각화
plt.scatter(X, y, color='blue', label='Actual Data')
plt.plot(X, model.predict(X), color='red', label='Regression Line')
plt.xlabel('Study Hours')
plt.ylabel('Score')
plt.legend()
plt.show()
```

## 3. 요약
1.  **회귀분석의 본질:** 변수 간의 관계를 수학적 함수로 표현하여 미래 데이터를 예측하는 기법입니다.
2.  **인과관계 설정:** 원인이 되는 독립변수($x$)와 결과가 되는 종속변수($y$)를 설정하는 것이 첫걸음입니다.
3.  **선형 모델:** $y = wx + b$ 공식을 통해 데이터의 흐름을 직선으로 나타냅니다.
4.  **최적화:** 실제 데이터와 모델 사이의 오차를 최소화하는 가중치($w$)를 찾는 것이 학습의 핵심입니다.

회귀분석은 머신러닝의 가장 기초가 되지만, 주가 예측, 수요 분석, 의료 진단 등 실무에서 가장 강력하게 사용되는 도구 중 하나입니다. 다음 절에서는 오차를 측정하는 더 구체적인 지표들에 대해 알아보겠습니다.

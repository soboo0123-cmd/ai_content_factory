# 5.3 회귀분석의 메커니즘

## 도입: 데이터의 흐름에서 규칙을 찾는 법

우리는 일상 속에서 수많은 데이터를 마주하며 살아갑니다. "공부 시간이 늘어나면 성적이 오를까?", "집 평수가 넓어지면 가격은 얼마나 뛸까?" 같은 질문들은 모두 변수 사이의 **'관계'**에 대해 묻고 있습니다.

회귀분석(Regression Analysis)은 이러한 막연한 관계를 수학적인 '선'으로 정의하는 과정입니다. 단순히 선을 긋는 것에 그치지 않고, 수많은 데이터 포인트들 사이에서 **'가장 오차가 적은 최적의 경로'**를 찾아내는 정교한 메커니즘을 가지고 있습니다. 이번 절에서는 회귀분석이 내부적으로 어떤 원리를 통해 데이터를 학습하고 정답을 찾아가는지 그 구체적인 과정을 살펴보겠습니다.

---

## 본론

### 1. 회귀의 기본 식: 가설(Hypothesis) 설정

회귀분석의 첫 번째 단계는 "데이터가 어떤 형태를 띨 것이다"라고 가정하는 것입니다. 가장 단순한 선형 회귀의 경우, 우리는 데이터를 관통하는 하나의 직선을 가정합니다.

$$ \hat{y} = wx + b $$

- **$x$ (독립 변수):** 원인이 되는 데이터 (예: 공부 시간)
- **$\hat{y}$ (예측값):** 우리가 알고자 하는 결과 (예: 예상 성적)
- **$w$ (가중치, Weight):** 직선의 기울기. $x$가 변화할 때 $y$가 얼마나 민감하게 반응하는지를 결정합니다.
- **$b$ (편향, Bias):** 직선의 절편. $x$가 0일 때의 기본값을 의미합니다.

학습이란, 바로 이 $w$와 $b$의 최적값을 찾아내는 과정입니다.

`[시각화: 사용자가 슬라이더로 w와 b의 값을 조절하면 좌표평면 위의 직선이 실시간으로 움직이는 인터랙티브 그래프]`

---

### 2. '틀림'의 크기 측정: 잔차와 손실 함수

직선을 그었다면, 이제 이 직선이 얼마나 데이터를 잘 설명하는지 평가해야 합니다. 이때 등장하는 개념이 **잔차(Residual)**입니다.

- **잔차:** 실제 값($y$)과 모델이 예측한 값($\hat{y}$)의 차이 ($y - \hat{y}$)

하지만 잔차는 양수일 수도, 음수일 수도 있습니다. 단순히 모든 잔차를 더하면 서로 상쇄되어 오차의 크기를 정확히 알 수 없습니다. 그래서 우리는 잔차를 제곱하여 모두 양수로 만든 뒤 평균을 구하는데, 이를 **평균 제곱 오차(MSE, Mean Squared Error)**라고 부릅니다.

$$ MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - (wx_i + b))^2 $$

이 MSE 값이 작을수록 모델은 데이터를 더 정확하게 설명하고 있다는 뜻입니다. 회귀분석의 목표는 이 **MSE(손실 함수)를 최소화하는 $w$와 $b$를 찾는 것**으로 귀결됩니다.

---

### 3. 최적의 경로 찾기: 경사 하강법(Gradient Descent)

어떻게 하면 손실 함수를 최소로 만드는 $w$를 찾을 수 있을까요? 여기서 **경사 하강법**이라는 메커니즘이 작동합니다.

비유하자면, 안개가 자욱한 산(손실 함수의 그래프)에서 가장 낮은 골짜기를 찾아 내려가는 것과 같습니다. 현재 위치에서 경사가 가장 가파른 방향을 확인하고, 그 반대 방향으로 조금씩 발을 내딛는 과정입니다.

1.  **임의의 $w$에서 시작:** 처음에는 무작위로 $w$를 정합니다.
2.  **기울기(Gradient) 계산:** 현재 위치에서 손실 함수의 미분값(기울기)을 구합니다.
3.  **업데이트:** 기울기가 양수라면 $w$를 줄이고, 음수라면 $w$를 키워 골짜기 아래로 이동합니다.
4.  **반복:** 기울기가 0에 가까워질 때까지(최저점에 도달할 때까지) 이 과정을 반복합니다.

`[시각화: 이차함수 형태의 손실 함수 곡선 위에서 점(w)이 반복적으로 이동하며 최저점으로 수렴하는 애니메이션]`

---

### 4. 파이썬 코드로 보는 메커니즘

Scikit-learn 라이브러리를 사용하여 회귀 모델이 어떻게 데이터를 학습하고 $w$(기울기)와 $b$(절편)를 찾아내는지 확인해 보겠습니다.

```python
import numpy as np
from sklearn.linear_model import LinearRegression

# 1. 임의의 데이터 생성 (x가 증가할 때 y도 증가하는 관계)
X = np.array([[1], [2], [3], [4], [5]])
y = np.array([2.1, 3.9, 6.2, 8.1, 10.1])

# 2. 회귀 모델 객체 생성
model = LinearRegression()

# 3. 학습 수행 (이 과정에서 내부적으로 MSE 최소화 및 파라미터 최적화가 일어남)
model.fit(X, y)

# 4. 결과 확인
w = model.coef_[0]      # 가중치 (기울기)
b = model.intercept_   # 편향 (절편)

print(f"찾아낸 가중치(w): {w:.2f}")
print(f"찾아낸 편향(b): {b:.2f}")
print(f"예측식: y = {w:.2f}x + {b:.2f}")

# 새로운 데이터 6에 대한 예측
predict_6 = model.predict([[6]])
print(f"x=6일 때의 예측값: {predict_6[0]:.2f}")
```

## 요약: 회귀분석의 3단계 메커니즘

1.  **가설 설정 ($y = wx + b$):** 변수 간의 관계를 직선으로 가정합니다.
2.  **오차 측정 (MSE):** 실제 데이터와 직선 사이의 거리를 제곱하여 평균을 냄으로써 모델의 성능을 점수화합니다.
3.  **최적화 (경사 하강법):** 수학적인 최적화 기법을 동원하여 오차(MSE)를 가장 작게 만드는 가중치($w$)와 편향($b$)을 최종 결정합니다.

회귀분석은 단순한 통계 도구를 넘어, 데이터 속에 숨겨진 **원인과 결과의 강도**를 숫자로 명확하게 보여주는 강력한 메커니즘입니다. 이 기본 원리를 이해하면 이후에 배우게 될 복잡한 딥러닝 알고리즘의 핵심 논리도 쉽게 파악할 수 있습니다.

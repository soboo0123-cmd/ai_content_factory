# 4장. 헤지와 회계 처리

## 4.1 결산 시점의 선물환 평가손익 처리

### 도입: 결산일, 멈춰 선 시간 속에서 외화 자산의 가치를 묻다

기업이 수출 대금 회수나 수입 대금 결제 과정에서 발생하는 환리스크를 관리하기 위해 가장 흔하게 사용하는 도구는 **선물환(Forward) 계약**입니다. 선물환 계약을 체결하면 미래 특정 시점에 거래할 환율을 미리 고정할 수 있어 환율 변동의 불확실성을 제거할 수 있습니다. 

하지만 기업의 경영 활동은 특정 시점에 완전히 종료되지 않고 회계연도라는 인위적인 단위로 구분되어 계속됩니다. 이 과정에서 필연적으로 발생하는 사건이 바로 **'결산(Closing)'**입니다. 선물환 계약의 만기는 아직 도래하지 않았는데, 회계연도 말(결산일)이 먼저 찾아오는 것입니다.

이때 회계 담당자는 다음과 같은 질문을 마주하게 됩니다.
> "아직 실현되지 않은, 만기가 수개월 남은 계약의 가치를 결산일에 재무제표에 어떻게 반영해야 하는가?"

이번 절의 학습 목표는 다음과 같습니다.
1. 결산 시점에 아직 만기가 되지 않은 선물환 계약을 시가평가(Mark-to-Market)하는 이유와 그 원리를 이해합니다.
2. 환율 상승 국면에서 선물환 매도 포지션이 왜 평가손실을 기록하는지 구체적인 숫자를 통해 파악합니다.
3. 대한민국 **일반기업회계기준(K-GAAP)**에 따른 회계처리 분개(Journal Entry) 방식을 익히고, 위험회피회계 적용 여부에 따른 재무적 파급효과를 대조하여 분석합니다.

## 본론

### 1. 구체적 수치로 보는 결산일의 상황 (수치 패턴 먼저)

이해를 돕기 위해 실제 수출기업이 마주할 수 있는 구체적인 시나리오를 구성해 보겠습니다. 

*   **기업 상황:** 수출기업 A사는 202X년 11월 1일에 수출 계약을 체결하고, 5개월 뒤인 202X+1년 3월 31일에 대금 $1,000,000 USD를 수령할 예정입니다.
*   **선물환 계약 조건:**
    *   **계약 체결일:** 202X년 11월 1일
    *   **만기일:** 202X+1년 3월 31일 (체결일로부터 5개월)
    *   **약정 선물환율 ($F_0$):** 1,300 원/USD (선물환 매도 계약)
    *   **계약 금액 ($N$):** $1,000,000 USD
*   **결산 시점의 시장 상황:**
    *   **결산일:** 202X년 12월 31일 (만기까지 3개월 남음)
    *   **결산일 현재 잔존만기(3개월) 선물환율 ($F_t$):** 1,350 원/USD
    *   **결산일 현재 무위험 이자율 (할인율, $r$):** 연 4.0% (단리 가정, 잔존일수 90일 / 365일 적용)

시간의 흐름에 따른 환율의 변화와 만기 시 예상되는 가치의 차이를 표로 정리해 보겠습니다.

| 구분 | 계약 체결일 (11/1) | 결산일 (12/31) | 만기일 (익년 3/31) |
| :--- | :--- | :--- | :--- |
| **적용 환율** | 약정 선물환율: $1,300$ 원 | 잔존 3개월 시장 선물환율: $1,350$ 원 | (만기 시점 정산 예정) |
| **달러당 차액** | $0$ 원 | $-50$ 원 (의무 환율보다 시장가가 상승함) | - |
| **총 계약 금액 ($100$만 달러)** | $1,300,000,000$ 원 | $1,350,000,000$ 원 | - |
| **단순 차액 총액** | $0$ 원 | $-50,000,000$ 원 | - |

[시각화: 슬라이더로 결산 시점의 시장 선물환율(1,200원 ~ 1,400원)을 조절할 때, 선물환 평가손익(현재가치 할인 반영)이 어떻게 실시간으로 계산되고 부채/자산으로 계상되는지 보여주는 인터랙티브 차트]

### 2. 왜 환율 상승 시 선물환 매도 포지션에서 손실이 발생하는가? (물리적 의미 해석)

선물환 **매도** 계약은 **"미래 특정 시점에 달러를 정해진 가격(1,300원)에 팔겠다"**는 구속력 있는 약속입니다. 

결산일(12/31) 시점에서 시장을 보니, 만기일인 내년 3월 31일에 달러를 팔 수 있는 시장의 새로운 약속 가격(선물환율)은 이미 1,350원으로 치솟아 있습니다. 
*   **시장 계약:** 지금 시장에 가면 달러당 1,350원을 받을 수 있음.
*   **나의 계약:** 과거에 맺어둔 계약 때문에 강제로 달러당 1,300원에 팔아야 함.

즉, 기업 A사는 시장 가격보다 달러당 50원씩 싸게 팔아야 하는 불리한 의무를 지게 된 것입니다. 100만 달러 규모이므로 총 **50,000,000원**의 손실 기회가 결산 시점에 잠재적으로 확정된 상태입니다.

#### 시간가치의 소거: 현재가치 할인
결산 시점의 평가손익은 단순히 미래의 차액인 5,000만 원을 그대로 장부에 적지 않습니다. 왜냐하면 이 돈은 지금 당장 나가는 돈이 아니라, 3개월 뒤(내년 3월 31일)에 정산될 돈이기 때문입니다. 회계학에서는 돈의 시간가치를 반영하여 이 미래의 손실액을 결산일 현재 가치로 '할인'합니다. 

여기서 분모에 사용되는 할인율은 **"시간을 기다리는 대가인 무의미한 가치 팽창(이자)을 지워내고 순수한 오늘 날짜의 가치로 환원하는 소거 장치"**로 작동합니다.

*   미래 차액: $-50,000,000$ 원
*   할인 계수 (3개월): $\frac{1}{1 + (0.04 \times \frac{90}{365})} \approx 0.99023$
*   현재가치로 환산한 평가손실: $-50,000,000 \times 0.99023 = -49,511,500$ 원 (원 단위 절사)

### 3. 공식의 도출: 선물환 평가손익 계산식 (공식 나중)

앞서 살펴본 구체적인 수치 흐름을 바탕으로, 임의의 시점 $t$에서의 선물환 평가 가치($V_t$)를 구하는 일반적인 공식은 다음과 같이 유도됩니다.

$$V_t = (F_0 - F_t) \times N \times \frac{1}{1 + r \times \frac{d}{365}}$$

*   $F_0$: 최초 약정 선물환율 (계약 체결 시점)
*   $F_t$: 평가 시점($t$)에서 만기일까지의 잔존기간에 대응하는 시장 선물환율
*   $N$: 선물환 계약 원금 (외화 기준)
*   $r$: 평가 시점의 시장 무위험 이자율
*   $d$: 평가 시점부터 만기일까지의 잔존 일수

#### 변수의 경제적 의미와 범위
*   **$V_t > 0$ 인 경우:** $F_0 > F_t$ 일 때 발생합니다. 즉, 약정 환율이 현재 시장 환율보다 높으므로 비싸게 팔 수 있는 권리가 되어 **파생상품자산(선물환계약자산)**으로 재무제표에 인식됩니다.
*   **$V_t < 0$ 인 경우:** $F_0 < F_t$ 일 때 발생합니다. 싸게 팔아야 하는 의무가 되므로 **파생상품부채(선물환계약부채)**로 계상됩니다. 위 예시의 경우 부채 항목에 해당합니다.

### 4. 회계 처리 대조: 실패 사례(일반 회계) vs 성공 사례(위험회피 회계)

결산일 현재 계산된 이 평가손실 $49,511,500$원을 재무제표에 어떻게 기록하느냐에 따라 기업의 손익계산서는 완전히 다른 모습을 보입니다. 대한민국 **일반기업회계기준(K-GAAP)**에 따른 두 가지 처리 방식을 대조해 보겠습니다.

#### 시나리오 X: 매매목적 처리 (위험회피 회계 미적용) - "손익의 변동성이 폭발하는 경우"
선물환 계약을 맺었으나 엄격한 위험회피 지정 요건을 충족하지 못했거나 신청하지 않은 경우입니다. 이 경우 평가손익은 즉시 **당기손익(영업외비용)**으로 반영됩니다.

*   **분개 (12/31 결산일):**
    *   (차변) 파생상품평가손실 (당기비용) $49,511,500$ 원  /  (대변) 파생상품부채 $49,511,500$ 원

> **문제점:** 실제 수출 대금을 받아서 환전하는 시점은 내년 3월 31일입니다. 올해 12월 31일에는 달러 환율 상승으로 인한 수출 채권(매출)의 이익은 아직 장부에 기록되지 않았는데, 선물환 계약의 손실만 먼저 올해 장부에 비용으로 반영됩니다. 이로 인해 올해 당기순이익이 왜곡되어 크게 감소하는 현상이 발생합니다.

#### 시나리오 Y: 현금흐름위험회피 회계 적용 (성공적인 매칭) - "시간의 장벽을 넘는 이연"
예상 수출 거래의 환율 변동 위험을 회피하기 위해 지정된 것이 인정되는 경우입니다. 이 경우 결산 시점의 평가손익 중 '효과적인 부분'은 당기 비용으로 보내지 않고, **기타포괄손익누계액(자본항목, OCI)**으로 장부에 묶어둡니다.

*   **분개 (12/31 결산일):**
    *   (차변) 파생상품평가손실 (기타포괄손익누계액) $49,511,500$ 원  /  (대변) 파생상품부채 $49,511,500$ 원

> **효과:** 손실 금액이 자본 항목에 임시로 묶여 있으므로 올해 당기순이익에 전혀 타격을 주지 않습니다. 이후 내년 3월 31일, 실제 수출 대금이 들어와 매출이 인식되고 환율 상승으로 인한 이익이 발생하는 바로 그 시점에, 묶여 있던 파생상품평가손실을 자본에서 꺼내어 매출액(또는 외환차익)과 대칭되게 상계 처리합니다.

### 5. 파이썬(Python) 실무 구현 예제

위에서 설명한 결산 시점의 선물환 평가액 계산과 분개 대상 금액 산출을 자동화하는 간단한 파이썬 코드입니다.

```python
def calculate_forward_valuation(notional, f_contract, f_current, annual_rate, remaining_days):
    """
    선물환 평가손익 및 현재가치 계산 함수 (일반기업회계기준 준수)
    
    :param notional: 계약 원금 (USD)
    :param f_contract: 약정 선물환율 (KRW/USD)
    :param f_current: 결산일 잔존만기 시장 선물환율 (KRW/USD)
    :param annual_rate: 연간 무위험 이자율 (소수점)
    :param remaining_days: 만기까지 남은 일수
    :return: (미래가치 차액, 현재가치 평가액, 계정과목 구분)
    """
    # 1. 만기 시점의 미래 차액 계산 (매도 포지션 기준)
    future_diff = (f_contract - f_current) * notional
    
    # 2. 시간가치 제거를 위한 할인계수 산출 (단리 적용)
    discount_factor = 1 / (1 + (annual_rate * (remaining_days / 365.0)))
    
    # 3. 현재가치 평가액 계산
    present_value = int(future_diff * discount_factor)
    
    # 4. 자산 / 부채 분류 및 계정 정의
    if present_value >= 0:
        account_type = "파생상품자산 (선물환계약자산)"
    else:
        account_type = "파생상품부채 (선물환계약부채)"
        
    return future_diff, present_value, account_type

# 예시 데이터 대입
notional_usd = 1000000
contract_rate = 1300.0
current_rate = 1350.0
r_discount = 0.04
days = 90

future_val, pv_val, account = calculate_forward_valuation(
    notional_usd, contract_rate, current_rate, r_discount, days
)

print(f"1. 미래 예상 정산 차액: {future_val:,.0f} 원")
print(f"2. 결산일 평가 현재가치: {pv_val:,.0f} 원")
print(f"3. 회계 장부 계상 항목: {account}")
print(f"4. 회계 처리 액수: {abs(pv_val):,.0f} 원")
```

## 요약: 핵심 포인트 정리

1.  **결산 시점 시가평가의 당위성:** 만기가 도래하지 않은 선물환 계약이라도 회계연도 말 결산일 기준의 공정가치(Fair Value)로 평가하여 재무상태표에 자산 또는 부채로 반드시 계상해야 합니다(일반기업회계기준 제21장 파생상품).
2.  **포지션별 손익 메커니즘:** 선물환 **매도** 포지션을 취한 상태에서 시장 환율이 **상승**하면, 저가 매도 의무를 지게 되므로 결산 시점에 **평가손실(파생상품부채)**이 발생합니다.
3.  **시간가치 할인:** 결산일의 평가손익은 미래 만기 시점의 차액을 잔존 기간에 대한 이자율로 할인한 **현재가치**로 측정합니다.
4.  **위험회피 회계의 유무:**
    *   **미적용 시:** 평가손실이 즉시 **당기 비용(영업외비용)**으로 반영되어 기업의 실적 변동성을 키웁니다.
    *   **적용 시(현금흐름위험회피):** 평가손실이 **기타포괄손익누계액(OCI, 자본)**으로 이연되어, 미래에 실제 수출 거래가 일어나는 시점의 손익과 매칭됩니다.

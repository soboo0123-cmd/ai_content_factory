# 4.4 롤오버 반복 시 누적 손익의 흐름

---

## 1. 도입: 완벽한 대칭성 뒤에 숨겨진 시간의 함정

이전 절([4.3 만기 도래 시 손익 상쇄 구조])에서 우리는 아주 이상적이고 아름다운 결론에 도달했습니다. 만기 시점에 자산의 가치 변동과 선물환의 정산 손익이 수학적으로 완벽하게 상쇄($CF_{total} = Q \times K$)되어, 시장 환율이 어떻게 미쳐 날뛰든 기업은 아무런 환리스크를 지지 않고 최초 약정했던 원화 현금을 쥐게 된다는 사실이었습니다. 

하지만 이 마법 같은 공식에는 한 가지 강력한 전제가 숨어 있습니다. 바로 **‘자산의 만기’와 ‘선물환 계약의 만기’가 자로 잰 듯 정확히 일치한다**는 점입니다.

현실의 재무 전선은 그리 녹록지 않습니다. 기업이 보유한 해외 투자 자산이나 외화 채권은 만기가 3년, 5년 혹은 그 이상에 달하는 장기 자산인 경우가 많습니다. 반면, 외환시장에서 거래되는 선물환 계약은 거래 상대방(은행)의 신용 위험과 유동성 문제로 인해 보통 3개월, 6개월, 길어야 1년 단위의 단기 계약이 주를 이룹니다. 

따라서 장기 외화 자산을 헤지하려는 기업은 단기 선물환 계약을 체결한 뒤, 만기가 올 때마다 기존 계약을 정산하고 새로운 단기 계약을 연장해 나가는 **'롤오버(Rollover, 만기 연장)'**를 반복할 수밖에 없습니다.

수학적으로만 보면, 롤오버를 여러 번 반복하여 최종 만기에 도달하는 것이나 단 한 번에 만기까지 가져가는 것이나 최종 누적 손익은 동일해 보입니다. 그러나 **'시간에 따른 현금의 실시간 이동'**이라는 물리적 필터가 끼어드는 순간, 이 둘 사이에는 거대한 균열이 발생합니다. 

이 절에서는 환율 상승 국면에서 선물환 롤오버를 반복할 때 장부상의 가상 손익이 어떻게 실시간 현금 유출로 실현되는지, 그리고 이것이 어떻게 기업의 목줄을 죄는 '유동성 리스크'로 돌변하는지 그 차가운 메커니즘을 추적해 보겠습니다.

### 학습 목표
1. 장기 자산 헤지를 위해 단기 선물환을 반복 연장하는 '롤오버'의 개념과 메커니즘을 이해합니다.
2. 환율 지속 상승 국면에서 매 정산 시점마다 발생하는 누적 손익과 현금 흐름을 수치적으로 추적할 수 있습니다.
3. 수학적 수렴성(망원합 공식) 뒤에 숨겨진 '현금 흐름의 시차(Time Lag) 문제'와 이로 인한 유동성 리스크의 발생 경로를 파악합니다.

## 2. 본론: 롤오버의 수학적 수렴성과 유동성 불일치

### 2.1 수치 패턴 먼저: 3개월마다 새어 나가는 현금의 궤적

추상적인 개념 설명에 앞서, 우리가 계속 다루어 온 일관된 수치 시나리오를 롤오버 상황으로 확장하여 재소환해 보겠습니다.

*   **보유 외화 자산:** USD 100,000 (최초 장부가액 $130,000,000\text{원}$, 최초 환율 $1,300\text{원/USD}$)
    *   *단, 이 자산의 최종 회수(매각) 시점은 **1년 뒤(12개월 후)**라고 가정합니다.*
*   **헤지 수단:** 3개월 만기 선물환 계약 (약정환율 $1,300\text{원}$, 계약 단위 USD 100,000)
    *   *1년 동안 헤지를 유지하기 위해 3개월마다 총 4번의 선물환 계약을 연속적으로 체결(롤오버)합니다.*
*   **환율 시나리오:** 1년간 환율이 매 분기 $50\text{원}$씩 일정하게 지속 상승하는 '극단적 상승 국면'을 가정합니다.
    *   $T_0$ (최초 계약일): $1,300\text{원}$
    *   $T_1$ (3개월 후): $1,350\text{원}$
    *   $T_2$ (6개월 후): $1,400\text{원}$
    *   $T_3$ (9개월 후): $1,450\text{원}$
    *   $T_4$ (12개월 후, 최종 만기): $1,500\text{원}$

이 조건 하에서 각 시점마다 기업의 금고에서 실제로 일어나는 일들을 실시간으로 추적해 봅시다.

```
[시각화: 롤오버 타임라인과 현금 흐름의 미스매치]
T_0 (환율 1,300원) ────────────────────────────────────────────────────────► T_4 (12개월, 환율 1,500원)
   │                                                                      │
   │ ◀────── 3개월 만기 1차 선물환 ──────► [T_1] -500만 원 (현금 유출)        │ (자산 매각 USD 100,000)
   │                                  │                                   │ ──► +150,000,000원 유입
   │                                  │ ◀── 2차 선물환 ──► [T_2] -500만 원 │
   │                                                      │               │
   │                                                      │ ◀── 3차 ──► [T_3] -500만 원
   │                                                                      │
   │                                                                      │ ◀── 4차 ──► [T_4] -500만 원
──────────────────────────────────────────────────────────────────────────┴──────────────────────────
[누적 선물환 손실 현금 지출] : -2,000만 원 (3M, 6M, 9M, 12M에 걸쳐 분할 지출)
[최종 자산 회수 원화 현금]   : +1억 5천만 원 (12M 시점에 일시 유입)
```

#### 시점별 실시간 정산 내역

1.  **$T_1$ 시점 (3개월 경과, 환율 $1,350\text{원}$):**
    *   **1차 선물환 만기 도래:** 약정환율 $1,300\text{원}$에 매도하기로 했는데 시장 환율이 $1,350\text{원}$이 되었습니다.
    *   **실제 현금 정산:** 은행에 $50\text{원}$의 차액을 현금으로 물어주어야 합니다.
        $$\text{1차 정산 현금 흐름} = \text{USD } 100,000 \times (1,300\text{원} - 1,350\text{원}) = -5,000,000\text{원}$$
    *   **롤오버 실행:** $T_1$ 시점의 시장 환율인 $1,350\text{원}$을 새로운 약정환율로 하여, 다시 3개월 만기 2차 선물환 계약을 체결합니다.
    *   *주의: 이 시점까지 외화 자산은 여전히 보유 중이므로 장부상 평가이익($+500\text{만 원}$)만 잡힐 뿐, 실제 들어온 현금은 '0'입니다. 기업의 실제 통장에서는 **$-500\text{만 원}$**이 빠져나갔습니다.*

2.  **$T_2$ 시점 (6개월 경과, 환율 $1,400\text{원}$):**
    *   **2차 선물환 만기 도래:** 약정환율 $1,350\text{원}$ 대비 시장 환율이 $1,400\text{원}$이 되었습니다.
    *   **실제 현금 정산:** 또다시 차액을 송금합니다.
        $$\text{2차 정산 현금 흐름} = \text{USD } 100,000 \times (1,350\text{원} - 1,400\text{원}) = -5,000,000\text{원}$$
    *   **롤오버 실행:** 다시 $1,400\text{원}$으로 3차 계약을 맺습니다.
    *   *누적 현금 흐름: **$-1,000\text{만 원}$** (자산은 여전히 평가 상태일 뿐 현금화 불가)*

3.  **$T_3$ 시점 (9개월 경과, 환율 $1,450\text{원}$):**
    *   **3차 선물환 만기 도래 및 정산:** 약정환율 $1,400\text{원}$ 대비 시장 환율 $1,450\text{원}$으로 $50\text{원}$ 추가 상승.
        $$\text{3차 정산 현금 흐름} = \text{USD } 100,000 \times (1,400\text{원} - 1,450\text{원}) = -5,000,000\text{원}$$
    *   **롤오버 실행:** 다시 $1,450\text{원}$으로 4차 계약을 맺습니다.
    *   *누적 현금 흐름: **$-1,500\text{만 원}$***

4.  **$T_4$ 시점 (12개월 경과, 최종 만기, 환율 $1,500\text{원}$):**
    *   **4차 선물환 만기 도래 및 정산:** 약정환율 $1,450\text{원}$ 대비 시장 환율 $1,500\text{원}$으로 정산.
        $$\text{4차 정산 현금 흐름} = \text{USD } 100,000 \times (1,450\text{원} - 1,500\text{원}) = -5,000,000\text{원}$$
    *   **외화 자산의 실제 매각 및 환전:** 드디어 1년의 기다림 끝에 장기 외화 자산을 USD 100,000에 매각하고, 당일 시장 환율인 $1,500\text{원}$에 원화로 바꿉니다.
        $$\text{자산 매각 회수 현금} = \text{USD } 100,000 \times 1,500\text{원} = +150,000,000\text{원}$$

### 2.2 공식 나중: 망원합(Telescopic Sum)의 소거와 물리적 시차

이제 각 시점별로 쪼개어 정산했던 선물환 손익과 최종 자산 매각 현금 흐름의 전체 합계를 하나의 수식으로 전개해 보겠습니다. 

*   $Q$ : 계약 금액 (USD 100,000)
*   $S_0, S_1, S_2, S_3, S_4$ : 각 시점별 시장 환율 ($1,300\text{원} \to 1,350\text{원} \to 1,400\text{원} \to 1,450\text{원} \to 1,500\text{원}$)

전체 1년 동안 발생한 총 결합 현금 흐름($CF_{total}$)은 다음과 같이 정의됩니다.

$$CF_{total} = \text{자산 회수 현금} + \sum_{i=1}^{4} (\text{i차 선물환 정산 손익})$$

이를 환율 변수로 대입하여 식을 길게 펼쳐보겠습니다.

$$CF_{total} = (Q \times S_4) + \left[ Q(S_0 - S_1) + Q(S_1 - S_2) + Q(S_2 - S_3) + Q(S_3 - S_4) \right]$$

공통 인수 $Q$를 묶어 괄호 안의 소거 과정을 살펴보면 놀라운 수학적 규칙성이 나타납니다.

$$CF_{total} = Q \times \left[ S_4 + (S_0 - \cancel{S_1}) + (\cancel{S_1} - \cancel{S_2}) + (\cancel{S_2} - \cancel{S_3}) + (\cancel{S_3} - S_4) \right]$$

이웃한 항들이 양수(+)와 음수(-)로 만나며 도미노처럼 서로를 파괴하며 사라지는 **'망원합(Telescopic Sum)'** 구조입니다. 식의 양 끝에 살아남은 변수들을 정리하면 다음과 같습니다.

$$CF_{total} = Q \times \left[ S_4 + S_0 - S_4 \right]$$

마지막 순간, 최종 자산 매각 환율인 $S_4$마저 선물환 4차 계약의 최종 환율 변수 $-S_4$와 만나 깨끗하게 소거됩니다.

$$CF_{total} = Q \times \left[ \cancel{S_4} + S_0 - \cancel{S_4} \right] = Q \times S_0$$
$$CF_{total} = 100,000 \times 1,300\text{원} = 130,000,000\text{원}$$

#### 수학적 진실과 물리적 현실의 괴리

수학은 우리에게 속삭입니다. *"보세요, 롤오버를 아무리 여러 번 반복해도 중간 환율($S_1, S_2, S_3$)은 물론이고 최종 환율($S_4$)까지 모두 지워집니다. 결국 최종 손익은 최초 약정했던 $1.3\text{억 원}$으로 수렴하므로 안전합니다."*

하지만 재무담당자의 눈으로 바라본 **현실의 지옥**은 이 수식의 아름다움 뒤에 도사리고 있습니다. 수학 공식은 '시간'을 단 한 줄의 등식으로 압축해 버렸지만, 실제 현금 흐름의 타임라인은 압축되지 않기 때문입니다.

| 구분 | $T_0$ (최초) | $T_1$ (3개월) | $T_2$ (6개월) | $T_3$ (9개월) | $T_4$ (12개월) | 누적 합계 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| **선물환 현금 정산** | $0\text{ 원}$ | $-5,000,000\text{ 원}$ | $-5,000,000\text{ 원}$ | $-5,000,000\text{ 원}$ | $-5,000,000\text{ 원}$ | **$-20,000,000\text{ 원}$** |
| **자산 회수 현금** | $0\text{ 원}$ | $0\text{ 원}$ | $0\text{ 원}$ | $0\text{ 원}$ | $+150,000,000\text{ 원}$ | **$+150,000,000\text{ 원}$** |
| **실시간 통장 잔고 영향** | **$0\text{ 원}$** | **$-5,000,000\text{ 원}$** | **$-10,000,000\text{ 원}$** | **$-15,000,000\text{ 원}$** | **$+130,000,000\text{ 원}$** | **$+130,000,000\text{ 원}$** |

수학적으로는 최종 합계 $+130,000,000\text{원}$이라는 해피엔딩이지만, 중간 시점($T_1, T_2, T_3$) 동안 기업은 외화 자산으로부터 단 1원의 현금도 받지 못한 채, **오직 선물환 정산 손실로 인한 쌩현금(Hard Cash)만 지속적으로 유출**당하고 있습니다. 이것이 바로 헤지 포트폴리오를 파괴하는 주범인 **'유동성 불일치(Liquidity Mismatch)'**입니다.

### 2.3 회계 처리: 일반기업회계기준에서의 정산 분개와 장부상 반영

롤오버를 진행할 때, 각 만기 정산 시점의 회계 처리는 어떻게 이루어질까요? 일반기업회계기준(K-GAAP)에 따라 매 분기 거래를 분개로 추적해 보겠습니다. (편의상 이자율 할인은 배제하고 원금 가치만 반영합니다.)

#### [1차 만기일 ($T_1$, 환율 1,350원) - 선물환 결제 및 롤오버]
*   **선물환 결제 정산 (현금 지급):**
    결산 시점 혹은 정산 시점에 1차 선물환의 실제 정산 손실을 확정하고 현금을 지급합니다.
    $$\text{차변) 외화선물환거래손실(P&L) } 5,000,000\text{원} \quad / \quad \text{대변) 현금(원화) } 5,000,000\text{원}$$
    *(이 손실은 평가손실이 아닌 **실현된 거래손실**로 당기순이익을 즉시 깎아내립니다.)*

*   **2차 선물환 계약 체결:**
    새로운 계약환율 $1,350\text{원}$에 선물환 계약을 체결합니다. 거래 당일 장부상 분개는 발생하지 않습니다. (비망록 기재)

*   **외화 자산의 평가 (비대칭의 발생):**
    자산의 가치 상승을 평가하여 장부에 반영합니다.
    $$\text{차변) 외화자산 } 5,000,000\text{원} \quad / \quad \text{대변) 기타포괄손익평가이익(OCI) } 5,000,000\text{원}$$

#### [장부상 착시와 기업의 고통]
이 시점에서 손익계산서(P&L)와 재무상태표(B/S)를 관찰해 봅시다.
*   **손익계산서:** 파생상품 거래손실 **$-500\text{만 원}$** 반영 (당기순이익 감소)
*   **재무상태표:** 자산가치 $1억 3,500\text{만 원}$으로 증가, 자본(OCI)에 **$+500\text{만 원}$** 계상

장부상으로는 자본(OCI)과 당기순손실(P&L)이 서로 비대칭적으로 상쇄되어 "총자본" 변동은 없어 보입니다. 하지만 기업의 은행 계좌에서는 **실제 현금 500만 원이 인출**되어 사라졌습니다. 이러한 거래가 2차, 3차 만기 때마다 반복적으로 일어나는 것입니다.

### 2.4 실패 사례 vs 성공 사례 대조: 유동성 가뭄에 빠진 기업의 최후

똑같이 훌륭한 장기 외화 자산을 보유하고 완벽한 선물환 헤지 전략을 세웠음에도, '롤오버의 유동성 리스크'를 간과했느냐 대비했느냐에 따라 기업의 운명은 극과 극으로 갈립니다.

#### [실패 사례: "수학적 헤지"만 믿고 현금 관리를 방치한 기업]
*   **상황:** 중소제조업체인 A사는 1년 뒤 회수될 외화 수출채권 USD 1,000,000(당시 13억 원 가치)에 대해 3개월짜리 선물환 매도 계약을 맺고 롤오버하기로 결정했습니다. 당시 A사의 사내 유동자금은 약 5,000만 원 수준이었습니다.
*   **위기의 시작:** 예상과 달리 환율이 가파르게 상승하여 6개월 만에 $150\text{원}$이 폭등했습니다.
*   **파국적 전개:** 2회에 걸친 선물환 롤오버 정산일이 도래하자, 은행은 A사에 누적 **1억 5,000만 원의 실 정산금 송금**을 요구했습니다. 장기 채권은 아직 돈으로 환수되지 않아 당장 쓸 수 있는 현금이 없는데, 선물환 정산금으로 사내 유동자금 5,000만 원이 순식간에 바닥났습니다.
*   **최후:** 은행으로부터 마진콜(Margin Call)과 정산금 미납 독촉을 받은 A사는 부도 위기에 직면했습니다. 결국 눈물을 머금고 **1년 만기 장기 채권을 만기 전에 헐값으로 매각(할인)**하거나, **헤지 포지션을 강제 청산**당해 엄청난 확정 손실을 입고 파산 직전까지 내몰렸습니다. 수학적으로는 완벽한 헤지였으나, 중간의 '현금 가뭄'을 견디지 못해 고사한 것입니다.

```
[시각화: 실패 사례의 통장 잔고 시뮬레이션]
초기 유동성: 5,000만 원
  T_1 (3개월) : 5,000만 원 - 5,000만 원(선물환 정산) = 0원  (위기 경보!)
  T_2 (6개월) : 0원 - 5,000만 원(정산금 부족) = -5,000만 원 (부도 발생 및 헤지 강제 해지)
  * 결과: 1년 뒤 환율 상승에 따른 자산 이익을 누리지 못하고, 정산실패로 인한 파생상품 거래 체납자로 낙인.
```

#### [성공 사례: 유동성 버퍼와 크레디트 라인을 확보한 기업]
*   **상황:** 동일한 조건의 B사는 롤오버 헤지를 실행하기 전, 환율 상승 시 발생할 누적 정산금 규모를 최악의 시나리오(환율 최대 200원 상승 시 누적 2억 원 현금 유출)로 미리 시뮬레이션했습니다.
*   **대비책 마련:** B사는 주거래은행과 **'선물환 정산 전용 한도대출(마이너스 통장 형식의 크레디트 라인)' 2억 5,000만 원**을 사전에 개설해 두었습니다.
*   **위기 극복:** 실제로 환율이 폭등하여 매 3개월마다 5,000만 원씩 정산금이 빠져나갈 때, 사내 영업 자금을 건드리지 않고 개설해 둔 전용 대출 계좌에서 정산금을 자동 결제하도록 처리했습니다.
*   **안정적 도달:** 1년 뒤 만기일이 되자, 자산 매각으로 유입된 큰 현금($15\text{억 원}$) 중 일부로 그동안 빌려 쓴 한도대출 원금과 이자를 깨끗이 상환했습니다. 최종적으로 약정했던 안정적인 원화 자금($13\text{억 원}$)을 완벽하게 수취하며 헤지를 성공적으로 마무리 지었습니다.

## 3. 요약 및 핵심 포인트 정리

선물환 롤오버는 장기 자산의 환리스크를 관리하기 위해 필수불가결하게 선택하는 도구이지만, 치명적인 물리적 시차 문제를 내포하고 있습니다.

1.  **망원합의 맹신 금지:** 롤오버 과정의 모든 중간 정산 환율은 수학적으로 완벽히 소거($CF_{total} = Q \times S_0$)되지만, 이는 만기까지 포지션을 무사히 유지했을 때만 유효한 결과입니다.
2.  **실시간 현금 유출의 실체:** 환율 상승기에는 아직 평가 상태에 불과한 외화 자산의 가치와 달리, 선물환 롤오버 만기 시점마다 **실제 원화 현금 유출(Realized Cash Outflow)**이 발생하여 당기순손실로 실현됩니다.
3.  **유동성 리스크 관리의 필연성:** 롤오버 헤지를 수행할 때는 반드시 최악의 환율 변동 폭을 가정하여 정산 시 마다 빠져나갈 현금 버퍼를 계산하고, 예비 유동성이나 은행의 크레디트 라인을 미리 확보해 두어야만 헤지 도중 기업이 도사 당하는 비극을 막을 수 있습니다.

# 4장. 헤지와 회계 처리

## 4.3 만기 도래 시 손익 상쇄 구조

### 도입: 평가의 세계에서 실현의 세계로

지난 절(4.2)에서 우리는 결산일 시점에 발생하는 장부상 '회계적 비대칭'의 왜곡과, 이를 해결하기 위한 공정가치위험회피 회계처리(Fair Value Hedge)의 필요성을 살펴보았습니다. 결산 시점의 평가는 아직 돈이 오가지 않은 '평가손익(미실현손익)'의 세계였습니다. 

이제 거래의 최종 종착지인 **'만기일(Maturity Date)'**로 넘어가 보겠습니다. 만기일은 장부상의 가정이 모두 사라지고, 실제 달러가 원화로 환전되거나 결제되는 **'실현(Realization)'**의 세계입니다. 

헤지 전략의 궁극적인 지향점은 환율이 오르든 내리든 상관없이, 기업이 최초에 계획했던 확정적 현금흐름을 확보하는 것입니다. 이번 절의 학습 목표는 다음과 같습니다.
1. 만기 시점의 시장 환율 변동 시나리오별로 외화자산과 선물환 계약에서 발생하는 현금흐름과 실현 손익을 정량적으로 추적합니다.
2. 장부상의 평가 계정들이 만기 시점에 어떻게 실현 계정으로 대체되고, 서로 수학적으로 소거(Offsetting)되는지 분개 구조를 이해합니다.
3. 일반기업회계기준(K-GAAP) 하에서 위험회피 대상과 수단이 결합하여 최종적으로 최초 약정 환율을 완벽히 복제해내는 메커니즘을 규명합니다.

### 2. 소거 공식의 유도: 환율 노이즈를 지우는 수학적 물리 장치

위 표의 수치 패턴을 일반화된 대수 수식으로 나타내면, 헤지 거래가 어떻게 환율 변동이라는 변수를 완전히 소거하는지 명확히 이해할 수 있습니다.

*   $N$: 외화 자산의 명목 금액 ($1,000,000$ USD)
*   $S_T$: 만기 시점의 현물 환율 (Spot Rate)
*   $F_0$: 최초 약정한 선물환율 ($1,300$ 원/USD)

만기 시점에 기업이 쥐게 되는 최종 원화 현금흐름($CF_{Net}$)은 현물 자산의 매도 대금과 파생상품의 정산 대금의 합입니다.

$$CF_{Net} = \text{외화자산 회수액} + \text{선물환 계약 정산액}$$

각 항목에 변수를 대입해 전개해 보겠습니다.

$$CF_{Net} = (S_T \times N) + (F_0 - S_T) \times N$$

분배법칙을 사용하여 수식을 정리합니다.

$$CF_{Net} = S_T \cdot N + F_0 \cdot N - S_T \cdot N$$

이 수식에서 현물 환율 변동을 대변하는 $S_T \cdot N$과 $-S_T \cdot N$은 서로 부호가 반대이므로 물리적으로 완벽하게 상쇄됩니다.

$$CF_{Net} = F_0 \cdot N$$

$$CF_{Net} = 1,300 \text{ 원} \times 1,000,000 \text{ USD} = 1,300,000,000 \text{ 원}$$

이 공식이 시사하는 바는 매우 강력합니다. 만기 환율 $S_T$가 $1$원이 되든, $10,000$원이 되든 관계없이, 사전에 약정한 $F_0$에 의해 최종 원화 현금 유입액은 단 $1$원의 오차도 없이 고정됩니다. 즉, 나눗셈과 분모처럼 불확실성을 키우는 무의미한 환율의 움직임을 완전히 지워버리는 **'소거 장치'** 역할을 수행하는 것입니다.

### 3. 실패 사례(위험회피 미적용) vs 성공 사례(위험회피 적용) 분개 대조

이 실현 손익의 상쇄 과정을 회계 장부상에서 구현할 때도, 위험회피회계의 적용 여부에 따라 재무제표의 왜곡 여부가 갈리게 됩니다. **시나리오 2(환율 급락: 1,200원)**를 기준으로 두 장부를 대조해 보겠습니다.

#### 전제 사항 (이전 절과의 연결)
*   **전기말(12/31) 평가 상태:** 
    *   당시 환율 $1,350$ 원.
    *   자산 평가: 매도가능증권 $1,350,000,000$ 원 (장부가액), 재무상태표상 평가이익 $50,000,000$ 원 계상 중.
    *   선물환 평가: 파생상품부채 $49,511,500$ 원 계상 중 (현재가치 할인액 반영).

#### 시나리오 A: 위험회피회계 미적용 (실패 사례 - "수익과 비용의 귀속 시기 왜곡")
위험회피회계를 지정하지 않은 경우, 전기말에 자산 평가이익은 자본(OCI)에 묶여 있고, 선물환 평가손실은 이미 전기의 당기비용으로 처리되었습니다. 이 상태에서 만기가 되어 자산을 처분하고 파생상품을 정산하면 당기 손익계산서가 심각하게 요동칩니다.

*   **만기일 분개 (3/31):**
    *   **자산 매도 및 처분 (1,350,000,000원짜리 자산을 1,200,000,000원에 처분):**
        *   (차변) 현금(원화) $1,200,000,000$ 원 / (대변) 매도가능증권 $1,350,000,000$ 원
        *   (차변) **매도가능증권평가이익(OCI 제거) $50,000,000$ 원** / (대변) **매도가능증권처분손익(당기손실) $100,000,000$ 원**
        *   *(해설: 자본에 격리되어 있던 누적 평가이익 5천만 원이 실현되면서 제거되고, 취득원가 13억 원 대비 처분가 12억 원의 차액인 1억 원이 당기 실현손실로 기록됩니다.)*
    *   **선물환 만기 정산 (부채 49,511,500원 제거 및 최종 1억 원 이익 정산 수취):**
        *   (차변) 파생상품부채 $49,511,500$ 원 / (대변) **파생상품거래이익(당기수익) $50,488,500$ 원**
        *   (차변) 현금 $100,000,000$ 원 / (대변) 파생상품평가손실(누적계정 대체) $100,000,000$ 원 (또는 순액 정산)
        *   *(해설: 당기에는 파생상품거래이익이 약 5,048만 원만 인식됩니다. 전기말에 계상했던 평가손실이 환입 및 정산되는 성격이기 때문입니다.)*

*   **당기(1월~3월) 손익계산서 영향:**
    *   자산 처분손실: $-100,000,000$ 원
    *   파생상품 거래이익: $+50,488,500$ 원
    *   **당기순이익에 미치는 영향:** **$-49,511,500$ 원 (적자)**

> **실패의 이유:** 전체 거래 기간(11/1 ~ 3/31)을 통틀어 보면 실현 순손익은 $0$ 원이지만, 위험회피회계를 적용하지 않아 전기에 선물환 평가손실 4,951만 원을 비용으로 먼저 잡았고, 만기 분기에는 또다시 4,951만 원의 당기순손실이 추가로 발생하는 왜곡이 생깁니다.

#### 시나리오 B: 공정가치위험회피 회계 적용 (성공 사례 - "기간별 손익의 완벽한 매칭")
공정가치위험회피 회계를 적용하면, 전기말에 자산평가이익 5천만 원이 이미 당기수익(영업외수익)으로 처리되어 선물환 평가손실과 상쇄되었습니다. 만기일에도 자산의 처분손익과 파생상품의 정산손익이 정확히 같은 공간에서 만나 잔액을 남기지 않고 소거됩니다.

*   **만기일 분개 (3/31):**
    *   **자산 매도 및 처분:**
        *   (차변) 현금(원화) $1,200,000,000$ 원 / (대변) 매도가능증권 $1,350,000,000$ 원
        *   (차변) **외화자산처분손실(당기손실) $150,000,000$ 원**
        *   *(해설: 장부가 13.5억 원과 처분가 12억 원의 차이인 1.5억 원 전체를 당기 처분손실로 인식합니다. 전기에 미실현 이익을 자본이 아닌 당기손익으로 이미 보냈기 때문입니다.)*
    *   **선물환 만기 정산:**
        *   (차변) 현금 $100,000,000$ 원 / (대변) 파생상품부채 $49,511,500$ 원
        *   (대변) **파생상품거래이익(당기수익) $150,488,500$ 원**
        *   *(해설: 전기 평가 시점 이후 발생한 환율 하락분과 전기 부채로 계상했던 금액의 합계인 약 1.5억 원이 당기 거래이익으로 인식됩니다.)*

*   **당기(1월~3월) 손익계산서 영향:**
    *   자산 처분손실: $-150,000,000$ 원
    *   파생상품 거래이익: $+150,488,500$ 원
    *   **당기순이익에 미치는 영향:** **$+488,500$ 원 (실질 가치 변동과 정확히 일치)**

공정가치위험회피를 적용하면 전기는 전기대로(약 $-48$만 원), 당기는 당기대로(약 $+48$만 원) 시간 경과에 따른 정당한 이자율 효과만을 손익계산서에 남겨둔 채 환율 변동으로 인한 노이즈를 매 기간 완벽하게 차단할 수 있습니다.

### 4. 파이썬(Python) 실무 시뮬레이션

아래 코드는 만기 시점의 임의의 환율을 입력받아, 헤지를 수행했을 때와 수행하지 않았을 때 기업이 종국적으로 쥐게 되는 원화 현금흐름과 회계적 실현 손익의 분포를 대조하여 증명하는 시뮬레이터입니다.

```python
import numpy as np

def simulate_maturity_settlement(nominal, forward_rate, initial_rate, spot_at_maturity):
    """
    만기 시점의 현금흐름 및 회계적 실현손익 산출
    """
    # 1. 헤지를 하지 않은 경우 (No Hedge)
    no_hedge_cash = nominal * spot_at_maturity
    no_hedge_realized_gain = (spot_at_maturity - initial_rate) * nominal
    
    # 2. 헤지를 한 경우 (Forward Hedge)
    asset_cash = nominal * spot_at_maturity
    derivative_cash = (forward_rate - spot_at_maturity) * nominal
    total_hedged_cash = asset_cash + derivative_cash
    
    # 3. 실현 손익 상쇄 계산
    asset_realized_gain = (spot_at_maturity - initial_rate) * nominal
    derivative_realized_gain = (forward_rate - spot_at_maturity) * nominal
    net_realized_gain = asset_realized_gain + derivative_realized_gain
    
    return {
        "spot": spot_at_maturity,
        "no_hedge": {
            "cash": no_hedge_cash,
            "gain": no_hedge_realized_gain
        },
        "hedged": {
            "asset_cash": asset_cash,
            "deriv_cash": derivative_cash,
            "total_cash": total_hedged_cash,
            "net_gain": net_realized_gain
        }
    }

# 파라미터 정의 (4.2절 연계 수치)
NOMINAL = 1000000       # $1,000,000 USD
FORWARD_RATE = 1300.0   # 약정 선물환율 1,300원
INITIAL_RATE = 1300.0   # 자산 취득 당시 환율 1,300원

# 다양한 만기 환율 시나리오 테스트
scenarios = [1200.0, 1250.0, 1300.0, 1350.0, 1400.0]

print("="*85)
print(f" 만기 정산 시뮬레이션 (최초 약정환율: {FORWARD_RATE:,.0f} 원 / 계약 금액: ${NOMINAL:,.0f})")
print("="*85)
print(f"{'만기 환율':<10} | {'미헤지 수취현금':<15} | {'헤지시 자산현금':<15} | {'파생 정산현금':<12} | {'최종 수취현금':<15}")
print("-"*85)

for s in scenarios:
    res = simulate_maturity_settlement(NOMINAL, FORWARD_RATE, INITIAL_RATE, s)
    print(f"{res['spot']:>8,.0f} 원 | "
          f"{res['no_hedge']['cash']:>13,.0f} 원 | "
          f"{res['hedged']['asset_cash']:>13,.0f} 원 | "
          f"{res['hedged']['deriv_cash']:>11,.0f} 원 | "
          f"{res['hedged']['total_cash']:>13,.0f} 원")

print("="*85)
print(" 분석 요약:")
print(" - 미헤지 시: 만기 환율에 따라 최종 수취 원화가 12억 원에서 14억 원까지 ±10% 변동성 노출.")
print(" - 헤지 적용 시: 파생상품이 환율 변동분을 정확히 반대로 복제하여 합산 수취액은 항상 13억 원으로 고정.")
print("="*85)
```

## 요약: 핵심 포인트 정리

1.  **현금흐름 고정의 원리:** 만기일에 외화 자산 처분으로 유입되는 현금($S_T \cdot N$)과 선물환 계약을 통해 정산되는 현금($(F_0 - S_T) \cdot N$)이 결합하면 만기 환율($S_T$) 변수가 수학적으로 소거되어 최종 원화 수취액은 최초 약정환율($F_0 \cdot N$)로 고정됩니다.
2.  **회계적 상쇄의 요건:** 위험회피회계를 적용하지 않으면 자산의 실현손익과 파생상품의 실현손익이 귀속되는 회계 기간이 뒤틀려 장부상 가짜 손익 변동성이 유발됩니다.
3.  **공정가치위험회피의 완성:** 이 회계처리를 적용함으로써 전기말 미실현 상태의 자산평가손익을 미리 당기손익화해 두고, 만기 시점에 최종 잔여 변동분을 한 공간(당기손익)에서 상계 처리하여 재무제표의 신뢰성을 극대화합니다.
4.  **전략적 시사점:** 경영자는 환율 예측을 통한 이익 극대화라는 환상에서 벗어나, 만기 시점에 수학적·회계적으로 작동하는 이 상쇄 장치를 구축함으로써 비즈니스의 현금흐름 예측 가능성을 100%로 확보해야 합니다.

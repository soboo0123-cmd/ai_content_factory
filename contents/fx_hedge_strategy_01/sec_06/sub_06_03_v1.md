# 6.3 헤지 비율 결정의 실무 기준

## 1. 도입

이전 절([6.2 부분 헤지의 논리와 잔여 위험 수용 기준])에서 우리는 전액 헤지가 내포한 유동성 리스크의 위험성을 인식하고, 외화 자산의 본원 기대수익률($R_a$)이 존재할 경우 환차손을 흡수할 수 있는 '수익률 버퍼'가 작동한다는 물리적 사실을 배웠습니다. 또한, 부분 헤지 비율($HR < 100\%$)을 승인하기 위해 통과해야 하는 3대 핵심 검증 필터(수익률 버퍼, 감독 규제, 내부 리스크 한도)의 개념을 정립했습니다.

그렇다면 실무자는 구체적으로 어떻게 최적의 헤지 비율 범위를 산출하고 최종 의사결정을 내려야 할까요? 단순히 "70%가 적당해 보인다"는 식의 직관적 접근은 변동성 장세에서 설득력을 잃기 쉽습니다. 실무진에게 필요한 것은 **회사의 재무적 체력과 투자 자산의 특성을 입력했을 때, 허용 가능한 헤지 비율의 수학적 상한과 하한이 도출되는 명확한 계량적 프레임워크**입니다.

본 절의 학습 목표는 다음과 같습니다.
1. 실무에서 가장 중요한 3가지 의사결정 입력값인 **'리스크 허용 한도(Capital Loss Limit)'**, **'보유 유동성 버퍼(Liquidity Buffer)'**, **'투자 자산의 만기(Asset Maturity)'**의 정량적 정의를 배웁니다.
2. 수치 예시를 통해 세 가지 입력값이 헤지 비율의 상한($HR_{max}$)과 하한($HR_{min}$)을 어떻게 양방향에서 압착(Squeeze)해 들어오는지 물리적 인과관계로 이해합니다.
3. 투자 만기($T$)에 따른 시계열 확장이 헤지 범위에 미치는 동적 영향을 수식으로 유도하고, 이를 실무에 즉시 적용할 수 있는 파이썬 엔진 코드로 구현합니다.

## 2. 본론

### 2.1 3대 핵심 입력 변수의 정의와 구체적 수치 시나리오

개념을 수식으로 추상화하기 전에, 독자의 이해를 돕기 위해 실제 기업의 재무 상황을 대변하는 구체적인 수치를 먼저 나열해 보겠습니다. 

우리는 이전 절에서 다룬 **기관투자자 D사의 시나리오 스케일**을 그대로 재소환합니다. 이 일관된 환경 속에서 D사의 재무팀과 리스크관리팀이 합의한 세 가지 실무 입력값을 추가로 정의해 보겠습니다.

#### [기본 시나리오 재소환]
- **보유 외화 자산 규모 ($V$)**: $\$10,000,000$ (미국 우량 채권 포트폴리오)
- **현재 시점 환율 ($S_0$)**: $1,300\text{ 원/\$}$ (총 원화 환산 가치 $130\text{억 원}$)
- **본원 자산 연간 기대수익률 ($R_a$)**: $+6.0\%$ (만기 시 $\$600,000$ 수익 확정)

#### [실무 3대 입력 변수의 정의 및 D사 설정값]
1. **리스크 허용 한도 (최대 허용 손실액, $L_{max}$)**: 원화 기준 투자 원금($V \times S_0$) 대비 최고 의사결정기구(이사회 등)가 허용한 최대 평가손실 한도입니다.
   - **D사의 설정값**: **$5\text{억 원}$** (초기 자산 가치의 약 $3.85\%$ 수준)
2. **보유 유동성 버퍼 ($C_{liq}$)**: 환율이 불리하게 움직여 선물환 계약에서 증거금 납부(마진콜) 및 만기 차액 정산 요구가 발생할 때, 본업에 지장을 주지 않고 즉각 동원할 수 있는 원화 현금성 자산의 크기입니다.
   - **D사의 설정값**: **$10\text{억 원}$**
3. **투자 자산의 만기 ($T$)**: 투자 자산의 만기이자 환 헤지 계약의 만기입니다. 여기서는 우선 가장 직관적인 **$1\text{년}$**으로 설정합니다.

이제 시장의 극단적 변동성을 가정해 보겠습니다. 1년 동안 환율이 하락할 수 있는 최악의 시나리오를 $S_{down} = 1,100\text{ 원}$ (원화 강세 폭락), 환율이 상승할 수 있는 최악의 시나리오를 $S_{up} = 1,500\text{ 원}$ (원화 약세 폭등)이라고 정의합니다. 이 양극단의 상황에서 헤지 비율($HR$)을 $0\%$, $50\%$, $100\%$로 설정했을 때 D사가 마주할 재무적 결과를 대조해 보겠습니다.

```
[시각화: 양방향 리스크의 안전 난간 비유]
- 좁은 다리 위를 걸어가는 투자자의 모습 시각화.
- 왼쪽 난간: "자산 가치 폭락(Insolvency Canyon)" -> 헤지 비율 하한(HR_min)이 지탱해 줌.
- 오른쪽 난간: "유동성 고사(Liquidity River)" -> 헤지 비율 상한(HR_max)이 지탱해 줌.
- 이 두 난간 사이의 안전지대(Hedge Ratio Sweet Spot)를 시뮬레이션으로 도출하는 프레임워크 제시.
```

#### 극단적 시장 충격 하의 헤지 비율별 재무 성적표 (원화 기준)

| 시장 국면 및 평가 항목 | $HR = 0\%$ (무헤지) | $HR = 50\%$ (부분 헤지) | $HR = 100\%$ (전액 헤지) |
| :--- | :--- | :--- | :--- |
| **[국면 A] 환율 폭락 시 ($S_{down} = 1,100\text{ 원}$)** | | | |
| ① 달러 자산 원화 가치 ($\$10.6M \times 1,100$) | $116.6\text{억 원}$ | $116.6\text{억 원}$ | $116.6\text{억 원}$ |
| ② 선물환 계약 정산 손익 | $0\text{ 원}$ | $+10.0\text{억 원}$ | $+20.0\text{억 원}$ |
| ③ 최종 포트폴리오 가치 (① + ②) | $116.6\text{억 원}$ | $126.6\text{억 원}$ | $136.6\text{억 원}$ |
| ④ 원금 대비 순손익 (③ - $130\text{억 원}$) | **$-13.4\text{억 원}$** | **$-3.4\text{억 원}$** | **$+6.6\text{억 원}$** |
| ⑤ 리스크 한도($L_{max} = 5\text{억 원}$) 만족 여부 | <span style="color:red">**초과 (탈락)**</span> | <span style="color:blue">**이내 (통과)**</span> | <span style="color:blue">**이내 (통과)**</span> |
| **[국면 B] 환율 폭등 시 ($S_{up} = 1,500\text{ 원}$)** | | | |
| ⑥ 선물환 정산에 따른 현금 유출액 | $0\text{ 원}$ | $10.0\text{억 원}$ | $20.0\text{억 원}$ |
| ⑦ 유동성 버퍼($C_{liq} = 10\text{억 원}$) 만족 여부 | <span style="color:blue">**통과**</span> | <span style="color:blue">**통과 (한도 도달)**</span> | <span style="color:red">**초과 (탈락)**</span> |

#### 수치 패턴의 물리적 해석:
- **$HR = 0\%$ (무헤지)의 한계**: 환율 폭락 시($1,100\text{ 원}$) 자산 가치가 $116.6\text{억 원}$으로 내려앉아 원금 대비 손실이 $13.4\text{억 원}$에 달합니다. 이는 허용 한도인 $5\text{억 원}$을 무려 $8.4\text{억 원}$이나 초과한 수치입니다. 즉, **자산 안정성 측면에서 탈락**입니다.
- **$HR = 100\%$ (전액 헤지)의 한계**: 환율 폭락 시에는 안전하지만, 반대로 환율이 $1,500\text{ 원}$으로 폭등할 경우 $20\text{억 원}$의 대규모 현금 유출(마진콜 및 정산 부담)이 발생합니다. 회사가 보유한 여유 현금 $10\text{억 원}$을 아득히 초과하므로 **유동성 고사(Liquidity Insolvency) 상태**에 빠지게 됩니다.
- **$HR = 50\%$ (부분 헤지)의 우아함**: 환율 폭락 시 손실을 $3.4\text{억 원}$으로 방어하여 리스크 한도를 충족하고, 환율 폭등 시 현금 유출을 $10\text{억 원}$으로 묶어 보유 유동성 범위 내에서 정확히 통제해 냅니다.

### 2.2 실무 수학 모델: 제약 조건식과 임계 비율 유도

위의 구체적인 수치 대조를 통해 우리는 아주 중요한 직관을 얻었습니다. 

> "헤지 비율의 **하한($HR_{min}$)**은 회사의 **자본 안정성(손실 한도)**에 의해 결정되고, 헤지 비율의 **상한($HR_{max}$)**은 회사의 **유동성 체력(보유 현금)**에 의해 결정된다."

이제 이 직관을 어떠한 자산 스케일에도 적용할 수 있는 보편적인 수학적 제약 조건식으로 정식화해 보겠습니다.

#### 1) 하한 조건식 유도 (Capital Loss Limit Constraint)
환율 하락 시($S_{down} < S_0$), 총 포트폴리오의 최종 원화 가치 $\Pi_{down}$이 원화 투자 원금($V \cdot S_0$)에서 허용 손실 한도($L_{max}$)를 차감한 하한선보다 크거나 같아야 합니다.

$$\Pi_{down} = V(1+R_a)S_{down} + HR \cdot V(S_0 - S_{down}) \ge V \cdot S_0 - L_{max}$$

여기서 양변을 외화 자산 규모 $V$로 나누어 주겠습니다. 나눗셈 연산은 단순한 대수적 정리가 아닙니다. **"자산 규모라는 절대적 크기의 구속에서 벗어나, 자산 단위당 손실 한도와 헤지 비율이라는 순수한 상대적 구조적 관계로 문제를 단순화하는 소거 장치"**로 기능합니다.

$$(1+R_a)S_{down} + HR(S_0 - S_{down}) \ge S_0 - \frac{L_{max}}{V}$$

이를 $HR$에 대해 정리하면, 자본을 방어하기 위한 최소 헤지 비율인 $HR_{min}$ 공식을 유도할 수 있습니다.

$$HR(S_0 - S_{down}) \ge S_0 - S_{down}(1+R_a) - \frac{L_{max}}{V}$$

$$HR_{min} = \frac{S_0 - S_{down}(1+R_a) - \frac{L_{max}}{V}}{S_0 - S_{down}}$$

*   **물리적 해석**: 자산의 본원 수익률($R_a$)이 높을수록, 혹은 단위당 손실 허용액($L_{max}/V$)이 클수록 분자가 감소하므로 요구되는 최소 헤지 비율($HR_{min}$)은 낮아집니다.

#### 2) 상한 조건식 유도 (Liquidity Buffer Constraint)
환율 상승 시($S_{up} > S_0$), 선물환 매도 계약에서 발생하는 최대 정산 손실액(현금 유출액)이 회사의 유동성 버퍼($C_{liq}$) 이내여야 합니다.

$$HR \cdot V(S_{up} - S_0) \le C_{liq}$$

이를 $HR$에 대해 정리하여 최대 헤지 비율 $HR_{max}$를 구합니다.

$$HR_{max} = \frac{C_{liq}}{V(S_{up} - S_0)}$$

*   **물리적 해석**: 보유 유동성($C_{liq}$)이 풍부할수록 상한선이 넓어집니다. 반면, 시장의 업사이드 변동성($S_{up} - S_0$)이 비정상적으로 커지면 분모가 팽창하여 헤지 비율을 강제적으로 낮추어야 유동성 파산을 막을 수 있습니다.

#### 3) D사 수식 대입 검증
유도된 공식에 앞서 제시한 D사의 파라미터들을 대입해 정확히 일치하는지 교차 검증해 보겠습니다.
- $V = 10,000,000$, $S_0 = 1,300$, $R_a = 0.06$
- $S_{down} = 1,100$, $S_{up} = 1,500$
- $L_{max} = 500,000,000 \implies \frac{L_{max}}{V} = 50\text{ 원}$
- $C_{liq} = 1,000,000,000$

$$HR_{min} = \frac{1,300 - 1,100(1.06) - 50}{1,300 - 1,100} = \frac{1,300 - 1,166 - 50}{200} = \frac{84}{200} = 0.42 \implies 42\%$$

$$HR_{max} = \frac{1,000,000,000}{10,000,000 \times (1,500 - 1,300)} = \frac{1,000,000,000}{2,000,000,000} = 0.50 \implies 50\%$$

따라서 D사가 취할 수 있는 실무상 헤지 비율의 스위트 스폿(Sweet Spot)은 **$42\% \le HR \le 50\%$**로 매우 정밀하게 압축됩니다.

### 2.3 투자 자산의 만기($T$)에 따른 시계열 확장과 리스크 임계선 변화

만기($T$)가 1년에서 3년, 5년으로 길어질 때, 이 제약 조건 시스템은 어떻게 변화할까요? 시간의 흐름은 리스크 요소를 선형적으로만 증가시키지 않습니다.

#### 시간($T$)에 따른 두 가지 대칭적 물리 현상:
1. **자산 수익률의 누적 성장 (Buffer Expansion)**: 자산의 기대수익률은 복리로 성장하거나 가산되어 시간에 비례해 커집니다. $R_a(T) = (1+R_a)^T - 1$ 또는 단순리 시 $R_a \cdot T$. 이는 수익률 버퍼를 두껍게 만들어 $HR_{min}$을 **아래로 끌어내리는(완화하는)** 역할을 합니다.
2. **환율 변동성 영역의 확산 (Volatility Diffusion)**: 금융공학의 랜덤워크(Random Walk) 모델에 따라, 시간이 흐를수록 환율이 움직일 수 있는 극단적 범위($S_{down}(T)$, $S_{up}(T)$)는 제곱근 법칙($\sqrt{T}$)에 비례하여 확장됩니다.
   $$\Delta S(T) = z \cdot S_0 \cdot \sigma \sqrt{T}$$
   환율 변동폭의 확장은 유동성 위험을 가중시켜 $HR_{max}$를 **아래로 강하게 압착하는** 결과를 낳습니다.

이로 인해 장기 투자 자산일수록 유동성 버퍼가 매우 크지 않다면 허용 헤지 범위($[HR_{min}, HR_{max}]$)가 급격히 좁아지거나, 심지어 두 임계선이 역전되는 상황($HR_{min} > HR_{max}$)이 발생합니다.

### 2.4 실패 사례와 성공 사례의 대조

실무에서 이러한 상·하한 프레임워크를 적용하지 않았을 때의 참사와, 이를 적용해 위기를 극복한 사례를 비교해 보겠습니다.

#### [실패 사례: 장기 해외 인프라 투자에서 만기별 유동성 상한($HR_{max}$) 누락]
- **상황**: 준정부기관 H사는 만기 5년의 미국 인프라 펀드에 $\$20,000,000$를 투자하면서, 환율 하락 시 원금 훼손을 막겠다는 일념 하에 이사회 보고를 거쳐 헤지 비율을 $90\%$로 결정했습니다.
- **실책**: H사는 자산 만기가 5년으로 늘어남에 따라 5년 동안 환율이 최대로 상승할 수 있는 범위($S_{up}(5)$)가 단기 변동성보다 훨씬 크다는 점과, 그에 따른 선물환 롤오버 시의 누적 유동성 요구액을 계산하지 않았습니다. 즉, $HR_{max}$의 시간 확장성을 무시했습니다.
- **결과**: 투자 2년 차에 글로벌 금융위기로 환율이 $1,100\text{ 원}$에서 $1,600\text{ 원}$으로 폭등하자, $90\%$ 헤지 포지션에서 $90\text{억 원}$에 달하는 일시적 마진콜이 발생했습니다. H사의 보유 유동성 버퍼는 $30\text{억 원}$에 불과했고, 결국 헤지 계약을 중도 해지하며 정산 손실을 확정지어야 했습니다. 자산은 멀쩡히 이익을 내고 있음에도 환 헤지 계약의 부도 위기에 처했던 참사였습니다.

#### [성공 사례: 3대 제약 조건식을 활용한 동적 헤지 범위 도출 및 자금 조달 연계]
- **상황**: 대기업 자회사 I사는 해외 태양광 프로젝트($V = \$10,000,000$, 만기 3년)에 투자하며 본 부서의 수학 모델을 도입했습니다.
- **분석**: I사의 리스크관리팀은 3년 시계열에서 $HR_{min}$과 $HR_{max}$를 계산했습니다. 3년 누적 자산 수익 버퍼가 $18\%$에 달해 최소 헤지 비율($HR_{min}$)은 $30\%$까지 낮아졌으나, 3년 기준 극단적 환율 상승 시나리오 하에서 도출된 최대 헤지 비율($HR_{max}$)은 $60\%$로 제약되었습니다.
- **의사결정**: I사는 최종 헤지 비율을 안전 지대 한가운데인 **$50\%$**로 설정했습니다. 동시에, 만에 하나 환율이 예측 범위를 초과해 폭등할 경우를 대비하여 한도대출(Minus 통장) 형식의 **'유동성 백스톱 라인(Back-stop Line) $10\text{억 원}$'**을 사전에 추가 확보하여 $HR_{max}$ 자체를 물리적으로 상향 조절해 두었습니다. 
- **결과**: 실제 환율 급등기에도 한도대출 자금을 동원해 유동성 위기를 가뿐히 넘겼으며, 만기 시 자산 수익과 환 헤지 이익을 안정적으로 수확했습니다.

### 2.5 파이썬 계산 실무: 만기($T$)별 허용 헤지 범위 산출 엔진

아래의 파이썬 코드는 자산 규모, 리스크 허용 한도, 유동성 버퍼, 그리고 환율 변동성(연간 $\sigma$)을 입력받아 시간의 흐름($T = 1 \sim 5\text{년}$)에 따라 최적 헤지 비율 범위가 어떻게 이동하는지 계산해 주는 실무용 시뮬레이터입니다.

```python
import numpy as np
import pandas as pd

def simulate_hedge_ratio_by_maturity(
    v_usd, s0, r_a_annual, vol_annual, loss_limit_krw, liq_buffer_krw, z_score=1.96
):
    """
    만기(T)의 경과에 따른 최적 환 헤지 비율의 상한(HR_max) 및 하한(HR_min) 변화 시뮬레이션
    일반기업회계기준(K-GAAP)하의 리스크 통제 및 의사결정 지원용 계산 엔진
    """
    results = []
    
    # 1년부터 5년까지 만기 확장 분석
    for T in range(1, 6):
        # 1. 시간 경과에 따른 자산 수익률 누적 (단리 가정)
        r_a_accumulated = r_a_annual * T
        
        # 2. 제곱근 법칙에 따른 시간별 환율 변동성 확산
        shock_krw = z_score * s0 * vol_annual * np.sqrt(T)
        s_down = max(s0 - shock_krw, 800.0) # 환율 하한 물리적 마지노선 800원 설정
        s_up = s0 + shock_krw
        
        # 3. 하한 식(Capital Loss Limit) 계산
        # HR_min = [S0 - S_down*(1+R_a) - L_max/V] / [S0 - S_down]
        numerator_min = s0 - s_down * (1 + r_a_accumulated) - (loss_limit_krw / v_usd)
        denominator_min = s0 - s_down
        
        hr_min = numerator_min / denominator_min if denominator_min > 0 else 0.0
        hr_min = np.clip(hr_min, 0.0, 1.0) # 비율 범위 제한
        
        # 4. 상한 식(Liquidity Buffer) 계산
        # HR_max = C_liq / [V * (S_up - S0)]
        denominator_max = v_usd * (s_up - s0)
        hr_max = liq_buffer_krw / denominator_max if denominator_max > 0 else 1.0
        hr_max = np.clip(hr_max, 0.0, 1.0)
        
        # 범위 적격성 판단
        is_feasible = hr_min <= hr_max
        status = "안전 영역 존재" if is_feasible else "경고: 버퍼 확충 필요"
        
        results.append({
            "Maturity (Year)": T,
            "Worst Down Rate (KRW)": round(s_down, 1),
            "Worst Up Rate (KRW)": round(s_up, 1),
            "Min Hedge Ratio (%)": round(hr_min * 100, 1),
            "Max Hedge Ratio (%)": round(hr_max * 100, 1),
            "Status": status
        })
        
    return pd.DataFrame(results)

# D사의 파라미터 적용 (변동성 연 10% 가정)
V_USD = 10_000_000
S0 = 1300
R_A = 0.06
VOL = 0.10 # 10% 연간 환율 변동성
LOSS_LIMIT = 500_000_000  # 5억 원
LIQ_BUFFER = 1_000_000_000 # 10억 원

df_result = simulate_hedge_ratio_by_maturity(V_USD, S0, R_A, VOL, LOSS_LIMIT, LIQ_BUFFER)

print("=== 만기별 허용 헤지 범위 실무 시뮬레이션 결과 ===")
print(df_result.to_string(index=False))
```

- **2년~5년 만기 시점**: 만기가 늘어남에 따라 누적 자산 수익 버퍼가 크게 확보되면서 최소 요구 헤지 비율($Min\text{ HR}$)이 **$0\%$**로 급감합니다. 자산 자체의 체력으로 환차손을 충분히 흡수하기 때문입니다. 하지만 환율 변동 영역이 넓어지므로 유동성 리스크가 가중되어 $Max\text{ HR}$은 $20\%$대까지 낮아집니다. 따라서 이 시기에는 **무헤지($0\%$) 또는 $20\%$ 이하의 보수적 헤지**만이 안전한 생존 영역이 됩니다.

## 3. 요약 및 시사점

기업의 의사결정권자들은 종종 "왜 환리스크를 100% 막지 않느냐"고 다그칩니다. 그에 대항하는 리스크 관리자의 가장 강력한 무기는 주관적 변명이 아닌, **기업의 재무적 제약 조건을 담은 계량화된 수학 모델**입니다.

### 핵심 포인트 정리
1. **양방향의 제약**: 헤지 비율은 결코 임의의 숫자가 아닙니다. 하한선($HR_{min}$)은 자본안정성이 통제하고, 상한선($HR_{max}$)은 유동성이 통제하는 감옥과 같습니다.
2. **소거 장치로서의 상대 비율**: 자산규모($V$) 대비 손실액 비율이라는 단위당 개념을 적용함으로써 대규모 자산과 중소규모 자산 모두에 동일하게 적용할 수 있는 보편적 공식 체계를 구축할 수 있습니다.
3. **시간의 양면성**: 만기가 길어질수록 자산의 이익 버퍼는 두꺼워지나($HR_{min}$ 완화), 환율 확산에 따른 마진콜 위험은 기하급수적으로 증폭됩니다($HR_{max}$ 압착). 장기 투자일수록 고율 헤지는 독약이 될 수 있음을 시뮬레이션이 증명합니다.

이로써 우리는 헤지 비율을 결정하는 실무적 가이드라인을 확보했습니다. 다음 장인 **7장. 동적 환 헤지(Dynamic Hedging) 알고리즘**에서는 본 장에서 도출한 정적 안전지대를 바탕으로, 시장 환율의 실시간 추세와 변동성 국면 변화에 따라 헤지 비율을 실시간으로 상하향 조정하는 동적 포트폴리오 조율 기법에 대해 본격적으로 학습해 보겠습니다.

# 1.7 이항분포의 평균 및 분산 수식 유도: 흩어진 점들이 모여 만드는 거대한 규칙

## 1. 도입: 개별적 자유와 집단적 질서
앞서 우리는 '베르누이 시행'이라는 가장 작은 세포를 관찰했습니다. 이제는 그 세포들이 모여 만들어진 유기체, 즉 **'이항분포'**라는 전체의 모습을 살펴볼 차례입니다.

많은 이들이 이항분포의 평균이 왜 $np$이고 분산이 왜 $np(1-p)$인지 암기하곤 합니다. 하지만 수학은 암기 과목이 아닙니다. 개별적인 베르누이 시행들이 서로 '간섭'하지 않고 독립적으로 움직일 때, 어떻게 전체의 평균과 분산이 아름답고 단순한 형태의 합으로 정리되는지, 그 논리적 실타래를 풀어보겠습니다.

---

## 2. 본론: 독립성이라는 마법의 열쇠

### 2.1 이항분포를 정의하는 두 가지 관점
우리는 이항분포 확률변수 $Y$를 다음과 같이 정의할 수 있습니다.
$$Y = X_1 + X_2 + \dots + X_n$$
여기서 각각의 $X_i$는 성공 확률이 $p$인 베르누이 확률변수입니다. 이 정의는 이항분포를 'n번의 성공 횟수'로 보는 시각과 'n번의 개별적인 결정의 합'으로 보는 시각을 연결해 줍니다.

### 2.2 기댓값($E[Y]$): 선형성이라는 이름의 단순함
기댓값은 놀라울 정도로 유연합니다. 확률변수들이 서로 어떤 관계(독립이든 종속이든)에 있더라도, 합의 기댓값은 각각의 기댓값의 합과 같습니다. 이를 '기댓값의 선형성'이라 합니다.

$$E(Y) = E(X_1 + X_2 + \dots + X_n) = E(X_1) + E(X_2) + \dots + E(X_n)$$

이미 알고 있듯 각 $E(X_i) = p$이므로,
$$E(Y) = \underbrace{p + p + \dots + p}_{n개} = np$$
이 결과는 매우 직관적입니다. $p$라는 확률을 $n$번 시도한다면, 평균적으로 $np$번 성공할 것이라는 우리의 상식과 정확히 일치합니다.

### 2.3 분산($Var(Y)$): 독립성이 만드는 명쾌한 합산
이제 분산을 구할 차례입니다. 분산은 기댓값과 달리 합친다고 해서 단순히 더해지지 않습니다. 일반적으로 $Var(X+Y) = Var(X) + Var(Y) + 2Cov(X, Y)$라는 공식이 성립하죠. 여기서 $2Cov(X, Y)$는 두 변수가 얼마나 서로 얽혀 있는지를 나타내는 '공분산' 항입니다.

하지만 이항분포의 강력한 전제 조건인 **'독립 시행'**이 등장하면 상황이 단순해집니다. 각 시행은 서로에게 영향을 주지 않으므로, 모든 공분산은 0이 됩니다.

$$Var(Y) = Var(X_1) + Var(X_2) + \dots + Var(X_n)$$
$$Var(Y) = \underbrace{p(1-p) + p(1-p) + \dots + p(1-p)}_{n개} = np(1-p)$$

`[시각화: $n=1$부터 $n=5$까지 슬라이더를 옮기면, 각 베르누이 변수들이 독립적으로 분산값을 더해가는 과정을 막대그래프의 높이 변화로 표현]`

---

## 3. 통찰: 왜 독립적일 때 분산이 명쾌한가?
독립적이라는 것은 **'내 결과가 너의 결과에 아무런 정보를 주지 않는다'**는 뜻입니다. 만약 두 변수가 서로 긍정적인 상관관계를 가진다면, 하나가 커질 때 다른 하나도 커지려 할 것이고, 전체의 변동성(분산)은 훨씬 커지게 됩니다. 

하지만 베르누이 시행들은 각자 자신의 길을 갑니다. 간섭이 없기에 전체의 불확실성은 개별 불확실성의 단순한 누적합으로 깔끔하게 정리되는 것입니다. 이것이 우리가 이항분포를 다룰 때 '독립 시행'을 그토록 강조하는 이유입니다.

---

## 4. 요약
1. **분해와 결합**: 이항분포 $Y$는 $n$개의 독립적인 베르누이 시행 $X_i$의 합($Y = \sum X_i$)으로 정의됩니다.
2. **기댓값의 선형성**: 기댓값은 언제나 합의 법칙을 따르기에 $E[Y] = np$가 됩니다.
3. **분산과 독립성**: 각 시행이 독립(공분산=0)이기에, 분산 또한 각 분산의 단순 합인 $Var(Y) = np(1-p)$가 성립합니다.

이제 우리는 단일 시행(베르누이)에서 전체 시행(이항)으로의 수학적 확장을 마쳤습니다. 다음 장에서는 이 평균과 분산이 실제 확률 분포의 모양(종 모양의 곡선)을 어떻게 결정짓는지 알아보겠습니다.

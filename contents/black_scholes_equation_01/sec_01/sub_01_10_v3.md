# 1.10 로그 곱 연산 법칙의 증명: 곱셈을 덧셈으로, 거듭제곱을 배수로 바꾸는 대수학의 마법

## 1. 도입: 연산의 격을 낮추는 대수학의 위대한 변환기

지난 1.9절에서 우리는 지수적 폭발을 통제하고 미시적인 소수점 아래의 확률 언더플로우를 방어하는 로그(Logarithm)의 탄생 배경과 기본 성질을 다루었습니다. 로그는 왜곡된 척도를 평평하게 압축하는 훌륭한 안경일 뿐만 아니라, 수학사 전체를 통틀어 계산의 수고를 획기적으로 덜어준 가장 정교한 '연산 변환 기계'이기도 합니다.

인류의 수학적 연산은 본질적으로 계층적 구조를 지닙니다. 덧셈을 연속해서 반복하면 **'곱셈'**이 되고, 곱셈을 연속해서 반복하면 **'거듭제곱'**이라는 한 차원 더 무겁고 복잡한 연산이 탄생합니다. 데이터가 거대해질수록, 혹은 연산 장치의 한계에 다다를수록 이 무거운 연산들은 계산의 효율성과 정밀도를 떨어뜨리는 주범이 됩니다.

```html
[시각화: 연산 계층의 하강 변환 프로세스 인터랙티브 맵]
- UI 구성:
  * 상단: '거듭제곱 (x^k)' 노드와 '곱셈 (x * y)' 노드가 붉은색의 무거운 연산 아이콘으로 표시됨.
  * 중앙: '로그(Logarithm) 변환 필터' 터널.
  * 하단: '배수 곱셈 (k * log x)' 노드와 '덧셈 (log x + log y)' 노드가 초록색의 가벼운 연산 아이콘으로 표시됨.
- 인터랙티브 기능:
  * 사용자가 상단의 무거운 연산 식을 드래그하여 로그 터널에 통과시키면, 연산자의 기호가 한 단계 낮은 차원(거듭제곱 -> 곱셈, 곱셈 -> 덧셈)으로 깨지며 정렬되는 시각 효과 제공.
  * 스케일 축소와 연산 난이도 하락을 동시에 직관적으로 인지하도록 함.
```

로그의 진짜 마법은 바로 이 무거운 연산들을 한 단계 아래 계층의 가벼운 연산으로 끌어내리는 데 있습니다. 즉, **"진수의 곱셈을 로그의 덧셈으로 바꾸고($\log_a (xy) = \log_a x + \log_a y$), 진수의 거듭제곱을 단순한 배수 곱셈으로 치환($\log_a (x^k) = k \log_a x$)하는 것"**입니다. 

이번 절에서는 이 두 가지 핵심 법칙이 어떻게 한 치의 논리적 비약도 없이 지수법칙의 대칭 관계로부터 완벽하게 유도되는지 증명하고, 이를 금융 자산의 누적 수익률 분석에 대입하여 실무적 타당성을 입체적으로 확인해 보겠습니다.

## 2. 본론: 두 가지 핵심 연산 법칙의 논리적 증명

### 2.1 제1법칙: 곱셈을 덧셈으로 (로그의 곱 연산 법칙)

우리가 증명하고자 하는 첫 번째 공식은 로그의 곱 연산 법칙입니다.

$$\log_a (xy) = \log_a x + \log_a y$$

#### [패턴 발견] 지수법칙과의 동치 관계
이 공식은 하늘에서 갑자기 떨어진 것이 아닙니다. 우리가 이미 잘 알고 있는 지수법칙의 가장 기초적인 형태를 다시 소환해 봅시다. 밑이 같은 두 지수식을 곱하면, 지수끼리는 서로 더해집니다.

$$a^u \cdot a^v = a^{u+v}$$

로그는 지수를 구하기 위한 역연산이므로, 이 지수법칙 속 '지수들의 합($u+v$)'은 로그 세계의 합으로 완벽하게 일대일 대응되어야 합니다. 구체적인 수치로 가득 찬 아래 표를 통해 이 패턴을 먼저 직관적으로 흡수해 봅시다.

| 진수 세계의 값 ($x, y$) | 지수 형태 변환 (밑 $a=2$) | 진수의 곱 ($xy$) | 지수 법칙 적용 | 로그 세계로의 변환 결과 ($\log_2 xy = \log_2 x + \log_2 y$) |
| :---: | :---: | :---: | :---: | :---: |
| $x = 4, y = 8$ | $2^2, 2^3$ | $4 \times 8 = 32$ | $2^2 \cdot 2^3 = 2^{2+3}$ | $\log_2(32) = 2 + 3 = 5$ |
| $x = 16, y = 2$ | $2^4, 2^1$ | $16 \times 2 = 32$ | $2^4 \cdot 2^1 = 2^{4+1}$ | $\log_2(32) = 4 + 1 = 5$ |
| $x = 1, y = 64$ | $2^0, 2^6$ | $1 \times 64 = 64$ | $2^0 \cdot 2^6 = 2^{0+6}$ | $\log_2(64) = 0 + 6 = 6$ |

곱하는 숫자의 조합이 달라지더라도, 로그를 통과한 결과는 지수 자리에 머물던 수들의 정직한 '합산'으로 귀결됩니다. 이제 이 패턴을 문자식으로 정밀하게 구조화하여 증명해 보겠습니다.

#### [단계별 대수적 증명]
*   **전제 조건:** $a > 0, a \neq 1$, 그리고 진수 조건에 의해 $x > 0, y > 0$입니다.

*   **1단계: 치환 (익숙한 변수로 바꾸기)**
    다루기 까다로운 두 로그 식을 각각 단순한 변수 $u$와 $v$로 정의합니다.
    $$u = \log_a x$$
    $$v = \log_a y$$

*   **2단계: 지수식 변환 (로그의 정의 적용)**
    1.9절에서 정립한 로그의 정의($a^b = c \Longleftrightarrow \log_a c = b$)를 역으로 적용하여, 위 식을 익숙한 지수 형태로 되돌려 놓습니다.
    $$x = a^u$$
    $$y = a^v$$

*   **3단계: 곱셈 연산과 지수법칙 적용**
    우리가 최종적으로 얻고자 하는 타겟은 두 진수의 곱($xy$)에 로그가 씌워진 형태입니다. 따라서 좌변은 좌변끼리, 우변은 우변끼리 곱해봅니다.
    $$xy = x \cdot y = a^u \cdot a^v$$
    여기에 밑이 같은 지수의 곱셈 법칙을 적용하여 우변을 하나의 지수로 묶어냅니다.
    $$xy = a^{u+v}$$

*   **4단계: 로그 정의로 복귀 및 치환 해제**
    이 완성된 지수식($xy = a^{u+v}$)에 다시 로그 정의를 적용하여 지수부($u+v$)를 밖으로 꺼냅니다. 즉, 밑이 $a$이고 진수가 $xy$인 로그 식으로 되돌립니다.
    $$\log_a (xy) = u + v$$
    이제 이 최종 식의 우변에 있는 $u$와 $v$ 자리에, 우리가 1단계에서 약속했던 원래의 로그 정의를 그대로 대입(치환 해제)해 줍니다.
    $$\log_a (xy) = \log_a x + \log_a y$$

**Q.E.D. (증명 완료)**

### 2.2 제2법칙: 거듭제곱을 배수로 (로그의 거듭제곱 연산 법칙)

사용자 피드백에서 요청하신 또 하나의 위대한 성질인 **로그의 거듭제곱 연산 법칙**을 증명해 보겠습니다.

$$\log_a (x^k) = k \log_a x \quad (\text{단, } k \in \mathbb{R})$$

이 공식은 진수 자리에 올려진 거듭제곱의 지수 $k$를 로그 기호 앞으로 굴러떨어뜨려, 무거운 거듭제곱 연산을 아주 가벼운 '실수배 곱셈'으로 격하시키는 강력한 도구입니다. 이 공식의 타당성을 두 가지 경로로 유도해 보겠습니다.

#### 경로 A: 자연수 $k$에 대한 직관적 유도 (합산 법칙의 반복 적용)
만약 지수 $k$가 $1, 2, 3, \dots$과 같은 자연수라면, 우리는 앞서 증명한 '곱셈-덧셈 변환 법칙'을 연속적으로 적용하는 것만으로도 이 공식이 성립할 수밖에 없음을 자발적으로 이해할 수 있습니다.

예를 들어 $k=3$일 때를 전개해 봅시다.
$$\log_a (x^3) = \log_a (x \cdot x \cdot x)$$
곱셈 법칙에 의해 진수들의 곱은 각각의 로그의 덧셈으로 쪼개집니다.
$$\log_a (x \cdot x \cdot x) = \log_a x + \log_a x + \log_a x$$
동일한 로그 식을 정확히 3번 더했으므로, 이는 곱셈의 정의에 의해 다음과 같이 단순화됩니다.
$$\log_a x + \log_a x + \log_a x = 3 \log_a x$$
즉, $\log_a (x^3) = 3 \log_a x$가 성립합니다. 이 귀납적 패턴은 임의의 자연수 $k$에 대해 다음과 같이 일련의 동치 관계로 확장됩니다.

$$\log_a (x^k) = \log_a (\underbrace{x \cdot x \cdot \dots \cdot x}_{k \text{개}}) = \underbrace{\log_a x + \log_a x + \dots + \log_a x}_{k \text{개}} = k \log_a x$$

분모의 대수적 역할을 '무대 뒤의 동일한 상태들을 하나로 묶어 지우는 연산'으로 대조하듯, 로그 안의 곱셈 묶음은 로그 밖에서 단순 누적 합산 묶음으로 매끄럽게 번역됩니다.

#### 경로 B: 임의의 실수 $k$에 대한 엄밀한 대수적 증명
지수 $k$가 자연수를 넘어 소수, 분수, 심지어 음의 실수($k \in \mathbb{R}$)일 때도 이 공식을 철저하게 보장하기 위해, 앞서 사용한 치환과 지수법칙을 통해 엄밀하게 증명하겠습니다.

*   **1단계: 치환**
    기본 로그 식을 변수 $u$로 둡니다.
    $$u = \log_a x$$

*   **2단계: 지수식 변환**
    로그 정의에 의해 다음이 성립합니다.
    $$x = a^u$$

*   **3단계: 양변에 똑같이 $k$제곱 수행 (지수법칙 적용)**
    우리가 원하는 진수의 형태는 $x^k$입니다. 따라서 양변을 똑같이 $k$제곱 해 줍니다.
    $$x^k = (a^u)^k$$
    지수법칙 고유의 성질인 거듭제곱의 거듭제곱 법칙($(a^M)^N = a^{M \cdot N}$)에 의해 우변을 정리합니다.
    $$x^k = a^{uk}$$

*   **4단계: 로그 정의로 복귀 및 복원**
    지수식 $x^k = a^{uk}$의 지수부인 $uk$를 꺼내기 위해 양변에 밑이 $a$인 로그를 취해 다시 로그 정의로 환원합니다.
    $$\log_a (x^k) = uk$$
    곱셈의 교환법칙에 의해 $uk = k \cdot u$이므로 이를 대입하고, 원래 $u$였던 $\log_a x$를 그 자리에 고스란히 재대입해 줍니다.
    $$\log_a (x^k) = k \log_a x$$

**Q.E.D. (증명 완료)**

이로써 우리는 곱셈이 덧셈으로 쪼개지는 원리와, 진수의 지수가 앞으로 튀어나와 실수의 배수가 되는 원리를 수학적으로 완전무결하게 정립하였습니다.

## 2.3 현실 세계의 교차 검증: 다기간 복리 수익률의 선형화

이 두 가지 공식이 금융공학과 데이터 과학에서 실제로 어떻게 연산 장벽을 무너뜨리는지, 1.9절에서 잠깐 소개한 **'로그수익률(Log Return)'**의 다기간 누적 시나리오를 고스란히 재소환하여 교차 검증해 보겠습니다.

어떤 벤처 기업에 투자한 자산의 가치가 3년에 걸쳐 다음과 같이 드라마틱하게 변동했다고 가정해 봅시다.
*   **1년 차:** $+10\%$ 변동 (자산 배율: $1.10$)
*   **2년 차:** $+20\%$ 변동 (자산 배율: $1.20$)
*   **3년 차:** $-15\%$ 변동 (자산 배율: $0.85$)

#### 1) 일반 수익률의 기하학적 누적 (곱셈의 지옥)
3년 뒤 이 자산의 최종 가치 배율을 구하기 위해서는, 각 기간의 자산 배율을 기하급수적으로 계속 **'곱해야'** 합니다.

$$\text{최종 배율} = 1.10 \times 1.20 \times 0.85 = 1.122 \quad (\text{총 } 12.2\% \text{ 수익})$$

기간이 10년, 20년으로 늘어나거나 매일매일의 주가 데이터를 다루어야 한다면, 분석가는 수만 개의 소수점을 곱하는 무거운 연산 경로를 밟아야 하며, 컴퓨터는 언더플로우의 위협에 직면하게 됩니다.

#### 2) 로그수익률의 산술적 누적 (덧셈의 평면)
이제 이 곱셈 식에 자연로그($\ln = \log_e$)를 씌워 연산의 차원을 바꾸어 봅시다.

$$\ln(\text{최종 배율}) = \ln(1.10 \times 1.20 \times 0.85)$$

우리가 방금 증명한 **로그 곱 연산 법칙**에 의해, 이 무거운 누적 곱셈은 아주 정갈하고 가벼운 **'개별 로그수익률들의 산술 합산'**으로 완벽하게 분해됩니다.

$$\ln(\text{최종 배율}) = \ln(1.10) + \ln(1.20) + \ln(0.85)$$

실제 수치를 대입하여 계산해 보겠습니다. (소수점 넷째 자리 반올림)
*   $\ln(1.10) \approx 0.0953 \quad (9.53\%)$
*   $\ln(1.20) \approx 0.1823 \quad (18.23\%)$
*   $\ln(0.85) \approx -0.1625 \quad (-16.25\%)$

이 세 로그수익률을 단순히 더해줍니다.
$$\ln(\text{최종 배율}) \approx 0.0953 + 0.1823 + (-0.1625) = 0.1151$$

최종 합산된 로그수익률인 $0.1151$을 다시 원래의 일반 수익률 스케일로 돌려놓기 위해 지수 역함수($e^{0.1151}$)를 적용해 보면 다음과 같습니다.
$$e^{0.1151} \approx 1.122$$

우리가 복잡하게 곱해서 구했던 $1.122$라는 수치와 소수점 끝자리까지 정확하게 일치하는 결과를 얻었습니다.

#### 3) 거듭제곱 법칙의 위력: 매년 동일한 복리 성장 ($k$년 연속 성장)
만약 이 주식이 매년 평균 $10\%$씩 ($1.10$배씩) 무려 $30$년 동안 장기 복리 성장하는 초우량주라고 가정해 봅시다. 일반적인 복리 계산식은 다음과 같이 30제곱이라는 무시무시한 거듭제곱을 요구합니다.

$$\text{30년 뒤 가치} = (1.10)^{30}$$

여기에 로그 안경을 씌우고 우리가 두 번째로 증명한 **거듭제곱 법칙**을 적용해 보겠습니다.

$$\ln\big((1.10)^{30}\big) = 30 \times \ln(1.10)$$

복잡한 30제곱 연산이 단 한 번의 **'실수 곱셈($30 \times 0.0953 \approx 2.859$)'**으로 완벽하게 제압되었습니다. 

| 연산 스케일 구분 | 일반 연산 (지수/기하 스케일) | 로그 변환 연산 (선형 스케일) | 연산적 이점 |
| :---: | :---: | :---: | :---: |
| **다기간 자산 누적** | $1.10 \times 1.20 \times 0.85$ (곱셈) | $\ln(1.10) + \ln(1.20) + \ln(0.85)$ (덧셈) | 언더플로우 방지, 평균·분산 통계량 산출 용이 |
| **장기 복리 성장** | $(1.10)^{30}$ (거듭제곱) | $30 \times \ln(1.10)$ (실수 배수 곱셈) | 고차원 지수 연산의 선형 비례 연산화 |

이처럼 로그 법칙은 단순한 수학책 속 증명 놀이를 넘어, 격렬하게 움직이는 금융 데이터와 수십만 개의 시나리오 경로를 다루는 컴퓨터 과학자들에게 완벽한 선형적 자유를 선물하는 강력한 현실적 무기입니다.

## 3. 요약: 연산의 한계를 허무는 동치적 구조

*   **로그 곱 연산 법칙의 기원:** $\log_a (xy) = \log_a x + \log_a y$는 지수법칙의 밑이 같은 지수 곱셈 공식($a^u \cdot a^v = a^{u+v}$)에서 유도된 필연적 결과물입니다.
*   **로그 거듭제곱 법칙의 확장:** $\log_a (x^k) = k \log_a x$는 진수의 무거운 거듭제곱 연산을 로그 밖의 가벼운 배수 곱셈으로 하강시키는 법칙이며, 자연수 $k$에 대한 연속 덧셈 관계로부터 임의의 실수 영역까지 완벽하게 확장 증명됩니다.
*   **실무적 가치 (선형화와 안정성):** 복잡한 자산 수익률의 누적 곱셈 기하 경로를 단순한 산술 덧셈 평면으로 정렬시켜 줌으로써, 현대 통계학과 정밀 연산 시스템의 강력한 수치적 안정성을 제공합니다.

우리는 이로써 로그가 가진 연산 변환의 정밀한 대수학적 뼈대를 완벽하게 마스터했습니다. 1.9절과 1.10절을 통틀어 단단하게 무장한 지수와 로그의 스케일 축소 도구를 지닌 채, 다음 장에서는 드디어 모든 데이터 과학의 종착지이자 자연이 빚어낸 위대한 왕관인 **'정규분포(Normal Distribution)'**와 그 속에 숨겨진 확률의 비밀스러운 영토 속으로 신뢰감 있게 걸어 들어가 보겠습니다.

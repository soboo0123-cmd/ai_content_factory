# 1.7 이항분포의 평균 및 분산 수식 유도: 개별 세포의 독립적 결합과 가법성(Additivity)의 조화

## 1. 도입: 거대한 숲의 무게중심과 불확실성을 측정하다

지난 1.6절에서 우리는 모든 이항분포의 근본적인 세포이자 최소 단위인 **'베르누이 시행'**을 정밀하게 관찰했습니다. 단 한 번 주가가 오르거나 내리는 시행에서 기댓값 $E[X]$는 상승 확률 $q$ 자체였으며, 불확실성의 크기인 분산 $Var(X)$는 상승과 하락 확률의 상호보완적 곱인 $q(1-q)$로 완벽하게 규정됨을 수학적, 실증적으로 증명해 냈죠.

이제 우리의 시선을 세포 하나에서, 이 세포들이 무수히 얽혀 구성된 **'이항분포(Binomial Distribution)'**라는 거대한 유기체로 확장하고자 합니다. 동전을 한 번 던져 앞면이 나올 기댓값을 구하는 것은 쉽지만, 동전을 100번 던졌을 때 나타날 전체 성공 횟수의 평균과 분산은 어떻게 계산해야 할까요? 주가가 매 단계 독립적으로 변동하는 다단계 이항 트리 모델에서, 만기 시점 최종 주가 분포의 평균적인 위치와 변동 범위를 통제하려면 이 대수적 도구가 필수적입니다.

많은 이들이 이항분포의 평균 공식 $nq$와 분산 공식 $nq(1-q)$를 단순 암기 대상인 '죽은 수식'으로 취급합니다. 하지만 우리는 이번 장에서 개별 세포들이 서로 간섭하지 않고 '독립적'으로 결합할 때, 어떻게 집단 전체의 질서(평균과 분산)가 아름답고 단순한 형태의 합으로 도출되는지 그 논리적 실타래를 완전히 풀어헤칠 것입니다. 이 과정에서 우리는 수학적 단순화를 가능케 하는 '선형성'과 '독립성'의 마법을 직접 경험하게 될 것입니다.

## 2. 본론: 세포의 결합과 대수적 유도

### 2.1 이항 확률변수의 정의: 독립된 세포들의 축적
이항분포를 따르는 확률변수 $Y$는 $n$번의 독립적인 베르누이 시행에서 발생한 총 성공(상승) 횟수를 의미합니다. 이를 수학적으로 가장 우아하게 정의하는 방법은 각 시행의 결과를 나타내는 베르누이 확률변수 $X_1, X_2, \dots, X_n$들의 **'단순 합'**으로 표현하는 것입니다.

$$Y = X_1 + X_2 + \dots + X_n = \sum_{i=1}^{n} X_i$$

여기서 각 $X_i$는 서로에게 아무런 영향을 주지 않는 독립적인 베르누이 확률변수이며, 지난 장과 일관되게 상승(성공) 확률 $q = 0.6$, 하락(실패) 확률 $1-q = 0.4$를 가집니다. 즉, $Y$는 개별 베르누이 세포들이 일렬로 쌓여 만들어진 통계적 탑인 셈입니다.

```html

  * 사용자가 '합산(Sum)' 버튼을 누르면 5개의 블록이 아래로 떨어져 하나의 큰 기둥 'Y'를 형성함.
```

### 2.2 기댓값($E[Y]$): 선형성이라는 강력한 무기
이항 확률변수 $Y$의 기댓값 $E[Y]$를 구하는 일은 놀라울 정도로 명쾌합니다. 기댓값은 **'선형성(Linearity)'**이라는 독보적인 대수적 성질을 지니고 있기 때문입니다. 선형성이란 여러 확률변수의 합에 대한 기댓값이, 개별 확률변수 기댓값들의 단순 합과 무조건적으로 일치한다는 원리입니다.

$$E[Y] = E[X_1 + X_2 + \dots + X_n]$$
$$E[Y] = E[X_1] + E[X_2] + \dots + E[X_n]$$

이 선형성이 위대한 이유는 개별 확률변수들이 서로 독립이든, 아주 강하게 얽혀 있는 종속 상태이든 상관없이 **항상 성립**한다는 점에 있습니다. 우리는 이미 1.6절에서 단일 베르누이 변수의 기댓값이 $E[X_i] = q$임을 증명했습니다. 따라서 위 식은 다음과 같이 정리됩니다.

$$E[Y] = \underbrace{q + q + \dots + q}_{n \text{개}}$$
$$E[Y] = nq$$

#### 구체적 수치 시나리오 대입 검증
이 공식이 얼마나 직관적이고 강력한지 확인해 봅시다. 이전 절에서 사용한 파라미터($q = 0.6$, 즉 성공 확률 60%)를 그대로 가져와, 시행 횟수 $n = 10$인 상황에 대입해 보겠습니다.

$$E[Y] = 10 \times 0.6 = 6$$

성공 확률이 60%인 독립적인 시행을 10번 반복한다면, 우리는 상식적으로 평균 6번의 성공을 기대합니다. 대수적으로 복잡하게 유도된 공식 $nq$가 우리의 상식적 직관과 한 치의 오차도 없이 일치하는 순간입니다.

### 2.3 분산($Var(Y)$): 독립성이 보장하는 깔끔한 가법성
이제 이항분포의 흩어짐 정도, 즉 변동성을 정량화하는 분산 $Var(Y)$를 구해봅시다. 분산은 기댓값과 달리 합친다고 해서 항상 단순 합으로 쪼개지지 않습니다. 두 확률변수의 합에 대한 분산은 다음과 같이 공분산(Covariance)이라는 보정 항을 반드시 동반하기 때문입니다.

$$Var(X_1 + X_2) = Var(X_1) + Var(X_2) + 2Cov(X_1, X_2)$$

하지만 이항분포에는 **'각 시행은 서로 독립적이다'**라는 강력한 물리적 철벽 방어막이 존재합니다. 서로 완전히 독립인 두 변수는 공분산이 정확히 $0$이 되어 흔적도 없이 사라집니다. (이 공분산 소멸의 구체적인 수학적 증명은 본문 하단의 [부록]에서 깊이 있게 다루겠습니다.)

따라서 상호 독립적인 베르누이 변수들의 합인 이항분포의 분산은, 개별 변수 분산들의 온전한 단순 합산으로 깔끔하게 정리됩니다.

$$Var(Y) = Var(X_1) + Var(X_2) + \dots + Var(X_n)$$

1.6절에서 유도한 단일 베르누이 변수의 분산 $Var(X_i) = q(1-q)$를 대입하면 최종 공식이 도출됩니다.

$$Var(Y) = \underbrace{q(1-q) + q(1-q) + \dots + q(1-q)}_{n \text{개}}$$
$$Var(Y) = nq(1-q)$$

#### 물리적 한계 범위 및 의미 분석
이 공식이 가지는 물리적 범위와 의미를 시나리오 분석을 통해 음미해 봅시다.
1.  **완전 확실성 상태 ($q = 0$ 또는 $q = 1$):**
    *   성공 확률이 0%이거나 100%라면, 아무리 $n$번 시행을 반복하더라도 전체 분산 $Var(Y) = n \cdot 0 = 0$이 됩니다. 결과가 완전히 결정되어 불확실성이 전혀 없는 상태를 정밀하게 묘사합니다.
2.  **최대 불확실성 상태 ($q = 0.5$):**
    *   매 시행이 50:50의 극단적인 동전 던지기일 때, 전체 이항분포의 분산은 $Var(Y) = n(0.25)$로 이론적 최대치에 도달합니다.
3.  **수치 시나리오 매칭 검증 ($n = 10, q = 0.6$):**
    *   우리의 표준 시나리오를 대입하면 분산은 다음과 같습니다.
        $$Var(Y) = 10 \times 0.6 \times 0.4 = 2.4$$
    *   만약 $q=0.5$였다면 분산은 $2.5$였을 것입니다. 성공 확률이 60%로 한쪽으로 다소 치우침에 따라, 전체 시스템의 불확실성이 $2.5$에서 $2.4$로 미세하게 감소했음을 수치가 명확히 보여줍니다.

```html

- UI 구성:
```

### 2.4 파이썬 실습: 10,000번의 이항 실험을 통한 이론치 교차 검증
대수적으로 정밀하게 유도해 낸 이항분포의 평균($nq = 6.0$)과 분산($nq(1-q) = 2.4$) 공식이 실제 대규모 무작위 시뮬레이션 환경에서도 정확히 작동하는지 파이썬 코드로 검증해 보겠습니다. 앞서 설정한 시나리오 변수값을 그대로 유지한 채 컴퓨터로 가상 실험을 수행합니다.

```python
import numpy as np

def verify_binomial_statistics(n, q, num_simulations):
    """
    n번의 베르누이 시행을 거치는 이항분포 실험을 대규모로 반복하여 
    표본 통계량과 대수적 이론치를 교차 검증합니다.
    """
    # np.random.binomial을 통해 가상 이항실험 수행
    # 각 샘플은 n번 시행 중 성공한 횟수(0 ~ n 사이의 정수)를 나타냄
    samples = np.random.binomial(n=n, p=q, size=num_simulations)
    
    # 1. 표본 통계량 계산
    sample_mean = np.mean(samples)
    sample_var = np.var(samples)
    
    # 2. 대수적 이론값 계산
    theoretical_mean = n * q
    theoretical_var = n * q * (1 - q)
    
    # 결과 출력
    print(f"--- {num_simulations:,}회 가상 이항분포 실험 결과 (n={n}, q={q}) ---")
    print(f"표본 평균 (Sample Mean):     {sample_mean:.5f} (이론치 nq: {theoretical_mean:.5f})")
    print(f"표본 분산 (Sample Variance): {sample_var:.5f} (이론치 nq(1-q): {theoretical_var:.5f})")
    
    # 오차 검증 (허용 오차 범위 내 일치 여부 확인)
    mean_match = np.isclose(sample_mean, theoretical_mean, atol=1e-2)
    var_match = np.isclose(sample_var, theoretical_var, atol=1e-2)
    
    print(f"평균 공식 일치 여부: {mean_match}")
    print(f"분산 공식 일치 여부: {var_match}")

# 시나리오 매칭 파라미터 적용
verify_binomial_statistics(n=10, q=0.6, num_simulations=100000)
```

### 코드 실행 결과

```text
표본 분산 (Sample Variance): 2.40185 (이론치 nq(1-q): 2.40000)
평균 공식 일치 여부: True
분산 공식 일치 여부: True
```

10만 번에 달하는 무작위 가상 실험을 통해 계산된 표본 평균은 정확히 `6.00`으로, 분산은 `2.40`으로 이끌리듯 수렴했습니다. 복잡한 무작위 사건의 이면에는 이처럼 기하학적으로 완벽하고 견고한 대수적 규칙이 자리 잡고 있음을 시뮬레이션 결과가 명백히 대조하여 증명해 줍니다.

## 3. [부록] 합의 분산 공식과 공분산 소멸의 수학적 증명

독자 여러분이 지닌 수학적 인지적 공백을 완벽히 메우기 위해, 분산의 합산 과정에서 왜 공분산 항이 발생하며, 독립이라는 특수한 장치를 통해 이 공분산이 어떻게 완벽히 소거되는지 한 단계씩 대수적으로 증명해 보겠습니다.

### 단계 1: 두 확률변수 합의 분산 전개
임의의 두 확률변수 $A$와 $B$의 합 $A+B$에 대한 분산의 정의식에서 출발합니다. 분산의 본질은 '값과 평균의 편차 제곱에 대한 평균(기댓값)'입니다.

$$Var(A+B) = E\left[ \Big( (A+B) - E[A+B] \Big)^2 \right]$$

기댓값의 선형성($E[A+B] = E[A] + E[B]$)을 적용하여 내부 식을 묶어줍니다.

$$Var(A+B) = E\left[ \Big( (A - E[A]) + (B - E[B]) \Big)^2 \right]$$

이제 중고등학교 시절 배운 곱셈 공식 $(x+y)^2 = x^2 + 2xy + y^2$을 활용해 중괄호 내부를 전개합니다. ($A - E[A]$를 $x$로, $B - E[B]$를 $y$로 치환해 생각하면 쉽습니다.)

$$Var(A+B) = E\left[ (A - E[A])^2 + 2(A - E[A])(B - E[B]) + (B - E[B])^2 \right]$$

기댓값 연산자($E[\cdot]$)의 선형성을 각각의 항에 분배해 줍니다.

$$Var(A+B) = E\left[ (A - E[A])^2 \right] + 2E\left[ (A - E[A])(B - E[B]) \right] + E\left[ (B - E[B])^2 \right]$$

각 항의 물리적 정의를 매핑해 보면 놀라운 결과가 나타납니다.
*   $E\left[ (A - E[A])^2 \right]$은 정확히 $Var(A)$의 정의입니다.
*   $E\left[ (B - E[B])^2 \right]$은 정확히 $Var(B)$의 정의입니다.
*   중앙의 $E\left[ (A - E[A])(B - E[B]) \right]$은 두 변수가 같이 움직이는 경향성을 나타내는 **'공분산 $Cov(A, B)$'**의 정의입니다.

따라서 아래의 보편적 합의 분산 공식이 도출됩니다.

$$Var(A+B) = Var(A) + Var(B) + 2Cov(A, B)$$

---

### 단계 2: 독립(Independence)일 때 공분산의 소멸 증명
두 확률변수 $A$와 $B$가 서로 **독립**이라는 것은 무엇을 의미할까요? 수학적으로 독립인 두 변수는 공동 기댓값이 각각의 기댓값의 곱으로 완전히 분리되는 성질을 가집니다: $E[AB] = E[A]E[B]$. 

이 정의를 바탕으로 공분산 식을 전개해 보겠습니다.

$$Cov(A, B) = E\left[ (A - E[A])(B - E[B]) \right]$$
$$Cov(A, B) = E\left[ AB - A \cdot E[B] - B \cdot E[A] + E[A]E[B] \right]$$

기댓값을 선형적으로 전개합니다. 이때 $E[A]$와 $E[B]$는 변수가 아닌 고정된 '상수'이므로 기댓값 연산 밖으로 그대로 빠져나옵니다.

$$Cov(A, B) = E[AB] - E[A]E[B] - E[B]E[A] + E[A]E[B]$$
$$Cov(A, B) = E[AB] - E[A]E[B]$$

여기에 독립의 핵심 조건인 $E[AB] = E[A]E[B]$를 대입하면 어떻게 될까요?

$$Cov(A, B) = E[A]E[B] - E[A]E[B] = 0$$

두 변수가 독립일 경우, 공분산은 계산할 필요도 없이 정확하게 **$0$**으로 수렴하며 사라집니다. 이 대수적 필연성 덕분에, 독립 시행을 전제로 하는 이항분포의 분산은 복잡한 상호 간섭 항 없이 개별 분산의 합($nq(1-q)$)만으로 단순 명쾌하게 계산할 수 있는 것입니다.

---

### 단계 3: 극단적 대조군 시나리오 (독립 vs 완벽 종속)
독립성이 분산 통제에 미치는 영향력을 체감할 수 있도록, 극단적인 대조 시나리오를 표를 통해 비교 분석해 보겠습니다.

*   **시나리오 1 (독립적인 두 자산):** 서로 아무 상관 없이 독립적으로 움직이는 두 자산 $X_1, X_2$ ($Var(X_i) = 2.4, Cov(X_1, X_2) = 0$).
*   **시나리오 2 (완벽히 동조하는 두 자산):** 하나의 가격 움직임을 그대로 완벽히 복제하여 100% 같이 움직이는 두 자산 $X_1, X_1$ ($Cov(X_1, X_1) = Var(X_1) = 2.4$).

| 비교 항목 | 시나리오 1 (독립적 결합) | 시나리오 2 (완벽 종속 결합) |
| :---: | :---: | :---: |
| **대수적 공식** | $Var(X_1 + X_2) = Var(X_1) + Var(X_2)$ | $Var(X_1 + X_1) = Var(X_1) + Var(X_1) + 2Var(X_1)$ |
| **실제 수치 연산** | $2.4 + 2.4 = 4.8$ | $2.4 + 2.4 + 2(2.4) = 4(2.4) = 9.6$ |
| **변동성 증폭 효과** | 불확실성이 단순 합산 수준에서 완만히 제어됨 | 불확실성이 제곱 형태로 폭발하여 위험이 2배(9.6)로 증폭됨 |

이 대조 테이블은 금융 시장에서 왜 **'독립적인 자산에 분산 투자하라'**고 그토록 강조하는지 수학적으로 명징하게 드러내 줍니다. 독립성이 결여되는 순간 공분산 항이 부활하여 전체 포트폴리오의 불확실성을 기하급수적으로 폭발시키기 때문입니다. 이항분포의 분산 공식 $nq(1-q)$가 지닌 단순한 아름다움은 바로 이 독립성이 가져다준 평화의 결과물입니다.

## 4. 요약: 개별 세포의 질서 정연한 연대

*   **이항 확률변수의 본질:** 이항 확률변수 $Y$는 $n$개의 상호 독립적인 베르누이 시행 확률변수 $X_i$들의 총합($Y = \sum X_i$)입니다.
*   **평균의 선형적 확장:** 기댓값의 선형성 덕분에 개별 변수의 관계와 무관하게 전체 기댓값은 각 평균의 단순 합인 $nq$가 됩니다.
*   **독립성과 분산의 결합:** 각 시행이 완벽한 독립 상태일 때 공분산($Cov$)은 수학적으로 소멸($0$)합니다. 이에 따라 전체 이항분포의 분산은 개별 분산의 단순 합산 형태인 $nq(1-q)$라는 극도로 정갈한 공식으로 귀결됩니다.

단일 베르누이 세포의 유전 코드가 어떻게 $n$차원의 거대한 이항분포 구조로 질서 정연하게 이식되고 확장되는지 그 수학적 통로를 완벽히 마스터했습니다. 다음 장에서는 이렇게 완성된 평균과 분산이라는 기둥을 축으로 하여, 이항분포가 무수히 반복될 때 그 모양이 어떻게 인류 역사상 가장 위대한 곡선인 '종 모양의 정규분포'로 수렴해 나가는지, 그 전율 돋는 극한의 세계를 탐험해 보겠습니다.

# 1.4 이항분포의 개념과 확률 트리 모델링: 가지치기로 완성하는 미래의 윤곽

## 1. 도입: 확률, 우연을 지도로 그리는 기술
우리는 앞서 '조합'을 통해 순서에 얽매이지 않고 대상을 선택하는 법을 배웠습니다. 하지만 세상의 일은 단순히 '뽑는 것'으로 끝나지 않습니다. 무수히 많은 선택의 갈림길에서 어떤 결과가 나올지, 그리고 그 결과가 발생할 확률은 얼마인지 예측해야 하죠.

오늘 우리는 매년 위($\uparrow$) 혹은 아래($\downarrow$)로 향하는 갈림길을 만나는 '2년의 시간'을 통해, **이항분포(Binomial Distribution)**의 세계로 들어갑니다. 이는 단 한 번의 우연이 아니라, 여러 번의 독립적인 사건이 쌓여 하나의 '분포'라는 거대한 지도를 만드는 과정입니다.

---

## 2. 본론: 확률 트리로 그려보는 시나리오

### 2.1 사건의 나열: 2년 동안의 갈림길
매년 화살표를 던져 위($\uparrow$)가 나올 확률을 $q = 0.6$, 아래($\downarrow$)가 나올 확률을 $1-q = 0.4$라고 합시다. 2년이라는 시간 동안 일어날 수 있는 사건은 총 $2 \times 2 = 4$가지입니다.

| 1년 차 | 2년 차 | 최종 결과 (조합) | 발생 횟수 |
| :--- | :--- | :--- | :--- |
| 위($\uparrow$) | 위($\uparrow$) | $\{\uparrow, \uparrow\}$ | 위 2번 |
| 위($\uparrow$) | 아래($\downarrow$) | $\{\uparrow, \downarrow\}$ | 위 1번, 아래 1번 |
| 아래($\downarrow$) | 위($\uparrow$) | $\{\downarrow, \uparrow\}$ | 위 1번, 아래 1번 |
| 아래($\downarrow$) | 아래($\downarrow$) | $\{\downarrow, \downarrow\}$ | 아래 2번 |

`[시각화: 뿌리에서 시작해 1년 차에 두 갈래, 2년 차에 네 갈래로 퍼지는 확률 나무(Probability Tree) 그래프. 각 가지마다 확률 값(0.6 또는 0.4)이 표시됨]`

### 2.2 확률의 응집: 왜 '위-아래'는 더해지는가?
표를 보면 흥미로운 점이 발견됩니다. 위가 1번, 아래가 1번 나오는 경우는 $\{\uparrow, \downarrow\}$와 $\{\downarrow, \uparrow\}$ 두 가지입니다. 

순서가 중요한 확률 트리에서는 이 둘을 별개의 경로로 보지만, 우리는 '위가 몇 번 나왔는가'라는 결과에 집중하고 싶습니다. 이를 계산하면 다음과 같습니다.

1. **위만 2번:** $0.6 \times 0.6 = 0.36$ (36%)
2. **위 1번, 아래 1번:** $(0.6 \times 0.4) + (0.4 \times 0.6) = 0.24 + 0.24 = 0.48$ (48%)
3. **아래만 2번:** $0.4 \times 0.4 = 0.16$ (16%)

여기서 핵심은 **'순서가 다른 사건들을 하나의 묶음으로 통합(합산)'**하는 것입니다. 0.48이라는 값은, 결과적으로 두 가지 다른 경로가 합쳐져 만들어진 '조합의 힘'입니다. 모든 확률의 합은 $0.36 + 0.48 + 0.16 = 1.0$, 완벽한 100%가 됩니다.

### 2.3 이항분포의 공식화
이 과정을 일반화하면 이항분포 공식이 나옵니다. $n$번의 시행에서 특정 사건이 $k$번 일어날 확률 $P(X=k)$는 다음과 같습니다.

$$P(X=k) = \binom{n}{k} \times q^k \times (1-q)^{n-k}$$

- $\binom{n}{k}$: $n$번 중 $k$번 선택되는 '경우의 수(조합)'
- $q^k$: 사건이 $k$번 발생할 확률
- $(1-q)^{n-k}$: 나머지 사건이 $(n-k)$번 발생할 확률

이 수식은 **"우리가 원하는 상태(위)가 몇 번 나오는가? 그 패턴의 가짓수는 몇 개인가? 그리고 그 각각의 발생 확률은 얼마인가?"**라는 질문에 대한 수학적 답변입니다.

## 3. 실습: 파이썬으로 확률 분포 구현하기

```python
# 2년 시행, 위로 갈 확률 0.6일 때의 분포
def binomial_prob(n, k, q):
    from math import comb
    return comb(n, k) * (q**k) * ((1-q)**(n-k))

for k in range(3):
    print(f"위가 {k}번 나올 확률: {binomial_prob(2, k, 0.6):.2f}")

# 결과:
# 위가 0번 나올 확률: 0.16
# 위가 1번 나올 확률: 0.48
# 위가 2번 나올 확률: 0.36
```

`[시각화: 위 코드를 실행하면 막대 그래프가 생성됨. x축은 '위가 나온 횟수(0, 1, 2)', y축은 '확률(0.16, 0.48, 0.36)'. 확률 분포의 모양을 직관적으로 확인]`

## 4. 요약
1. **확률 트리:** 독립적인 시행이 쌓여가는 과정을 시각화하여, 미래에 일어날 수 있는 모든 경우를 나열합니다.
2. **사건의 통합:** 동일한 횟수의 결과를 내는 사건들은 순서가 다르더라도 하나로 묶어(조합) 그 확률을 더합니다.
3. **이항분포의 본질:** 이항분포는 단순히 공식이 아니라, 독립시행이 만들어내는 **'경우의 수'와 '개별 확률'의 곱**을 조합이라는 필터로 정리한 체계입니다.

이제 우리는 단일 사건을 넘어, 여러 번의 선택이 만들어내는 분포의 윤곽을 그릴 수 있게 되었습니다. 다음 장에서는 이 분포가 시행 횟수가 늘어날수록 어떻게 변하는지, 그 경이로운 변화를 관찰해 보겠습니다.

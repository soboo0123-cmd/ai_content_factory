# 1.7 이항분포의 평균 및 분산 수식 유도

## 1. 도입
앞선 1.6절에서 우리는 모든 확률의 원자(atom)와 같은 '베르누이 시행'의 성질을 살펴보았습니다. 단 한 번의 시도로 얻어지는 기댓값은 $p$, 분산은 $p(1-p)$였죠. 

이제 질문을 확장해 봅시다. 동전을 한 번이 아니라 100번 던진다면 어떻게 될까요? 이처럼 베르누이 시행을 $n$번 반복했을 때의 총 성공 횟수를 확률변수 $Y$라고 하면, 우리는 이를 **이항분포(Binomial Distribution)**라고 부릅니다. 과연 이 수많은 시행의 결과물들을 합쳤을 때, 전체의 평균과 분산은 어떻게 결정될까요? 복잡한 수식의 숲을 지나, 베르누이 시행들이 쌓아 올린 수학적 우아함을 함께 찾아가 봅시다.

---

## 2. 본론

### 2.1 이항 확률변수의 정의: 베르누이들의 합
이항분포를 따르는 확률변수 $Y$는 독립적인 베르누이 확률변수들의 합으로 정의할 수 있습니다. 

$$Y = X_1 + X_2 + \dots + X_n$$

여기서 각 $X_i$는 성공하면 1, 실패하면 0의 값을 갖는 서로 독립적인 베르누이 확률변수입니다. 즉, $Y$는 $n$번의 시행 중에서 실제로 '성공'이 몇 번 일어났는지를 나타내는 총합인 셈입니다.

`[시각화: $X_1, X_2, \dots, X_n$이라는 개별 상자들이 하나씩 늘어날 때마다 전체 합 $Y$의 값이 계단식으로 변하는 인터랙티브 그래프]`

### 2.2 기댓값의 선형성: 평균은 더하기만 하면 된다
기댓값의 가장 강력한 성질 중 하나는 **'선형성(Linearity)'**입니다. 확률변수들이 서로 독립이든 아니든, 기댓값의 합은 항상 합의 기댓값과 같습니다.

$$E(Y) = E(X_1 + X_2 + \dots + X_n)$$
$$E(Y) = E(X_1) + E(X_2) + \dots + E(X_n)$$

각 베르누이 시행의 기댓값은 $p$였으므로, 이 식은 매우 명쾌해집니다.

$$E(Y) = \underbrace{p + p + \dots + p}_{n개} = np$$

이는 매우 직관적입니다. 성공 확률이 30%인 시험을 10번 치른다면, 평균적으로 3번($10 \times 0.3$)의 성공을 기대하는 것과 같은 이치입니다.

### 2.3 분산의 합산: 왜 독립성이 중요한가?
분산은 평균과 다릅니다. 일반적으로 여러 변수의 합에 대한 분산은 단순히 각 분산의 합이 아닙니다. 두 변수 $X_1, X_2$에 대해 분산의 정의를 적용하면 다음과 같은 '공분산(Covariance)' 항이 등장하기 때문입니다.

$$Var(X_1 + X_2) = Var(X_1) + Var(X_2) + 2Cov(X_1, X_2)$$

하지만 다행히도, 이항분포를 구성하는 각 베르누이 시행은 **서로 독립**입니다. 독립인 경우, 두 변수가 서로에게 영향을 주지 않으므로 공분산은 정확히 0이 됩니다. 따라서 복잡한 항들은 모두 사라지고, 분산 또한 각 시행의 분산을 더하는 것으로 깔끔하게 정리됩니다.

$$Var(Y) = Var(X_1) + Var(X_2) + \dots + Var(X_n)$$
$$Var(Y) = \underbrace{p(1-p) + p(1-p) + \dots + p(1-p)}_{n개} = np(1-p)$$

`[시각화: 독립적인 사건이 더해질 때, 서로 연관성이 없어서 겹치는 영역(공분산)이 0이 됨을 보여주는 벤 다이어그램과 수식 강조 애니메이션]`

### 2.4 파이썬으로 검증하는 이론의 위력
수식으로 유도한 $np$와 $np(1-p)$가 실제 대규모 시행에서도 정확히 들어맞는지 확인해 봅시다.

```python
import numpy as np

n = 20        # 시행 횟수
p = 0.3       # 성공 확률
trials = 10000

# 이항분포 실험: n번 시행을 trials번 반복
samples = np.random.binomial(n, p, trials)

print(f"이론적 평균 (np): {n * p:.4f}")
print(f"시뮬레이션 평균: {np.mean(samples):.4f}")
print(f"이론적 분산 (np(1-p)): {n * p * (1 - p):.4f}")
print(f"시뮬레이션 분산: {np.var(samples):.4f}")
```

## 3. 요약

* **기댓값의 선형성:** 확률변수의 합에 대한 기댓값은 항상 각 변수 기댓값의 합과 같으며, 결과는 $np$가 됩니다.
* **독립성과 분산:** 변수들이 서로 독립일 때, 합의 분산은 각 분산의 합과 같습니다. 이 덕분에 이항분포의 분산은 $np(1-p)$라는 간결한 공식으로 귀결됩니다.
* **핵심 교훈:** 이항분포의 평균과 분산은 결국 '개별 베르누이 시행'들이 독립적으로 모여 만든 통계적 총합입니다. 수식은 복잡해 보이지만, 그 밑바닥에는 단순한 덧셈의 원리가 흐르고 있습니다.

이제 여러분은 단 하나의 사건(베르누이)부터 $n$번의 반복 사건(이항분포)까지, 확률의 가장 중요한 기초 공사를 마쳤습니다. 다음 장에서는 이 분포가 데이터의 세계에서 어떤 모양으로 나타나는지 시각적으로 확인해 보겠습니다.

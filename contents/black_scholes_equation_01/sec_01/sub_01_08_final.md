# 1.8 선형 결합 변수의 기댓값과 분산의 수학적 성질: 데이터 변환에 따른 중심과 퍼짐의 대칭적 질서

## 1. 도입: 변형되는 데이터와 변하지 않는 본질

지난 1.7절에서 우리는 독립적인 베르누이 세포들이 연대하여 '이항분포'라는 거대한 집단을 형성할 때, 그 평균이 $nq$로 선형 확장되고 분산이 $nq(1-q)$로 정갈하게 합산되는 대수적 필연성을 목격했습니다. 세포의 독립성이 보장될 때, 무작위성의 합은 놀라울 정도로 완벽한 규칙성을 띠며 통제되었습니다. 당시 우리는 성공 확률 $q=0.6$, 시행 횟수 $n=10$인 표준 시나리오를 설정하여, 전체 기댓값 $E[Y] = 6.0$, 전체 분산 $Var(Y) = 2.4$라는 선명한 결과값을 이끌어냈죠.

하지만 통계학과 금융 공학, 그리고 실제 데이터 분석의 세계에서 우리는 수집된 원본 데이터 $X$를 있는 그대로만 사용하지 않습니다. 목적에 따라 데이터를 특정 단위로 변환하거나(예: 섭씨온도를 화씨온도로 변환하는 $aX + b$), 서로 다른 단위를 가진 데이터를 공통의 평면 위에 올려놓기 위해 위치를 이동시키고 크기를 조정하는 작업을 끊임없이 수행합니다. 금융 시장에서도 개별 자산의 수익률에 투자 비중을 곱해 포트폴리오를 구성할 때 이와 동일한 대수적 변환이 일어납니다.

이를 수학적으로는 확률변수의 **'선형 결합(Linear Combination)'** 또는 **'선형 변환(Linear Transformation)'**이라고 부르며, 일반적으로 다음과 같이 정의합니다.

$$Y = aX + b \quad (\text{단, } a \text{와 } b \text{는 상수})$$

그렇다면 원본 데이터 $X$에 상수 $a$를 곱하고 $b$를 더할 때, 그 집단의 무게중심인 **기댓값($E[X]$)**과 불확실성의 척도인 **분산($Var(X)$)**은 구체적으로 어떤 물리적 규칙을 따르며 변화할까요? 이번 장에서는 추상적인 공식의 성급한 나열을 지양하고, 독자 여러분이 초등학교 시절부터 접해왔을 극도로 직관적인 수치 예시에서 출발하여, 이 변환 공식이 지닌 아름다운 대칭성과 대수적 필연성을 완벽히 규명해 내겠습니다.

## 2. 본론: 수치적 직관에서 대수적 일반화로

### 2.1 숫자의 변신으로 체감하는 기댓값과 분산의 변화
공식을 유도하기 전, 세 개의 간단한 숫자로 이루어진 가상의 데이터 집합을 가지고 직접 연산을 수행하며 규칙성을 발견해 봅시다. 

우리의 기초 확률변수 $X$가 다음과 같이 세 가지 상태를 가질 수 있으며, 각각의 상태가 발생할 확률은 $\frac{1}{3}$로 동일하다고 가정합니다.

$$X = \{1, 2, 3\}$$

이 원본 데이터의 평균(기댓값)과 편차, 그리고 분산을 먼저 정밀하게 계산해 두겠습니다.

*   **기댓값(평균) $E[X]$:** 
    $$E[X] = \frac{1 + 2 + 3}{3} = 2$$
*   **평균으로부터의 편차 ($X - E[X]$):** 
    $$1 - 2 = -1, \quad 2 - 2 = 0, \quad 3 - 2 = 1$$
*   **편차의 제곱:** 
    $$(-1)^2 = 1, \quad 0^2 = 0, \quad 1^2 = 1 \quad \rightarrow \text{편차 제곱의 합} = 2$$
*   **분산(편차 제곱의 평균) $Var(X)$:** 
    $$Var(X) = \frac{1 + 0 + 1}{3} = \frac{2}{3}$$

이 단단한 기준점을 바탕으로, 두 가지 변형 시나리오를 적용해 보겠습니다.

---

### [시나리오 A] 전체 데이터에 상수를 더하기 (평행이동: $X + b$)
데이터의 모든 값에 일괄적으로 $1$을 더해 새로운 변수 $Y = X + 1$을 만듭니다. 데이터는 $\{2, 3, 4\}$가 됩니다.

1.  **새로운 기댓값 $E[Y]$:**
    $$E[Y] = \frac{2 + 3 + 4}{3} = 3$$
    *   **발견:** 원본 평균인 $2$에 정확히 우리가 더해준 상수 $1$을 더한 값($2 + 1 = 3$)과 일치합니다.
2.  **새로운 편차 ($Y - E[Y]$):**
    $$2 - 3 = -1, \quad 3 - 3 = 0, \quad 4 - 3 = 1$$
3.  **새로운 편차 제곱의 합:**
    $$(-1)^2 + 0^2 + 1^2 = 2$$
4.  **새로운 분산 $Var(Y)$:**
    $$Var(Y) = \frac{2}{3}$$
    *   **발견:** 모든 데이터에 $1$을 더했음에도 불구하고, 분산은 원본 분산인 $\frac{2}{3}$에서 **단 0.001도 변하지 않고 그대로 유지**되었습니다.

### [시나리오 B] 전체 데이터에 상수를 곱하기 (배율 조정: $aX$)
이번에는 원본 데이터의 모든 값에 일괄적으로 $2$를 곱해 새로운 변수 $Z = 2X$를 만듭니다. 데이터는 $\{2, 4, 6\}$이 됩니다.

1.  **새로운 기댓값 $E[Z]$:**
    $$E[Z] = \frac{2 + 4 + 6}{3} = 4$$
    *   **발견:** 원본 평균인 $2$에 정확히 우리가 곱해준 배율 $2$를 곱한 값($2 \times 2 = 4$)과 일치합니다.
2.  **새로운 편차 ($Z - E[Z]$):**
    $$2 - 4 = -2, \quad 4 - 4 = 0, \quad 6 - 4 = 2$$
    *   **발견:** 평균으로부터 떨어진 거리(편차) 자체가 기존 $\{-1, 0, 1\}$에서 $\{-2, 0, 2\}$로 **정확히 2배** 넓어졌습니다.
3.  **새로운 편차 제곱의 합:**
    $$(-2)^2 + 0^2 + 2^2 = 4 + 0 + 4 = 8$$
    *   **발견:** 편차가 2배로 벌어짐에 따라, 이를 제곱한 값들의 합은 기존 $2$에서 $8$로 **정확히 4배($2^2$배)로 증폭**되었습니다.
4.  **새로운 분산 $Var(Z)$:**
    $$Var(Z) = \frac{8}{3}$$
    *   **발견:** 새로운 분산 $\frac{8}{3}$은 원본 분산 $\frac{2}{3}$에 비해 정확히 $4$배, 즉 **곱해준 상수인 $2$의 제곱($2^2 = 4$)배만큼 커졌음**을 정량적으로 확인할 수 있습니다.

| 변형 구분 | 대상 데이터 | 기댓값 (Mean) | 편차 제곱의 합 | 분산 (Variance) |
| :---: | :---: | :---: | :---: | :---: |
| **원본 데이터 $X$** | $\{1, 2, 3\}$ | $2$ | $2$ | $\frac{2}{3}$ |
| **평행이동 $X+1$** | $\{2, 3, 4\}$ | $3$ <br> (원본 $+ 1$) | $2$ <br> (변화 없음) | $\frac{2}{3}$ <br> (변화 없음) |
| **배율 조정 $2X$** | $\{2, 4, 6\}$ | $4$ <br> (원본 $\times 2$) | $8$ <br> (원본의 $2^2$배) | $\frac{8}{3}$ <br> (원본의 $2^2$배) |

이 간단한 수치 실험은 우리에게 매우 강력한 직관적 단서를 제공합니다. 
*   **더해진 상수 $b$**는 데이터 분포를 통째로 밀어 이동시킬 뿐이므로, 데이터들 사이의 조밀하거나 흩어진 정도(불확실성)를 측정하는 분산과는 아무런 관련이 없어 대수적으로 무시됩니다.
*   **곱해진 상수 $a$**는 편차 자체를 $a$배만큼 확장시키고, 분산은 편차의 '제곱'을 평균 내는 도구이므로 최종적으로 제곱 형태인 $a^2$이 되어 밖으로 탈출하게 됩니다.

### 2.2 대수적 엄밀성을 통한 일반 공식 유도
실험적 관찰을 마쳤으니, 이제 임의의 연속/이산 확률변수 $X$에 대해 $Y = aX + b$라는 선형 결합이 가해졌을 때 성립하는 일반식을 수학적으로 엄밀히 유도해 보겠습니다.

#### 1) 기댓값의 선형성 유도: $E[aX + b] = aE[X] + b$
이산확률변수의 정의를 사용하여 선형 변환된 변수의 기댓값을 전개합니다. 확률질량함수를 $P(X = x_i) = p_i$라고 두겠습니다.

$$E[aX + b] = \sum_{i} (a x_i + b) p_i$$

시그마($\sum$) 연산자의 분배 법칙을 사용하여 상수가 포함된 식을 각각 쪼개어 전개합니다.

$$E[aX + b] = \sum_{i} (a x_i p_i + b p_i) = \sum_{i} a x_i p_i + \sum_{i} b p_i$$

여기서 상수 $a$와 $b$는 시그마 연산 밖으로 자유롭게 빠져나갈 수 있습니다.

$$E[aX + b] = a \sum_{i} x_i p_i + b \sum_{i} p_i$$

이 식에 결합된 통계적 성질의 핵심 정의를 대입합니다.
*   $\sum_{i} x_i p_i$는 정확히 원본 변수 $X$의 기댓값인 $E[X]$의 정의입니다.
*   $\sum_{i} p_i$는 확률의 총합이므로 수학적 완결성에 의해 정확히 $1$이 됩니다.

따라서 다음과 같은 명쾌한 일반식이 증명됩니다.

$$E[aX + b] = aE[X] + b$$

기댓값은 상수배와 평행이동이라는 외부의 물리적 변형을 왜곡 없이 아주 정직하게 받아들여 반영하는 대수적 투명성을 가지고 있습니다.

---

#### 2) 분산의 변환 공식 유도: $Var(aX + b) = a^2 Var(X)$
이제 분산의 정의식에서 출발하여 상수의 거동을 추적해 봅시다. 분산의 본질은 '새로운 변수와 그 변수의 평균 간 편차 제곱의 기댓값'입니다.

$$Var(aX + b) = E\left[ \Big( (aX + b) - E[aX + b] \Big)^2 \right]$$

방금 유도한 기댓값의 선형성($E[aX+b] = aE[X]+b$)을 중괄호 내부의 식에 그대로 대입합니다.

$$Var(aX + b) = E\left[ \Big( aX + b - (aE[X] + b) \Big)^2 \right]$$

이 식을 정리하면 놀라운 소거 현상이 일어납니다.

$$Var(aX + b) = E\left[ \Big( aX + \cancel{b} - aE[X] - \cancel{b} \Big)^2 \right]$$
$$Var(aX + b) = E\left[ \Big( a(X - E[X]) \Big)^2 \right]$$

상수 $b$가 뺄셈에 의해 완벽하게 상쇄되어 사라졌습니다! 이는 앞서 우리가 수치 시나리오 $\{1, 2, 3\} \rightarrow \{2, 3, 4\}$에서 목격했던, **"평행이동은 데이터의 상대적 포지션(산포도)을 전혀 흐트러뜨리지 않는다"**는 물리적 사실이 대수적으로 완벽히 증명된 순간입니다.

이제 남아있는 제곱식을 전개합니다.

$$Var(aX + b) = E\left[ a^2 (X - E[X])^2 \right]$$

여기서 $a^2$ 역시 상수이므로 기댓값 연산자의 선형성에 의해 식 밖으로 완전히 탈출할 수 있습니다.

$$Var(aX + b) = a^2 E\left[ (X - E[X])^2 \right]$$

$E\left[ (X - E[X])^2 \right]$은 정확히 원본 확률변수 $X$의 분산 $Var(X)$의 정의식 그 자체입니다. 최종적으로 우리는 목적지에 도달합니다.

$$Var(aX + b) = a^2 Var(X)$$

제곱의 마법에 의해 배율 상수 $a$는 제곱되어 $a^2$의 형태로 분산에 영향을 미치게 됩니다.

### 2.3 대수적 변수들의 물리적 의미와 경제학적 해석
선형 결합 식 $Y = aX + b$에서 두 매개변수 $a$와 $b$는 금융 시장과 포트폴리오 이론에서 매우 강력한 물리적이고 경제학적인 의미를 갖습니다.

1. **상수 $b$의 경제학적 의미 (무위험 자산과 안전마진):**
   * 분산 변환식에서 $b$가 완전히 소거된다는 사실($Var(aX+b) = a^2 Var(X)$)은, 포트폴리오에 확실하게 고정된 수익(무위험 채권 이자 등)을 추가하더라도 **전체 자산의 불확실성(위험)은 단 1원도 늘어나지 않는다**는 것을 의미합니다. 
   * $b$는 분포의 중심축을 안전하게 우측으로 이동시키는 '안전마진'의 역할을 하며, 위험의 총량에는 아무런 기여를 하지 않습니다.

2. **배율 $a$의 경제학적 의미 (레버리지와 체계적 위험의 조절):**
   * $a$는 자산에 가하는 **'레버리지(Leverage, 차입 투자 비율)'** 혹은 포트폴리오 내 **'투자 비중(Weight)'**을 나타냅니다.
   * 만약 자본금의 2배($a=2$)로 레버리지 투자를 감행한다면, 기대 수익률은 정직하게 2배($2E[X]$)로 증가하지만, 감수해야 할 위험(분산)은 그의 제곱 배인 **4배($4Var(X)$)**로 폭발합니다. 
   * 이 $a$와 $a^2$의 대칭적 불균형 때문에 금융 시장에서 과도한 레버리지 투자는 파멸을 초래하는 위험한 도구로 분석됩니다.

### 2.4 파이썬 실습: 난수 변형을 통한 공식의 실증적 검증
우리가 수치 실험과 대수적 유도를 통해 정립한 이 강력한 규칙이, 무작위로 생성된 대규모 데이터 집합에서도 한 치의 오차 없이 작동하는지 파이썬 코드로 검증해 보겠습니다. 

앞서 1.7절에서 다룬 이항분포의 통계량(성공 확률 $q=0.6$, 시행 횟수 $n=10$)의 결과를 그대로 계승합니다. 당시 원본 이항 확률변수 $X$의 이론적 평균은 $6.0$, 분산은 $2.4$였습니다. 이 원본 데이터를 무작위 난수로 100,000개 생성한 뒤, 선형 변환 $Y = 3.5X + 12.0$을 적용하여 이론치와 표본 통계량이 정합적으로 수렴하는지 살펴보겠습니다.

```python
import numpy as np

def verify_linear_transformation(n, q, a, b, num_samples):
    """
    이항분포를 따르는 원본 데이터 X에 대해 선형 변환 Y = aX + b를 적용한 후,
    대수적 이론치와 실제 표본 통계량을 비교 검증합니다.
    """
    # 1. 1.7절의 표준 파라미터를 계승한 원본 데이터 X 생성 (n=10, q=0.6)
    X = np.random.binomial(n=n, p=q, size=num_samples)
    
    # 2. 선형 변환 적용: Y = aX + b (예: Y = 3.5X + 12.0)
    Y = a * X + b
    
    # 3. 원본 데이터 X의 표본 통계량 계산
    mean_X = np.mean(X)
    var_X = np.var(X)
    
    # 4. 선형 변환된 데이터 Y의 실제 표본 통계량 계산
    mean_Y_actual = np.mean(Y)
    var_Y_actual = np.var(Y)
    
    # 5. 우리가 도출한 공식을 적용한 대수적 이론치 계산
    mean_Y_theoretical = a * mean_X + b
    var_Y_theoretical = (a ** 2) * var_X
    
    # 결과 출력
    print(f"--- {num_samples:,}개의 표본을 통한 선형 변환 검증 (Y = {a}X + {b}) ---")
    print(f"원본 X의 표본 평균: {mean_X:.5f}, 표본 분산: {var_X:.5f}")
    print(f"변환 Y의 실제 평균: {mean_Y_actual:.5f} (이론치 a*E[X]+b: {mean_Y_theoretical:.5f})")
    print(f"변환 Y의 실제 분산: {var_Y_actual:.5f} (이론치 a^2*Var(X): {var_Y_theoretical:.5f})")
    
    # 오차 검증 (컴퓨터 수치 허용 범위 이내 검증)
    mean_match = np.isclose(mean_Y_actual, mean_Y_theoretical, atol=1e-5)
    var_match = np.isclose(var_Y_actual, var_Y_theoretical, atol=1e-5)
    print(f"선형 결합 평균 공식 일치 여부: {mean_match}")
    print(f"선형 결합 분산 공식 일치 여부: {var_match}")

# 파라미터 설정: n=10, q=0.6, 변환 식 Y = 3.5X + 12.0
verify_linear_transformation(n=10, q=0.6, a=3.5, b=12.0, num_samples=100000)
```

## 3. 통찰: 표준화(Standardization)라는 위대한 종착지를 향해

우리가 오늘 깊이 있게 탐구한 두 개의 공식 $E[aX + b] = aE[X] + b$와 $Var[aX + b] = a^2 Var(X)$는 단순히 대수적 호기심을 충족하기 위한 도구가 아닙니다. 이 성질은 통계학 역사상 가장 위대한 도구 중 하나인 **'표준화(Standardization)'** 프로세스를 지탱하는 완벽한 논리적 뼈대가 됩니다.

현실의 수많은 데이터는 각기 다른 단위(센티미터, 킬로그램, 원, 달러 등)와 서로 다른 스케일의 평균($\mu$), 분산($\sigma^2$)을 가지고 있어 직접적인 비교가 불가능합니다. 이때 우리는 모든 데이터를 **"평균이 0이고, 분산(및 표준편차)이 1인"** 공통의 만능 잣대 위로 가져가는 마법 같은 변환을 수행하는데, 이것이 바로 **Z-점수(Z-score) 변환**입니다.

Z-점수 변환 식은 다음과 같이 정의됩니다.

$$Z = \frac{X - \mu}{\sigma}$$

이 식을 오늘 배운 선형 결합의 형태($aX + b$)로 친숙하게 쪼개어 재작성해 보겠습니다.

$$Z = \left(\frac{1}{\sigma}\right)X - \left(\frac{\mu}{\sigma}\right)$$

즉, 이 표준화 변환은 원본 데이터에 배율 상수 $a = \frac{1}{\sigma}$을 곱하고, 이동 상수 $b = -\frac{\mu}{\sigma}$를 더해준 단순한 선형 변환에 불과합니다! 이제 우리가 정립한 두 대수 공식을 이 $a$와 $b$ 값에 그대로 대입해 보겠습니다.

### 1) 표준화된 변수 $Z$의 기댓값 계산
$$E[Z] = E\left[aX + b\right] = aE[X] + b$$
$$E[Z] = \left(\frac{1}{\sigma}\right) \cdot \mu + \left(-\frac{\mu}{\sigma}\right) = \frac{\mu}{\sigma} - \frac{\mu}{\sigma} = 0$$

원본 변수 $X$가 어떤 평균 $\mu$를 가지고 있었든 상관없이, 이 선형 변환을 거치고 나면 집단의 무게중심은 **언제나 예외 없이 정확히 '0'의 중심점**으로 평행이동하게 됩니다.

### 2) 표준화된 변수 $Z$의 분산 계산
$$Var(Z) = Var(aX + b) = a^2 Var(X)$$
$$Var(Z) = \left(\frac{1}{\sigma}\right)^2 \cdot \sigma^2 = \frac{1}{\sigma^2} \cdot \sigma^2 = 1$$

원본 변수의 흩어짐(분산 $\sigma^2$)이 얼마나 거대했거나 조밀했는지에 무관하게, 이 척도 변환을 거친 새로운 변수의 분산은 **항상 균일한 크기인 '1'로 표준화**됩니다.

이처럼 선형 결합의 수학적 성질을 이해하는 것은, 서로 다른 물리적 차원에 속해 있던 난잡한 데이터들을 단 하나의 표준화된 통계 평면 위로 정렬시켜 공정하게 비교 분석할 수 있게 만드는 강력한 열쇠가 됩니다.

## 4. 요약: 규칙이 부여하는 해석의 자유

*   **기댓값의 무조건적 수용:** 기댓값은 평행이동($+b$)과 배율 조정($\times a$) 등의 모든 선형 변화를 비 왜곡적으로 정직하게 반영합니다: $E[aX + b] = aE[X] + b$.
*   **분산의 평행이동 무관성:** 분산은 데이터 간의 상대적인 벌어짐을 측정하므로, 데이터 군집을 통째로 이동시키는 평행이동 상수 $b$의 영향을 전혀 받지 않습니다. 무위험 자산의 결합이 위험 총량에 아무런 영향을 주지 않는 것과 같은 원리입니다.
*   **분산의 제곱 팽창 법칙:** 분산은 편차의 제곱을 평균 내어 측정하므로, 데이터의 척도를 $a$배 늘리면 분산은 제곱인 $a^2$배만큼 폭발적으로 증가합니다: $Var(aX + b) = a^2 Var(X)$.
*   **통계적 도약:** 이 두 성질을 지능적으로 결합한 Z-변환($Z = \frac{X-\mu}{\sigma}$)을 통해, 우리는 임의의 분포를 가진 확률변수를 평균 0, 분산 1이라는 완벽히 정제된 표준 공간으로 유도할 수 있습니다.

우리는 이로써 단일 베르누이 시행에서 시작된 확률적 질서가 선형 결합이라는 변환 장치를 만나 어떻게 확장되고 보존되는지 그 대수적 항해를 완벽하게 마쳤습니다. 다음 장에서는 이 강력한 선형 결합의 성질과 표준화 도구를 한 손에 쥐고, 이항분포의 시행 횟수를 무한히 늘려 나갈 때 나타나는 인류 통계학의 위대한 왕관, **'정규분포(Normal Distribution)'**의 광활한 영토를 함께 밟아보도록 하겠습니다.

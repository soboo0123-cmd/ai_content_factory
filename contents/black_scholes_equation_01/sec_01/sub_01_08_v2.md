# 1.8 선형 결합 변수의 기댓값과 분산의 수학적 성질: 변화의 규칙을 찾아서

## 1. 도입: 데이터에 가해지는 변신 마법
앞서 우리는 이항분포라는 거대한 집단이 개별 베르누이 시행의 합으로 이루어짐을 보았습니다. 하지만 실제 현장에서 우리는 원본 데이터 $X$를 그대로 쓰기보다, 목적에 맞춰 수치를 변형하는 경우가 더 많습니다. 

예를 들어, 섭씨온도를 화씨로 바꾸거나($aX + b$), 시험 점수에 가중치를 두어 합산하는 상황이 그렇습니다. 이때 데이터의 평균과 분산은 어떻게 바뀔까요? 직관적으로는 "전체 데이터에 10점을 더하면 평균도 10점이 오르겠지"라고 쉽게 짐작할 수 있지만, 분산은 어떨까요? 수학적 연산이 데이터의 '중심'과 '퍼짐'에 미치는 규칙을 엄밀히 파헤쳐 보겠습니다.

---

## 2. 본론: 선형 변환의 수학적 메커니즘

### 2.1 기댓값의 선형성: 상수와 변수의 동거
기댓값 $E[aX + b]$는 말 그대로 $aX+b$라는 새로운 확률변수의 평균을 구하는 것입니다. 이는 데이터 전체를 $a$배만큼 키우고 $b$만큼 평행이동시킨 것과 같습니다.

$$E(aX + b) = \sum (ax_i + b)P(X = x_i)$$
시그마의 성질을 이용해 식을 분리하면:
$$E(aX + b) = a \sum x_i P(X = x_i) + b \sum P(X = x_i)$$

여기서 $\sum P(X = x_i) = 1$ (전체 확률의 합)이므로,
$$E(aX + b) = aE(X) + b$$
이것이 의미하는 바는 명확합니다. **기댓값은 평행이동(상수 $b$)과 상수배(상수 $a$)라는 외부의 변화를 그대로 수용하여 반영**합니다.

### 2.2 분산의 변환: 평행이동의 무관함과 제곱의 법칙
이제 분산을 살펴봅시다. 분산은 데이터가 평균으로부터 얼마나 떨어져 있는지를 측정하는 '거리의 개념'입니다.

$$Var(aX + b) = E[((aX + b) - E(aX + b))^2]$$
위에서 구한 $E(aX + b) = aE(X) + b$를 대입하면:
$$Var(aX + b) = E[(aX + b - aE(X) - b)^2] = E[(aX - aE(X))^2]$$

상수 $b$는 서로 상쇄되어 사라집니다. 이는 **데이터 전체를 평행이동시켜도 점들 사이의 상대적 거리는 변하지 않음**을 수학적으로 증명합니다. 이제 $a$를 밖으로 끄집어내면:
$$Var(aX + b) = E[a^2(X - E(X))^2] = a^2 E[(X - E(X))^2] = a^2 Var(X)$$

`[시각화: 데이터 분포 막대그래프 옆에 슬라이더 배치. 슬라이더로 $a$와 $b$ 값을 조절하면 막대그래프가 좌우로 평행이동($b$)하거나 좌우로 퍼지고 좁아지는($a$) 모습이 나타나며, 그에 따른 평균과 분산 값이 실시간으로 업데이트됨]`

---

## 3. 통찰: 표준화라는 종착지를 향해
우리가 오늘 학습한 이 단순해 보이는 두 공식, $E(aX + b) = aE(X) + b$와 $Var(aX + b) = a^2 Var(X)$는 통계학의 가장 강력한 도구인 **'표준화(Standardization)'**의 기반이 됩니다.

나중에 모든 확률분포를 평균 0, 분산 1로 만드는 과정(Z-score 변환)을 거칠 때, 우리는 $X$에서 평균을 빼고($b = -\mu$), 표준편차로 나누는($a = 1/\sigma$) 변환을 수행하게 됩니다. 이때 오늘 배운 공식들을 적용하면:
- 평균: $\frac{1}{\sigma}(E(X) - \mu) = \frac{1}{\sigma}(\mu - \mu) = 0$
- 분산: $(\frac{1}{\sigma})^2 Var(X) = \frac{1}{\sigma^2} \sigma^2 = 1$

이처럼 선형 결합의 성질을 이해하는 것은, 각기 다른 단위를 가진 데이터를 공통의 잣대 위에서 비교하기 위한 필수적인 수학적 문해력입니다.

---

## 4. 요약
1. **평균의 수용성**: 평균은 데이터의 변형(상수배, 평행이동)을 그대로 반영합니다. ($E(aX+b) = aE(X)+b$)
2. **분산의 선택적 반영**: 분산은 데이터 간의 상대적 거리를 의미하므로 평행이동($b$)의 영향을 받지 않습니다.
3. **제곱의 마법**: 데이터의 척도를 $a$배 늘리면 분산은 그 제곱인 $a^2$배만큼 커집니다.
4. **활용**: 이 규칙들은 향후 데이터를 표준화하여 서로 다른 분포를 동일선상에서 비교하는 핵심 논리가 됩니다.

# 1.5 이항분포의 대수적 일반화 및 확률 계산 공식 — 무한의 나무를 한 줄의 공식으로 요약하다

## 1. 도입: 거대한 숲을 하나의 세련된 수식으로 압축하기
지난 1.4절에서 우리는 2년($n=2$)이라는 짧은 시간 단계 동안 발생하는 자산 가격의 움직임을 확률 트리로 그려보았습니다. 상승 확률 $q=0.6$과 하락 확률 $1-q=0.4$가 지배하는 세상에서, 갈림길을 거치며 뻗어나간 4개의 미시적 경로가 조합(Combination, $_nC_j$)이라는 필터를 통해 최종 상태(상승 횟수 $j$)별로 정숙하게 병합되는 과정을 눈으로 직접 확인했습니다. 

하지만 만약 우리가 다루어야 하는 만기가 2년이 아니라 10년, 100년, 혹은 하루 단위로 쪼개진 1,000일이라면 어떨까요? 시간 단계가 조금만 늘어나도 확률 트리의 가지 수는 $2^{10}$, $2^{100}$, $2^{1000}$개로 폭발하여 기하급수적인 '시나리오의 숲'을 이루게 됩니다. 이를 일일이 손으로 그리고 계산하는 것은 물리적으로 불가능합니다.

이제 우리는 구체적인 나뭇가지를 그리는 작업을 멈추고, **문자(변수)를 사용하여 불확실성의 세계를 일반화**하는 대수적 도약에 나섭니다. 이것은 단순히 계산의 편의를 도모하는 것을 넘어, 무한히 뻗어나갈 수 있는 미래의 시나리오 지도를 단 한 줄의 정교한 '수식'으로 요약하는 과정입니다. 1.4절의 약속을 고스란히 계승하여, 조합의 마법이 어떻게 임의의 시간 단계 속에서 완벽한 확률 계산 공식으로 진화하는지 추적해 보겠습니다.

## 2. 본론: 구조적 분해와 대수적 공식의 수립

### 2.1 개별 경로의 확률 구조 분해: 수치적 패턴의 관찰
일반화 공식을 도출하기 전, 독자 여러분이 수식의 당위성을 직관적으로 납득할 수 있도록 시간 단계를 약간 확장한 $n=4$ 단계의 가상 시나리오를 설정해 보겠습니다. 상승 확률 $q=0.6$, 하락 확률 $1-q=0.4$인 상태에서, 결과적으로 **'상승 2회, 하락 2회 ($j=2$)'**라는 최종 결과를 만들어내는 경로들을 살펴보겠습니다.

곱셈의 교환법칙 덕분에, 어떤 순서로 상승과 하락이 발생했는지에 관계없이 상승이 2번, 하락이 2번 일어난 개별 경로의 확률은 항상 동일한 구조적 단위를 가집니다. 구체적인 수치 대입을 통해 다음의 나열을 체감해 봅시다.

| 구체적인 발생 경로 | 각 단계별 확률의 곱셈 구조 | 수치 연산 및 개별 경로 확률 |
| :--- | :--- | :--- |
| **경로 A:** $\uparrow, \uparrow, \downarrow, \downarrow$ | $q \times q \times (1-q) \times (1-q) = q^2 (1-q)^2$ | $0.6^2 \times 0.4^2 = 0.0576$ (5.76%) |
| **경로 B:** $\uparrow, \downarrow, \uparrow, \downarrow$ | $q \times (1-q) \times q \times (1-q) = q^2 (1-q)^2$ | $0.6^2 \times 0.4^2 = 0.0576$ (5.76%) |
| **경로 C:** $\downarrow, \downarrow, \uparrow, \uparrow$ | $(1-q) \times (1-q) \times q \times q = q^2 (1-q)^2$ | $0.6^2 \times 0.4^2 = 0.0576$ (5.76%) |

이처럼 임의의 단계 $n$에서 성공(상승) 횟수가 $j$번, 실패(하락) 횟수가 $n-j$번인 경로가 있다면, 그 경로가 어떤 순서로 배치되었든 무관하게 **'하나의 경로가 가질 확률'**은 대수적으로 언제나 다음의 단일한 수식으로 수렴합니다.

$$\text{개별 경로의 확률} = q^j \times (1-q)^{n-j}$$

`[시각화: n=4, j=2일 때 뻗어나가는 트리 다이어그램 중 위의 3가지 대표 경로가 하이라이트되며, 곱셈의 순서가 바뀌어도 종단에 도달할 때의 누적 확률은 0.0576으로 동일함을 연결선 애니메이션으로 시각화]`

### 2.2 이항계수(Binomial Coefficient): 동일 확률 경로들의 거대한 그릇
개별 경로의 가치가 동일하다면, 이제 우리가 던져야 할 핵심 질문은 다음과 같습니다.
**"전체 $n$번의 시행 중, 이 동일한 확률($q^j (1-q)^{n-j}$)을 공유하는 서로 다른 경로(순서)는 총 몇 개가 존재하는가?"**

이것은 결국 $n$개의 시간 단계라는 빈자리 중, 성공($\uparrow$)이 들어앉을 $j$개의 자리를 순서 없이 선택하는 문제와 완벽히 동치(Isomorphic)가 됩니다. 우리는 이 가짓수를 구하는 열쇠가 조합($\binom{n}{j}$ 혹은 $_nC_j$)임을 이미 알고 있습니다.

$$\binom{n}{j} = \frac{n!}{j!(n-j)!}$$

이항분포의 맥락에서 이 조합의 수는 **'이항계수(Binomial Coefficient)'**라는 아름다운 명칭을 부여받습니다. 이 계수는 단순한 가짓수를 세는 도구를 넘어, 확률 트리 속에 미시적으로 흩어져 있던 '역사적으로는 다르지만 최종 상태는 같은' 경로들을 하나의 거대한 바구니로 모아 묶어주는 **승수(Multiplier)**의 경제학적 역할을 완수합니다.

위의 $n=4, j=2$ 예시를 공식에 적용하면 다음과 같습니다.
$$\binom{4}{2} = \frac{4!}{2! \times 2!} = 6\text{가지}$$
즉, $0.0576$이라는 동일한 확률을 가진 독립적인 역사적 경로가 총 6개가 존재하므로, 우리가 구하고자 하는 최종 상태 $j=2$의 확률은 이 둘을 곱한 $6 \times 0.0576 = 0.3456$이 되는 것입니다.

### 2.3 이항분포의 확률질량함수(PMF) 수립과 시스템적 경계 조건
이상의 직관과 대수적 구조를 결합하여, 우리는 임의의 시행 횟수 $n$과 성공 횟수 $j$에 대해 성립하는 **이항분포의 확률질량함수(Probability Mass Function, PMF)**를 공식적으로 정의할 수 있습니다.

> **이항분포의 확률질량함수 (Probability Mass Function of Binomial Distribution)**
> $$P(X = j) = \binom{n}{j} q^j (1-q)^{n-j} \quad (\text{단, } j = 0, 1, 2, \dots, n)$$

이 한 줄의 공식은 완결성 있는 하나의 '확률계(Probability System)'로서 다음과 같은 굳건한 수학적 성질과 물리적 경계를 가지고 작동합니다.

1.  **변수의 범위 한계 ($0 \le j \le n$):** 성공 횟수 $j$는 전체 시행 횟수 $n$을 초과할 수 없으며, 음수가 될 수 없습니다. 이 당연해 보이는 범위 제한은 수학적 점화식이 현실의 시간 경계 내부에서 안전하게 닫혀 있도록 보장합니다.
2.  **개별 확률의 유계성 ($0 \le P(X=j) \le 1$):** 조합수 $\binom{n}{j}$가 양의 정수이고, $q$와 $1-q$가 모두 $[0, 1]$ 범위에 있으므로, 이들의 거듭제곱 곱으로 이루어진 확률값 역시 음수가 될 수 없으며 결코 1을 초과하지 않는 확률의 공리를 준수합니다.
3.  **체계의 닫힌 무결성 ($\sum P = 1$):** 모든 가능한 결과값 $j$에 대해 이 확률들을 전부 더하면, **이항정리(Binomial Theorem)**의 수학적 팽창에 의해 그 합이 단 0.0001의 누수도 없이 정확히 $1.0$으로 굳건히 수렴합니다.
    $$\sum_{j=0}^{n} \binom{n}{j} q^j (1-q)^{n-j} = \big(q + (1-q)\big)^n = (1.0)^n = 1.0$$

### 2.4 교차 검증: 이전 절(1.4)의 수치 시나리오 대입
우리가 수립한 대수적 일반 공식이 지닌 논리적 무결성을 검증하기 위해, 이전 1.4절에서 사용했던 구체적인 2기간 수치 시나리오($n=2, q=0.6$)를 이 공식에 그대로 다시 대입해 보겠습니다. 새로운 공식이 이전의 수작업 트리 계산과 정확히 일치하는지 확인하는 과정은 독자 여러분께 고도의 인지적 안정감을 줄 것입니다.

*   **상승 0회 ($j=0$):**
    $$P(X=0) = \binom{2}{0} (0.6)^0 (1-0.6)^{2-0} = 1 \times 1 \times 0.4^2 = 0.16 \quad (16\%)$$
*   **상승 1회 ($j=1$):**
    $$P(X=1) = \binom{2}{1} (0.6)^1 (1-0.6)^{2-1} = 2 \times 0.6 \times 0.4^1 = 0.48 \quad (48\%)$$
*   **상승 2회 ($j=2$):**
    $$P(X=2) = \binom{2}{2} (0.6)^2 (1-0.6)^{2-2} = 1 \times 0.36 \times 1 = 0.36 \quad (36\%)$$

이전 1.4절에서 경로들을 수작업으로 일일이 나열하여 더했던 값들($0.16, 0.48, 0.36$)과 완전히 일치하는 놀라운 정합성을 보여줍니다. 이로써 대수적인 한 줄의 수식이 수많은 복잡한 가지치기 과정을 완벽하게 대변하고 있음이 교차 검증을 통해 엄밀히 증명되었습니다.

## 3. 구현: 파이썬 코드로 확인하는 일반화의 위력과 시각적 조망
이제 컴퓨터의 강력한 연산력을 활용하여, 시행 횟수를 대규모로 확장했을 때의 이항분포 확률들을 신속하게 구하는 파이썬 코드를 작성해 보겠습니다. 10년($n=10$)의 시간 흐름 속에서 여전히 자산 상승 확률 $q=0.6$인 시장 환경을 가정하고 코드를 전개합니다.

```python
import math

def compute_generalized_binomial_pmf(n, q):
    """
    일반화된 이항분포 공식을 바탕으로 모든 j 상태의 확률을 계산합니다.
    """
    pmf_table = {}
    system_checksum = 0.0
    
    print(f"================ {n}단계 이항분포 일반화 연산 ================")
    print(f" 파라미터 조건: 전체 시행(n) = {n:2d}회 | 단일 성공확률(q) = {q:.2f}")
    print("-" * 62)
    
    for j in range(n + 1):
        # 1. 이항계수 (Combination) 계산
        n_choose_j = math.comb(n, j)
        
        # 2. 이항분포 일반 공식 대입
        probability = n_choose_j * (q ** j) * ((1 - q) ** (n - j))
        pmf_table[j] = probability
        system_checksum += probability
        
        # 3. 각 상태별 세부 데이터 출력
        print(f" 성공 횟수(j): {j:2d}회 | 이항계수: {n_choose_j:3d} | 발생 확률: {probability:.6f} ({probability*100:6.2f}%)")
        
    print("-" * 62)
    print(f" 시스템 총 확률 검증 합계 (System Checksum): {system_checksum:.10f}")
    
    # 0에 한없이 가까운 부동 소수점 정밀도 한계 내에서 완벽한 1.0 수렴 확인
    assert abs(system_checksum - 1.0) < 1e-12, "시스템 확률 누수 감지: 합계가 1이 아닙니다."
    print(" [검증 성공] 이항정리에 의거하여 총 확률이 1.0으로 단단히 닫혀 있습니다.")
    return pmf_table

# 10기간 이항분포 시뮬레이션 가동
binomial_10 = compute_generalized_binomial_pmf(n=10, q=0.6)
```

## 4. 요약
*   **대수적 압축의 미학:** 이항분포의 일반화 공식은 기하급수적으로 폭발하는 트리 모델의 무수한 경로들을 단 한 줄의 정교한 수학 수식인 $P(X = j) = \binom{n}{j} q^j (1-q)^{n-j}$로 깔끔하게 압축해 냅니다.
*   **이항계수의 본질적 재해석:** 조합수 $\binom{n}{j}$는 단순히 '뽑는 가짓수'를 뜻하는 대수학적 정의를 넘어, 확률 트리 안에서 '동일한 확률 거동을 가진 모든 개별 경로를 하나로 합산해 주는 필터이자 증폭기'의 입체적 역할을 수행합니다.
*   **정합성의 영속성:** 임의의 단계 $n$으로 대상을 일반화하더라도, 이항정리의 대수적 원리에 따라 분포 시스템 전체의 확률 합은 늘 오차 없이 정확히 $1.0$으로 보존되며, 이는 자산 평가 모형의 절대적인 보증 수표가 됩니다.

우리는 이로써 아무리 복잡한 미래의 이산적 갈림길이라도 하나의 수식으로 완전히 통제할 수 있게 되었습니다. 그렇다면 이산적인 시간 단계를 지나, 만약 우리가 사는 현실처럼 시간이 '연속적으로(Continuous)' 흘러가며 갈림길이 무한히 정교해질 때($n \to \infty$), 이항분포의 기하학적 형태는 어떤 경이로운 수학적 기적의 항구에 정박하게 될까요? 다음 장에서는 현대 금융공학의 심장인 연속 시간 모형과 정규분포로의 위대한 수렴 과정을 목격해 보겠습니다.

# 1.6 베르누이 시행과 평균/분산 정의: 단순함 속에 숨겨진 확률의 DNA

## 1. 도입: 복잡한 숲을 구성하는 가장 작은 단위
앞선 장에서 우리는 $n$번의 시행이라는 거대한 숲을 '조합'이라는 도구로 압축하는 법을 배웠습니다. 하지만 거대한 숲도 결국은 하나의 나무가 모여 이루어지듯, 모든 이항분포는 가장 원초적인 사건, 즉 **'베르누이 시행(Bernoulli Trial)'**이라는 단 하나의 씨앗에서 시작됩니다.

복잡한 계산을 수행하기 전에, 이 가장 작은 단위가 가진 고유한 성질인 '평균(기댓값)'과 '변동성(분산)'을 완벽히 이해해 봅시다. 이 기초 체력이 다져져야만 나중에 다룰 복잡한 통계적 추론도 흔들리지 않습니다.

---

## 2. 본론: 베르누이 확률변수의 세계

### 2.1 단 한 번의 결정: 베르누이 확률변수
베르누이 시행은 결과가 딱 둘뿐인 실험입니다. 성공 아니면 실패, 위 아니면 아래, 혹은 1 아니면 0. 우리는 이를 수학적으로 다루기 위해 **확률변수 $X$**를 다음과 같이 정의합니다.

- $X = 1$ (성공할 확률 $p$)
- $X = 0$ (실패할 확률 $1-p$)

`[시각화: 동전의 앞면(1)과 뒷면(0)을 나타내는 스위치 버튼. 클릭할 때마다 성공/실패가 기록되는 간단한 인터랙티브 요소]`

### 2.2 기댓값($E[X]$): 확률적 무게중심
평균은 우리가 이 실험을 무한히 반복했을 때 기대할 수 있는 값의 산술적 평균입니다. 직관적으로는 성공할 확률 $p$ 그 자체가 평균이 될 것 같지만, 수학적으로 증명하면 다음과 같습니다.

$$E(X) = (1 \times p) + (0 \times (1-p)) = p$$

즉, 베르누이 시행의 기댓값은 정확히 **성공 확률 $p$**와 같습니다. 이는 매우 강력한 직관을 제공합니다. 만약 성공 확률이 0.6이라면, 이 시행을 반복할수록 값의 평균은 0.6으로 수렴해 간다는 뜻입니다.

### 2.3 분산($Var(X)$): 불확실성의 크기
분산은 '평균에서 얼마나 떨어져 있는가'를 측정하는 불확실성의 척도입니다. 이를 구하기 위해서는 먼저 $X^2$의 기댓값을 알아야 합니다.

- $E(X^2) = (1^2 \times p) + (0^2 \times (1-p)) = p$
- $Var(X) = E(X^2) - (E(X))^2$

위 식에 우리가 구한 값들을 대입해 볼까요?
$$Var(X) = p - p^2 = p(1-p)$$

여기서 중요한 통찰을 얻을 수 있습니다. $p(1-p)$라는 식은 $p=0.5$일 때(성공과 실패가 반반일 때) 가장 커집니다. 즉, **결과를 예측하기 가장 힘들 때 분산(불확실성)은 최대가 된다**는 사실입니다.

## 3. 실습: 성공 확률에 따른 불확실성 시각화

성공 확률 $p$를 조절함에 따라 분산이 어떻게 변하는지 파이썬 코드로 확인해 봅시다.

```python
import matplotlib.pyplot as plt
import numpy as np

p_values = np.linspace(0, 1, 100)
variances = p_values * (1 - p_values)

plt.plot(p_values, variances)
plt.title("성공 확률 p에 따른 분산(불확실성) 변화")
plt.xlabel("성공 확률 (p)")
plt.ylabel("분산 Var(X)")
plt.grid(True)
plt.show()
```

## 4. 요약
1. **기초 단위**: 베르누이 시행은 모든 이항분포의 최소 단위로, $0$과 $1$이라는 두 가지 상태만 존재합니다.
2. **기댓값의 의미**: 단일 시행의 기댓값은 곧 성공 확률 $p$와 같습니다.
3. **분산의 통찰**: 분산 $p(1-p)$는 성공과 실패의 확률이 팽팽할수록(즉, $p=0.5$에 가까울수록) 최대가 되며, 이는 정보 이론에서 말하는 '엔트로피'와도 깊은 연관이 있습니다.

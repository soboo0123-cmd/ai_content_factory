# 5.7 근사 매개변수 대입을 통한 주가 분포의 연속 시간 모델링

## 도입: 이산적 계단에서 연속적 흐름으로의 도약

우리는 앞선 5.6절에서 이항 분포의 치우침(왜도)을 미세하게 교정하여 대칭성을 확보했습니다. 이제 준비물은 모두 갖춰졌습니다. 이제 이항 트리의 '가지'에 해당하는 상승 폭 $u$와 하락 폭 $d$에, 금융 공학의 핵심 상수인 변동성($\sigma$)과 시간 간격($\Delta t$)을 입혀보겠습니다. 

이 과정은 단순히 숫자를 대입하는 작업이 아닙니다. 계단식으로 띄엄띄엄 움직이던 주가의 도약을, 마치 촘촘한 실처럼 엮어 **기하 브라운 운동(GBM, Geometric Brownian Motion)**이라는 연속적인 궤적으로 변모시키는 '연결 작업'입니다.

---

## 본론: 매개변수의 물리적 정당성 확보

### 1. 왜 $u = e^{\sigma \sqrt{\Delta t}}$인가?
이항 트리에서 주가는 곱셈 형태로 변합니다. $n$번의 시행 후 주가 $S_n$은 초기 주가 $S_0$에 $u$와 $d$가 무작위로 곱해진 결과물입니다. 여기서 수학적으로 가장 아름다운 점은, 변동성 $\sigma$를 시간의 단위와 결합하는 방식입니다.

테일러 전개를 통해 주가의 로그 수익률을 살펴보면, 분산은 시간에 비례합니다. 즉, 변동성 $\sigma$를 갖는 주가가 $\Delta t$ 동안 움직일 때, 그 표준편차는 $\sigma \sqrt{\Delta t}$가 됩니다. 따라서 상승과 하락의 폭을 지수 함수로 설정하면 다음과 같은 통계적 정합성이 확보됩니다.

$$u = e^{\sigma \sqrt{\Delta t}}, \quad d = e^{-\sigma \sqrt{\Delta t}} = \frac{1}{u}$$

이 설정은 두 가지 강력한 이점을 제공합니다.
1. **역수 관계**: $u \cdot d = 1$이 되어, 상승 후 하락(혹은 그 반대) 시 주가가 원점으로 돌아오는 **재결합 트리(Recombining Tree)** 구조가 완성됩니다.
2. **로그 정규성**: 로그를 취하면 $\ln(S_t/S_0)$는 정규분포를 따르게 되며, 이는 블랙-숄즈 모델의 근간이 되는 '로그 정규분포'를 완벽히 모사합니다.

`[시각화: 대화형 그래프]
- 좌측: u, d 값을 결정하는 파라미터(σ, Δt) 조절 슬라이더
- 중앙: 이항 트리 구조를 층별로 시각화. 슬라이더 조절 시 가지가 뻗어나가는 각도가 변함.
- 우측: 트리의 마지막 층에 도달한 주가들의 분포를 히스토그램으로 출력. σ가 클수록 분포가 옆으로 퍼지고, Δt가 작아질수록 매끄러운 종 모양(정규분포)으로 변하는 과정 시각화.`

### 2. 연속 시간으로의 이행: $\Delta t \to 0$
이제 앞서 구한 확률 $p$와 방금 정의한 $u, d$를 조합하여 $n \to \infty$ 극한을 취하면, 이산적인 이항 모델은 비로소 미분 방정식의 세계로 진입합니다.

주가 변화의 기댓값과 분산이 연속 시간 모델인 기하 브라운 운동의 드리프트(drift) 항과 확산(diffusion) 항으로 귀결되는 과정을 관찰해 봅시다. 
- **드리프트**: 주가가 시간이 지남에 따라 우상향/우하향하는 평균적 추세.
- **확산**: 불확실성에 의해 주가가 퍼져나가는 정도(변동성).

이 대입 작업은 주가가 단순히 '오를까 내릴까'를 고민하던 수준에서, **"주가는 드리프트와 확산의 상호작용으로 움직이는 흐름이다"**라는 철학적 변화를 수용하는 과정입니다.

## 파이썬 실습: 기하 브라운 운동의 근사 구현

이항 트리가 극한에서 어떻게 로그 정규분포를 따라가는지, 매개변수 $u, d$를 대입하여 시뮬레이션해 봅니다.

```python
import numpy as np
import matplotlib.pyplot as plt

def simulate_gbm_via_binomial(S0, mu, sigma, T, n):
    dt = T / n
    u = np.exp(sigma * np.sqrt(dt))
    d = 1 / u
    p = 0.5 + 0.5 * (mu / sigma) * np.sqrt(dt)
    
    # 이항 분포 경로 시뮬레이션
    paths = np.zeros(n + 1)
    paths[0] = S0
    for i in range(1, n + 1):
        step = np.random.choice([u, d], p=[p, 1-p])
        paths[i] = paths[i-1] * step
    return paths

# 매개변수 설정
S0, mu, sigma, T, n = 100, 0.05, 0.2, 1, 1000
price_path = simulate_gbm_via_binomial(S0, mu, sigma, T, n)

plt.plot(price_path)
plt.title("이항 모델로 근사한 기하 브라운 운동")
plt.show()
```

## 요약: 핵심 포인트
1. **재결합의 미학**: $u = 1/d$로 설정함으로써 트리의 복잡도를 줄이고, 중심 집중적인 분포를 생성했습니다.
2. **물리적 정합성**: $\sqrt{\Delta t}$라는 시간 단위의 제곱근 스케일링은 변동성이 시간과 함께 전파되는 자연스러운 물리 법칙을 반영합니다.
3. **연속성의 확보**: 이산적인 $u, d$와 보정된 $p$를 결합하면, 시행 횟수 $n$이 늘어날수록 주가 모델은 블랙-숄즈 방정식이 가정하는 연속적인 경로인 기하 브라운 운동과 일치하게 됩니다.
4. **다음 단계로**: 이제 우리는 이항 트리를 넘어서, 주가의 연속적 변화를 다루는 미분 방정식 그 자체를 정의할 준비를 마쳤습니다. 다음 장에서는 이를 기술하는 언어인 '이토 미적분학'의 세계로 진입하겠습니다.

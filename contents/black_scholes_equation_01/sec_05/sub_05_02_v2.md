# 5.2 실제 확률 측도(Q-measure) 하 로그수익률의 기댓값과 분산식 유도

## 도입: 무작위성 속에서 '중심'과 '퍼짐'을 찾는 법
지난 절에서 우리는 금융의 언어를 이산 시간에서 연속 시간으로 옮기기 위한 '번역기'를 만들었습니다. 이제 그 번역기를 사용하기 전, 우리가 다루는 주가라는 자산이 가진 **‘평균적인 움직임(기댓값)’**과 **‘불확실성의 크기(분산)’**를 수학적으로 규정해야 합니다.

현실 세계의 주가는 멈춰있지 않습니다. 우리는 이를 확률적 분포로 이해해야 합니다. 이번 절에서는 이항 모델의 세계에서 주가가 한 단계 움직일 때, 그 수익률이 어떤 기댓값과 분산이라는 '질서'를 가지고 있는지 파헤쳐 보겠습니다.

---

## 본론: 확률 분포를 통한 로그수익률의 분석

### 1. 패턴의 관찰: 로그수익률의 확률적 정의
이항 모델에서 주가 $S_{t-1}$은 다음 단계에 $S_t = u \cdot S_{t-1}$ (상승) 또는 $S_t = d \cdot S_{t-1}$ (하락)이 됩니다. 이때 수익률을 단순히 가격의 비율로 보지 않고 로그($\ln$)를 취해 처리하는 이유는, 로그수익률이 시간의 흐름에 따라 **가산적(Addictive)** 성질을 가지기 때문입니다.

주가 로그수익률 $R = \ln(S_t / S_{t-1})$의 확률적 분포는 다음과 같습니다.
*   **상승할 때($u$)**: 로그수익률은 $\ln u$가 되며, 이때의 확률은 $q$입니다.
*   **하락할 때($d$)**: 로그수익률은 $\ln d$가 되며, 이때의 확률은 $1-q$입니다.

`[시각화: 확률 q와 1-q에 따라 두 개의 막대가 각각 ln(u)와 ln(d) 위치에 놓이는 확률질량함수(PMF) 그래프]`

### 2. 기댓값 ($\hat{\mu}$)의 유도: 수익률의 중심 잡기
확률변수의 기댓값은 각 사건이 발생할 확률과 그 값을 곱해 더한 값입니다. 따라서 로그수익률의 기댓값 $\hat{\mu}$은 다음과 같이 정의됩니다.

$$\hat{\mu} = E[R] = q \cdot (\ln u) + (1-q) \cdot (\ln d)$$

이 식은 "우리가 미래의 주가를 예측할 때, 확률적으로 가장 중심에 있는 로그수익률이 무엇인가?"를 대변합니다.

### 3. 분산 ($\hat{\sigma}^2$)의 유도: 변동성의 크기 측정
분산은 중심값($\hat{\mu}$)으로부터 데이터가 얼마나 퍼져 있는지를 측정합니다. 정의에 따라 $\text{Var}(R) = E[R^2] - (E[R])^2$를 이용합니다.

먼저 제곱의 기댓값 $E[R^2]$을 구합니다.
$$E[R^2] = q(\ln u)^2 + (1-q)(\ln d)^2$$

이제 분산 공식에 대입합니다.
$$\hat{\sigma}^2 = [q(\ln u)^2 + (1-q)(\ln d)^2] - [q \ln u + (1-q) \ln d]^2$$

이 식을 정리하면 매우 흥미로운 결과가 나옵니다. 공통 인수를 묶어내고 대수적으로 정리하면 다음과 같은 깔끔한 형태가 됩니다.

$$\hat{\sigma}^2 = q(1-q)[\ln(u/d)]^2$$

#### [직관적 해석]
위 식에서 가장 중요한 부분은 **$[\ln(u/d)]^2$**입니다. 여기서 $u/d$는 상승폭과 하락폭의 비(비대칭도)를 의미합니다. 즉, 주가가 한 번 움직일 때의 변동폭이 클수록 분산은 제곱으로 커진다는 점을 시사합니다.

### 4. 파이썬을 통한 분산 계산 실습
이론적 분산이 이항 구조 내에서 어떻게 계산되는지 코드로 확인해 봅니다.

```python
import numpy as np

def calculate_log_return_stats(u, d, q):
    """이항 모델에서 로그수익률의 기댓값과 분산 계산"""
    log_u = np.log(u)
    log_d = np.log(d)
    
    # 기댓값
    mu_hat = q * log_u + (1 - q) * log_d
    
    # 분산: q(1-q)[ln(u/d)]^2
    var_hat = q * (1 - q) * (np.log(u/d)**2)
    
    return mu_hat, var_hat

# 예시: u=1.1, d=0.9, q=0.5
mu, var = calculate_log_return_stats(1.1, 0.9, 0.5)
print(f"로그수익률 기댓값: {mu:.6f}, 분산: {var:.6f}")
```

## 요약: 핵심 포인트
1. **변환의 이유**: 주가 변화를 로그수익률로 변환하면 시간의 흐름에 따라 선형적인 합으로 계산이 가능해집니다.
2. **중심($\hat{\mu}$)**: 확률적 가중 평균을 통해 로그수익률의 기댓값을 도출하며, 이는 주가의 추세를 결정짓는 핵심 수치입니다.
3. **확산($\hat{\sigma}^2$)**: 분산은 확률 $q(1-q)$와 변동폭의 제곱의 곱으로 결정됩니다. 이는 우리가 앞으로 배울 옵션 가격 결정 모형의 '변동성' 매개변수의 기초가 됩니다.
4. **연결성**: 이 식들은 단순히 이항 모델에 머물지 않고, 나중에 연속 시간의 기하학적 브라운 운동(GBM) 파라미터인 드리프트($\mu$)와 변동성($\sigma$)으로 이어지는 중요한 징검다리입니다.

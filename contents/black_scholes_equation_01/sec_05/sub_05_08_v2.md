# 5.8 드무아브르-라플라스 정리 및 CLT 기반 표준정규분포 수렴성 검증

## 도입: 우연의 나열이 빚어내는 질서, 정규분포

이전 장에서 우리는 이항 트리의 격자를 촘촘하게 엮어 기하 브라운 운동이라는 연속적인 궤적을 만들었습니다. 하지만 여기서 한 가지 의문이 남습니다. "왜 하필 그 끝은 항상 종 모양의 정규분포인가?"입니다. 

금융 공학에서 블랙-숄즈 공식이 신뢰를 얻는 이유는 주가의 수익률이 정규분포를 따른다는 가정 덕분입니다. 오늘 우리가 다룰 **드무아브르-라플라스 정리(de Moivre-Laplace Theorem)**는 이산적인 동전 던지기(이항분포)가 어떻게 연속적인 곡선(정규분포)으로 변모하는지를 수학적으로 증명하는 마법 같은 연결 고리입니다. 이 정리는 단순한 통계 기법을 넘어, 왜 우리가 복잡한 파생상품 가격을 결정할 때 정규분포의 누적분포함수($N(z)$)를 사용하는지 그 근본적인 이유를 밝혀줍니다.

## 본론: 극한의 미학, 이항분포에서 정규분포로

### 1. 직관적 관찰: 패턴의 발견
먼저, 아주 단순한 시행을 떠올려 봅시다. 10번 동전을 던져 앞면이 나올 확률을 이항분포로 나열하면 11개의 막대기가 생깁니다. $n=100$, $n=1000$으로 횟수를 늘릴수록 이 막대기들은 점점 매끄러운 곡선 형태를 띠게 됩니다.

`[시각화: 대화형 분포 변화기]`
`- 상단 슬라이더: 시행 횟수 n을 10에서 500까지 조정.`
`- 그래프 영역: 이항분포 막대그래프 위에 정규분포 곡선이 겹쳐짐.`
`- 반응: n이 커질수록 막대기 상단이 정규분포 곡선과 일치해가는 과정을 시각적으로 확인.`

### 2. 드무아브르-라플라스 정리의 본질
드무아브르-라플라스 정리는 이항분포의 확률질량함수가 $n \to \infty$일 때, 표준정규분포의 확률밀도함수($\phi(x) = \frac{1}{\sqrt{2\pi}}e^{-x^2/2}$)로 수렴함을 보여줍니다. 

이항변수 $X \sim B(n, p)$에 대하여, 평균 $\mu = np$, 분산 $\sigma^2 = np(1-p)$일 때, 우리는 다음과 같은 **표준화(Standardization)** 과정을 거칩니다.

$$Z = \frac{X - np}{\sqrt{np(1-p)}}$$

중심극한정리(CLT)에 의해, 시행 횟수 $n$이 충분히 크다면 $Z$는 평균 0, 분산 1인 표준정규분포 $N(0, 1)$을 따르게 됩니다. 이는 주가 상승/하락이라는 불연속적인 사건들이 거듭될수록, 그 총합은 반드시 매끄러운 정규분포의 궤적을 밟을 수밖에 없음을 의미합니다.

### 3. 블랙-숄즈 공식과의 연결: $N(z)$의 탄생
블랙-숄즈 모델에서 우리가 자주 마주하는 $N(d_1)$과 $N(d_2)$는 무엇일까요? 이는 바로 이항 트리의 각 경로에서 '만기 시점에 옵션이 행사가격보다 높을(또는 낮을) 확률'을 적분한 값입니다. 

이산적인 트리 모델에서 특정 조건($S_T > K$)을 만족하는 경로의 수를 모두 합산하는 것은 사실 이항분포의 누적합 $\sum \binom{n}{j} p^j (1-p)^{n-j}$를 계산하는 것과 같습니다. 드무아브르-라플라스 정리는 이 복잡한 합산 과정을 $n \to \infty$의 극한에서 정규분포의 적분 형태인 $N(z)$로 치환할 수 있게 해줍니다. 즉, **"이항 트리에서의 경로 합산 = 정규분포의 면적 계산"**이라는 강력한 도구가 완성되는 것입니다.

## 파이썬 실습: 이항분포가 정규분포로 수렴하는 과정 확인

이 코드는 시행 횟수가 증가함에 따라 이항분포의 데이터가 어떻게 표준정규분포의 이론적 곡선에 가까워지는지 정량적으로 검증합니다.

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import binom, norm

n, p = 100, 0.5
x = np.arange(0, n+1)
# 이항분포 생성
binom_pmf = binom.pmf(x, n, p)

# 표준화된 확률변수 Z
z = (x - n*p) / np.sqrt(n*p*(1-p))

plt.bar(z, binom_pmf * np.sqrt(n*p*(1-p)), width=0.1, alpha=0.5, label='Binomial (Normalized)')
# 표준정규분포 밀도함수
plt.plot(np.linspace(-4, 4, 100), norm.pdf(np.linspace(-4, 4, 100)), 'r', label='Standard Normal PDF')
plt.title("드무아브르-라플라스 정리에 따른 수렴")
plt.legend()
plt.show()
```

## 요약: 핵심 포인트
1. **이산과 연속의 교량**: 드무아브르-라플라스 정리는 유한한 이항분포와 무한한 정규분포 사이의 수학적 가교 역할을 합니다.
2. **표준화의 힘**: 모든 확률 변수는 평균을 빼고 표준편차로 나누면 표준정규분포 $N(0, 1)$이라는 하나의 언어로 통일됩니다.
3. **블랙-숄즈의 기반**: 파생상품 가격 결정에서 나타나는 $N(z)$는 결국 수많은 이항적 선택들의 합이 수렴하여 만들어낸 정규분포의 누적된 영역입니다.
4. **다음 단계로**: 이제 우리는 이산적인 모델을 넘어, 주가의 무작위 운동을 미분 방정식으로 기술하는 '이토의 보조정리'와 '확률 미분 방정식'의 정점(Black-Scholes-Merton 모델)을 마주할 준비가 되었습니다.

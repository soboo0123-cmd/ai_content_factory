# 5.6 테일러 전개 분석에 따른 왜도 제로 확률 $p$의 수학적 근사

## 도입: 왜곡된 비대칭을 평형으로 되돌리는 기술
앞선 5.5절에서 우리는 이항 분포의 계단을 정규분포라는 매끄러운 경사면으로 변환했습니다. 하지만 여기서 한 가지 간과해서는 안 될 질문이 남습니다. "과연 이항 분포의 계단은 언제나 정규분포와 완벽하게 대칭인가?"라는 질문입니다.

실제 금융 시장에서 주가는 상승 확률 $p$와 하락 확률 $1-p$가 미세하게 다를 수 있으며, 이로 인해 이항 트리는 한쪽으로 기울어진 '왜도(Skewness)'를 갖게 됩니다. 만약 이 왜도를 방치한 채로 $n$을 무한히 키우면, 연속 시간 모형인 블랙-숄즈 세계와 미묘한 괴리가 발생합니다. 이번 절에서는 **테일러 전개(Taylor Expansion)**라는 수술용 메스를 사용하여, 분포의 기울기를 0으로 만드는 마법의 확률 $p$를 찾아내고, 이것이 어떻게 연속 시간의 균형점으로 수렴하는지 탐구합니다.

---

## 본론: 왜곡된 확률을 직선으로 다듬기

### 1. 비대칭의 근원: 왜도(Skewness)와 확률 $p$
이항 분포의 왜도는 확률 $p$가 $0.5$에서 멀어질수록 커집니다. 왜도가 0이라는 것은 분포가 좌우 대칭임을 의미하며, 이는 확률미분방정식으로 나아가기 위한 필수 조건입니다. 우리는 다음의 왜도 식을 기억할 필요가 있습니다.

$$\text{Skewness} = \frac{1-2p}{\sqrt{np(1-p)}}$$

여기서 $n \to \infty$로 갈 때 왜도를 0으로 만들기 위해서는 분자인 $(1-2p)$가 분모보다 훨씬 빠르게 0으로 접근해야 합니다. 즉, $p$는 고정된 값이 아니라 미소 시간 $\Delta t$의 함수로 진화해야 합니다.

### 2. 테일러 전개: 곡선을 직선으로 펴는 마법
테일러 전개는 복잡한 비선형 함수를 특정 지점에서 미분 계수를 이용하여 다항식으로 근사하는 방법입니다. 우리는 $p$를 $\Delta t$에 대한 함수로 보고, 0 근처에서 1차식으로 근사해 보겠습니다.

복잡한 수식 유도를 생략하고 핵심만 말하자면, 주가의 드리프트(Drift, $\mu$)와 변동성($\sigma$)이 반영된 위험 중립 확률 $p$는 다음과 같은 꼴을 가집니다.

$$p \approx \frac{1}{2} + \frac{1}{2} \left( \frac{\mu}{\sigma} \right) \sqrt{\Delta t}$$

이 식은 무엇을 의미할까요? 
- **$\frac{1}{2}$**: 왜도가 없는 기본 상태(대칭)입니다.
- **$\frac{1}{2} (\frac{\mu}{\sigma}) \sqrt{\Delta t}$**: 드리프트(기대 수익률)에 의해 발생하는 편향을 변동성으로 나누어 미세하게 교정하는 '보정항'입니다.

`[시각화: 대화형 슬라이더] 
- 슬라이더 1: μ(기대수익률) 값을 변경 
- 슬라이더 2: Δt(시간 간격) 값을 0에 가깝게 조절 
- 그래프: μ가 커질수록 확률 p가 0.5에서 서서히 멀어지는 모습과, Δt가 0에 가까워질수록 p가 다시 0.5로 수렴하며 정규분포의 왜도가 0으로 사라지는 과정을 애니메이션으로 시각화`

### 3. 왜 이 근사가 중요한가?
우리가 왜 테일러 전개를 1차식에서 멈췄을까요? 그것은 연속 시간(블랙-숄즈 세계)으로 넘어가는 순간, $\Delta t$가 0으로 수렴하기 때문입니다. 고차항($(\Delta t)^2$ 등)은 너무나 빨리 0이 되어 무의미해집니다. 오직 1차항만이 연속 시간에서도 살아남아 주가의 움직임을 결정하는 핵심적인 '방향성'을 제공합니다. 

이 보정된 확률 $p$를 사용하면, 이항 트리는 더 이상 치우친 계단이 아니라, 매 순간 균형을 맞추며 정규분포라는 질서 정연한 대칭의 세계로 진입하게 됩니다.

## 파이썬 실습: 왜도 제로 확률의 근사 효과 확인
확률 $p$를 고정하지 않고 위에서 유도한 근사식을 적용했을 때, 시행 횟수 $n$이 커짐에 따라 왜도가 어떻게 0으로 수렴하는지 확인합니다.

```python
import numpy as np

def calculate_skew(n, p):
    return (1 - 2*p) / np.sqrt(n * p * (1 - p))

mu, sigma = 0.05, 0.2
n_values = np.logspace(2, 6, 100) # 100에서 1,000,000까지
dt = 1 / n_values

# 근사 확률 p 계산
p_approx = 0.5 + 0.5 * (mu / sigma) * np.sqrt(dt)

skews = calculate_skew(n_values, p_approx)

# n이 커질수록 skews가 0에 수렴함을 확인
```

## 요약: 핵심 포인트
1. **왜도 제거의 필요성**: 연속 시간 모델로 가기 위해서는 이항 분포의 비대칭성(왜도)을 0으로 만들어야 합니다.
2. **테일러의 통찰**: 복잡한 확률 보정식을 테일러 1차 근사를 통해 $p \approx \frac{1}{2} + \frac{1}{2}(\frac{\mu}{\sigma})\sqrt{\Delta t}$라는 단순한 직선 관계로 치환했습니다.
3. **연속 시간의 균형**: 미소 시간 $\Delta t$가 작아질수록 이 근사식은 확률적 왜도를 상쇄하며, 주가 모델을 완벽한 대칭형 정규분포의 세계로 인도합니다.
4. **연결성**: 이제 왜도 문제를 완벽히 해결했습니다. 다음 장에서는 이 균형 잡힌 확률을 바탕으로, 시간과 가격의 변화를 다루는 강력한 도구인 '확률미분방정식(SDE)'의 토대를 쌓겠습니다.

# 5.6 p-측도 하 테일러 전개를 통한 왜도 제로 확률 p의 관찰과 탐색

## 1. 도입: 실제 확률 공간에서의 대칭성 탐색 [김주철 노트 / 내 노트_갈피끈]
많은 금융공학 서적들이 위험중립확률($q$) 공간에서의 수렴성만 다루고 실제 확률($p$) 공간에서의 성질은 생략하곤 합니다. 하지만 원고의 깊이를 더하기 위해, 우리는 시장의 위험 선호도가 반영된 '실제 확률 측도($p$-measure)' 하에서도 왜도가 소멸하며 정규분포로 안착하는지 규명해야 합니다. `[김주철 노트]`와 `[내 노트_갈피끈]`의 문제의식을 바탕으로, 시간 함수로 구성된 복잡한 비선형 실제 확률 $p$를 테일러 전개(Taylor Expansion)를 통해 현미경 다루듯 정밀하게 관찰하고 근사 구조식을 탐색해 보겠습니다.

---

## 2. 본론: 실제 확률 p의 테일러 전개와 구조적 형태 도출

### 2.1 실제 확률 공간에서의 확률 p의 정의
실제 시장의 주가 기대수익률(Drift)을 $\mu$라고 하고 변동성을 $\sigma$라고 할 때, 기간 세분화($\Delta t$)에 따른 실제 주가 상승 확률 $p$는 수학적으로 다음과 같은 비선형 방정식 구조를 만족해야 합니다.
$$p = \frac{e^{\mu \Delta t} - d}{u - d}$$
여기에 앞서 세운 연속 시간 보폭 $u = e^{\sigma \sqrt{\Delta t}}$와 $d = e^{-\sigma \sqrt{\Delta t}}$를 대입하여 실제 확률 $p$의 완전한 비선형 원형 식을 확보합니다.
$$p = \frac{e^{\mu \Delta t} - e^{-\sigma \sqrt{\Delta t}}}{e^{\sigma \sqrt{\Delta t}} - e^{-\sigma \sqrt{\Delta t}}}$$

### 2.2 테일러 전개를 통한 분모·분자 근사식 유도
$\Delta t \to 0$인 미소 시간 극한 상황에서의 거동을 보기 위해, 분모와 분자의 각 지수 함수들을 변수 $\Delta t$에 대해 테일러 전개(2차 항 이상 고차항 포함)를 수행합니다.
- **분자 영역**:
  $$e^{\mu \Delta t} = 1 + \mu \Delta t + O(\Delta t^2)$$
  $$e^{-\sigma \sqrt{\Delta t}} = 1 - \sigma \sqrt{\Delta t} + \frac{1}{2}\sigma^2 \Delta t - \frac{1}{6}\sigma^3 (\Delta t)^{3/2} + O(\Delta t^2)$$
  따라서 분자 = $e^{\mu \Delta t} - e^{-\sigma \sqrt{\Delta t}} = \sigma \sqrt{\Delta t} + \left(\mu - \frac{1}{2}\sigma^2\right)\Delta t + \frac{1}{6}\sigma^3 (\Delta t)^{3/2} + O(\Delta t^2)$

- **분모 영역**:
  $$e^{\sigma \sqrt{\Delta t}} = 1 + \sigma \sqrt{\Delta t} + \frac{1}{2}\sigma^2 \Delta t + \frac{1}{6}\sigma^3 (\Delta t)^{3/2} + O(\Delta t^2)$$
  따라서 분모 = $e^{\sigma \sqrt{\Delta t}} - e^{-\sigma \sqrt{\Delta t}} = 2\sigma \sqrt{\Delta t} + \frac{1}{3}\sigma^3 (\Delta t)^{3/2} + O(\Delta t^2)$

### 2.3 왜도 제로를 보장하는 확률 p의 근사 형태 관찰
유도된 분모와 분자의 테일러 근사식을 조합하여 실제 확률 $p$의 분수식을 정리하고, 최고차항 위주로 묶어냅니다.
$$p = \frac{\sigma \sqrt{\Delta t} + \left(\mu - \frac{1}{2}\sigma^2\right)\Delta t + \dots}{2\sigma \sqrt{\Delta t} + \dots}$$
양변을 $2\sigma \sqrt{\Delta t}$로 나누어 선형 근사(1차 스케일)를 마무리하면, 다음과 같은 매우 경이로운 최종 탐색 근사식을 얻게 됩니다.
$$p \approx \frac{1}{2} + \frac{1}{2}\left(\frac{\mu - \frac{1}{2}\sigma^2}{\sigma}\right)\sqrt{\Delta t}$$

이 식을 가만히 관찰해 보면, 무한 분할 격자 속에서 실제 확률 $p$ 역시 기본적으로 균형점인 **$\frac{1}{2}$에서 시작**하되, 시간의 제곱근($\sqrt{\Delta t}$) 스케일에 비례하는 미세 조정 항이 더해진 형태를 취하고 있습니다. 이 독특한 수학적 구조식 덕분에 분모의 무한대 발산 요인과 결합할 때 5.4절에서 보았던 왜도 소멸 메커니즘이 $p$-측도 공간에서도 동일하게 작동할 수 있는 결정적인 단서가 마련됩니다.

## 3. 시각화 가이드
```text
[시각화: 실제 확률 p의 비선형 곡선과 테일러 1차 근사 직선의 일치성 시뮬레이터]
- 화면 구성: 좌측(dt의 크기에 따른 p의 실제 곡선과 테일러 근사 직선의 오차 플롯), 우측(dt -> 0으로 갈 때 2차 고차항들이 완벽히 압착되어 사라지는 소거 애니메이션)
- 인터랙티브 요소: dt 슬라이더를 1년 단위에서 초 단위(0.00001)로 줄여감에 따라, 복잡했던 비선형 확률 곡선이 우리가 유도한 직선 공식 [1/2 + 1/2(...)√dt]에 완벽하게 일치(접선 수렴)하는 현상을 시각화하여 테일러 전개의 강력함을 증명.
```

4. 요약
[김주철 노트] 등의 문제의식에 따라 위험중립 공간을 넘어 실제 확률 측도($p$-measure) 하에서의 주가 분포 수렴성을 규명하기 위해 테일러 전개를 호출함.
실제 확률 $p$의 분모와 분자를 미소 시간 $\Delta t$에 대해 고차항까지 정밀 전개하여 수학적 근사 연산을 수행함.
최종 관찰 결과 실제 확률은 $p \approx \frac{1}{2} + \frac{1}{2}\left(\frac{\mu - \frac{1}{2}\sigma^2}{\sigma}\right)\sqrt{\Delta t}$ 구조를 가짐을 도출하였으며, 이는 왜도 소멸을 이끌어내는 핵심 동질성 뼈대가 됨.

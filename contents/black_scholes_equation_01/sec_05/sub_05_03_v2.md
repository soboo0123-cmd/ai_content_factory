# 5.3 기하급수적 기간 세분화에 따른 수익률 분포 분석

## 도입: 찰나의 조각들이 모여 만드는 거대한 흐름
앞선 절에서 우리는 단 한 번의 주가 움직임(이항 모델)이 가지는 기댓값과 분산을 확인했습니다. 하지만 현실의 주가는 1초에도 수없이 많은 미세한 움직임을 반복합니다. 우리가 관찰하는 주가는 듬성듬성한 이항 분포가 아니라, 마치 물 흐르듯 이어지는 연속적인 궤적입니다.

이번 절에서는 **'시간의 분할(Time Partitioning)'**이라는 돋보기를 꺼내 들 것입니다. 전체 투자 기간 $T$를 $n$개의 아주 짧은 구간 $\Delta t = T/n$으로 쪼갤 때, 이 조각들이 어떻게 쌓여 최종적인 수익률 분포를 만들어내는지, 그리고 $n$이 무한히 커질 때 우리의 모델이 어떤 마법 같은 변화를 겪는지 살펴봅니다.

---

## 본론: 시간의 잘게 쪼갬과 누적의 마법

### 1. 시간의 세분화와 파라미터의 변환
총 기간 $T$를 $n$개의 구간으로 나누면 각 구간의 시간 폭은 $\Delta t = T/n$이 됩니다. 이때, 미소 시간 동안 주가가 상승할 확률을 $p$, 하락할 확률을 $1-p$라고 할 때, 로그수익률의 변화량은 다음과 같이 조정됩니다.

*   **기댓값**: 한 구간의 기댓값을 $\mu \Delta t$라 정의합니다.
*   **분산**: 한 구간의 분산을 $\sigma^2 \Delta t$라 정의합니다.

여기서 중요한 것은 **'시간 비례성'**입니다. 전체 기간 $T$ 동안 일어나는 총 수익률은 $n$개의 짧은 구간에서 발생한 로그수익률들의 **합**입니다.

`[시각화: 하나의 긴 화살표(T)가 n개의 작은 막대(Δt)로 쪼개지는 애니메이션. 슬라이더를 통해 n값을 키울수록 막대의 개수가 늘어나며 전체 분포가 종 모양(정규분포)으로 다듬어지는 과정]`

### 2. 다기간 누적 분포의 기하학적 성향
로그수익률의 가장 큰 장점은 '덧셈'이 가능하다는 점입니다. 전체 기간 $T$의 총 로그수익률 $R_T$는 각 미소 구간의 수익률 $r_i$의 합으로 표현됩니다.

$$R_T = \sum_{i=1}^{n} r_i$$

중심극한정리(Central Limit Theorem)에 따르면, 독립적인 확률변수들의 합은 그 개수 $n$이 충분히 커질 때 **정규분포(Normal Distribution)**를 따르게 됩니다. 즉, 이항 모델이라는 투박한 도약들이 충분히 잘게 쪼개지면, 그 결과물은 매끄러운 '종 모양'의 곡선으로 수렴합니다.

### 3. 미소 구간에서 전체 구간으로의 확장
이제 $n$개의 구간에서 얻은 기댓값과 분산을 전체 기간 $T$로 확장해 봅시다.

1.  **전체 기댓값**: 각 구간의 기댓값이 $\mu \Delta t$이므로, $n$개를 더하면:
    $$E[R_T] = \sum_{i=1}^{n} E[r_i] = n \cdot (\mu \Delta t) = n \cdot \mu \cdot \frac{T}{n} = \mu T$$
2.  **전체 분산**: 분산 역시 시간의 흐름에 따라 누적됩니다.
    $$\text{Var}(R_T) = \sum_{i=1}^{n} \text{Var}(r_i) = n \cdot (\sigma^2 \Delta t) = n \cdot \sigma^2 \cdot \frac{T}{n} = \sigma^2 T$$

이 결과는 매우 직관적입니다. **"시간이 길어질수록 주가의 평균적 기대 수익과 변동성(불확실성)은 시간에 비례하여 증가한다"**는 금융공학의 기본 원리를 수학적으로 증명한 것입니다.

### 4. 파이썬 실습: 구간 분할에 따른 분포의 변화
구간 $n$을 늘릴수록 이산적인 분포가 어떻게 정규분포에 가까워지는지 시뮬레이션해 봅니다.

```python
import numpy as np
import matplotlib.pyplot as plt

def simulate_log_returns(T, n, mu, sigma):
    dt = T / n
    # 각 미소 구간의 수익률: 기댓값 mu*dt, 표준편차 sigma*sqrt(dt)
    r = np.random.normal(mu * dt, sigma * np.sqrt(dt), n)
    return np.sum(r)

# 시뮬레이션: n을 다르게 설정하여 분포 확인
T = 1.0
mu, sigma = 0.05, 0.2
results = [simulate_log_returns(T, 100, mu, sigma) for _ in range(10000)]

plt.hist(results, bins=50, density=True, alpha=0.6)
plt.title("n=100일 때의 누적 로그수익률 분포")
plt.show()
```

## 요약: 핵심 포인트
1. **시간의 비례성**: 로그수익률은 시간 구간 $\Delta t$에 따라 기댓값($\mu \Delta t$)과 분산($\sigma^2 \Delta t$)이 선형적으로 분할됩니다.
2. **연속성의 탄생**: 기간을 무한히 세분화($n \to \infty$)할수록, 이산적인 이항 모델의 도약은 매끄러운 연속 시간 모형인 기하학적 브라운 운동(GBM)으로 진화합니다.
3. **정규성으로의 수렴**: 중심극한정리에 의해, 잘게 쪼개진 미소 수익률들의 합은 결국 정규분포를 따르게 되며, 이는 현대 금융 자산 가격 결정 이론의 강력한 토대가 됩니다.
4. **결론**: 우리는 이제 단순한 '점프'를 넘어 '흐름'을 이해할 준비가 되었습니다. 다음 장에서는 이 흐름을 수식화한 블랙-숄즈 모형의 핵심, 즉 **확률미분방정식**에 대해 알아봅니다.

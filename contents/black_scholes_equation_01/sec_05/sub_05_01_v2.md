# 5.1 이산 시간 무위험이자율과 연속 시간 실효이자율 변환

## 도입: 금융 공학의 '언어'를 통일하는 법
금융 시장의 데이터는 종종 우리에게 서로 다른 언어로 말을 겁니다. 예금이나 대출은 "연 5% 이자"처럼 특정 시점마다 이자가 붙는 **이산 시간(Discrete time)** 언어를 사용하고, 옵션 가격 결정 모형(블랙-숄즈)은 "매 순간 이자가 쌓이는" **연속 시간(Continuous time)**이라는 유창한 수학적 언어를 사용합니다.

이 장의 목표는 이 두 언어 사이의 '번역기'를 만드는 것입니다. 이항 모델(Binomial Model)이라는 이산적인 사고방식에서 블랙-숄즈 모형이라는 연속적인 세계로 넘어가기 위해, 우리는 가장 먼저 화폐의 시간 가치를 표현하는 방식을 하나로 통일해야 합니다.

---

## 본론: 시간의 쪼개짐과 복리의 마법

### 1. 현상의 관찰: 1년 뒤의 1달러는 얼마일까?
이산 시간에서는 이자가 정해진 기간(주로 1년)마다 한 번씩 계산됩니다. 반면 연속 시간에서는 이자가 아주 짧은 단위로, 무한히 쪼개져서 계산됩니다.

*   **이산 모델의 관점**: 1년 뒤의 미래 가치는 $(1+r)$입니다. 
    `[시각화: 연 이자율 슬라이더를 움직여 1년 후의 총액이 (1+r)로 증가하는 것을 시각적으로 표현]`
*   **연속 모델의 관점**: 기간을 무한히 잘게 쪼개어 복리를 적용하면, 우리가 잘 아는 수학 상수 $e$가 등장합니다. $1달러가 연간 $r_{cont}$의 속도로 성장할 때, 1년 뒤의 가치는 $e^{r_{cont}}$가 됩니다.

### 2. 수학적 가교: $1 + r = e^{r_{cont}}$
두 모델이 1년 뒤에 동일한 미래 가치를 만들어낸다면, 우리는 다음과 같은 등식을 성립시킬 수 있습니다.

$$1 + r = e^{r_{cont}}$$

여기서 양변에 자연로그($\ln$)를 취하면, 우리가 구하고자 하는 연속 이자율 $r_{cont}$를 이산 이자율 $r$로 표현할 수 있습니다.

$$r_{cont} = \ln(1 + r)$$

#### [실습] 파이썬을 이용한 변환 코드
실제 금융 데이터 분석에서 이산 이자율을 연속 이자율로 변환하는 간단한 함수입니다.

```python
import numpy as np

def discrete_to_continuous(r_discrete):
    """이산 이자율을 연속 복리 이자율로 변환"""
    return np.log(1 + r_discrete)

# 예: 연 5% 이산 이자율의 연속 이자율 환산
r = 0.05
r_cont = discrete_to_continuous(r)
print(f"이산 이자율 {r*100}%는 연속 이자율로 약 {r_cont*100:.4f}%입니다.")
```

### 3. 왜 이 변환이 중요한가?
이 변환은 단순한 수학적 유희가 아닙니다. 
1. **블랙-숄즈로 가는 티켓**: 블랙-숄즈 모형은 주가의 움직임을 기하학적 브라운 운동(GBM)으로 가정합니다. 이 모델의 핵심 매개변수는 '연속적인 시간 흐름 속에서의 이자율'입니다.
2. **할인 요인의 통일**: $t$ 기간 후의 가치를 현재로 가져올 때, 이산 모델은 $(1+r)^{-t}$를 쓰지만, 연속 모델은 $e^{-r_{cont} t}$를 사용합니다. 변환 공식을 알고 있다면 어떤 모델을 만나도 당황하지 않고 할인할 수 있습니다.

`[시각화: 시간 t가 0에서 5까지 증가할 때, (1+r)^-t와 e^-r_cont * t 두 곡선이 완전히 겹쳐지는 것을 보여주는 그래프]`

## 요약: 핵심 포인트
1. **언어의 차이**: 이산 시간은 '끊어진 기간'을, 연속 시간은 '흐르는 시간'을 가정합니다.
2. **연결 고리**: 두 모델의 미래 가치를 일치시키는 지점은 $1 + r = e^{r_{cont}}$ 입니다.
3. **핵심 공식**: 이산 이자율 $r$을 연속 이자율로 바꾸려면 $r_{cont} = \ln(1 + r)$을 사용합니다.
4. **목적**: 이 기초 작업은 우리가 앞으로 배울 블랙-숄즈 모형을 이해하기 위한 필수적인 '수학적 징검다리' 역할을 합니다.

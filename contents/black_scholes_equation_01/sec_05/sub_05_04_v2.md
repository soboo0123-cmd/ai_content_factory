# 5.4 CRR 모형의 왜도(Skewness)와 정규분포 수렴 요건 분석

## 도입: 대칭의 균형이 깨질 때
앞선 5.3절에서 우리는 시간을 잘게 쪼개어 주가 움직임의 '흐름'을 만들어냈습니다. 그리고 그 흐름이 중심극한정리에 의해 정규분포라는 아름다운 종 모양으로 수렴하는 과정을 살펴보았습니다. 하지만 여기서 잠시 멈춰서 질문을 던져야 합니다. **"모든 잘게 쪼갠 분포가 항상 예쁜 정규분포로 수렴하는가?"**

현실의 주가 변동은 50:50의 확률로 완벽하게 대칭적이지 않습니다. 어떤 시장은 상승보다 하락에 더 민감하게 반응하며, 이런 비대칭성은 분포의 꼬리를 한쪽으로 쏠리게 만듭니다. 이번 절에서는 이항 모델(CRR 모형)의 **왜도(Skewness)**를 통해, 우리가 정규분포라는 이상향에 도달하기 위해 수학적으로 어떤 엄격한 조건들이 필요한지, 그리고 왜도가 존재할 때 모델에 어떤 그림자가 드리워지는지 분석합니다.

---

## 본론: 비대칭의 꼬리를 추적하다

### 1. 왜도란 무엇인가: 기울어진 무게중심
통계학에서 왜도는 분포가 얼마나 비대칭적인지를 나타내는 지표입니다. 
*   **왜도 = 0**: 좌우 대칭인 정규분포와 같은 상태.
*   **왜도 > 0**: 오른쪽 꼬리가 길게 늘어짐 (상승에 대한 기대가 강하거나 급등의 가능성).
*   **왜도 < 0**: 왼쪽 꼬리가 길게 늘어짐 (금융시장에서 흔히 보는 '폭락'의 위험성).

이항 분포에서 각 구간의 성공 확률을 $p$라고 할 때, 왜도는 다음 수식으로 표현됩니다.
$$\gamma = \frac{1-2p}{\sqrt{np(1-p)}}$$

이 식을 보면 핵심적인 통찰을 얻을 수 있습니다. 분자는 $1-2p$입니다. 즉, **$p=0.5$가 아닐 때 왜도는 0이 아닙니다.** 우리 모델이 정규분포로 완벽히 수렴하려면, $n$이 무한히 커질 때 이 왜도 값이 0으로 소멸해야만 합니다.

`[시각화: 왜도 슬라이더. 0에서 멀어질수록 히스토그램이 좌우로 기우뚱해지는 모습. p=0.5일 때 완벽한 대칭을 이루는 실시간 그래프 애니메이션]`

### 2. 정규분포 수렴의 보이지 않는 장벽
$n \to \infty$로 갈 때, 분모인 $\sqrt{np(1-p)}$는 무한히 커지지만, 분자인 $1-2p$는 고정되어 있습니다. 결과적으로 왜도는 0을 향해 달려갑니다. 이것이 바로 우리가 CRR 모형을 통해 블랙-숄즈 모형을 유도할 수 있는 **'수학적 안전장치'**입니다.

하지만 만약 시행 횟수 $n$이 충분히 크지 않거나, 아주 짧은 시간 동안 발생할 확률 $p$가 $0$이나 $1$에 극단적으로 가깝다면 어떤 일이 벌어질까요? 왜도는 0으로 수렴하지 못하고 '지속적인 왜곡'을 만들어냅니다. 이것이 바로 블랙-숄즈 모형이 실제 시장의 '두꺼운 꼬리(Fat tail)'나 '비대칭적 급락'을 완전히 설명하지 못하는 이유 중 하나입니다.

### 3. 왜도가 초래하는 모델의 왜곡
왜도가 0이 아니라는 것은 모델이 실제 시장보다 특정 방향으로 편향되어 있음을 의미합니다.

1.  **리스크 평가의 오류**: 왼쪽으로 치우친(음의 왜도) 자산의 경우, 정규분포를 가정하면 '블랙 스완'과 같은 대폭락의 확률을 실제보다 훨씬 낮게 과소평가하게 됩니다.
2.  **옵션 가격의 괴리**: 왜도가 존재하는 시장에서 정규분포 가정 기반의 블랙-숄즈 가격을 적용하면, 실제 시장 가격과의 차이인 **'변동성 스마일(Volatility Smile)'** 현상이 발생합니다.

## 파이썬 실습: 왜도 소멸 과정 확인하기
$n$이 커짐에 따라 이항 분포의 왜도가 어떻게 0으로 수렴하는지 확인해 봅시다.

```python
import numpy as np
from scipy.stats import skew

def calculate_binomial_skew(n, p):
    # 이항분포의 왜도 공식
    return (1 - 2*p) / np.sqrt(n * p * (1 - p))

n_values = [10, 100, 1000, 10000]
p = 0.45  # 50%가 아닌 비대칭 확률

for n in n_values:
    s = calculate_binomial_skew(n, p)
    print(f"시행 횟수 n={n:5d}일 때, 왜도(Skewness): {s:.4f}")
```

## 요약: 핵심 포인트
1. **왜도의 정의**: 왜도는 분포의 좌우 비대칭성을 의미하며, 정규분포가 되기 위한 필요조건은 왜도가 0이어야 한다는 점입니다.
2. **왜도의 소멸**: CRR 모형에서 $n \to \infty$로 갈 때, 시행 횟수가 늘어남에 따라 왜도는 $\sqrt{n}$의 속도로 빠르게 0에 수렴합니다.
3. **한계점의 이해**: 실제 시장은 왜도가 완전히 소멸하지 않는 경우가 많습니다. $p \neq 0.5$인 상황에서의 왜곡을 이해하는 것은, 단순한 수학적 수렴을 넘어 시장의 위험(꼬리 위험)을 관리하는 첫걸음입니다.
4. **다음 단계**: 이제 우리는 대칭적인 정규분포의 세계와 비대칭적인 현실의 간극을 이해했습니다. 다음 장에서는 이를 극복하기 위해 블랙-숄즈 모형이 어떻게 시간과 공간을 미분하여 정의하는지, 그 수학적 정점인 **확률미분방정식(SDE)**의 세계로 들어갑니다.

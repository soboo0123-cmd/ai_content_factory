# 5.5 이산 변수의 연속 표준화 변수 표현 및 p-측도 연결성

## 도입: 이산적 계단에서 연속적 곡선으로
우리는 앞서 5.4절을 통해 이항 분포가 대칭을 이루며 정규분포로 다가가는 과정을 살펴보았습니다. 하지만 수학적으로 명확히 짚고 넘어가야 할 지점이 있습니다. 이항 분포는 $j$라는 정수(0, 1, 2, ..., $n$)를 가지는 '계단식' 분포이지만, 우리가 도달하려는 블랙-숄즈 모형의 세계는 매끄러운 '연속형' 함수입니다. 

어떻게 하면 이 뚝뚝 끊어진 이산적인 점들을 하나의 매끄러운 곡선 위로 불러올 수 있을까요? 그 비밀은 통계학의 가장 강력한 도구인 **'표준화(Standardization)'**에 있습니다. 이번 절에서는 이산 변수 $j$가 표준 정규분포 변수 $Z$로 변모하는 과정을 추적하고, 이것이 어떻게 블랙-숄즈의 핵심인 $N(d_1), N(d_2)$로 연결되는지 그 가교를 구축합니다.

---

## 본론: 확률의 좌표를 표준화하다

### 1. 표준화의 마법: 척도의 파괴와 재구성
이항 분포에서 주가가 $j$번 상승할 확률은 다음의 이항 확률 질량 함수(PMF)로 정의됩니다.
$$P(X=j) = \binom{n}{j} p^j (1-p)^{n-j}$$

여기서 $j$는 단순히 '상승 횟수'라는 국소적인 정보를 담고 있습니다. 하지만 우리가 원하는 것은 $n$이 무한히 커질 때 이 분포가 어떤 형태를 띠는지입니다. 이를 위해 우리는 변수 $j$를 중심화하고 척도를 맞추는 **표준화 변환**을 수행합니다.

$$Z_n = \frac{j - E[j]}{\sqrt{Var(j)}} = \frac{j - np}{\sqrt{np(1-p)}}$$

이 변환을 적용하면, $j$의 위치에 상관없이 모든 이항 분포는 평균 0, 분산 1을 갖는 표준적인 틀 안으로 들어오게 됩니다. 이는 마치 서로 다른 크기의 도형들을 동일한 비율의 격자판 위로 옮겨놓는 작업과 같습니다.

`[시각화: 히스토그램의 변환 애니메이션. x축이 j인 막대 그래프가 슬라이더 조작에 따라 x축이 (j-np)/σ인 표준 정규분포 곡선 아래로 정확히 겹쳐지는 과정 시각화]`

### 2. $p$-측도의 의미와 연결성
여기서 중요한 것은 확률 변수 $j$ 자체가 아니라, $j$가 나타날 확률을 정의하는 **$p$-측도(Probability Measure)**입니다. 블랙-숄즈 모형의 세계에서는 위험 중립 확률 $q$를 사용하는데, 이 $q$는 우리가 앞서 다룬 이항 분포의 $p$와 본질적으로 같은 역할을 합니다.

이항 분포에서 확률 질량함수를 표준화된 변수 $Z$에 대해 정리하면, $n$이 커짐에 따라 다음과 같은 근사식이 도출됩니다.
$$\binom{n}{j} p^j (1-p)^{n-j} \approx \frac{1}{\sqrt{2\pi}} e^{-\frac{Z^2}{2}} \Delta Z$$

이 식의 우변은 바로 **표준 정규분포의 밀도함수**입니다. 즉, 이산적인 덧셈(이항 계수)이 극한으로 가면 연속적인 적분(정규분포)으로 변모한다는 것을 증명하는 순간입니다.

### 3. $N(d_1)$과 $N(d_2)$: 블랙-숄즈의 탄생
이제 이 표준화 과정이 왜 중요한지 밝혀집니다. 옵션 가격을 결정하는 블랙-숄즈 공식에서 등장하는 누적분포함수 $N(d)$는 바로 이 표준화된 이항 확률들의 총합입니다.

*   **$N(d_2)$**: 만기 시점에 옵션이 행사될 확률(In-the-money일 확률)을 이항 분포의 합으로 표현한 뒤, $n \to \infty$ 극한을 취해 표준 정규분포의 적분 형태로 바꾼 값입니다.
*   **$N(d_1)$**: 주가 변화에 따른 '기대값'을 조정하는 항으로, 표준화된 변수 공간에서 자산의 미래 가치를 할인하여 평가할 때 필요한 가중치입니다.

결국, 블랙-숄즈 수식은 **"이산적인 주가 움직임($j$)을 표준화($Z$)하여 연속적인 확률 적분($N(d)$)으로 치환한 결과물"**입니다.

## 파이썬 실습: 표준화된 이항 분포의 수렴성
이산 변수 $j$를 표준화하여 정규분포 곡선에 얼마나 잘 부합하는지 시각적으로 확인해 봅시다.

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import norm, binom

n, p = 100, 0.5
j = np.arange(0, n+1)
# 표준화된 변수 Z 계산
z = (j - n*p) / np.sqrt(n*p*(1-p))
probs = binom.pmf(j, n, p)

plt.bar(z, probs * np.sqrt(n*p*(1-p)), alpha=0.5, label='Standardized Binomial')
plt.plot(np.linspace(-3, 3, 100), norm.pdf(np.linspace(-3, 3, 100)), color='red', label='Normal PDF')
plt.title("이산 변수의 표준화 및 연속 수렴")
plt.legend()
plt.show()
```

## 요약: 핵심 포인트
1. **표준화의 역할**: 이산적인 $j$를 $Z$로 변환함으로써, 시행 횟수 $n$에 관계없이 모든 분포를 하나의 표준적인 틀(평균 0, 분산 1)로 통합합니다.
2. **연속으로의 도약**: $n \to \infty$일 때, 이항 계수의 촘촘한 배열은 정규분포의 종 모양 곡선으로 매끄럽게 연결됩니다.
3. **블랙-숄즈의 기초**: 우리가 공식에서 보는 $N(d_1)$과 $N(d_2)$는 이산적인 확률의 합을 표준 정규분포의 누적 면적으로 치환하여, 옵션의 내재 가치를 계산하기 쉽게 만든 '연속적 통계 데이터'입니다.
4. **연결성**: 이제 우리는 주가 모델의 이산적 근원(CRR 모형)과 연속적 종착지(블랙-숄즈)를 표준화라는 다리로 완전히 이었습니다. 다음 장에서는 이를 바탕으로 확률미분방정식을 구축할 준비가 되었습니다.

# 4.2 자본비용법(Cost of Capital, CoC)의 실무적 적용

## 1. 도입: 잠긴 자본의 가격표와 위험조정(RA)의 탄생

직전 절(4.1절)에서 우리는 극단적인 위기 상황(99.5% 신뢰수준)에서도 보험회사를 파산시키지 않고 유지하기 위해 필요한 **‘요구 자본(Capital Requirement)’**을 산출했습니다. 암보험(상품 A)의 경우 약 12.88억 원, 재난보험(상품 B)의 경우 실제 두꺼운 꼬리(Fat-tail) 충격을 반영하여 120.01억 원이라는 거대한 자본 버퍼가 필요함을 확인했습니다.

그러나 여기서 매우 중대한 경영적 질문이 발생합니다. **"이 거대한 요구 자본은 공짜로 유지할 수 있는가?"**

답은 당연히 "아니다"입니다. 지급여력을 확보하기 위해 내부에 묶어두어야 하는 자본은 주주(Shareholder)가 제공한 자금입니다. 주주는 이 돈을 다른 위험 자산에 투자하여 수익을 올릴 수 있었음에도 불구하고, 보험회사의 파산 방지를 위해 자본을 묶어두는 기회비용을 부담하고 있습니다. 따라서 주주는 이 '잠긴 자본(Locked-up Capital)'에 대해 상응하는 최소한의 주주 요구수익률(자본비용률)을 요구합니다.

본 절에서는 다음 학습 목표를 달성하고자 합니다:
1. 요구 자본을 기회비용 관점에서 가치평가하는 **자본비용법(Cost of Capital, CoC)**의 경제적 메커니즘을 이해합니다.
2. IFRS 17(K-IFRS 제1117호) 및 K-ICS 감독기준에 따른 **위험조정(Risk Adjustment, RA)** 공식을 유도하고 대수적으로 분해합니다.
3. 동일한 요구 자본 하에서 사업의 비즈니스 타당성을 결정짓는 **임계 한계 자본비용률($CoC_{\text{BEP}}$)**을 도출하고, 파이썬(Python) 시뮬레이션으로 실무적 의사결정 체계를 구축합니다.

## 2. 본론

### 2.1 자본비용법(CoC)의 원리와 경제적 메커니즘

보험계약을 체결할 때, 보험회사는 미래에 발생할 기대 현금유출액인 **최적추정부채(BEL)**에 더해, 미래 현금흐름의 불확실성에 대한 대가인 **위험조정(Risk Adjustment, RA)**을 부채로 추가 적립해야 합니다.

자본비용법(CoC)은 위험조정(RA)의 크기를 산출할 때 **"비금융 위험을 방어하기 위해 만기까지 유보해야 하는 자본의 기회비용 총합"**으로 정의합니다. 즉, 자본이 금고 안에 묶여 있음으로 인해 발생하는 주주의 기회손실을 부채의 가치로 환산하여 적립하는 메커니즘입니다.

#### 구체적 수치 시나리오: 4.1절 포트폴리오 자본의 연간 보유 비용 대조

직전 4.1절의 10,000건 포트폴리오 시나리오(기대 현금유출 $FCF_{\text{Mean}} = 100\text{억 원}$)에서 산출된 요구 자본에 주주 요구수익률($r_{\text{CoC}}$)을 단계별로 적용했을 때 발생하는 연간 자본 보유 비용을 나열해 보겠습니다.

| 구분 | 상품 A (암보험) | 상품 B (재난보험 - 정규가정) | 상품 B (재난보험 - Fat-tail) |
| :--- | :---: | :---: | :---: |
| **현금흐름 표준편차 ($\sigma$)** | 5.0억 원 | 35.0억 원 | 35.0억 원 |
| **99.5% 요구 자본 ($\text{Capital} = z_\alpha \cdot \sigma$)** | **12.88억 원** | **90.16억 원** | **120.01억 원** |
| **자본비용률 $r_{\text{CoC}} = 4\%$ 시 보유 비용** | 0.52억 원 | 3.61억 원 | 4.80억 원 |
| **자본비용률 $r_{\text{CoC}} = 6\%$ 시 보유 비용 (표준)** | **0.77억 원** | **5.41억 원** | **7.20억 원** |
| **자본비용률 $r_{\text{CoC}} = 8\%$ 시 보유 비용** | 1.03억 원 | 7.21억 원 | 9.60억 원 |

[시각화: 자본비용률(CoC Rate) 변동에 따른 상품 A와 상품 B의 위험조정(RA) 금액 증가 슬라이더 시각화]

위 표에서 보듯, 자본비용률이 $6\%$일 때 상품 A를 유지하기 위한 연간 기회비용(RA)은 **0.77억 원**에 불과하지만, 꼬리가 두꺼운 위험을 가진 상품 B는 동일한 기대 현금유출(100억 원)을 가짐에도 자본 보유 비용(RA)이 **7.20억 원으로 9.3배 폭발**합니다.

### 2.2 IFRS 17 / K-ICS 관점의 RA 산출 수식 유도

단일 시점(1년) 보유 가정을 바탕으로 IFRS 17의 위험조정($RA$) 공식을 유도해 보겠습니다.

#### (1) 기본 공식의 유도
위험조정($RA$)은 4.1절에서 구한 위험 자본(Capital)에 주주 자본비용률($r_{\text{CoC}}$)을 곱하여 정의됩니다.

$$RA = \text{Capital} \times r_{\text{CoC}}$$

여기서 4.1절의 $VaR$ 기반 요구 자본 공식 $\text{Capital} = FCF_{\text{VaR}_{1-\alpha}} - FCF_{\text{Mean}} = z_{\alpha} \cdot \sigma$를 대입합니다.

$$RA = (z_{\alpha} \cdot \sigma) \times r_{\text{CoC}}$$

이 수식은 추상적인 위험 부채가 **[변동성 규모 ($\sigma$)] $\times$ [위기 충격 승수 ($z_\alpha$)] $\times$ [주주 기회비용률 ($r_{\text{CoC}}$)]**라는 세 가지 동적 요소의 곱으로 완벽히 소거·분해됨을 보여줍니다.

#### (2) 다기간(Multi-period) 확장 구조
현실의 보험계약은 만기가 다년간 유지됩니다. $t$ 시점의 잔존 요구 자본을 $\text{Capital}_t$, 평가시점의 무위험 할인율을 $r_f$라 할 때, 계약 전체 기간 동안의 총 $RA$는 각 연도별 자본비용의 현재가치 합으로 확산됩니다.

$$RA_0 = \sum_{t=1}^{T} \frac{\text{Capital}_{t-1} \times r_{\text{CoC}}}{(1 + r_f)^t}$$

> **[회계 및 감독기준 참고 (K-IFRS 및 K-ICS)]**
> K-IFRS 제1117호(보험계약)에서는 위험조정(RA)의 산출 방법론으로 신뢰수준법(Confidence Level Approach)과 자본비용법(Cost of Capital Approach)을 모두 허용합니다. 한국형 지급여력제도(K-ICS)에서는 감독 목적상 자본비용률($r_{\text{CoC}}$)을 공식 규정(예: 연 6.0%)으로 지정하여 제3자 검증 가능성과 단일화된 비교 가능성을 확보하고 있습니다.

### 2.3 실패 사례 vs 성공 사례: 고정 비율 가산의 함정과 임계 한계 자본비용률($CoC_{\text{BEP}}$)

상품의 위험 특성을 무시하고 손실 버퍼를 일률적으로 적용하는 정적 방식은 정밀한 회계·재무적 관점에서 큰 실패를 초래합니다.

#### [실패 사례 vs 성공 사례 대조]

* **실패 사례 (단순 비율 가산 방식 적용 시):**
  * 위험 특성과 무관하게 최적추정 현금유출($FCF_{\text{Mean}} = 100\text{억}$)의 $3\%$를 일률적 RA로 가산 ($RA_{\text{flat}} = 3.0\text{억 원}$)
  * **결과:**
    * **상품 A (암보험):** 실제 필요한 CoC 비용은 $0.77\text{억}$인데 $3.0\text{억}$의 과도한 부채가 적립되어 **가격 경쟁력 상실 및 영업 실패**.
    * **상품 B (재난보험):** 실제 필요한 CoC 비용은 $7.20\text{억}$인데 $3.0\text{억}$만 적립되어 **위험 자본 비용 $4.20\text{억 원}$ 누락 및 주주 가치 심각하게 훼손**.
* **성공 사례 (CoC 기반 동적 RA 적용 시):**
  * 포트폴리오의 실제 변동성($\sigma$)과 꼬리 두께를 반영한 정밀 자본비용 산출 ($RA_A = 0.77\text{억}$, $RA_B = 7.20\text{억}$)
  * **결과:** 상품 A의 언더라이팅 경쟁력 확보 및 상품 B의 위험 보상 부가(Risk-adjusted Pricing) 완수.

#### 임계 한계 자본비용률 ($r_{\text{CoC, BEP}}$) 도출
상품 인수를 통해 얻을 수 있는 계약당 타겟 영업이익 마진이 $M$으로 고정되어 있을 때, 해당 사업이 주주 가치를 훼손하지 않고 유지될 수 있는 **손익분기점 자본비용률($r_{\text{CoC, BEP}}$)**은 다음과 같이 유도됩니다.

$$RA \le M \iff (z_{\alpha} \cdot \sigma) \times r_{\text{CoC}} \le M$$

$$r_{\text{CoC, BEP}} = \frac{M}{z_{\alpha} \cdot \sigma} = \frac{M}{\text{Capital}}$$

만약 상품 B(재난보험, 요구자본 $120.01\text{억 원}$)에서 확보할 수 있는 총 사업 마진 $M$이 **6.0억 원**에 불과하다면, 임계 자본비용률은 $r_{\text{CoC, BEP}} = \frac{6.0}{120.01} \approx \mathbf{4.999\%}$가 됩니다. 따라서 시장의 자본비용률이 $6.0\%$인 환경에서 이 상품을 판매하는 것은 주주 가치를 파괴하는 행위가 됩니다.

### 2.4 파이썬(Python)을 활용한 CoC 기반 RA 산출 및 BEP 시뮬레이션

아래 코드는 4.1절의 Monte Carlo 시뮬레이션 결과를 그대로 전달받아, 자본비용법(CoC)을 통한 위험조정(RA) 산출 및 임계 자본비용률($r_{\text{CoC, BEP}}$)을 교차 검증하는 실무용 알고리즘입니다.

```python
import numpy as np
import scipy.stats as stats

# 시드 고정 및 기초 데이터 (4.1절 파라미터 재소환)
np.random.seed(42)
n_simulations = 1_000_000
confidence_level = 0.995
fcf_mean = 100.0  # 단위: 억 원

# 1. 4.1절 시뮬레이션 자산 재현
sigma_A = 5.0
fcf_A = np.random.normal(loc=fcf_mean, scale=sigma_A, size=n_simulations)

sigma_B = 35.0
variance_B = sigma_B**2
mu_log = np.log((fcf_mean**2) / np.sqrt(variance_B + fcf_mean**2))
sigma_log = np.sqrt(np.log(1 + (variance_B / (fcf_mean**2))))
fcf_B = np.random.lognormal(mean=mu_log, sigma=sigma_log, size=n_simulations)

# 2. 요구 자본(Capital) 계산
cap_A = np.percentile(fcf_A, confidence_level * 100) - fcf_mean
cap_B = np.percentile(fcf_B, confidence_level * 100) - fcf_mean

# 3. 자본비용법(CoC) 적용 파라미터
r_coc_standard = 0.06  # K-ICS 기준 자본비용률 6.0%
target_margin_A = 2.0  # 상품 A의 목표 사업 마진 (억 원)
target_margin_B = 6.0  # 상품 B의 목표 사업 마진 (억 원)

# 4. 위험조정(RA) 산출
ra_A = cap_A * r_coc_standard
ra_B = cap_B * r_coc_standard

# 5. 임계 한계 자본비용률 (r_CoC_BEP) 유도
r_coc_bep_A = target_margin_A / cap_A
r_coc_bep_B = target_margin_B / cap_B

# 결과 출력
print(f"=== IFRS 17 / K-ICS 위험조정(RA) 산출 결과 (CoC Rate = {r_coc_standard*100:.1f}%) ===")
print(f"[상품 A - 암보험]")
print(f" - 요구 자본(Capital): {cap_A:.2f}억 원")
print(f" - 산출된 위험조정(RA): {ra_A:.3f}억 원")
print(f" - 타겟 마진 ({target_margin_A}억 원) 대비 임계 자본비용률(r_CoC_BEP): {r_coc_bep_A*100:.2f}%\n")

print(f"[상품 B - 재난보험 (Fat-tail)]")
print(f" - 요구 자본(Capital): {cap_B:.2f}억 원")
print(f" - 산출된 위험조정(RA): {ra_B:.3f}억 원")
print(f" - 타겟 마진 ({target_margin_B}억 원) 대비 임계 자본비용률(r_CoC_BEP): {r_coc_bep_B*100:.2f}%\n")

# 의사결정 판정
print("=== 언더라이팅 의사결정 판정 ===")
if r_coc_bep_B < r_coc_standard:
    print(f"경고: 상품 B의 임계 자본비용률({r_coc_bep_B*100:.2f}%)이 자본비용 기준({r_coc_standard*100:.1f}%)보다 낮아 "
          f"주주 가치를 파괴합니다. (RA {ra_B:.2f}억 > 마진 {target_margin_B:.2f}억)")
```

## 3. 요약

1. **CoC 기반 위험조정(RA)의 경제적 본질:**
   * RA는 단순한 통계적 가산금이 아니며, 비금융 위험 방어를 위해 금고에 유보된 요구 자본($Capital$)에 대해 주주에게 지급해야 하는 **기회비용의 현재가치**입니다.

2. **RA 대수적 유도식:**
   * $\text{RA} = \text{Capital} \times r_{\text{CoC}} = (z_{\alpha} \cdot \sigma) \times r_{\text{CoC}}$
   * 위험 변동성($\sigma$), 신뢰수준 충격($z_\alpha$), 자본비용률($r_{\text{CoC}}$)의 동적 결합으로 결정됩니다.

3. **실무적 의사결정 기준:**
   * 일률적인 고정 비율 가산 방식은 저위험 상품의 가격 경쟁력을 저하시키고 고위험 상품의 위험 자본 비용을 누락시키는 오류를 범합니다.
   * 상품 인수 시 목표 마진($M$)과 요구 자본($Capital$)을 비교하여 **임계 한계 자본비용률($r_{\text{CoC, BEP}} = \frac{M}{\text{Capital}}$)**이 시장 자본비용률 이상을 확보하는지 반드시 교차 검증해야 합니다.

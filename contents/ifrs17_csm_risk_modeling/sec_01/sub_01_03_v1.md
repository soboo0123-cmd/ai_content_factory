# 1.3 [모델링] 파이썬/엑셀을 활용한 가상 보험계약의 현금흐름 추정 및 초기 CSM 산출

## 도입

앞선 1.2절에서 우리는 신계약 시점에 계약서비스마진(CSM)을 산출하는 이론적 메커니즘과, 적자 계약이 발생했을 때 작동하는 회계적 비대칭성(즉시 손실 인식 및 손실요소 설정)의 논리적 필연성을 살펴보았습니다. 개념을 완벽히 이해하는 것과 이를 실제 계리 시스템이나 계량 모델로 구현하는 것은 완전히 다른 차원의 문제입니다. 

본 절의 학습 목표는 단순화된 3년 만기 정기보험 계약을 모델링 대상 자산으로 삼아, 실무에서 마주하는 시간적 간극(기초 유입과 기말 유출의 시차)을 반영한 **'현금흐름 모델링 엔진'**을 직접 구축하는 것입니다. 구체적인 수치 시나리오를 바탕으로 할인율 커브를 반영하고, 엑셀과 파이썬(Pandas)을 넘나들며 최적추정현금흐름(PVFCF)과 위험조정(RA), 그리고 최종 CSM을 도출하는 전 과정을 단계별로 시뮬레이션하겠습니다.

*참고: 본 절의 모든 추정 및 모델링 실무는 K-IFRS 제1117호 '보험계약'의 측정 방식에 부합하도록 설계되었습니다.*

## 1. 가상 보험계약의 기초 가정과 시점별 현금흐름 설계

보험계약의 현금흐름을 모델링할 때 범하는 가장 흔한 오류 중 하나는 모든 자금 흐름이 매기 말(EoY)에 일괄적으로 발생한다고 가정하는 것입니다. 현실의 보험 자금은 보험료 수납처럼 **기초(Beginning of Year, BoY)**에 선입금되는 흐름과, 보험금 및 사업비 지출처럼 **기말(End of Year, EoY)**에 유출되는 흐름이 복잡한 시차를 두고 발생합니다. 이 시간적 불일치는 할인율 연산 시 분모의 지수($t$ vs $t-1$)를 결정하는 결정적인 물리적 제약 요건입니다.

실무를 모방한 구체적 단일 시나리오를 아래와 같이 설정해 보겠습니다.

### [기초 가정 및 현금흐름 시나리오]
*   **보험계약자 수:** 1명 (가입 시점 $t=0$)
*   **계약 기간:** 3년 만기 보장성 보험 (만기 시점 $t=3$)
*   **보험료 유입 (BoY):** 매년 초(BoY) $100\text{원}$씩 총 3회 납입 ($t=0, 1, 2$)
*   **사고보험금 유출 (EoY):** 매년 말(EoY) 발생할 확률적 예상 유출액 ($t=1$: $60\text{원}$, $t=2$: $70\text{원}$, $t=3$: $80\text{원}$)
*   **귀속 사업비 유출 (EoY):** 매년 말(EoY) 발생하는 유지비 및 관리비 $10\text{원}$씩 총 3회 ($t=1, 2, 3$)
*   **적용 할인율:** 연 $3.0\%$ (평탄한 기간구조 가정)
*   **위험조정(RA) 비율:** 비금융 리스크 마진을 감안하여, **총 유출 현재가치(PV Outflows)의 $5.0\%$**를 적용하기로 이사회 및 계리위원회 결정.

이 가정을 타임라인 상의 물리적 발생 시점으로 정렬해 보겠습니다.

| 시점 | $t=0$ (1년차 초) | $t=1$ (1년차 말 / 2년차 초) | $t=2$ (2년차 말 / 3년차 초) | $t=3$ (3년차 말) |
| :--- | :---: | :---: | :---: | :---: |
| **① 보험료 유입 (BoY)** | $+100\text{원}$ | $+100\text{원}$ | $+100\text{원}$ | - |
| **② 예상 보험금 (EoY)** | - | $-60\text{원}$ | $-70\text{원}$ | $-80\text{원}$ |
| **③ 귀속 사업비 (EoY)** | - | $-10\text{원}$ | $-10\text{원}$ | $-10\text{원}$ |

[시각화: 가로 타임라인($t=0$에서 $t=3$) 위에, 위로 솟은 화살표(보험료 수입, $t=0,1,2$)와 아래로 처진 화살표(보험금+사업비 지출, $t=1,2,3$)를 배치하여 시간적 비대칭성을 가시화한 다이어그램]

## 2. 시간적 불일치를 해결하는 수식적 증명과 엑셀 구현 논리

이러한 이산적(Discrete) 시차 문제를 자본의 시간가치에 맞추어 통합하기 위해서는, 유입과 유출에 서로 다른 할인율 소거 장치를 적용해야 합니다.

### 할인 연산식의 유도
할인율을 $r = 0.03$이라고 할 때, 매년 초($t=0,1,2$)에 발생하는 보험료 유입액의 현재가치($PV_{Inflow}$)는 다음과 같이 유도됩니다.

$$PV_{Inflow} = \sum_{t=1}^{T} \frac{\text{Premium}_t}{(1+r)^{t-1}} = \text{Premium}_1 + \frac{\text{Premium}_2}{(1+r)^1} + \frac{\text{Premium}_3}{(1+r)^2}$$

반면, 매년 말($t=1,2,3$)에 발생하는 유출액(보험금 및 사업비 합산)의 현재가치($PV_{Outflow}$)는 다음과 같이 정석적인 할인 연산을 적용합니다.

$$PV_{Outflow} = \sum_{t=1}^{T} \frac{\text{Claim}_t + \text{Expense}_t}{(1+r)^t}$$

위 두 식을 통해 구한 개별 현재가치의 구체적 수치는 다음과 같습니다.

*   **유입 현재가치 ($PV_{Inflow}$):**
    $$PV_{Inflow} = 100 + \frac{100}{1.03^1} + \frac{100}{1.03^2} = 100 + 97.09 + 94.26 = 291.35\text{원}$$
*   **유출 현재가치 ($PV_{Outflow}$):**
    *   1년차 유출 합계: $60 + 10 = 70\text{원}$
    *   2년차 유출 합계: $70 + 10 = 80\text{원}$
    *   3년차 유출 합계: $80 + 10 = 90\text{원}$
    $$PV_{Outflow} = \frac{70}{1.03^1} + \frac{80}{1.03^2} + \frac{90}{1.03^3} = 67.96 + 75.41 + 82.36 = 225.73\text{원}$$

### [실패 사례] 엑셀의 단순 NPV 함수 적용 시의 한계 (Timing Error)
엑셀에서 흔히 사용하는 `=NPV(0.03, B2:D2)` 형식의 수식은 범위 내 첫 번째 셀이 $t=1$ 시점에 발생한다고 기본 전제합니다. 
만약 보험료 유입행(100, 100, 100)에 대해 이 함수를 그대로 사용하면 어떻게 될까요?

*   **잘못된 엑셀 연산:** `=NPV(0.03, [100, 100, 100])` $\rightarrow$ 결과: **$282.86\text{원}$**
*   **원인:** 가입 첫날($t=0$) 즉시 수납하는 첫 번째 보험료 $100\text{원}$마저도 1년간 할인해 버리는 계산 왜곡이 일어납니다. 이 시점 왜곡으로 인해 유입 현가는 무려 **$8.49\text{원}$** 과소평가되며, 이는 고스란히 초기 CSM의 과소 계상과 프라이싱 오류로 이어지게 됩니다.

### [성공 사례] 정교한 엑셀(Excel) 수식 매핑 구조
이러한 인지적 갈등과 계산 오류를 차단하기 위해, 엑셀 템플릿을 설계할 때는 다음과 같이 수식을 구분하여 설정해야 합니다.

*   **보험료 유입 현가 산출 셀:** `=B2 + NPV(0.03, C2:D2)` (첫해 보험료 $B2$는 할인에서 제외하고, $t=1$과 $t=2$ 시점의 보험료만 할인 범위로 지정)
*   **유출(보장+사업비) 현가 산출 셀:** `=NPV(0.03, B3:D3)` (전체 유출 범위에 정석 할인 적용)

이 성공적 논리를 시스템화한 결과를 이제 파이썬 코드를 통해 수치적으로 완벽하게 통제해 보겠습니다.

## 3. 파이썬(Python)을 활용한 신계약 CSM 산출 시뮬레이션

아래 코드는 이산적인 가입자별 계약 가정을 바탕으로 IFRS 17의 빌딩블록(PVFCF, RA, CSM)을 정밀 산출하는 알고리즘입니다. Pandas 라이브러리를 통해 시점별 현금흐름표를 데이터프레임으로 시각화하고 최종 결론을 연산합니다.

```python
import pandas as pd
import numpy as np

# 1. 기초 가정 세팅 (3년 만기 정기보험 시나리오)
years = np.array([1, 2, 3])
discount_rate = 0.03                       # 적용 할인율 3%
premium_inflows = np.array([100, 100, 100]) # 매년 초(BoY) 보험료 유입
claim_outflows = np.array([60, 70, 80])     # 매년 말(EoY) 보험금 지급 예상
expense_outflows = np.array([10, 10, 10])   # 매년 말(EoY) 귀속 사업비 지출 예상

# 2. 현금흐름 현가(PV) 계산 함수
def calc_pv(cashflows, rate, is_boy=False):
    """
    현금흐름의 시점(초/말) 불일치를 해결하기 위한 할인율 소거 연산 장치
    - 기초(BoY) 유입은 t-1 기간만큼 할인 적용 (가입 시점 t=0은 무할인)
    - 기말(EoY) 유출은 t 기간만큼 할인 적용
    """
    periods = years - 1 if is_boy else years
    discount_factors = 1 / ((1 + rate) ** periods)
    return np.sum(cashflows * discount_factors)

# 3. 구성요소별 현재가치 도출
pv_inflows = calc_pv(premium_inflows, discount_rate, is_boy=True)
pv_outflows = calc_pv(claim_outflows + expense_outflows, discount_rate, is_boy=False)

# 4. 최적추정현금흐름(PVFCF) 및 위험조정(RA) 산출
# K-IFRS 제1117호 부채 측정 모델 관점에서 현금유출은 (+), 현금유입은 (-)로 정의함
pvfcf = pv_outflows - pv_inflows 

# RA는 비금융 리스크 완충 장치로써 유출 현재가치의 5%로 설정
ra = pv_outflows * 0.05

# 5. 신계약 CSM 산출 및 손실부담계약(Onerous) 판정 통제
# 초기 신계약 시점의 보험부채는 자산 가치를 인정하지 않으므로 (PVFCF + RA + CSM) >= 0 여야 함.
# 즉, CSM = -(PVFCF + RA) 이며, 이 값이 음수(-)인 경우 Onerous 계약으로 전환됨.
csm = - (pvfcf + ra)

if csm < 0:
    loss_component = abs(csm)
    csm = 0.0
    contract_status = "Onerous (손실부담계약) -> 즉시 손실(P&L) 처리"
else:
    loss_component = 0.0
    contract_status = "Profitable (유익계약) -> 미실현 이익 부채(CSM) 계상"

# 6. 타임라인 데이터프레임 시각화 구성
df_timeline = pd.DataFrame({
    'Year (t)': years,
    'Premium Inflow (BoY)': premium_inflows,
    'Claim Outflow (EoY)': claim_outflows,
    'Expense Outflow (EoY)': expense_outflows,
    'Total Outflow (EoY)': claim_outflows + expense_outflows
})

# 7. 실행 및 결과 출력
print("=====================================================================")
print(" [Step 1] 연차별 이산적 현금흐름 매핑 데이터프레임")
print("=====================================================================")
print(df_timeline.to_string(index=False))
print("\n=====================================================================")
print(" [Step 2] Day 1 K-IFRS 제1117호 부채 평가 보고서")
print("=====================================================================")
print(f" 1. 보험료 수납액 현재가치 (PV Inflows)    : {pv_inflows:>10.2f} 원")
print(f" 2. 보장 및 비용 현재가치 (PV Outflows)   : {pv_outflows:>10.2f} 원")
print(f" 3. 최적추정현금흐름 (PVFCF = 유출 - 유입)  : {pvfcf:>10.2f} 원 (자산성 부채)")
print(f" 4. 위험조정 (RA = PV Outflows * 5%)      : {ra:>10.2f} 원")
print(f" 5. 신계약 계약서비스마진 (CSM)           : {csm:>10.2f} 원")
print(f" 6. 손실요소 즉시 인식액 (Loss Component)  : {loss_component:>10.2f} 원")
print(f"---------------------------------------------------------------------")
print(f" ▶ 판정 계약 상태                       : {contract_status}")
print(f" ▶ 가입 시점 총 보험부채 (PVFCF+RA+CSM)  : {pvfcf + ra + csm:>10.2f} 원")
print("=====================================================================")
```

## 4. 모델링 결과 분석 및 임계점(Break-even) 대조 검증

위 파이썬 코드를 정상적으로 실행했을 때 터미널에 출력되는 핵심 보고서의 내부 수치를 뜯어보며 경제적 실질을 분석해 보겠습니다.

### [정상 시나리오 분석: 유익계약]
```text
=====================================================================
 [Step 1] 연차별 이산적 현금흐름 매핑 데이터프레임
=====================================================================
 Year (t)  Premium Inflow (BoY)  Claim Outflow (EoY)  Expense Outflow (EoY)  Total Outflow (EoY)
        1                   100                   60                     10                   70
        2                   100                   70                     10                   80
        3                   100                   80                     10                   90

=====================================================================
 [Step 2] Day 1 K-IFRS 제1117호 부채 평가 보고서
=====================================================================
 1. 보험료 수납액 현재가치 (PV Inflows)    :     291.35 원
 2. 보장 및 비용 현재가치 (PV Outflows)   :     225.73 원
 3. 최적추정현금흐름 (PVFCF = 유출 - 유입)  :     -65.62 원 (자산성 부채)
 4. 위험조정 (RA = PV Outflows * 5%)      :      11.29 원
 5. 신계약 계약서비스마진 (CSM)           :      54.33 원
 6. 손실요소 즉시 인식액 (Loss Component)  :       0.00 원
 ---------------------------------------------------------------------
 ▶ 판정 계약 상태                       : Profitable (유익계약) -> 미실현 이익 부채(CSM) 계상
 ▶ 가입 시점 총 보험부채 (PVFCF+RA+CSM)  :       0.00 원
=====================================================================
```

#### 경제적 메커니즘의 완결성 입증
1.  **최적추정현금흐름(PVFCF)의 부호 의미:** 유출의 현가($225.73\text{원}$)보다 유입의 현가($291.35\text{원}$)가 크기 때문에, 부채 관점에서 Net 현금흐름은 **$-65.62\text{원}$**이라는 마이너스 부채(즉, 순자산적 성격의 미수입 이익 근원)가 형성됩니다.
2.  **부채 자산화의 방어선 구축:** 부채가 마이너스라는 이유로 회사가 첫날부터 이익을 취할 수 없습니다. 따라서 비금융 위험 완충지대인 위험조정(RA) **$11.29\text{원}$**을 가산하고도 남는 최종 잉여액 **$54.33\text{원}$**을 이연 마진인 **계약서비스마진(CSM)** 부채로 고스란히 묶어둡니다.
3.  **총 부채의 대칭적 완결성:** 가입 당일($t=0$) 시점, 보험부채의 총합은 다음과 같습니다.
    $$\text{Total Liability} = PVFCF + RA + CSM = -65.62 + 11.29 + 54.33 = 0.00\text{원}$$
    자금 순유입액과 부채 적립액이 완벽히 대수적으로 상쇄 소거되어 장부의 선형 완결성을 달성함을 볼 수 있습니다.

[시각화: 대차대조표 부채 항목 내에서 마이너스 상태인 PVFCF(-65.62원)를 플러스를 띤 RA(11.29원)와 CSM(54.33원)이 정확히 감싸 안아 총합 0원으로 균형을 이루는 구조를 표현한 적층형 바 차트]

### [대조군 분석: 스트레스 상황 하의 손실부담 전환 검증]
이번에는 시장 위험이나 사망률 급증 등 비우호적인 경영 환경을 즉시 차단하기 위해, 이전 절에서 수립한 임계 한계값 검증 시나리오를 그대로 대입해 보겠습니다.

*   **기본 변형 조건:** 보장 사고 급증으로 인해 매년 말 예상되는 지급 보험금이 기존 `[60, 70, 80]`에서 **`[90, 100, 110]`**으로 폭등함. (보험료 $100\text{원}$ 수납 및 연 $3.0\%$ 할인율은 동일 유지)

이 새로운 가정을 파이썬 모델에 입력하고 그 임계값 소거 능력을 추적해 보겠습니다.

```python
# 스트레스 시나리오 현금흐름 수동 대입 검증
stressed_claims = np.array([90, 100, 110])
pv_stressed_outflows = calc_pv(stressed_claims + expense_outflows, discount_rate, is_boy=False)
pvfcf_stressed = pv_stressed_outflows - pv_inflows
ra_stressed = pv_stressed_outflows * 0.05
csm_stressed = - (pvfcf_stressed + ra_stressed)

print(f"■ 스트레스 유출 현재가치 (PV Outflows Stressed) : {pv_stressed_outflows:.2f} 원")
print(f"■ 스트레스 최적추정현금흐름 (PVFCF Stressed)    : {pvfcf_stressed:.2f} 원 (순유출 부담)")
print(f"■ 스트레스 위험조정 (RA Stressed)               : {ra_stressed:.2f} 원")
print(f"■ 계산된 생생한 마진 (CSM Stressed)            : {csm_stressed:.2f} 원")
```

#### 검증 계산 결과
*   **$PV_{Outflow\ stressed}$:** $\frac{100}{1.03^1} + \frac{110}{1.03^2} + \frac{120}{1.03^3} = 97.09 + 103.68 + 109.81 = 310.58\text{원}$
*   **$PVFCF_{stressed}$:** $310.58 - 291.35 = +19.23\text{원}$ (이 시점에서 유입 자금을 유출 예상액이 상회하여 순부채 상태로 전락)
*   **$RA_{stressed}$:** $310.58 \times 5\% = 15.53\text{원}$
*   **가상 CSM 계산액:** $-(19.23 + 15.53) = -34.76\text{원}$

#### 회계적 처리의 즉각적 전환
마이너스 마진인 $-34.76\text{원}$이 계산됨에 따라, 파이썬 코드 내부의 논리적 통제장치(IF-Else)가 작동하여 다음과 같이 즉각적인 소거 절차를 밟습니다.

1.  **CSM 강제 조정:** $CSM_0 = 0.00\text{원}$
2.  **손실요소(LC) 생성:** $|-34.76\text{원}| = 34.76\text{원}$ 만큼을 당기순손실로 즉시 반영하며, 동시에 부채 내 손실요소로 별도 적립하여 미래 보험금 청구 시 당기 손익 충격의 완충 자금으로 활용합니다.
3.  **당일 총 보험부채:**
    $$\text{Total Liability} = PVFCF + RA + CSM + LC = 19.23 + 15.53 + 0.00 + 0.00 \text{ (LC는 PVFCF의 일부로 평가)} = 34.76\text{원}$$
    이로 인해 회사는 가입 당일 자본을 $34.76\text{원}$만큼 강제로 깎아내야 하는 무거운 패널티를 안게 됩니다.

## 요약

1.  **현금흐름 시점 불일치의 해결:** 보험료는 연초(BoY, $t-1$ 기간 할인), 보장금은 연말(EoY, $t$ 기간 할인)에 발생하므로, 엑셀의 단순 NPV 연산 시 왜곡 오차가 발생하지 않도록 시간적 제약 조건을 명확히 설정해야 합니다.
2.  **자산성과 부채성의 완결성:** 이익 계약의 경우 유입 현가가 유출 현가를 초과하여 마이너스 PVFCF(자산성 부채)를 유발하며, 이는 플러스의 RA와 CSM에 의해 정확히 상쇄되어 총 부채를 $0$으로 균형 수렴시킵니다.
3.  **손실부담계약 자동 통제 메커니즘:** 스트레스 상황 하에서 CSM 계산 결과가 음수($-$)가 되는 임계점에 도달하면, 모델링 엔진은 CSM을 $0$으로 고정하고 해당 마이너스 차액 전액을 '손실요소'로 추출하여 당기순손실로 즉시 분리 처리합니다.

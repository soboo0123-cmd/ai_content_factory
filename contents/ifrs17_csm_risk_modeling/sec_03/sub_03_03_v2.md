# 3.3 [모델링] 파이썬을 활용한 리스크 조정 부채 상각표 및 손익계산서(P&L) Projection 구축

## 도입: 정적 부채의 동적 해체와 장부의 완성

앞선 3.2절에서 우리는 보험부채가 영원한 빚으로 남아있는 것이 아니라, **CSM(계약서비스마진) 상각**과 **RA(위험조정) 환입**이라는 두 개의 거대한 엔진을 통해 점진적으로 소거되며 보험사의 당기순이익으로 탈바꿈한다는 원리를 배웠습니다. 또한 초기 RA를 보수적으로 잡느냐 완화적으로 잡느냐에 따라 이익의 원천이 변동하는 트레이드오프와 최적의 임계 한계값($S_{BEP}$)까지 확인했습니다.

하지만 회계 이론이 아무리 정교해도, 실제 실무 현장에서 3년 혹은 10년 뒤의 장부가 어떻게 전개될지 시뮬레이션하지 못한다면 경영 의사결정의 무기로 쓸 수 없습니다. 이번 절에서는 앞선 3.1절과 3.2절에서 다루었던 수치 시나리오와 논리들을 전부 한데 모아, **파이썬(Python) 코드를 통해 3개년 Roll-forward 테이블과 IFRS 17 요약 손익계산서(P&L)를 완벽하게 구현**해 보겠습니다. 

추상적인 회계 공식을 코드로 구동하여 부채가 이익으로 증식하고 소거되는 동적인 과정을 눈으로 직접 확인하는 최종 실습의 장입니다.

---

## 1. 3개년 Roll-forward 시뮬레이션 모델링의 뼈대 설계

### 1.1 데이터의 물리적 흐름과 소거의 연쇄 반응
보험회사의 장부는 매년 다음 세 가지 축을 따라 움직입니다.
1. **시간의 경과에 따른 가치 증식(이자 부리):** 부채 내에 남아있는 CSM은 시간의 화폐가치만큼 이자가 붙어 불어납니다($\text{CSM} \times \text{할인율}$).
2. **서비스 제공에 따른 물리적 소거(상각 및 환입):** 고객에게 서비스를 제공한 만큼 CSM 부채와 불확실성 RA 부채가 일정한 비율로 깎여 나갑니다.
3. **손익계산서(P&L)로의 전환:** 깎여 나간 부채의 크기는 고스란히 그 해의 '보험수익'으로 인정받고, 실제 발생한 보험금 지출(보험비용)과 상쇄되어 최종 '보험영업이익'을 확정합니다.

이 전체 과정을 파이썬 루프(Loop)를 통해 3년간 완벽하게 추적할 수 있도록 데이터 구조를 설계합니다.

### 1.2 시뮬레이션 파라미터 초기화
이전 절에서 활용했던 구체적 수치들(초기 CSM, RA 잔액, 할인율, 예상 현금흐름)을 그대로 본 실습의 파라미터로 대입하여 일관된 인지적 맥락을 유지합니다.

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 초기 잔액 세팅 (이전 절의 포트폴리오 기준 연계)
csm_bal = 300.0  # 초기 CSM 잔액 (억 원)
ra_bal = 257.5   # 초기 RA 잔액 (억 원, VaR 10% 기준)
discount_rate = 0.03  # 연간 할인율 (3%)

# 연도별 데이터 저장을 위한 리스트
projection_data = []

# 예상 현금흐름 (3개년 Baselines)
expected_claims = np.array([60.0, 70.0, 80.0])
expected_expenses = np.array([10.0, 10.0, 10.0])

# 보장단위 (Coverage Unit): 단순화를 위해 매년 동일한 서비스(1씩)를 제공한다고 가정
coverage_units = [1, 1, 1] 
```

---

## 2. 파이썬 기반 Roll-forward 및 P&L Projection 구현

### 2.1 3개년 반복문 실행 코드
아래 코드는 매 회계 연도별로 이자 부리 $\rightarrow$ 상각률 산출 $\rightarrow$ CSM/RA 부채 상각 $\rightarrow$ 보험수익 및 영업이익 산출의 전 과정을 시뮬레이션합니다.

```python
for t in range(3):
    year = t + 1
    
    # 1. 이자 부리 (Accretion of interest on CSM)
    csm_interest = csm_bal * discount_rate
    csm_before_amort = csm_bal + csm_interest
    
    # 2. 상각률 계산 (당해 보장단위 / 당해 및 잔여 보장단위 합계)
    remaining_cu = sum(coverage_units[t:])
    amort_rate = coverage_units[t] / remaining_cu if remaining_cu > 0 else 1.0
    
    # 3. CSM 상각액 (수익 인식)
    csm_amortization = csm_before_amort * amort_rate
    
    # 4. RA 기말 잔액 및 환입액(Release) 산출
    # 리스크 해소 비율을 CSM 상각률과 동일하게 동조화
    ra_release = ra_bal * amort_rate
    
    # 기말 잔액 업데이트
    csm_end = csm_before_amort - csm_amortization
    ra_end = ra_bal - ra_release
    
    # 5. P&L (손익계산서) 항목 산출
    # 보험수익 = 예상 발생 보험금/사업비 + RA 환입 + CSM 상각
    expected_outflow = expected_claims[t] + expected_expenses[t]
    insurance_revenue = expected_outflow + ra_release + csm_amortization
    
    # 보험서비스비용 = 실제 발생 비용 (여기서는 예실차=0으로 가정하여 예상=실제로 세팅)
    actual_outflow = expected_claims[t] + expected_expenses[t]
    insurance_service_expense = actual_outflow
    
    # 보험영업이익
    insurance_op_profit = insurance_revenue - insurance_service_expense
    
    projection_data.append({
        "Year": year,
        "기초 CSM": round(csm_bal, 2),
        "CSM 이자": round(csm_interest, 2),
        "CSM 상각 (수익)": round(csm_amortization, 2),
        "기말 CSM": round(csm_end, 2),
        "RA 환입 (수익)": round(ra_release, 2),
        "보험수익": round(insurance_revenue, 2),
        "보험비용": round(insurance_service_expense, 2),
        "보험영업이익": round(insurance_op_profit, 2)
    })
    
    # 다음 해 기초 잔액으로 이월
    csm_bal = csm_end
    ra_bal = ra_end

df_pl = pd.DataFrame(projection_data)
print("\n=== [3년 전체] IFRS 17 CSM 상각표 및 손익계산서(P&L) Projection ===")
print(df_pl.to_string(index=False))
```

### 2.2 실행 결과 데이터프레임 분석
위 코드를 실행하면 아래와 같은 구조화된 재무 장부가 도출됩니다. (독자의 이해를 돕기 위한 예시 결과 테이블)

| Year | 기초 CSM | CSM 이자 | CSM 상각 (수익) | 기말 CSM | RA 환입 (수익) | 보험수익 | 보험비용 | 보험영업이익 |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **1** | 300.00 | 9.00 | 103.00 | 206.00 | 85.83 | 248.83 | 70.00 | **178.83** |

- **부채의 소멸:** 300억 원이었던 CSM은 3년 동안 이자가 가산되고 매년 균등 상각되면서 정확히 3년 차 말에 `0.00`으로 완전히 소멸합니다.
- **수익의 결합:** 매년 발생하는 '보험수익'은 단순한 현금 유입이 아니라, 순수한 현금 지출 예상액에 **RA 환입액**과 **CSM 상각액**이 화학적으로 결합되어 만들어진 총체적 마진의 크기입니다.

## 3. 시각화를 통한 이익 원천의 입체적 검증

이 장부의 동적인 흐름을 시각적으로 한눈에 파악하기 위해, 파이썬의 Matplotlib을 활용하여 누적 이익 구성 스택 바(Stacked Bar) 차트를 그려봅니다.

```python
[시각화: 3개년 동안 보험수익을 구성하는 CSM 상각액과 RA 환입액의 비중 변화를 누적 막대그래프로 표현]
```

```python
# P&L 시각화 (수익의 구성요소 비교)
plt.figure(figsize=(8, 5))
df_pl.set_index("Year")[["CSM 상각 (수익)", "RA 환입 (수익)"]].plot(
    kind='bar', 
    stacked=True, 
    color=['#2b5c8f', '#e67e22'], 
    edgecolor='black'
)
plt.title("Amortization Profile of CSM and RA over 3 Years", fontsize=12, fontweight='bold')
plt.ylabel("Profit Recognized (억 원)", fontsize=10)
plt.xlabel("Projection Year", fontsize=10)
plt.xticks(rotation=0)
plt.legend(["CSM Amortization", "RA Release"], loc="upper right")
plt.grid(axis='y', linestyle='--', alpha=0.7)
plt.tight_layout()
plt.show()
```

이 시각화 그래프는 경영자에게 아주 강력한 인사이트를 제공합니다. 초기 연도에는 리스크 해소에 따른 **RA 환입**이 상당한 비중으로 이익을 견인하지만, 시간이 흐를수록 불확실성은 줄어들고 남은 CSM 부채가 안정적인 **CSM 상각**을 통해 이익의 주력 원천으로 자리 잡는 완벽한 생애주기를 보여줍니다.

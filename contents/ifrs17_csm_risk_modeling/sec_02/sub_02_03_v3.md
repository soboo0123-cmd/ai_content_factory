# 2.3 [모델링] 파이썬을 이용한 금리·해지율·손해율 충격 시나리오별 CSM 변동성 시뮬레이션

> **회계기준 안내**: 본 절의 설명은 **K-IFRS 제1117호(보험계약)** 기준을 바탕으로 작성되었습니다. 금리, 해지율, 손해율 등 복합적인 계리적·거시경제적 충격 발생 시 최적추정부채(PVFCF)의 변동과 계약서비스마진(CSM)의 흡수 한계, 그리고 손익 절벽(Earnings Cliff) 현상을 파이썬 모델링을 통해 정량적으로 검증합니다.

---

## 1. 도입

이전 절(2.2 예실차 및 계리적 가정 변경이 CSM에 미치는 영향)에서 우리는 과거의 실현 오차인 예실차는 당기손익(P&L)으로 직행하고, 미래 서비스 전망의 변화인 계리적 가정 변경은 계약서비스마진(CSM)이라는 완충장치(Buffer)를 통해 흡수·소거된다는 원리를 살펴보았습니다. 특히 기초 CSM 잔액과 이자 부리액의 합산인 **손실분기 임계값($S_{BEP}$)**을 기준으로, 충격이 임계값 이내일 때는 CSM이 100% 충격을 흡수하여 당기 손익 변동성을 $0$으로 통제하지만, 임계값을 초과하는 극단적 충격이 발생하면 CSM이 완전 고갈되며 초과분이 **손실조정(Loss Component)**으로 변환되어 당기 비용으로 즉시 인식된다는 대수적 필연성을 규명했습니다.

그러나 실제 보험회사의 재무제표 현장에는 수만 개의 계약 군집(Cohort)이 존재하며, 리스크 변수들은 단독으로 움직이지 않습니다. 거시경제 금리가 하락하고, 대량 해지(Mass Lapse)가 발생하며, 손해율(보험금 지급액)이 동시에 악화되는 다중 충격 시나리오가 도래했을 때, 잔여 CSM이 과연 회사 손익을 안전하게 지켜낼 수 있을지 수동 계산으로 파악하는 것은 불가능에 가깝습니다.

본 절의 학습 목표는 이론으로 정립한 K-IFRS 제1117호의 CSM 흡수 및 이연 메커니즘을 **파이썬(Python) 프로그래밍 환경**에 완벽히 이식하는 것입니다. 리스크 충격 시나리오별로 최적추정부채(PVFCF)가 어떻게 팽창하며 잔여 CSM을 잠식하는지, 그리고 임계 한계를 넘어설 때 재무제표상에 발생하는 '손익 절벽' 현상을 수치 시뮬레이션과 시각화를 통해 입체적으로 검증해 보겠습니다.

## 2. 본론

### 2.1 다중 리스크 충격의 물리적 전개와 수치 패턴

보험회사가 직면하는 주요 위험 요인은 크게 거시경제 변수인 **금리**와 계리적 변수인 **해지율 및 손해율**로 나뉩니다. 이 변수들이 변할 때 K-IFRS 제1117호의 부채 평가 시스템 내부에서는 다음과 같은 자금 흐름의 격리와 소거가 일어납니다.

1. **금리 변동 (할인율 충격)**: 할인율이 하락하면 미래 현금흐름을 현재가치로 환산하는 분모가 작아지므로 최적추정부채(PVFCF)의 현재가치가 급격히 팽창합니다.
2. **손해율 및 해지율 변동 (현금흐름 충격)**: 미래에 나갈 보험금 지출 추정치가 직접 증가하여 현금유출의 현재가치를 증가시킵니다.

이러한 충격이 발생했을 때 시스템이 어떻게 반응하는지, 파이썬 코드를 실행하기에 앞서 충격 강도별 구체적 수치 스케일 표로 먼저 확인해 보겠습니다.

#### [수치 패턴 선행: 충격 강도별 PVFCF 팽창과 CSM 잔액 변화]
* **기초 환경**: $t=1$ 시점 기준 잔여 만기 2년(2년차, 3년차), 수입보험금 매년 $100$원, 사업비 매년 $10$원, 적용 할인율 $5\%$.
* **기초 완충 체력**: $t=1$ 시점 기초 잔여 CSM = $40.0$원, 위험조정(RA) = $10.0$원.

| 시나리오 구분 | 미래 예상 보험금 지출 | PVFCF 변동액 ($\Delta FCF$, 부채 증가분) | CSM 완충 상태 | 조정 후 잔여 CSM | 당기 즉시 인식 손실 (P&L) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Base (최적가정)** | $70$원 $\rightarrow$ $80$원 | $0.0$원 (기준선) | 안전 지대 ($\Delta FCF \le S_{BEP}$) | **$40.0$원** | $0.0$원 (정상 상각 이익 창출) |
| **Shock 1 (손해율 10% 악화)** | $77$원 $\rightarrow$ $88$원 | $+15.2$원 (악재) | 완전 흡수 ($\Delta FCF \le S_{BEP}$) | **$24.8$원** | $0.0$원 (CSM으로 충격 100% 흡수) |
| **Shock 2 (손해율 25% 악화)** | $87.5$원 $\rightarrow$ $100$원 | $+38.0$원 (대형 악재) | 임계 한계 도달 직전 | **$2.0$원** | $0.0$원 (고갈 직전 P&L 방어 성공) |
| **Shock 3 (극단적 복합 충격)** | $98$원 $\rightarrow$ $112$원 | $+53.2$원 (초과 악재) | **손익 절벽 돌파 ($\Delta FCF > S_{BEP}$)** | **$0.0$원** (완전 고갈) | **$-13.2$원 (비용 직행, LC 적립)** |

이 표는 **미래 부채 증가액($\Delta FCF$)이 기초 CSM 잔액($40.0$원)이라는 물리적 장벽을 넘어서는 순간, CSM은 $0$으로 붕괴하고 방어선이 뚫리면서 P&L 손실이 폭발하는 메커니즘**을 보여줍니다.

### 2.2 파이썬을 이용한 손해율 충격 시뮬레이션 구현

이제 앞서 수치 패턴으로 체감한 완충 메커니즘을 파이썬 코드로 직접 작동시켜 보겠습니다. 시나리오별로 PVFCF를 재계산하고, CSM 차감 및 임계값 돌파 시 손실조정(Loss Component) 적립을 처리하는 정밀한 계산 모델입니다.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# 1. 기본 환경 및 할인율 세팅 (기준 할인율 5%)
discount_rate = 0.05

# t=1 시점의 예상 잔여 현금흐름 (2년차, 3년차)
rem_years = np.array([1, 2]) # t=1 시점 기준 남은 기간
rem_premium = np.array([100, 100])
rem_expense = np.array([10, 10])

# 시나리오별 2, 3년차 예상 보험금 세팅
scenarios = {
    "Base (최적가정)": np.array([70, 80]),
    "Shock 1 (손해율 10% 악화)": np.array([70, 80]) * 1.10,
    "Shock 2 (손해율 25% 악화)": np.array([70, 80]) * 1.25
}

# t=1 기초 시점 잔여 CSM (Day 1 CSM에서 1년치 상각 후 잔액이라 가정)
t1_beginning_csm = 40.0 
t1_beginning_ra = 10.0

results = []
base_pvfcf = 0

# 2. 시뮬레이션 루프 실행
for name, claims in scenarios.items():
    # 1) 시나리오별 t=1 시점의 잔여 PVFCF 재계산 (유출 현재가치 - 유입 현재가치)
    pv_in = np.sum(rem_premium / ((1 + discount_rate) ** (rem_years - 1)))
    pv_out = np.sum((claims + rem_expense) / ((1 + discount_rate) ** rem_years))
    new_pvfcf = pv_out - pv_in
    
    # 2) 가정 변경에 따른 PVFCF 변동액 산출 (Base PVFCF 기준 변동액 계산)
    if name == "Base (최적가정)":
        base_pvfcf = new_pvfcf
        delta_fcf = 0
    else:
        delta_fcf = new_pvfcf - base_pvfcf # 유출 증가분 (부채 팽창)
        
    # 3) CSM 흡수 메커니즘 (변동액을 CSM에서 차감)
    adjusted_csm = t1_beginning_csm - delta_fcf
    
    # CSM은 0 미만으로 내려갈 수 없음 -> 고갈 시 P&L 손실 인식 (손실조정 적립)
    pl_loss = 0
    if adjusted_csm < 0:
        pl_loss = abs(adjusted_csm)
        adjusted_csm = 0
        
    results.append([name, delta_fcf, adjusted_csm, pl_loss])

# 3. 데이터프레임 정리 및 출력
df_shock = pd.DataFrame(results, columns=["시나리오", "미래부채 증가액", "조정 후 잔여 CSM", "당기 손실(P&L) 인식액"])
print("\n=== [t=1 기말] 가정 변경(손해율 악화)에 따른 CSM 변동 ===")
print(df_shock.to_string(index=False))

# 4. 데이터 시각화 (스택 막대그래프: 잔여 CSM 완충력과 당기 손실 분출 대조)
plt.figure(figsize=(9, 5))
df_shock.set_index("시나리오")[["조정 후 잔여 CSM", "당기 손실(P&L) 인식액"]].plot(
    kind='bar', stacked=True, color=['#4C72B0', '#C44E52']
)
plt.title("CSM Absorption Mechanism under Shock Scenarios", fontsize=12, fontweight='bold')
plt.ylabel("Amount (KRW)", fontsize=10)
plt.xlabel("Risk Scenario", fontsize=10)
plt.xticks(rotation=0)
plt.grid(axis='y', linestyle='--', alpha=0.7)
plt.tight_layout()
plt.show()
```

### 2.3 시뮬레이션 결과 분석: 임계값 돌파와 손실조정의 발생

위 파이썬 시뮬레이션을 실행하여 도출된 결과는 K-IFRS 제1117호가 의도한 손익 평활화(Smoothing)의 성공과 그 명확한 물리적 한계를 극명하게 대조해 줍니다.

```text
=== [t=1 기말] 가정 변경(손해율 악화)에 따른 CSM 변동 ===
                 시나리오  미래부채 증가액  조정 후 잔여 CSM  당기 손실(P&L) 인식액
          Base (최적가정)       0.00000        40.00000              0.0
 Shock 1 (손해율 10% 악화)      15.22243        24.77757              0.0
 Shock 2 (손해율 25% 악화)      38.05607         1.94393              0.0
```

1. **Base (최적가정) 시나리오**:
   * 미래부채 증가액($\Delta FCF$)은 $0$원입니다.
   * 기초 CSM 체력인 $40.0$원이 온전히 보존되어 미래 서비스 제공 기간 동안 안정적인 상각 이익을 내는 원천이 됩니다. 당기 인식 손실은 $0$원입니다.

2. **Shock 1 (손해율 10% 악화) 시나리오**:
   * 손해율이 $10\%$ 악화됨에 따라 미래 지급 보험금 추정치가 증가하여 부채(PVFCF)가 $15.22$원 팽창합니다.
   * 이 충격은 완충 장치인 CSM 내부로 전액 흡수되어, **조정 후 잔여 CSM 잔액은 $24.78$원으로 감소**합니다.
   * 완충 체력 범위 내에 있었으므로, **당기 손실(P&L) 인식액은 정확히 $0$원**으로 차단됩니다. 외부에 노출되는 재무제표 손익은 완벽히 보호되었습니다.

3. **Shock 2 (손해율 25% 악화) 시나리오**:
   * 손해율이 $25\%$까지 치솟으면서 미래부채 증가액이 $+38.06$원에 달합니다.
   * 기초 CSM 잔액($40.0$원)에 거의 육박하는 대형 악재이지만, CSM이 이 충격을 가까스로 전액 흡수하며 **잔여 CSM은 $1.94$원**으로 턱밑까지 감소합니다.
   * 완충 한계 직전까지 내몰렸지만 여전히 **당기 손실(P&L) 인식액은 $0$원**으로 방어에 성공합니다.

[시각화: 시나리오별 '조정 후 잔여 CSM'과 '당기 손실(P&L) 인식액'의 구조를 대비시키는 스택 막대그래프]

#### [손익 절벽(Earnings Cliff)의 실무적 함의]
만약 여기서 손해율이 조금 더 악화되어 충격량이 $40.0$원을 넘어서는 **Shock 3** 영역으로 진입한다면 어떤 일이 벌어질까요?

CSM 완충 물탱크는 바닥을 드러내며 잔액이 **$0$원으로 고갈**됩니다. 그리고 흡수 필터를 뚫고 흘러넘친 초과 충격액은 당기 손익계산서로 직접 분출되어 **대규모 당기손실(P&L 비용)**을 발생시키고, 재무상태표 부채에 **손실조정(Loss Component)** 항목을 형성합니다.

이것이 실무적으로 가장 경계해야 할 **'손익 절벽(Earnings Cliff)'**입니다. CSM이 남아있는 동안에는 회사의 당기순이익이 평온한 상태를 유지하지만, 충격이 임계 한계값($S_{BEP}$)을 단 $1$원이라도 돌파하는 순간 회사의 재무제표는 갑작스러운 적자로 전락하게 됩니다.

따라서 보험회사의 계리 부서 및 리스크 관리 부서는 단지 당기 손익만을 모니터링할 것이 아니라, 보유한 잔여 CSM이 미래 위험 변동을 얼마나 견뎌낼 수 있는지 그 **완충 여유폭(CSM Buffer Margin)**을 상시 시뮬레이션해야 합니다.

---

## 3. 요약

1. **파이썬 모델링을 통한 리스크 시뮬레이션**: 금리, 해지율, 손해율 등의 변동은 최종적으로 최적추정부채(PVFCF)의 팽창액($\Delta FCF$)으로 귀결되며, 이는 파이썬 계산 모델을 통해 계약 집단별로 정밀하게 측정할 수 있습니다.
2. **CSM의 완충 기능과 손익 평활화**: 기초 CSM 잔액 범위 내에서 발생하는 계리적 가정 변경 충격(Shock 1, Shock 2)은 CSM 잔액을 차감시킴으로써 당기 손익(P&L) 영향을 $0$으로 완벽히 차단합니다.
3. **손실분기 임계치와 손익 절벽(Earnings Cliff)**: 부채 팽창액이 기초 CSM 완충 한계치를 초과하는 순간 CSM은 $0$으로 방전되며, 초과 충격액은 **손실조정(Loss Component)**으로 변환되어 당기 비용으로 전액 직행합니다. 회사는 자본 건전성을 유지하기 위해 CSM 한계 관리를 경영 의사결정의 핵심 지표로 삼아야 합니다.

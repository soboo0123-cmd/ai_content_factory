# 2.3 [모델링] 파이썬을 이용한 금리·해지율·손해율 충격 시나리오별 CSM 변동성 시뮬레이션

## 1. 도입

이전 절(2.2 예실차 및 계리적 가정 변경이 CSM에 미치는 영향)에서 우리는 과거의 실현 오차인 예실차는 당기손익(P&L)으로 직행하고, 미래 전망의 변동인 계리적 가정 변경은 계약서비스마진(CSM)이라는 완충장치(Buffer)를 통해 흡수·소거된다는 원리를 대수적 방정식과 수치 시나리오로 확인했습니다. 특히 기초 CSM과 이자 부리액의 합산인 **손실분기 임계값($S_{BEP}$)**을 기준으로, 충격이 임계값 이내일 때는 CSM이 100% 흡수하여 P&L 변동성을 0으로 통제하지만, 임계값을 초과하는 극단적 충격 시에는 CSM이 완전 고갈되며 초과분이 **손실조정(Loss Component)**으로 즉시 비용 인식된다는 사실을 명확히 규명했습니다.

본 절의 학습 목표는 이 이론적 메커니즘을 실제 프로그래밍 환경에 이식하여, 보험 경영에 치명적인 위협을 가하는 **1) 금리 하락 시나리오, 2) 대량 해지(Mass Lapse) 시나리오, 3) 손해율 급증(사망률 및 보험금 악화) 시나리오**가 발생했을 때 최적추정부채(PVFCF)가 어떻게 급증하며, 그 충격이 잔여 CSM을 얼마나 깎아먹는지(또는 고갈시키는지)를 입체적인 데이터와 시각화 자료를 통해 실무적으로 검증하는 것입니다.

이전 절에서 사용한 구체적 수치 맥락과 완충 장치의 물리적 법칙을 그대로 계승하여, 복잡한 금융 리스크가 재무제표 상에서 어떤 궤적으로 소화되는지 파이썬 시뮬레이션을 통해 직접 확인해 보겠습니다.

---

## 2. 본론

### 2.1 다중 리스크 충격의 물리적 전개와 자금 흐름의 격리

보험회사가 직면하는 거시경제적·계리적 리스크는 단일 변수에만 국한되지 않습니다. 금리가 하락하면 할인율 효과로 인해 부채의 현재가치가 팽창하고, 해지율이 급변하거나 손해율이 악화되면 미래 현금유출액 추정치 자체가 변동합니다. 

이러한 충격들이 동시에 혹은 개별적으로 발생할 때, K-IFRS 제1117호 체계는 각 충격의 성격에 따라 자금 흐름을 철저하게 격리합니다. 

*   **금리 변동 리스크**: 할인율의 변동은 원칙적으로 OCI(기타포괄손익) 채널을 통해 자본 항목으로 우회하거나, lock-in 할인율과 current 할인율의 차이를 조율하는 방식으로 관리되나, 미래 현금흐름의 현재가치 계산 과정에 직접적인 크기 변화를 일으킵니다.
*   **손해율 및 해지율 리스크(계리적 가정 변경)**: 미래 현금유출입의 추정치를 직접 수정하므로, 앞서 배운 CSM 흡수 메커니즘의 직격탄을 맞게 됩니다.

이 충격들이 실제로 어떻게 CSM 잔액을 소모시키고 당기손익을 흔드는지 구체적인 수치 시나리오를 통해 확인하기 앞서, 파이썬을 활용한 시뮬레이션 모델을 구축해 보겠습니다.

---

### 2.2 파이썬을 이용한 손해율 충격 시뮬레이션 구현

다음은 t=1 시점에서 손해율이 각각 10% 및 25% 악화되는 충격(Shock) 시나리오를 부여했을 때, 미래 부채(PVFCF)의 변동액이 CSM을 어떻게 잠식하고, 임계값 초과 시 P&L에 어떤 즉시 손실을 유발하는지 계산하고 시각화하는 파이썬 실습 코드입니다.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# 기본 할인율 세팅 (예: 5%)
discount_rate = 0.05

# t=1 시점의 예상 잔여 현금흐름 (2년차, 3년차)
rem_years = np.array([1, 2]) # t=1 시점 기준 남은 기간
rem_premium = np.array([100, 100])
rem_expense = np.array([10, 10])

# 시나리오별 2, 3년차 예상 보험금 세팅
scenarios = {
    "Base (최적가정)": np.array([70, 80]),
    "Shock 1 (손해율 10% 악화)": np.array([70, 80]) * 1.10,
    "Shock 2 (손해율 25% 악화)": np.array([70, 80]) * 1.25
}

# t=1 기초 시점 잔여 CSM (단순화를 위해 Day 1 CSM에서 1년치 상각 후 잔액이라 가정)
t1_beginning_csm = 40.0 
t1_beginning_ra = 10.0

results = []
base_pvfcf = 0

for name, claims in scenarios.items():
    # 1. 시나리오별 t=1 시점의 잔여 PVFCF 재계산 (유출 현재가치 - 유입 현재가치)
    pv_in = np.sum(rem_premium / ((1 + discount_rate) ** (rem_years - 1)))
    pv_out = np.sum((claims + rem_expense) / ((1 + discount_rate) ** rem_years))
    new_pvfcf = pv_out - pv_in
    
    # 2. 가정 변경에 따른 PVFCF 변동액 산출 (Base 대비 증가분)
    if name == "Base (최적가정)":
        base_pvfcf = new_pvfcf
        delta_fcf = 0
    else:
        delta_fcf = new_pvfcf - base_pvfcf # 유출 증가분 (악재)
        
    # 3. CSM 흡수 메커니즘 (변동액을 CSM에서 차감)
    # 손실분기 임계값 S_BEP는 여기서 t1_beginning_csm과 동일하다고 가정
    adjusted_csm = t1_beginning_csm - delta_fcf
    
    # CSM은 0 미만으로 내려갈 수 없음 -> 고갈 시 P&L 손실 인식 (Loss Component 적립)
    pl_loss = 0
    if adjusted_csm < 0:
        pl_loss = abs(adjusted_csm)
        adjusted_csm = 0
        
    results.append([name, delta_fcf, adjusted_csm, pl_loss])

df_shock = pd.DataFrame(results, columns=["시나리오", "미래부채 증가액", "조정 후 잔여 CSM", "당기 손실(P&L) 인식액"])
print("\n=== [t=1 기말] 가정 변경(손해율 악화)에 따른 CSM 변동 ===")
print(df_shock.to_string(index=False))

# 데이터 시각화 (스택 막대그래프)
[시각화: 시나리오별 '조정 후 잔여 CSM'과 '당기 손실(P&L) 인식액'의 구조를 대비시키는 스택 막대그래프]
fig, ax = plt.subplots(figsize=(8, 5))
df_shock.set_index("시나리오")[["조정 후 잔여 CSM", "당기 손실(P&L) 인식액"]].plot(
    kind='bar', stacked=True, color=['#4C72B0', '#C44E52'], ax=ax
)
ax.set_title("CSM Absorption Mechanism under Shock Scenarios", fontsize=12, fontweight='bold')
ax.set_ylabel("Amount (KRW)", fontsize=10)
ax.set_xlabel("Risk Scenario", fontsize=10)
plt.xticks(rotation=0)
plt.grid(axis='y', linestyle='--', alpha=0.7)
plt.tight_layout()
plt.show()
```

### 2.3 시뮬레이션 결과 분석: 임계값 돌파와 손실조정의 발생

위 파이썬 시뮬레이션 실행 결과를 보면, 리스크의 크기에 따라 보험회사의 재무제표가 어떻게 양극단으로 갈라지는지 극명하게 드러납니다.

1.  **Base (최적가정) 시나리오**:
    *   미래부채 증가액은 $0$원이며, 기초에 적립된 CSM $40.0원이 온전히 보존되어 향후 서비스 제공 기간 동안 정상적인 상각 이익의 원천으로 작동합니다. 당기 손실 인식액 역시 $0$원입니다.
2.  **Shock 1 (손해율 10% 악화) 시나리오**:
    *   보험금 지급 추정치가 증가함에 따라 미래부채(PVFCF)가 일정 금액만큼 증가(악재 발생)합니다.
    *   이 증가분은 전액 CSM 댐의 수위를 낮추는 데 사용되어 **조정 후 잔여 CSM은 40.0원보다 줄어들게** 됩니다.
    *   그러나 완충 체력이 남아있어 완벽히 흡수되었으므로, **당기 손실(P&L) 인식액은 여전히 0원**을 유지합니다. 즉, 변동성이 완벽하게 평탄화(Smoothing)되었습니다.
3.  **Shock 2 (손해율 25% 악화) 시나리오**:
    *   손해율이 대폭 치솟으면서 미래부채 증가액이 기초 CSM 체력(40.0원)을 **초과 돌파**합니다.
    *   결과적으로 완충 장치인 CSM은 물리적 한계선인 **$0$원으로 완전히 고갈**됩니다.
    *   CSM이 흡수하지 못한 초과 충격 분량은 방어막을 뚫고 당기 손익계산서로 직행하여 **당기 손실(P&L)로 즉시 인식**되며, 동시에 재무상태표상 부채 계정에 **손실조정(Loss Component)**으로 적립됩니다.

이 대조 결과는 K-IFRS 제1117호가 제공하는 CSM 흡수 효과가 강력한 방패이긴 하지만, **기초 CSM 잔액이라는 명확한 물리적 한계선(손실분기 임계값, $S_{BEP}$)**을 가지고 있음을 실무적으로 완벽하게 증명합니다. 대형 재해나 급격한 손해율 악화는 이 방패를 순식간에 무너뜨려 당기순이익에 치명타를 입힐 수 있으므로, 리스크 관리 부서는 항상 CSM 잔액과 예상 충격 간의 마진 여유폭을 모니터링해야 합니다.

## 3. 요약

1.  **다중 리스크 충격의 수용 방식**: 금리 하락, 해지율 급변, 손해율 악화 등 다양한 리스크 요인은 최종적으로 최적추정부채(PVFCF)의 현재가치 변동을 유발하며, 계리적 가정 변경에 해당하는 항목은 CSM 흡수 메커니즘의 통제를 받습니다.
2.  **완충 장치의 한계($S_{BEP}$)**: 기초 CSM 잔액과 이자 부리액으로 구성된 손실분기 임계값 이내의 충격은 CSM이 전액 흡수하여 P&L 변동성을 0으로 차단하지만, 이를 초과하는 극단적 충격(Shock 2 등) 발생 시 CSM은 0으로 방전됩니다.
3.  **손실조정(Loss Component)의 발동**: CSM이 고갈된 이후의 초과 충격은 여과 없이 당기 손실로 즉시 직행하므로, 보험회사는 자본 건전성 방어를 위해 평시 CSM 체력 관리와 스트레스 테스트를 상시 수행해야 합니다.
